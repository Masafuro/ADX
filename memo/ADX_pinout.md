
# ADX Pinout (Master/Slave 共通・高耐ノイズ仕様)


EXTCLKをN.C.とGNDでシールドし、I2Cやアナログ信号の間に「静的な制御ピン（RE/DE）」を緩衝材として配置することで、フラットケーブル上でのクロストークを極限まで排除した究極のピンアウトです。

| CN2 ピン | ネット名 | GPIO | アナログ / タッチ | PWM | 通信 (UART/SPI/I2C) | その他の機能 |
| :---: | :--- | :---: | :--- | :--- | :--- | :--- |
| **1** | *N.C.* | - | - | - | - | 未接続 |
| **2** | `VDD` | - | - | - | - | 電源 |
| **3** | `VDD` | - | - | - | - | 電源 |
| **4** | *N.C.* | - | - | - | - | 未接続 |
| **5** | `PA3/EXTCLK`| PA3 | **AIN3** / PTC ※1 | - | - | **EXTCLK** (外部ｸﾛｯｸ) ※1 |
| **6** | `GND_5V` | - | - | - | - | グランド（EXTCLKのシールド） |
| **7** | `PA6/DAC0` | PA6 | AIN6 / PTC <br>**DAC0 出力** | **TCD0 WOC** | - | AC入力 |
| **8** | `PA5/AIN5` | PA5 | AIN5 / PTC | **TCA0 WO5**他 | - | **VREFA**, AC0出力 |
| **9** | `PA7/RE` | PA7 | - | - | UART `\RE` 制御 ※2 | （アナログのノイズ緩衝材） |
| **10** | `PA4/DE` | PA4 | - | - | UART `XDIR` (DE) ※3 | （I2Cのノイズ緩衝材） |
| **11** | `PB0/SCL` | PB0 | - | - | I2C `SCL` | - |
| **12** | `PB1/SDA` | PB1 | - | - | I2C `SDA` | - |
| **13** | `GND_5V` | - | - | - | - | グランド（RxDのシールド） |
| **14** | `PA2/R` | PA2 | - | - | UART `RxD` (受信) | - |
| **15** | `PA1/D` | PA1 | - | - | UART `TxD` (送信) | - |
| **16** | `PC3/SS` | PC3 | - | - | SPI `SS` | - |
| **17** | `PC2/MOSI`| PC2 | - | - | SPI `MOSI` | - |
| **18** | `PC1/MISO`| PC1 | - | - | SPI `MISO` | - |
| **19** | `PC0/SCK` | PC0 | - | - | SPI `SCK` | - |
| **20** | `GND_5V` | - | - | - | - | グランド（SCKの終端） |

> **※1 (PA3 / EXTCLK / AIN3)**: マスター時は外部クロック入力。スレーブ時は外部クロックが不要なため、3本目のアナログ入力として活用。
> **※2 (PA7 / RE)**: ソフトウェア制御の受信イネーブル。通信の切り替え時以外は「HIGH/LOWが固定（無音）」であるため、隣接するアナログ入力（AIN5）へのノイズ干渉を防ぐ最高のシールド壁として機能します。
> **※3 (PA4 / DE)**: ハードウェア自動制御の送信イネーブル。同じく通信中は状態が固定されるため、隣接するI2Cクロック（SCL）へのノイズを防ぎます。
