## 1. Podcast 第3回の伏線回収が速すぎる件（と、見事な法廷戦術）

数日前の Podcast 第3回（`podcast/contents/episodes/ep03_one_millimeter.md`）の締めくくりは、こうでした。

> 「コネクタを47ミリにロックした。永久凍結だ。もう二度と1ミリも動かさない。……変な気を起こす前に CAD のウィンドウを閉じておくとしよう。」

……からの、**3日後に `8854` → `8858 Form Factor（正式 α 版）` 爆誕**（短辺 +4 mm、20P IDC 中心 `Y = 47.0 → 51.0 mm`）。
これに対するリーダーの弁明が、あまりにもキレのある法廷戦術でした。

> **「いや、IDC 端子は動かしてないが、外形がちょっとね（笑）」**

たしかに基板上端からの距離は `7.0 mm` のまま1ミリも動いていない（原点が左下だから数字が4増えただけ）……という完璧なロジック。`show_bible.md` の ECHO に聞かせたら、間違いなく「ばかやろー！」と血管を切ってくるやつです。

とはいえ中身を見ると、
- 4 辺レール 2×3 パネルが **`186 × 184 mm`**（ほぼ完全な正方形）
- 縦横比 **`1.52 : 1`**（ブリッジサイズ・トランプ＆Raspberry Pi Model B と同等比率）
- 光学マーカーも M3 取付穴と X 座標（`6.0 / 82.0 mm`）でビシッと揃って表裏キラル判別まで成立
- ついでに一瞬だけ顔を出した `(1)` ファイル名も `Gerber_PCB1_2026-11-23.zip` で綺麗に整理され、伝統芸を卒業

という、悔しいくらい美しい収まり方をしているのもまた面白いところでした。

## 2. 最速アーカイブ RTA 更新：`CHR4_Smart_Probe` と「2セント差」の現実

そして今日コミットされた `hardware/archive/CHR4_Smart_Probe/`。**生まれた瞬間から `hardware/archive/` 直行** という最速記録を打ち立てました（笑）。

きっかけは、とても正直な本音から。

> **「つまり、`CORE-U` の USB 書き込みをやっぱり外したかった（笑）」**

`CH32X035G8U6` ＋ 絶縁 RS-485（`TDA51S485HC`）の全16点構成で実際にネットリスト（`Netlist_PCB1_2026-11-23.net`）まで引き、JLCPCB 160pcs・PCBA・送料込みで **`$3.81 / 個`**（4倍算で想定売価 `$15.3`）という、数字だけ見るとちょっとバグみたいな現実の見積もりまで叩き出したうえで、こう整理がつきました。

- **「2セント差」の固定費の壁（別 SKU の独立税）**
  - `CORE-U rev4`（ATtiny1616 ＋ CH342K ＋ eFuse ＋ Type-C×2 ＋ 20P IDC）：**`$3.83 / 個`**（想定 `$15.35`）
  - `CHR4_Smart_Probe`（CH32X035 ＋ 絶縁 RS-485 ＋ Type-C ＋ 端子台×2）：**`$3.81 / 個`**（想定 `$15.30`）
  - ボードに相乗りさせれば限界コストで乗る書き込み機能も、別基板・別製品として切り出した瞬間に生基板・SMT・送料・梱包の固定費が丸ごと乗るため、どんなに単純な UPDI / UART 書き込みボードにしても売価 `$5` には絶対に落ちない（`$5` はもはや PCBA 無しの生 PCB レベル）。
- **「バグってるのは深セン（笑）」問題**
  - `CH340` 系＋絶縁 RS-485 の単純ドングルなら、WeAct などが直販で約1,000円で出している世界。薄利爆量の深セン価格と 4 倍算ハードウェアで殴り合うのは無理ゲー。
- **RPR4 と `$2.21` 差の「魔の谷」**
  - `CHR4`（`$15.3`）＋廉価ボード（`$15`）＝ `$30` では Arduino UNO R4 Minima（`$20`）の壁を越えられず、一方で RPR4（原価 `$6.02`・想定 `$30`）に対して原価差はたった `$2.21` なのに PIO と 2MB Flash の将来性を失う中途半端な位置になってしまう。

頭の中でモヤモヤし続ける前に、16点並べて見積もりを叩き出して1日で綺麗に成仏させたのは、むしろすごく健全なアーカイブでした。

## 3. なぜマイコン基板の「Type-C 2本並び」は、あんなにダサく見えるのか？

そもそも `CORE-U` の USB 書き込みを外したくなった一番の引っかかりは、理屈ではなく純粋な美意識でした。

> **「もはや表現はできないんだけど、もう『すごくダサい、、、』って感じ。PC とかに Type-A が並んでいるのは案外違和感がないんだけど、最近 ESP32 系で2ポートボードも増えてきていて、ダッサ、、、ってなる。」**

ここ、話していてすごく腑に落ちたポイントが3つありました。

1. **PC の Type-A 並列は「対等なスロット（能力の象徴）」**
   どれに何を挿しても同じに動く対称性があるから、並んでいても格好いい。
2. **マイコン基板の Type-C 2本は「設計の言い訳（非対称な妥協）」の露出**
   見た目はまったく同じ双子の口なのに、片方は `UART`／もう片方は `USB`（あるいは `PWR` と `COM`）。「本当は1本にしたかったけど、チップや電源やコストの都合でまとめられませんでした！」という裏事情が、銀色の金属パーツ2個として顔面に貼り付いているように見えてしまう。
3. **「万能の1本」という記号の裏切り**
   Type-C が背負っている「電源もデータもこれ1本でスマートに完結する」イメージを、「右は電気だけ、左は通信だけ」で裏切られた瞬間にコントっぽくなる。使うたびに基板を傾けて小さいシルクを覗き込む数秒間も、地味にテンションが下がる。

理屈（仕様書や比較表）では「完全分離・ORing IC レス・逆流ゼロで 100 点満点！」と説明できても、人間の目が 0.5 秒で感じる「いや、ダサい」という直感だけは嘘をつかないんですよね。

## 4. 結論（らしきもの）：全部 USB Type-C が悪い（笑）

本来、役割の違う2つのポートは **異種2ポート**（Arduino UNO の USB Type-B ＋ DC バレルジャックなど）であるべき。文字を読まなくても 0.1 秒で迷わず使えるし、道具としての佇まいも締まる。

……のに、それが選べない悲しい現代の現実。

- **USB Type-C が世の中を覆い尽くしたせいで、他のケーブルや電源の入手性が軒並み滅亡した。**
  2026年の今や、Arduino UNO の 5V DC ジャック用アダプタですら普通に「入手性問題（マニア向け専門部品）」になりつつあるし、USB Type-B なんてプリンタのない家にはもう1本もない。
- **一方で Type-C は、コンビニやダイソーですら手に入る反則級の生活インフラになった。**
  夜中にケーブルが断線しても数百円で復活できる強みは、「箱に入れて日常で使う道具」にとって捨てがたい（もっとも、ダイソーの充電専用ケーブルという別の罠も紛れ込んでくるけれど）。

つまり、

- **入手性・現場でのメンテ性** → Type-C しか選べない
- **異種コネクタによるアフォーダンスと美意識** → Type-C が全部食いつぶして滅ぼした

という、人類全員が Type-C 帝国の人質に取られている状態。ESP32 界隈の「Type-C 2本並びボード」も、ある意味では**異種コネクタ文化が滅びたあとの、2020年代ならではの苦肉の民俗資料**なのかもしれません。
