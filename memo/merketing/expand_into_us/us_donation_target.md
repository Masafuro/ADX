
# US Hardware Donation Targets
マイコンボード・開発ボードの寄付／評価提供先調査

最終更新: 2026-11-25
対象地域: United States

## 1. 調査目的

日本で開発・製造しているマイコンボードを、アメリカの開発者やMakerに実際に使ってもらうための提供先を探す。

現段階では販売チャネルの開拓よりも、初期ユーザーの獲得と製品認知の形成を優先する。

### 解決したい課題

- Tindieでは低価格ボードに対して国際送料の負担が大きい。
- 個別発送では物流コストが高くなる。
- 3PLは初期段階では固定費・運用費に見合わない。
- Crowd Supplyへの応募では、製品を知っている人や反応を示すコミュニティの存在が重要になる。
- そのため、アメリカ国内のコミュニティや教育機関に複数台まとめて提供する方法を検討する。

## 2. 探している団体

以下の条件に合う団体を優先する。

### 必須条件

- アメリカ国内に拠点がある。
- 電子工作、組み込み開発、IoT、ロボティクス、STEM教育などに関係する。
- ハードウェアや電子工作キットの現物寄付を受け付けている。
- 公式サイトなどに寄付募集の根拠がある。

### 特に重視する条件

- Arduino、Raspberry Pi、ESP32、STM32などの開発ボードを具体的に募集している。
- 新品の開発ボードや電子工作キットを受け入れる。
- 複数台の一括提供が可能。
- メンバーや学生が実際に使用する環境がある。
- 評価結果、利用事例、技術記事などにつながる可能性がある。

### 調査上の注意

寄付を受け付けていることと、製品レビューやSNSでの紹介を約束していることは別である。

実際の受け入れ可否、海外からの発送可否、利用方法については個別確認が必要。

所在地: Urbana, Illinois

公式サイト:
https://iot.cs.illinois.edu/support/

連絡先:
admin@cs.illinois.edu

- Arduino

## 6. 今後確認すること

各団体に対して以下を確認する。

| 確認事項 | 内容 |
|---|---|
| 寄付受け入れ | 新品の開発ボードを受け入れるか |
| 海外発送 | 日本からの発送を受け付けるか |
| 数量 | 5〜10台程度の一括受け入れが可能か |
| 利用方法 | メンバーや学生が実際に使用するか |
| 評価協力 | 技術的なフィードバックを得られるか |
| 公開協力 | GitHub、ブログ、動画等で作例を公開できるか |
| 継続性 | 継続的なサンプル提供先になり得るか |

## 7. 最終的な目標

単に寄付先を確保することではなく、アメリカで最初の10〜30人の実利用者を獲得すること。

理想的には、以下のような実績を作る。

- アメリカのMakerSpaceでの利用実績
- 大学や教育機関での採用実績
- GitHub上の第三者による作例
- 技術ブログやレビュー記事
- 利用者からの技術的フィードバック
- 継続利用者やコミュニティの形成

これらを将来的なCrowd Supplyへの応募材料として蓄積する。
