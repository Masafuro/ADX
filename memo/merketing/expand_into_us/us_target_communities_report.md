## 1. ターゲット再設計の基本方針：なぜ「寄付先」から「評価コミュニティ」へ切り替えるか

初期調査（[us_donation_target.md](us_donation_target.md)）で挙げられた団体の多くは、K-12・キッズ向け STEM 教育やデジタル格差支援の寄付窓口であった。しかし、`ADX CORE-U` α版は以下の技術特性を持つ：

- **筐体組み込み特化（`8858` 規格・M3ネジ穴クリアランス・片側I/F集中）**
- **オンボード機能最小・20P IDC リボンケーブル一本化**（通常のブレッドボードにそのまま挿さらない）
- **デュアル Type-C（電源・通信完全分離）＋ `ATtiny1616` ＋ Arduino IDE 1.8.x / `megaTinyCore`**
- **FCC 評価キット免除（47 CFR § 2.803）の要件上、配布対象は「開発者・エンジニア・試作層」である必要がある**

したがって、**「既存の定番 Arduino Uno 教材が欲しい初心者向け寄付先」ではなく、「大人が自分の道具としてマイコン・3Dプリンタ・電子工作をいじり、新しいオープンハードウェアの設計思想に反応できる場」** にターゲットを再定義する。

また、組織の汎用寄付窓口に送って「Free Stuff Bin（ご自由にお持ちください棚）」で埋もれる無駄を防ぐため、以下の3類型を主戦場とし、**「実際に受け取ってメンバーへ配る1人の担当者（チャンピオン）」とメール等で会話できた先にだけ送る**ことを原則とする。

**※ Makeathon 向けの必須前提条件**：

## 4. 「無理・斑・無駄」なく実情を探るための次ステップ（パイロット検証設計）

いきなり10団体へ大量発送するのではなく、以下の3段階で**「そもそも米国側の現場に需要があるか・何を同梱すれば動くか」を最小工数で検証する**のが現実的である。

### Step 1：打診前の最小パッケージ定義（これがないと会話が噛み合わない）
メールで相談する時点で、相手が「具体的に何が届くのか」を30秒で理解できるよう、以下を1ページ（`arle.cc` の英語ページ＋実機写真／短い動画）にまとめておく：
1. **提供するセット内容（1箱 5〜10セット想定）**:
   - `ADX CORE-U` 基板（全数検品済み）
   - 20P IDC リボンケーブル ＋ `Prototype CARD`（または 2.54mm ピンヘッダ変換基板）
   - A6 クイックスタートカード（表面：USB 2本挿し＆ピン配列図解、裏面：Quickstart / GitHub Discussions フィードバック用 QRコード ＋ FCC § 2.803 免除表記）
   - 3Dプリント用 8858 基本ケース／マウントの STL 公開リンク
2. **相手側の負担ゼロの明示**:
   - 無償提供（Not for Sale）、国際送料・米国輸入関税ともに**発送者全額負担（DDP）**であること。
   - 義務的なレビューや宣伝は要求せず、「メンバーが自由に触って、気づいた点があれば GitHub Discussions に一言もらえると嬉しい」という対等なオープンハードウェア開発者としてのスタンス。

### Step 2：性質の異なる 3〜5 件へ「事前ヒアリング」を実施（ローカル管理）
連絡先をローカル側で調査したうえで、以下のように**類型を散らして 3〜5 件だけに短い英語メールで実情ヒアリング**を行う：
- **類型A（ポートランド圏 or 定期電子工作ナイトあり）**: 1〜2 件（例：Portland Hardware Meetup / CTRL-H / Seattle Makers 等）
- **類型A（中規模・地域密着型）**: 1 件（例：Triple Cities Makerspace / Bloominglabs 等）
- **類型B（中規模 Makeathon）**: 1 件（例：MakeCU / MakeUC / Hard Hack 等）
- **類型C（学生運営 ECE/IoT ラボ）**: 1 件（例：The Hive / UIUC IoT Makerspace の学生側 等）

**この段階で聞くべき4つの質問**：
1. こうした日本のインディー・オープンハードウェア（ATtiny1616 / 3Dプリント筐体向け）のα版評価キット（5〜10セット）は、メンバー／学生にとって興味を持ってもらえそうか？
2. 受け入れるとしたら、単体でなく「何」が同梱されていれば実際に使ってもらいやすいか？
3. 受け入れにあたり、時期（例：次期イベント・学期開始前）や事務手続き上の制約はあるか？
4. 日本から DDP（関税・送料元払い）で1箱送る場合、受け取りに支障はないか？

### Step 3：脈ありの 1〜2 箇所だけにテスト送付（1箱 5〜10セット）
- 「ぜひ欲しい、次の電子工作ナイト／イベントで配るよ」と**具体的な担当者（チャンピオン）が返答してくれた 1〜2 箇所にだけ**、日本郵便（EMS）＋ Zonos DDP で 1箱テスト送付する（総額 2〜4万円台）。
- ここで **①通関が完全に受取人負担ゼロで通るか、②本当に箱が開けられて火が入るか、③GitHub Discussions やメールで生の反応が返ってくるか** を実測し、手応えがあれば対象を広げる。

## 5. まとめ

- 米国での初期ユーザー獲得を「寄付（Charity）」として捉えると、K-12向け教材需要とのズレや「寄付箱での死蔵」という大きな無駄が生じる。
- 一方で、**「電子工作ナイトのあるハッカースペース／Hardware Meetup」「大学ハードウェア Makeathon」「学生運営 ECE/IoT ラボ」**へ対象を絞り、**「DDP元払いのα評価キット（5〜10セット）」**として現場リーダーへ事前ヒアリングする形に変えれば、50週間SNS運用のような消耗戦や渡米コストを回避しつつ、**数通のメールと数万円のテスト送付で米国市場の生の一次情報を取りに行ける**。
