# EasyEDA SPARK 2026用作品の構想

## 概要
EasyEDA SPARK 2026に応募するにあたり、現行のADX CORE-Uを起点とした作品の提出を構想しています。ADXははばが広いため、まずはブレストから始める必要がありそうです。

## 説明文

An open-source, enclosed modular desktop controller unit featuring a 3D-printed housing, an ATtiny1616-based core (separated 5V/2A USB-C power and serial interface), and swappable function modules via a 20-pin bus. Designed as a complete, ready-to-use desktop device—starting with a programmable status lamp ("Desktop Andon")—that makers can easily customize and extend into practical desktop automation tools.
