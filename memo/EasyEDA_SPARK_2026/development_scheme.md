## 2. 開発〜クーポン獲得〜公開の手順

クーポンは「事後キャッシュバック」ではなく、**設計審査に通ると発注用の割引クーポンがアカウントに付与される仕組み**です。必ず以下の順番で進めます。

### Step 1：エントリー登録（Sign Up） ✅完了
* コンテストへの参加意思と初期アイデア（Desktop Andon）を登録済み。
* ※この時点のプロジェクト概要は、本番のプロジェクトページ作成時に修正・肉付け可能。

### Step 2：設計作成（EasyEDA Pro／非公開）
* **必ず EasyEDA Pro** を使用し、**非公開（未公開）状態**で回路・基板・3D筐体データを設計する。
* 初期の動作確認（Rev1など）を審査待ちなしで進めたい場合は、**OSHWLabに公開しないまま自腹でJLCPCBへ発注して試作・検証しても問題ない**。

### Step 3：クーポン申請・審査（発注前・公開前）
* 発注できる状態まで設計が整ったら、コンテストページの案内に従ってプロジェクトを紐づけ（未公開・または進行中ステータス）、クーポンを申請する。
* **絶対にクーポン申請より前にプロジェクトを一般公開（Publish）しないこと。**

### Step 4：クーポン受領 → 自分で発注
* 審査を通過すると、自分のアカウントに **JLCPCB / JLC3DP / JLCCNC / JLCMC** で使えるクーポンが付与される。
* 通常通りカートへ入れ、**決済画面でクーポンを適用して注文**する。
* **複数回の試作（Rev2等）が必要な場合：**
  * 高品質プロジェクトには複数回のクーポン申請が認められているため、修正後のデータで再度Step 3から申請可能。

### Step 5：組み立て・動作確認 → 公開（Project Completed）
* 基板と筐体が届いたら実装・組み立て・動作確認を行う。
* OSHWLabのプロジェクトページ（`Spark 2026` タグ付き）に**完成品の実物写真**と解説を掲載し、ステータスを **`Completed`** にして一般公開する（**2027年3月31日まで**）。

## 3. クーポン対象サービスと費用ルール

### 主なサポート対象
* **PCB / FPC製造：** サイズ・層数制限なし（JLCPCBの製造対応範囲内）
* **SMT / PCBA：** 表面実装・部品実装
* **3Dプリント / CNC / MC：** 筐体・メカ部品製作（JLC3DP / JLCCNC / JLCMC）
* **マルチカラーシルク印刷：** フルカラー基板試作

### 費用・制限の注意点
* **補助率は約80%：** 輸出入制限のため、材料費と送料の約80%がクーポン負担。**残り約20%および関税・消費税などの税金は自己負担**。
* **PCB Layout Service（設計代行）の扱い：** 製造・実装系が主な支援対象のため、レイアウト代行費がクーポン対象になるかは審査・見積もり確定前に確認すること。

## 4. 開発・手続き上の厳守ルール（NG事項）

* **アカウント統一：** EasyEDA Pro・OSHWLab・JLCPCB系の発注はすべてエントリーした同一アカウントで行う。
* **手順の厳守：** 「申請前の先行公開」「クーポン受領前の発注（後払い請求）」は不可。
* **完成品としてまとめる：** 汎用マイコン開発ボード単体ではなく、筐体と具体的機能を備えた完成品（Desktop Andon等のモジュラー製品）として申請・公開する。
* **同時進行は1プロジェクトのみ：** 現在の作品が完成・公開されるまで、別テーマのクーポン申請は不可。
* **取り下げ不可：** 一度クーポン支援を受けたプロジェクトは、後から完全に削除・非公開化できない（公式側に読み取り専用でバックアップされる）。

## 5. 発注直前の確認チェックリスト

クーポン申請・発注のタイミングで、公式案内（Join the Contest / 審査通過メール）で以下を確認する。

- [ ] 基板シルク上に EasyEDA / Spark ロゴ等の指定表記が必要か
- [ ] 付与されたクーポンの有効期限と、サービス別（PCB / PCBA / 3D等）の適用条件
- [ ] フルカラー基板（マルチカラーシルク）を使う場合のベース色・オプション指定
- [ ] 疑問点があれば、設計を作り込む前にコンテストページの公式Discord（Event Consultation）へ事前確認する
