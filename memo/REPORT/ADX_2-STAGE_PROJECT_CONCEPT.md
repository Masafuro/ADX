# ADX 2-STAGE PROJECT CONCEPT
〜 二段階ローンチ戦略と CORE-U / CORE-A による新エコシステム構想 〜

---

## 1. エグゼクティブ・サマリー（課題の発見とコペルニクス的転回）

従来の「CORE-A（$28）＋ RPR4 Smart Probe（$25）」を起点とする構想は、産業現場向けのタフネスと革新的なUX（スマホOTW）を兼ね備えていた。  
しかし、市場投入とユーザー心理の観点から以下の**重大なボトルネック**が浮き彫りとなった：

1. **「$58の壁」と専用ドングル抱き合わせ感**:
   - 初期費用が実質60ドル前後となり、一般のメイカー・学生・Arduino層から見ると参入障壁が高すぎる。
   - 「専用ドングルを買わなければ動かないマイコン」というロックインへの心理的警戒感が生じる。
2. **開発負荷の過積載（死の谷リスク）**:
   - RPR4（RP2040ファーム、PIOサンプリング、プロトコル解析エンジン、スマホPWA、通信制御）を同時並行で完成させるには半年〜1年の開発期間が必要。
   - ボード本体（CORE-A）を世に出すまでのリードタイムが過大となり、クラファンの納期遅延リスクを高めてしまう。

### 【解決策：CORE-Uの再生と二段構え（2-Stage）戦略】
- **CORE-Uの復活**: Arduino UNO R4 Minima対抗（**$20前後**）。Type-Cケーブル1本でArduino IDEから即座に開発可能とし、参入障壁を完全粉砕。
- **CORE-Aの再定義**: 市販の安価なUSB-RS485ドングル（数百円〜千円）とPCブラウザ（Web Serial PWA）で安全に書き換え・デバッグ可能とする。
- **2段階Crowd Supply戦略**:
  - **第1弾**: プラットフォームの確立（CORE-U、CORE-A、DC24V絶縁Power CARD、Prototyping CARD）。PC中心の開発体系。
  - **第2弾**: プロ向け高付加価値ツール（RPR4 Smart Probe 単独）。全世界のFA・照明・組み込みエンジニアに向けた「汎用プログラマブルRS-485アナライザ」として投入。

## 2. 製品ポートフォリオと役割分担

### 2.1 ADX CORE-U（$20前後 / 机上・ホビー・エントリー特化）
- **ターゲット**: Arduino/メイカー層、学生、研究室、手軽にCARDを試したいエンジニア。
- **アーキテクチャ**:
  - メインMCU: Microchip `ATTINY1616-MNR`。
  - USB-UARTブリッジ: WCH `CH342K`（オンボードSerialUPDI回路を内蔵）。
  - **開発環境**: **Arduino IDE 完全丸乗り**（ブートローダー不要、ツールチェーン開発コスト実質ゼロ）。
  - **電源設計**: USB Type-Cから受電し、理想ダイオード（`LM66100`）経由で20P共通VDDバスへ供給。
  - **CARD完全互換**: 電池CARDなどを下層にスタックしてもPCへの逆流を瞬時遮断。机上ユニットの電源としてもそのまま機能。

### 2.2 ADX CORE-A（$28前後 / 工業現場・過酷環境・絶対標準機）
- **ターゲット**: 工場設備、車載、スマートアグリ、太陽光基地局、冷凍設備、配電盤。
- **アーキテクチャ**:
  - 完全絶縁RS-485: Mornsun `TDA51S485HC`（2500VDC耐圧、絶縁電源内蔵）。
  - 超低消費電力BMC: Microchip `ATTINY412`（暗電流 <10µA、常時バス監視）。
  - 耐熱規格: **-40℃〜+105℃ フルIndustrial Grade**（真夏のIP67密閉箱や車内で発振停止・熱暴走ゼロ）。
  - 端子台: スプリングクランプ式 `DB142R-5.08`（振動によるネジ緩みゼロ）。
  - **開発環境**: **PCブラウザ（Web Serial PWA）＋ 市販のUSB-RS485ドングル**。
    - **【決定打】ボード側が完全ガルバニック絶縁を持っているため、PC側のUSB-RS485ドングルはAmazonやAliExpressで数百円〜千円で買える非絶縁の安物でOK。作業者のPCは100%保護される。**

### 2.3 DC 24V 絶縁 Power CARD（産業現場の決定打）
- **概要**: 工場や設備で標準的なDC24V（広入力対応）から、トランス絶縁されたクリーンな5Vを生成し、IDC Pin 1〜4へ供給する電源カード。
- **現場役満の理由**:
  - **ダブル・ガルバニック絶縁**: 電源（Power CARD）も絶縁、通信（CORE-A）も絶縁。CORE-Aが完全に電気的浮遊状態（セーフゾーン）となる。
  - **通電中ホットプラグ安全保証**: 現場の24V強電設備とRS-485がガンガン稼働している最中に、作業者がノートPCをType-C直結しても火花ひとつ散らず、PCを絶対に壊さない。
  - **サージ保護の局所化**: 万が一の雷サージで破壊されるのは安価なPower CARD側のみで、CORE-Aは無傷で保護される。

## 4. 2段階ローンチ（Crowd Supply）の詳細シナリオ

### 4.1 第1弾：ADX Platform Launch（プラットフォームの確立）
- **メインメッセージ**:  
  *「Industrial Toughness for Everyone: A Modular 5V Edge-Controller Ecosystem Starting at $20」*
- **キャンペーン構成**:
  1. **Maker Tier ($20)**: CORE-U 単体
  2. **Prototyping Bundle ($26)**: CORE-U ＋ Prototyping CARD
  3. **Industrial Starter Kit ($44)**: CORE-A ＋ DC24V 絶縁 Power CARD
  4. **Full Ecosystem Kit ($68)**: CORE-U ＋ CORE-A ＋ 3種CARDすべて
- **成功の鍵**:
  - CORE-Uのおかげで自前ツールチェーンの開発遅延が一切起きない。
  - CORE-Aの書き込みも手持ちの市販RS-485ドングルとPCブラウザ（Web Serial）で動くため、即座に出荷・運用可能。
  - 「期日通りに高品質な製品が届いた」という確固たる実績とコミュニティを獲得。

### 4.2 第2弾：RPR4 Smart Probe Launch（世界中のエンジニアへ）
- **メインメッセージ**:  
  *「The Pocket-Sized Programmable RS-485 Smart Probe & Logic Analyzer」*
- **ポジショニングの拡張**:
  - ADXの枠を飛び越え、**「世界中のModbus / DMX512 / RS-485を扱うすべてのエンジニア必携のマルチツール」** としてアピール。
  - 「スマホのブラウザでパケット波形が見える」「Auto-Baud自動検出」「テストパケット送信」「絶縁保護」を全面に押し出す。
  - そして **「ADX CORE-Aユーザーなら、スマホからワンタップでOTA/OTWファーム更新ができる」** という究極のアドオンとして訴求。
- **成功の鍵**:
  - 第1弾のバッカーがそのまま初期支援者（リピーター）となり、初速から目標達成が確実視される。
  - 半年〜1年かけてじっくりPIOファームとPWA解析機能を磨き上げられるため、妥協のない最高峰の完成度でローンチできる。

## 5. 結論と次のアクション

この二段階戦略により：
1. **「専用ドングル強制による参入障壁（$58の壁）」を完全に消滅させた**。
2. **「$20のCORE-U」という強力な撒き餌でメイカーを総取りし、「$28のCORE-A ＋ 24V絶縁CARD」で現場のプロ需要を制圧する導線が完成した**。
3. **「RPR4 Smart Probe」を焦って未完成で出すリスクを回避し、最高峰の汎用プロツールへと昇華させるロードマップが確立された**。

**【直近の開発優先順位】**:
1. **CORE-U rev1 の回路図・ネットリストFIX**（CH342K SerialUPDI配線、LM66100給電ライン）
2. **DC24V 絶縁 Power CARD の荒設計**（絶縁DCDC選定、IDC Pin 1〜4給電）
3. **PCブラウザ向け Web Serial PWA（CORE-A用スケッチアップローダー）のプロトタイプ実装**
