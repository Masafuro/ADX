## 1. エグゼクティブ・サマリー（調査結論）

本調査では、Arduino公式をはじめ、Keyestudio、Elegoo、Seeed Studio、M5Stack、産業用PLC（Siemens / Arduino Opta）等、世界市場に流通する主要な「スターターキット」の価格、同梱物、対象用途を横断的に調査・分析した。

### 主要な発見（3大インサイト）

1. **「卓上・大量部品詰め合わせ型（$35〜$70）」の飽和とコモディティ化**:
   - ElegooやKeyestudioに代表されるサードパーティ製キットは、ブレッドボード、互換ボード、50〜60種のチープなセンサー・アクチュエータ（LED、サーボ、温度計等）を詰め込み、激しい価格競争に陥っている。
   - これらは完全な**「机の上の教育・電子工作入門（STEAM教育）」**を目的としており、長距離配線、耐ノイズ性、筐体適合性といった「現場のリアルワールド」には1ミリも対応できない。
2. **「産業用PLCキット（$180〜$350）」の高価格・集中制御の壁**:
   - Siemens LOGO! や Arduino Opta などの産業用キットは、堅牢性・信頼性を備えるものの、**「制御盤に固定される巨大な集中制御の箱」**であり、空間に散らばる複数箇所を制御する用途には極めて高価（1台$180〜$300超）で過剰である。
3. **未開拓の巨大な空白地帯（空席）：「現場向け分散ネットワーク」キットの不在**:
   - Waveshare等の産業用モジュールベンダーはRS-485やCANのHATを販売しているが、すべて「バラ売り（部品単体）」であり、**「箱を開けてすぐ、複数のノードが長距離数珠つなぎ（デイジーチェーン）で通信し、スマホからOTW書き換えできるオールインワンのスターターキット」は世界中のどこにも存在しない**。
   - したがって、ADXが提案する **「ADX Field Starter Kit ($79前後 / Early Bird $59)」** は、既存の「オモチャ詰め合わせキット」とも「高価な集中型PLC」とも競合しない、**唯一無二のブルーオーシャン**を切り拓くことができる。

## 3. 各セグメントの詳細分析

### セグメント①：公式・準公式教育キット（Arduino公式）
- **代表製品**: Arduino Starter Kit R4 (€99.90 / 約$109)
- **中身**:
  - Arduino UNO R4 WiFi本体
  - 830穴ブレッドボード、専用木製マウンティングプレート
  - サーボモーター、小型DCモーター、チルトセンサー、フォトリフレクタ、LCD1602、温湿度センサー、大量のLED・抵抗・ジャンパーワイヤ
  - 分厚い紙のプロジェクトブック（15のステップバイステップ実験）
- **用途・特徴**:
  - ブランド力と信頼性で教育機関（大学・高校・ワークショップ）に圧倒的な強みを持つ。
  - しかし、本質は「机の上で電子回路の基礎を学ぶための入門教材」。
  - 水滴、振動、長距離配線、12V/24Vの電源など、リアルワールドに出した瞬間に破綻する。

### セグメント②：サードパーティ・大容量コスパ型（ELEGOO / Keyestudio）
- **代表製品**: 
  - ELEGOO "The Most Complete Starter Kit for UNO R3"（定価$70 / 実売$45〜$55）
  - Keyestudio "Complete Starter Kit / Super Kit"（約$52〜$65）
- **中身**:
  - Arduino UNO互換マイコン（CH340搭載）
  - センサーシールド、RFIDリーダー、超音波モジュール、ステッピングモーター＋ドライバー基板、ジョイスティック、リレーモジュール、メンブレンキーパッドなど、とにかく「箱いっぱいに詰めた」60点以上の部品群。
  - 2段重ねのプラスチック製パーツケース。
- **用途・特徴**:
  - 「とにかく安く、あらゆる種類のセンサーやモーターを触ってみたい」というホビー層・メイカー層の部品セット。
  - **課題**: チュートリアル通りにブレッドボード上でジャンパー線を挿して動かして終わり。「その先（実際の作品・現場への実装）」に進むための物理的・電気的ソリューション（筐体への固定、ノイズ対策、配線保護）が一切提供されていない。

### セグメント③：はんだレス・モジュラー型（Seeed Studio / M5Stack）
- **代表製品**: 
  - Seeed Studio "Grove Beginner Kit for Arduino"（約$25〜$35）
  - M5Stack "Basic V2.7" / "CoreS3 Kit"（約$45〜$70）
- **中身**:
  - Seeed: 1枚の大きな基板にArduino互換機と10種類のGroveセンサーが事前配線（切断可能）。
  - M5Stack: ディスプレイ・ボタン・バッテリー・スピーカーが一体化された美しいABS射出成形ケース＋数本のGroveケーブル。
- **用途・特徴**:
  - 「ブレッドボードの配線ミスで挫折する」初心者のペインを完璧に解決した名作。
  - **限界**: デスク周りのIoTプロトタイプには最強だが、数メートル〜数百メートルの長距離配線や、12V/24V電源、工場・屋外の誘導ノイズ環境には耐えられない。

### セグメント④：産業用PLCキット（Siemens / Arduino Opta）
- **代表製品**:
  - Siemens "LOGO! 8 Starter Kit 24RCE"（約$250〜$350）
  - Arduino "Opta RS485"（単体€171 / PLC Starter Kit €200+）
- **中身**:
  - DINレール取り付け型PLC本体（Finderリレー内蔵、産業規格適合）
  - 24V DINレール電源、プログラミングソフトウェア（LOGO! Soft Comfort）、LANケーブル
- **用途・特徴**:
  - 工場の生産ライン、ビルの照明・空調制御盤、電気工事業界のデファクトスタンダード。
  - **限界**: 「1つの制御盤の中にすべてを集約する集中制御」。アートインスタレーションや広大な建築空間のように「10mおきにノードを点在させたい」場合、PLC 1台では配線がスパゲッティ化し、PLCを複数台置くと莫大なコスト（$185 × 台数）がかかる。

### セグメント⑤：産業用モジュール・HAT（Waveshare等）
- **代表製品**: Waveshare RS485 CAN HAT ($20〜$25), Isolated Expansion Board ($55)
- **特徴**:
  - ガルバニック絶縁やTVS保護を備えた高品質な通信ボードを安価に提供している。
  - **決定的な欠点**: **「キット（ソリューション）」として売られていない**。
    - ユーザーはホストマイコン（Raspberry Pi等）、電源、端子、配線、通信ドライバ、上位ソフトウェアをすべて自力で選定・設計しなければ動かない。
    - 「手軽に現場ネットワークを体験する」ための敷居（オンボーディング・フリクション）が極めて高い。

## 4. ADX Field Starter Kit ($79) の勝算と提供価値

### 4.1 「部品詰め合わせ」から「インフラ・ソリューション」への昇華
既存のスターターキットは、ほぼすべてが「**センサーやモーターのおもちゃを触るための学習教材**」です。
これに対し、ADX Field Starter Kitは、**「過酷な現実空間（リアルワールド）で動くインフラを構築するための実践ツール」** です。

```
既存のスターターキット ($40〜$100):
「机の上で、センサーの値を測ってLEDを光らせる方法を学ぶ」
  ↓
ADX Field Starter Kit ($79):
「現場の過酷なノイズと長距離配線を克服し、
  2つの空間を数珠つなぎで連動させ、スマホから即書き換えるシステムを構築する」
```

### 4.2 なぜ「$79（Early Bird: $59）」は適正かつ競争力が高いのか？

1. **ELEGOOやKeyestudio（$50〜$70）と比較して**:
   - サードパーティの詰め合わせキットが$50〜$70で売れている事実から見て、**$79という価格はホビー・メイカー層にとっても十分に射程圏内**である。
   - 単なる「安物パーツの数」ではなく、**「1.5kV完全ガルバニック絶縁」「8748筐体適合」「工具レス端子台」「RP2040搭載スマートプローブ」という圧倒的な産業級ハードウェア品質**が手に入るため、付加価値の説得力が段違いに高い。
2. **Arduino Starter Kit R4（$109）と比較して**:
   - Arduino公式の初心者キット（約$109）よりも**約$30安い**。
   - 「ブレッドボードの入門を終えて、本気で現場に作品を出したいクリエイター」にとって、公式キットより安くプロ仕様の現場機材が手に入る。
3. **Arduino Opta（$185）やPLCと比較して**:
   - Opta 1台の**半額以下の価格（$79）で、「2箇所の分散協調ノード ＋ スマホデバッガー」の完全なネットワーク環境**が手に入る。

### 4.3 バンドル内容の定義（無駄な部品は入れない）
ADX Field Starter Kitには、チープなセンサーを何十個も詰める必要はない。
現場での「成功体験（Day 0 Experience）」に特化したミニマルかつ高品位なパッケージとする。

- **同梱物案**:
  1. `ADX CORE-S` × 2台（メイン機 ＋ サブ機）
  2. `RPR4 Smart Probe` × 1台（スマホ直結デバッガー＆OTWプログラマー）
  3. `現場用スプリング端子接続ケーブル一式`（ツイストペア通信線 ＋ 電源線、被覆加工済み）
  4. `USB Type-C to C ケーブル`（スマホ/PC直結用）
  5. `クイックスタートカード / ステッカー`（スマホPWAへのQRコード、配線ダイアグラム記載）

## 5. 結論とマーケティング提言

1. **「スターターキット」の定義を書き換える**:
   - 「電子工作の入門おもちゃ」としてのスターターキット市場はレッドオーシャンだが、「**現場分散ネットワークのためのスターターキット**」市場は完全な未開拓（ブルーオーシャン）である。
2. **主力プレッジ（Pledge）としての確固たる位置づけ**:
   - Crowd Supply において、ADXの看板製品は単体ボードではなく、この **Field Starter Kit（定価$79 / Early Bird $59）** を最前面に押し出す。
3. **キャッチコピー案**:
   - *“Beyond the Breadboard: The First Field-Ready Network Starter Kit.”*
   - （ブレッドボードのその先へ。現場で本当に動く、初の分散ネットワーク・スターターキット。）
