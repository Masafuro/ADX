## 1. 調査の背景とエグゼクティブサマリー

### 1.1 調査の動機
ADX プロジェクトのトップページ（`README.md` / `docs/ja/README.md`）および主力ボード（`CORE-A5`）のドキュメントにおいて、しばしば目にする **「Zero Self-Heating（自己発熱ゼロ）」** という表現について、その歴史的背景と技術的実態の調査を行いました。

その結果、「従来の産業用ボードが抱えていた 24V/48V 降圧 DCDC の発熱（数ワット）をコア基板から追放した」という明確な技術的設計思想から生まれた言葉であることが判明しました。一方で、熱力学や電気工学の物理原則に照らすと「自己発熱がゼロ」ということは原理上あり得ず、また同様に **「絶対に緩まない」「100% 完全保護」「起動時間 0ms」「重装甲スレーブ」** といったマーケティング的・情緒的に強すぎる表現が複数箇所に散見されました。

### 1.2 本監査の総括結論
1. **技術的意図は極めて合理的で優れている**:
   - DCDC の外出しによるコア基板の低発熱化、プッシュイン端子台の耐振動性、SY6280 による短絡保護、2500V ガルバニック絶縁などは、いずれも実際の現場課題を解決する優れたハードウェア設計です。
2. **表現が工学的な信頼性と初学者の安心感を損ねている**:
   - 絶対的な表現（「絶対」「100%」「ゼロ」）は、プロのエンジニアから「物理を無視した誇大広告」「PL法（製造物責任）上の地雷」と見なされるリスクがあります。
   - ミリタリー調の表現（「重装甲」「鉄壁」「戦士」）は、ADX が掲げる「はたらくArduino（親しみやすく等身大）」のブランド方針と矛盾し、初学者を萎縮させる要因となります。
3. **提案**:
   - 技術的意図（なぜそう設計したか）を損なうことなく、**「客観的・工学的に正確で、かつ誠実で安心感を与える表現」** へトーン＆マナーを是正することを提案します。

## 2. 「Zero Self-Heating (自己発熱ゼロ)」の解剖

### 2.1 歴史的経緯：なぜこの言葉が生まれたのか？
リポジトリ履歴（コミット `ae2db79` / 2026-10-01付 `hardware/archive/CORE-A/rev1/concept.md`）の調査より、本表現は以下の対比から誕生しました：

```text
【従来の産業用 24V ボード】
  [24V/48V 工場電源] ──▶ [ オンボード降圧 DCDC / LDO ] ──▶ [ MCU ]
                           └── 💥 発熱の温床（数ワット損失）
                               密閉制御盤・真夏のボックス内で基板が数十℃上昇！

【 ADX のアーキテクチャ 】
  [24V/48V 工場電源] ──▶ 【 独立した Power CARD 】 (発熱源を物理分離)
                                 │ 5V (VBUS)
                                 ▼
                         【 ADX CORE-A5 】
                         MCU消費電力わずか 10〜15mW（3.3V / 10MHz）
                         ➜ 「熱設計計算において発熱上昇 ΔT がほぼ無視できる！」
```

従来の産業用マイコン基板では、基板上に 24V $\rightarrow$ 5V の降圧スイッチング電源（DCDC）やリニアレギュレータ（LDO）を同居させていたため、レギュレータ自身が数ワットの熱源となり、真夏の密閉ボックス内でマイコンや電解コンデンサの寿命を縮めていました。

ADX では、この高電圧降圧回路を「Power CARD」側に物理的に隔離し、コア基板（CORE-A5）自体は **5V 単一受電＋ATtiny1616（3.3V/10MHz動作、消費電力約 10〜20mW）** に徹することで、**「密閉エンクロージャ内でも基板温度がほとんど上昇しない」** という強力な差別化要因を獲得しました。この圧倒的な低発熱をアピールするために「Zero Self-Heating」「自己発熱ゼロ」というキャッチコピーが採用された経緯があります。

### 2.2 工学的実態とリスク
| 項目 | 工学的現実 | 「自己発熱ゼロ」と表記するリスク |
| :--- | :--- | :--- |
| **MCU & LDO** | ATtiny1616（約 3〜5mA）＋ ME6211 LDO（降圧差 $5\text{V} - 3.3\text{V} = 1.7\text{V}$）により、約 $10 \sim 15\,\text{mW}$ の熱が発生。 | 物理学上のジュール熱（$P = I^2 R$）が存在するため、「熱力学を無視した非科学的主張」と突っ込まれる。 |
| **絶縁 RS-485** | TDA51S485HC は内部に絶縁 DC-DC と差動ドライバを内蔵しており、通信時に約 $10 \sim 30\,\text{mA}$（$50 \sim 150\,\text{mW}$）を消費。 | 連続送信時などにはチップ表面に触れてわかる程度の微小な温度上昇が確実に生じるため、虚偽の指摘を受ける。 |
| **トータルの影響** | 全体で数十 mW 〜 最大 200mW 程度であり、自然放熱で温度上昇 $\Delta T < 1 \sim 2^\circ\text{C}$ に収まる。 | 「ゼロ」ではなく**「極小（Negligible / 無視できるレベル）」**であるのが正確な事実。 |

### 2.3 推奨される表現（改善案）
- **英語**: `Zero Self-Heating` $\rightarrow$ **`Negligible Self-Heating`** または **`Ultra-Low Thermal Dissipation (<0.1W)`**
- **日本語**: `自己発熱ゼロ` $\rightarrow$ **`極小の自己発熱（密閉筐体でも熱がこもらない低消費電力設計）`** または **`ヒートシンク不要の極低発熱`**

## 5. 「はたらくArduino」ブランドにおけるトーン＆マナー指針

ADX の最大の魅力は、**「これまで現場やプロの世界でしか使えなかったタフなインフラ技術（RS-485、絶縁、耐振動、耐熱）を、誰もが触れる Arduino スタイルで民主化する」** という点にあります。

過去のドキュメント（特に [`memo/PLAN/WORKING_ARDUINO_CORE-A_DOCUMENTATION_PLAN.md`](../../memo/PLAN/WORKING_ARDUINO_CORE-A_DOCUMENTATION_PLAN.md)）にも記されていた以下の原則に立ち返る必要があります：

> **「初学者を絶対に萎縮させない（性能誇示の厳禁）」**  
> 「2500V耐圧」「-40℃〜+105℃耐熱」「自己発熱ゼロ」「鉄壁の保護」「完全絶縁」といった過剰で強烈な言葉は、初学者に『自分には関係のないプロの怖い世界だ』と感じさせ、引き返させてしまいます。

### 採用すべきトーン＆マナー（3つの黄金律）
1. **Fact-Based（事実と数値で語る）**:
   - ✕「絶対に壊れない」「100%保護」
   - ◯「2500V ガルバニック絶縁」「SY6280 による短絡遮断回路」
2. **Accessible & Friendly（身近で親しみやすい言葉）**:
   - ✕「現場特化の重装甲スレーブ」「鉄壁の沈黙」
   - ◯「現場で安心して使えるタフな基板」「誤動作しない静かな通信」
3. **Honest Engineering（工学的な誠実さ）**:
   - ✕「自己発熱ゼロ」「起動時間 0ms」
   - ◯「放熱ファン不要の極小発熱」「電源投入後すぐに動く即時起動」

## 6. 次のアクション（ユーザーへの確認・ご相談）

本レポートの内容に基づき、以下のどのレベルでドキュメントの表現是正を進めるか、ご意見をいただけますでしょうか：

1. **【推奨】公開玄関口（README.md / docs/ja/README.md / CORE-A5 仕様書）の是正**:
   - 「絶対に緩みません」「Zero Self-Heating」「100%」「重装甲スレーブ」「起動遅延ゼロ (0ms)」など、外部エンジニアが最初に目にする重要ドキュメントの過剰表現を誠実な工学表現へ一括修正する。
2. **【プロジェクトの個性として一部残す選択肢】**:
   - 例えば「重装甲スレーブ」や「鉄壁」といった表現を、開発メモやブランディングの愛称としてあえて残すか、それとも完全にプロフェッショナルなトーンに統一するか。
