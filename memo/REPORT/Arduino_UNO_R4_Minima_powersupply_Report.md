# Arduino UNO R4 Minima の供給可能電力（ワット数）について

Arduino UNO R4 Minimaは、給電方法（USBかDCジャックか）によってメインボード（5Vピン・3.3Vピン）から周辺機器へ供給できる最大の電力が異なります。

結論から言うと、外部機器へ供給できる電力は**DCジャック使用時は最大で約6W**、**USB使用時は接続元の仕様に依存（約2.5W〜7.5W）**となります。

以下に各給電元とピンごとの詳細をまとめました。

## 1. DCジャック / VINピン から給電した場合（入力6V〜24V）

ボード上に搭載されている強力な降圧DC-DCコンバータ（ルネサス製 ISL854102）を経由して5Vが生成されます。以前のUNO R3のレギュレータと比べて熱を持ちにくく、高効率です。

*   **5Vピンの最大出力電流**: 1.2A（コンバータの仕様上の上限）
*   **5Vピンの最大供給電力**: **約6.0W**（5V × 1.2A）
    ※厳密には、ここからマイコンボード自身の消費電力を差し引いた余力を、外部のセンサーやシールドに供給可能です。

## 2. USB Type-C から給電した場合（入力5V）

USBから給電する場合、電力はDC-DCコンバータを経由せず直接5Vラインに供給されます。そのため、出力上限は「接続元のUSBポート（PCやACアダプタなど）の給電能力」にそのまま依存します。

*   **標準的なUSB 2.0ポート**: 最大500mA ＝ **約2.5W**
*   **標準的なUSB 3.0ポート**: 最大900mA ＝ **約4.5W**
*   **USB Type-C (1.5A供給可能ポート)**: 最大1.5A ＝ **約7.5W**

## 3. 3.3Vピンからの供給電力（給電方法問わず共通）

3.3Vピンの電力は、メインのマイコン（RA4M1）内蔵のUSB用LDOなどを経由して生成される仕様になっています。そのため扱える電力量は非常に限られています。

*   **3.3Vピンの最大出力電流**: 約50mA 〜 100mA程度
*   **3.3Vピンの最大供給電力**: **約0.16W 〜 0.33W**
    ※消費電力の大きいWi-Fiモジュールや外部ディスプレイなどを3.3Vピンから直接駆動させるのには電力不足となります。

---

### ⚠️ 設計上の注意点
R4 MinimaはDC-DCコンバータが強力になったため、DCジャックから給電すれば最大6W近く（約1.2A）の電力を5Vピンから安定して取り出せます。しかし、複数のサーボモーターや大電力のLEDマトリクスなどで**6W（1.2A）**を超える場合は、メインボードの焼損を防ぐため、Arduinoのピンを経由させずに直接外部電源からモーター等へ電力を供給する回路設計を行ってください。
