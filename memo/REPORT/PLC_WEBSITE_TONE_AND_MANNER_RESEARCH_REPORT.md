# 世界主要 PLC・FA メーカーの Web トンマナ調査 ＆ ARLE.cc / ADX 配色設計ブレインストーミング資料

- **文書 ID**: `REPORT-ARLE-DESIGN-001`
- **作成日**: 2026-11-23
- **ステータス**: トンマナ検討・ブレインストーミング用
- **目的**: 世界の主要 PLC / 産業用オートメーションメーカーおよびオープン産業ボード勢の Web サイト設計・配色傾向を整理し、**「白ベース × カラーユニバーサルデザイン（CUD）× 産業用道具感」** を軸にした `ARLE.cc / ADX` のビジュアルトーンを検討する土台を作る。

## 1. エグゼクティブサマリー（調査から見えた 5 つの核心）

1. **世界の PLC メーカーは「ほぼ例外なく白ベース（Pure White ＋ 工業ライトグレー）」**
   - 欧米・日本を問わず、技術情報・製品カタログ・ドキュメント領域は `#FFFFFF` ＋ `#EFF0F1` / `#F4F4F4`（制御盤の定番色 RAL 7035 に通じる明灰）が圧倒的多数。
   - Siemens のようにコーポレート LP 帯で濃紺（`#000028`）を使う例でも、実際の産業 UI・設計システム（Siemens iX）では明るい工場・制御室・タブレット閲覧を前提にした **Light テーマ** を正式基準として用意している。
2. **「白ベース」には産業機器ならではの明確な工学的理由がある**
   - ① 黒・金属・緑基板などのハードウェア実機写真が最も立体的に映える、② 明るい工場照明・屋外・紙/PDF 印刷で潰れない、③ 高密度なスペック表・ピンアサイン表・図面の視認性が最も高い、④ 「ゲーミング／ガジェット」ではなく「計測器・設計道具」の信頼記号になる。
3. **世界の PLC カラーは「赤・緑/ティール・青・橙/黄」に色相分化しており、赤とティールは超激戦区**
   - **赤系**: Beckhoff, ABB, Rockwell, KEYENCE, 三菱電機（最多だが、エラー/危険の安全色と衝突しやすいジレンマあり）
   - **緑/ティール系**: Siemens, Phoenix Contact, WAGO, Schneider Electric, Arduino Pro（欧州モダン勢＋Arduino 本家が密集）
   - **青系**: OMRON, Bosch Rexroth（CUD・コントラスト面で最も破綻しにくい）
   - **橙/黄系**: B&R, 横河電機（独自性は強いが、白地文字には濃スレートとの組み合わせが必須）
4. **「CUD（カラーユニバーサルデザイン）× 産業用カラー」という直感は規格面でも完全に正解**
   - 2018 年改定の **JIS Z 9103（安全色彩）** 自体が **CUDO（カラーユニバーサルデザイン機構）** と協働して CUD 準拠へ刷新されており、現代の産業安全色と CUD はすでに合流している。
   - 特に **Okabe-Ito パレット** や **CUD 推奨配色セット ver.4** を土台にすれば、Web UI・安全バッジ・**ADX 20 ピンバスのピンアウト色分け** まで 1 つの一貫した色彩体系で設計できる。
5. **プロの「産業道具感」を生むのは色以上に「引き算の無彩色」「シャープな罫線」「等幅数値」「ブランド色と意味色の分離」**
   - ABB の 60-30-10 ルール、WAGO のデザインシステム、Siemens iX のセマンティックトークン分離が示す通り、**画面の 85〜90% は白＋ライトグレー＋濃スレートで静かに組み、色は「操作の軸」と「工学的意味（安全・電源・信号種別）」に限定する** ことで、一気に現場の道具らしい品格が出る。

## 3. 世界の PLC サイトから抽出できる「産業用 Web トンマナ」の 6 原則

色の選定だけでなく、PLC メーカーのサイトが「ホビー用ガジェット」ではなく **「信頼できる産業道具」** に見える理由は以下の構造的特徴にあります。

### 原則 1：背景は「純白 `#FFFFFF`」＋ 補助面に「RAL 7035 系ライトグレー（`#F4F5F7` / `#EFF0F1`）」
- 制御盤の内装塗装や DIN レール機器の筐体標準色である **RAL 7035（ライトグレー）** に近い無彩色をカードや表ヘッダに使うと、それだけで「盤内機器・技術データシート」の空気感が出ます。
- 今後 `Reference CARD v0` や `Prototype CARD v0`、`CORE-U` の実基板写真・3D レンダリング・白黒の CAD 寸法図を載せたとき、白背景なら画像の切り抜き・馴染み・影の処理が圧倒的に美しく収まります。

### 原則 2：文字は「真っ黒 `#000000` ではなく、わずかに青みのある濃スレート（`#181C24` / `#1F2837`）」
- WAGO（`#1F2837`）や Arduino Docs（`#111827`）が採用しているように、純黒よりもわずかに冷たい濃スレートを本文に使うと、画面上のギラつきが減り、金属・電子回路らしい精密な印象になります。

### 原則 3：角丸と影を抑え、「1px ボーダー」でグリッドを組む
- 過度なドロップシャドウや大きな丸み（`border-radius: 16px+`）はコンシューマー向けアプリの記号です。
- 産業系サイトは **`border-radius: 4px〜6px` 程度＋明確な `1px` の枠線（`#D8DCE2` 等）** を使い、CAD 図面やデータシートのような「きっちり測られた秩序感」を演出します。

### 原則 4：数値・型番・ピン名・寸法は必ず等幅フォント（＋等幅数字）
- `88.0 × 58.0 mm`、`Φ10.0 mm`、`ADX_P01`、`3.3V LVCMOS`、`VBUS 2.0A` のような工学諸元は、`JetBrains Mono` 等の等幅フォント（あるいは `font-variant-numeric: tabular-nums`）で桁を揃えることで、一目でプロの資料としての説得力が跳ね上がります。

### 原則 5：ブランドカラー（操作色）とセマンティックカラー（安全・状態色）を混ぜない
- Siemens iX の最重要設計思想です。
- 赤をブランド色にしているメーカー（Beckhoff / ABB / KEYENCE / 三菱）は、そのままエラー表示や注意表示に赤を使うと画面上で意味が混線するため、ドキュメントや UI のリンク・操作色には「黒・濃紺・青」を当てざるを得なくなっています。
- 逆に、**ブランド色として安全色（赤・黄）と衝突しない色相を選ぶ**と、サイト全体のルールが劇的にシンプルになります。

### 原則 6：「ライト（白ベース）を正本」とし、ダークモードは任意切替に留める
- 明るい実験室・工場・オフィスでの閲覧や PDF 印刷、図面確認の主戦場は白ベースです。
- Starlight はテーマ切替を標準搭載しているため、**デフォルトを白ベース（Light）** に設計し、夜間作業向けのダークモードは補助テーマとして整えるのが、産業用ドキュメントポータルとして最も誠実な構成です（※初期 M1 で試作した黒ベースから反転させる方向）。

## 4. ユニバーサルデザインカラー（CUD）× 産業安全規格の整理

ユーザーが直感された **「CUD を基調にした産業用カラーパレット」** は、実は現行の日本の産業安全規格とも完璧に合致しています。

### 4.1 なぜ CUD が産業ハードウェアサイトに最適なのか
- 日本人男性の約 5%（20 人に 1 人）、欧米男性の約 8% は P 型・D 型などの色覚特性を持ちます。工場・設備・組込エンジニアの母集団では、**現場のチームに色覚特性を持つ技術者がいるのが当たり前**です。
- 2018 年改定の **JIS Z 9103（安全色彩）** は、NPO 法人カラーユニバーサルデザイン機構（CUDO）と共同で「色覚多様性でも見分けられる安全色」へ全面刷新されました。
- ADX が今後作成する **Arduino 風ピンアウト図（20 ピン色分け）** や **筐体キープアウト図（M3 座面／カードガイド／SMD Only／光学マーカー）** は、まさに「色の見分けミスが配線ミスや基板干渉に直結する」領域であり、**最初から CUD 準拠パレットで統一する工学的価値が極めて高い**です。

### 4.2 代表的な CUD 基準パレット（sRGB / デジタル画面用）

#### A. Okabe-Ito パレット（世界の科学・工学データ可視化のデファクト標準）
| 色名 | HEX | 白地上のコントラスト比（目安） | 産業・ADX での適性 |
| :--- | :---: | :---: | :--- |
| **Blue（青）** | `#0072B2` | **5.3 : 1（AA 合格）** | リンク・プライマリ操作・SPI・必須情報に最適 |
| **Bluish Green（青緑）** | `#009E73` | 3.4 : 1（大文字/図形向け） | 安全・正常・I2C（※本文リンクには `#007A5A` 等へ一段暗く調整） |
| **Vermillion（朱赤）** | `#D55E00` | 3.8 : 1（大文字/図形向け） | 危険・電源 `VBUS`・禁止・強アクセント（※小文字は `#B34B00` 等） |
| **Orange（橙）** | `#E69F00` | 2.2 : 1（背景塗り/バッジ向け） | 警告・注意・アナログ `P01/AIN`（黒文字 `#181C24` 載せで超高コントラスト） |
| **Sky Blue（空色）** | `#56B4E9` | 2.3 : 1（背景塗り/バッジ向け） | 補助情報・UART `P03–P04`（黒文字載せで高可読） |
| **Reddish Purple（赤紫）** | `#CC79A7` | 3.1 : 1（図形・バッジ向け） | クロック・特殊信号 `P02/EXTCLK` |
| **Yellow（黄）** | `#F0E442` | 1.3 : 1（黒枠＋黒文字必須） | 注意喚起ハイライト（白地テキスト単体では使用禁止） |
| **Black / Gray** | `#000000` / `#999999` | — | GND・構造線・システム `S00`（斜線併用） |

#### B. CUD 推奨配色セット ver.4 ＆ 改定 JIS Z 9103（画面用 sRGB 抜粋）
- **アクセント（小面積・サイン・安全色）**：
  - 赤（禁止・停止・危険）：`#FF4B00`
  - オレンジ（警告・注意）：`#F6AA00`
  - 緑（安全・進行）：`#03AF7A`（CUD v4）/ `#00B06B`（JIS Z 9103）
  - 青（指示・必須）：`#005AFF`（CUD v4）/ `#1971FF`（JIS Z 9103）
  - 空色：`#4DC4FF` / 紫：`#990099` / 茶：`#804000`
- **ベースカラー（図面の広い面塗り分け用：筐体キープアウト図に抜群に効く！）**：
  - 明るい空色 `#BFE4FF`、明るい緑 `#77D9A8`、ベージュ `#FFCA80`、明るいピンク `#FFCABF`、明るい紫 `#C9ACE6`、クリーム `#FFFF80`
- **無彩色**：白 `#FFFFFF`、明るいグレー `#C8C8CB`、グレー `#84919E`、黒 `#000000`

### 4.3 CUD 運用の絶対ルール（色だけに依存しない）
- **二重符号化（Redundant Coding）**: 色覚特性や白黒印刷への対応として、ピンアウト図や警告枠では必ず **「色 ＋ ラベル文字列（`VBUS`, `GND`, `MUST`）＋ 枠線・アイコン・斜線パターン」** を併用する。
- **白地上のテキストは WCAG AA（4.5 : 1 以上）を厳守**: CUD パレットの鮮やかな色（オレンジや空色など）は「塗りつぶしバッジ＋黒文字」や「アイコン・線」に使い、白背景上の小文字リンクや本文アクセントには明度を落としたテキスト専用トークンを用意する。

## 5. ARLE.cc / ADX 向けトンマナ方向性 3 案（ブレインストーミングたたき台）

世界の PLC メーカーのポジショニング（赤＝伝統重工・ティール＝Siemens/Arduino 密集地帯）と、CUD × 白ベースを掛け合わせたときの **3 つの現実的な候補** です。

```text
                【 産業機器 Web ブランドのカラーポジショニング図 】

                         高信頼・精密計測・インフラ寄り
                                      ▲
                                      │
          [OMRON / Bosch Rexroth]     │      ★ 案 A：CUD Precision Blue
                 (Blue)               │         (白 + 工業灰 + #0072B2)
                                      │
  伝統重工・保守的 ◀──────────────────┼──────────────────▶ モダン・オープン・軽快
  [ABB / Beckhoff /                   │      ★ 案 B：CUD Slate & Teal-Green
   KEYENCE / 三菱 / Rockwell]         │         (白 + 濃スレート + #007A5A)
          (Red)                       │         ※周辺: WAGO / Siemens / Arduino
                                      │
```

### 案 A：『CUD Precision Blue（精密計測・設計図スタイル）』— 最も破綻しにくい王道
- **ベース**: 純白 `#FFFFFF` ＋ 工業ライトグレー `#F4F6F8` ＋ 罫線 `#D5DCE4`
- **文字・構造**: 濃スレート `#171D26`（本文）、`#4A5568`（補助）
- **ブランド／UI プライマリ**: **Okabe-Ito Blue `#0072B2`**（ホバー `#00588A`、薄塗り `#E8F4FA`）
- **安全・状態・ピン色**: CUD / JIS Z 9103 の赤 `#D55E00`、橙 `#E69F00`、緑 `#009E73` を一切衝突せずに独立運用。
- **印象**: OMRON・Bosch Rexroth・精密計測器のような清潔さと揺るぎない信頼感。**Arduino Teal（`#008184`）とも一目で差別化でき、白地上のリンク視認性も WCAG AA（5.3:1）をそのままクリア**。

### 案 B：『CUD Industrial Green（WAGO / 次世代オープン FA スタイル）』— 現行 ARLE.cc からの自然な継承
- **ベース**: 純白 `#FFFFFF` ＋ `#F3F5F4`（ごくわずかに冷たい明灰）＋ 罫線 `#D6DDD9`
- **文字・構造**: 濃スレート `#18201E`（WAGO の `#1F2837` に近い引き締め）
- **ブランド／UI プライマリ**: **CUD 深青緑 `#007A5A`**（白地テキスト AA クリア、`5.2:1`）＋ 図形/バッジ用 **Okabe-Ito Bluish Green `#009E73`**
- **補助アクセント**: 必要箇所のみ CUD オレンジ `#E69F00`
- **印象**: 現行 `arle.cc` のグリーン系アクセントや「現場の正常稼働（RUN LED 緑）」の記憶を引き継ぎつつ、白ベースで洗練。ただし Arduino（`#008184`）や Siemens（`#009999`）と色相が近いため、**青に寄りすぎない CUD 青緑＋濃いスレート構造** で差別化するのがポイント。

### 案 C：『Monochrome Blueprint ＋ CUD Vermillion（ABB / B&R 昇華・ストイック道具スタイル）』— 個性と道具感が最強
- **ベース**: 純白 `#FFFFFF` ＋ 工業ライトグレー `#F5F5F4` ＋ 罫線 `#D4D4D8`
- **文字・構造**: 墨黒 `#111318`（ほぼ無彩色で「図面・工具・無印良品/Dieter Rams 的工業デザイン」の佇まい）
- **ブランドアクセント（面積 10% 以下）**: **CUD 朱橙 `#C85000` / `#D55E00`**（Okabe-Ito Vermillion 系：純赤 `#FF0000` より温かみがあり、色覚特性でも識別しやすい）
- **リンク／ドキュメント操作色**: 構造の秩序を保つため濃スレートまたは CUD Blue `#0072B2` を控えめに併用。
- **印象**: 他のマイコンボード系サイトと一切被らない、圧倒的な「実用品・工業ツール・長崎の町工場発エンジニアリングレーベル」の格好良さ。ただしエラー表示の赤と役割を分ける設計ルールが必要。

## 6. 次回ブレインストーミングで話し合いたい論点

このレポートをたたき台に、次の 4 点をすり合わせると `ARLE.cc / ADX` のビジュアル指針がくっきり定まります：

1. **「ARLE.cc らしさ」の立ち位置はどこに置きたいか？**
   - 精密計測器・信頼インフラ寄り（**案 A: CUD Blue**）
   - クリーンな次世代オープン FA・稼働感寄り（**案 B: CUD 青緑**）
   - 無骨でストイックな設計図・工具・プロ道具寄り（**案 C: 無彩色＋CUD 朱橙**）
   - あるいは「**無彩色（白＋RAL 7035 灰＋濃スレート）を 90% にして、ブランドの主張はロゴとタイポグラフィに任せ、色は CUD 規格色（ピンアウト図・状態バッジ・リンクの青）だけにする**」という引き算極振りも有力。
2. **「はたらく Arduino」としての親しみやすさ vs 産業用 PLC の硬さのバランス**
   - KEYENCE や Beckhoff ほど「工場の B2B 営業サイト」っぽく硬くしたいのか、それとも `docs.arduino.cc` と WAGO/Siemens の中間（「3D プリンター民も怖がらずに入れて、制御盤屋さんも『おっ、分かってるな』と思う温度感」）を狙うか？
3. **Starlight のデフォルトテーマを白ベース（Light）に変更するか？**
   - M1 の現状は旧 `site/index.html` を引き継いだダーク基調ですが、白ベースへ切り替える場合、デフォルトテーマを Light に固定または初期設定し、ダークモードは補助として用意する設計が自然です。
4. **サイト UI パレットと「ADX 20 ピンバス SVG ピンアウト図」の配色を同時設計するか？**
   - サイト全体の配色と Okabe-Ito / CUD v4 ベースのピンアウト図配色をセットで決めると、M3 で図面を入れた瞬間にサイト全体が 1 枚の美しい技術カタログとして統一されます。
