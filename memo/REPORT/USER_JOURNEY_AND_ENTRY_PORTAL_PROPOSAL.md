# ADX リポジトリ エントリー動線 ＆ ユーザー体験（UX）設計レポート
(ADX Repository User Journey & Entry Portal Architecture Report)

**文書ID**: REPORT-ADX-UX-001  
**作成日**: 2026-10-16  
**ステータス**: レビュー協議用提案書  

---

## 1. 概要と問題意識 (Background & Problem Statement)

GitHub リポジトリの顔であるルート `README.md`（および `docs/ja/README.md`）は、世界中の開発者やエンジニアが最初に目にする **最重要エントリーポイント（玄関口）** です。

現在の README は、**「はたらくArduino (The Working Arduino)」** という非常に魅力的で共感を呼ぶコンセプトを語れている一方で、近日の急速な仕様進化（CORE-A ➜ CORE-R ➜ CORE-A5、3.3V GPIO / VBUS 共通バスの確立）と照らし合わせた際に、**「ユーザーが次にどこへ行けばいいのか迷子になる」動線の断絶** が生じています。

---

## 2. 現状のエントリー動線における 3大課題

```text
【 現状のユーザー動線における課題 】

   初回来訪ユーザー
         │
         ▼
   [ ルート README.md ] ──▶ キャッチコピー「はたらくArduino」に共感！
         │
         ├─▶ 「ハードウェアを見よう」 ➜ リンク先が archive/CORE-A (旧仕様)
         ├─▶ 「ツールを見よう」       ➜ RPR4 (実は開発オミット済み)
         └─▶ 「で、自分は何から始めればいいの？」 ➜ 次の具体的なアクションがない (離脱)
```

### 課題 1: 看板ボードの不整合（最新 CORE-A5 への未案内）
- トップ README では依然として旧世代の **「ADX CORE-A」** が看板となっており、リンク先が旧ファイルやアーカイブを指しています。
- 本日策定された最新の決定版エッジ端末 **「ADX CORE-A5」**（前面 5VIN、3.3V ネイティブ、CCL 自律リセット）の存在がトップから見えず、新規ユーザーが古い 5V 仕様や BMC の記述を読んで混乱する原因になっています。

### 課題 2: オミットされたツール（RPR4）の居座り
- プロトタイプ検証を経てアーカイブ化（オミット）されたはずの **「RPR4 Smart Probe」** が、依然としてメインボードと同格で大きく紹介されており、リンク切れやプロジェクトの停滞感を与えてしまうリスクがあります。

### 課題 3: ユーザーペルソナ別「次の一歩（Call to Action）」の欠如
- 来訪者が「自分の目的に対して、どのドキュメントを読めばいいのか」が直感的に誘導されていません。
  - 「スケッチを動かしたい人」
  - 「回路図やBOMを見たい人」
  - 「自作 CARD を設計したい人」
  - 「3D ケースを印刷したい人」
  それぞれへの明確な道案内（サインポスト）が必要です。

## 3. ADX にやってくる 4大ユーザーペルソナと体験設計

ADX リポジトリを訪れるユーザーを以下の 4 つのペルソナに定義し、それぞれが最短で目的を達成できるジャーニーを設計します。

| ペルソナ | 想定人物像 | リポジトリ来訪時の主な目的 | 理想的な誘導先（ゴール） |
| :--- | :--- | :--- | :--- |
| **① メイカー / ホビースト** | ブレッドボード電子工作から実用化したい人 | ・自分のスケッチが現場で動くか？<br>・Arduino IDE でどう書くのか？<br>・ケースはどうするのか？ | 1. 「はたらくArduino」の理念<br>2. **クイックスタート (megaTinyCore)**<br>3. 3Dプリントケース STL |
| **② ハードウェア技術者** | 基板設計者、PCBA 発注をしたいプロ | ・回路図、BOM、PCBA コストを見たい<br>・保護回路や耐熱性能を確認したい | 1. **ADX CORE-A5 仕様書** (`hardware/CORE-A5/`)<br>2. ネットリスト・BOM・価格見積もり<br>3. 8748 フォームファクタ仕様書 |
| **③ 拡張 CARD 開発者** | センサーやリレー等の独自基板を作りたい人 | ・共通 20P バスのピン定義を知りたい<br>・電源供給能力や論理電圧を確認したい | 1. **ADX 20-Pin Bus (SSOT: `ADX_PINOUT.md`)**<br>2. 設計・解説ガイド (`ADX_pinout.md`)<br>3. Prototyping CARD テンプレート |
| **④ 産業・設備エンジニア** | 制御盤、照明、工場、車載機器への組込検討者 | ・RS-485 絶縁耐圧や耐熱保証温度<br>・現場配線（スプリング端子）の実用性<br>・現場での遠隔書き換え（OTW） | 1. ガルバニック絶縁・耐熱スペック<br>2. CCL 自律監視 OTW アーキテクチャ<br>3. 現場単体受電 (5VIN) 仕様 |

## 5. 具体的な改修チェックリスト (Action Items)

この提案に基づき、以下の具体的な改修を実施することを推奨します：

1. **ルート `README.md` (英語) の改訂:**
   - 看板コアを `ADX CORE-A` ➜ **`ADX CORE-A5`** に刷新。
   - `RPR4 Smart Probe` のセクションを削除し、最新のファームウェア書き込み動線（市販ドングルによる OTW / Web Flasher）に差し替え。
   - ペルソナ別の「Quick Navigation」セクションを新設。
   - ピン規格へのリンクを新設した `docs/spec/ADX_PINOUT.md` へ統一。
2. **`docs/ja/README.md` (日本語) の改訂:**
   - 英語版と 1:1 で対応する日本語版リファクタリング。
   - 日本のメイカーやエンジニアが現場感をイメージしやすい表現へのブラッシュアップ。
3. **リンク切れ・不要パスの点検:**
   - `hardware/CORE-A/` への古いリンクをすべて解消し、現役の `hardware/CORE-A5/` または仕様書へリダイレクト。
