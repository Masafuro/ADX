## 1. 改訂の総括と3大イノベーション (Key Innovations in v4.0)

ADX 共通拡張バス（2×10ピン 20P IDC コネクタ）は、現場での過酷な長期運用、筐体スロットイン構造、および次世代MCU（CORE-CX5 / CH32X035等）への展開を見据え、**「ADX-BUS-SPEC-v4.0」** として全面刷新します。

v4.0 では、以下の**3つの決定的な設計革新（イノベーション）**が導入されます。

```text
┌────────────────────────────────────────────────────────────────────────┐
│                      ADX Bus v4.0 の 3大革新                            │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 重力フェイルセーフ (Gravity Fail-Safe)                               │
│    大動脈電源 VBUS (4.5〜5.0V / 2〜3A) を最下部 (Pins 17〜20) へ配置。   │
│    縦型ユニット設置時に電源線が脱落しても、下へ垂れ下がるだけで信号線  │
│    (RS-485 / I2C / SPI / アナログ) への物理接触・全損事故を完全防止。   │
├────────────────────────────────────────────────────────────────────────┤
│ 2. 最外端GND ＆ AIN コプレーナ・シールド (Shield Architecture)          │
│    フラットケーブル最外端 (Pin 1) を GND 終端シールドとし、外部金属擦れ │
│    や静電ノイズを遮断。Pin 1 (GND) と Pin 4 (GND) で挟むことで、繊細な │
│    Pin 3 (AIN) を高周波クロックやデジタルノイズから完全に防護。         │
├────────────────────────────────────────────────────────────────────────┤
│ 3. OWD (One-Wire Debug / Factory Programming) の正式定義               │
│    旧「SYS_RST」の呼称を廃止し、Pin 2 を「OWD」として再定義。          │
│    ATtiny1616 (UPDI) と CH32X035 (SDI) を 1-Wire 保守線として抽象化。   │
│    出荷検査治具（IDC ヘッダー）でのUF2自動書込と現場長期保守を完全確立。│
└────────────────────────────────────────────────────────────────────────┘
```

## 3. 電気的・構造的メリットの詳細解説 (Engineering Rationale)

### 3.1 重力フェイルセーフ構造 (Pins 17〜20: VBUS)
- **現場配線トラブルへの耐性:**  
  PLCラックやスロットイン筐体に縦型実装された場合、大容量外部電源（DC 24V等）の配線が最下端（Pins 17〜20側）に配置されます。振動や現場での端子台ネジ締め不良により電源線が脱落した場合でも、電線は自重で直下の底面シャーシ（FG）や配線ダクトへ垂れ落ちます。上部に位置する通信線（RS-485/UART/SPI）やアナログ入力へ物理接触することが原理的に不可能です。
- **2×2 正方形電源ベタプレーン:**  
  Pins 17, 18, 19, 20 は基板上で完全な正方形グリッドを形成します。PCB CAD上で表裏ベタ銅箔プレーンを形成しやすく、低インピーダンス・大電流（2A〜3A連続）供給・優れた放熱性を達成します。

### 3.2 鉄壁の短絡防止壁 (Pin 16: GND)
- **高圧・大電流の遮断境界:**  
  VBUSクラスタ（Pins 17〜20）の直上に Pin 16（GND）を配置。フラットケーブル圧接時の位置ズレや芯線ヒゲ短絡が発生した場合、VBUS は必ず直上の Pin 16（GND）と短絡します。これにより、給電側の過電流保護回路（PTCヒューズやロードスイッチ）が瞬時にトリップし、上部の信号線（Pins 1〜15）への電圧侵入を物理的に阻止します。

### 3.3 AIN コプレーナ・シールド ＆ 最外端ガード (Pins 1〜4)
- **外周静電保護:**  
  リボンケーブルの最端（芯線 #1）に GND を配置。外部の金属筐体や別系統の配線束との摩擦・静電放電（ESD）からバス全体を守ります。
- **アナログ完全隔離:**  
  Pin 3 (`AIN`) は、外周側の Pin 1 (`GND`) と内周側の Pin 4 (`GND`) によって挟まれており、実質的なコプレーナ・ウェーブガイド構造（シールド構造）を形成します。Pin 5 (`EXTCLK`) などの高速デジタルスイッチングノイズが微弱アナログ信号に回り込むのを完璧に遮断します。

### 3.4 EXTCLK のコプレーナ・サンドイッチ (Pins 4〜6)
- 高速クロック線 Pin 5 (`EXTCLK`) は、両隣の Pin 4 (`GND`) および Pin 6 (`GND`) で挟まれています。これにより、クロックノイズの空間放射（EMI）を抑え、隣接するアナログおよび通信バスへのクロストークを完全に遮断します。

### 3.5 One-Wire Debug / 治具検査バス (Pin 2: OWD)
- **役割の明確化:**  
  旧「SYS_RST」を改め、治具検査およびMCU直接保守専用の 1-Wire デバッグ線として定義。
- **Card 側設計ルール (MUST):**  
  一般の拡張 Card は **Pin 2 を未接続（N.C.）** としなければなりません。タクトスイッチ等で強制的に GND へ落とす回路は明示的に禁止されます。
- **システムリセットの担保:**  
  フリーズ時の復旧は、主電源 `VBUS` のパワーサイクル（遮断・再投入）、MCU内部WDT、または通信コマンド（RS-485 / USB）によって安全に行われます。
