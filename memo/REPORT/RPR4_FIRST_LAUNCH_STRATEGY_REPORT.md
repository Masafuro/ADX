# 戦略転換レポート：RPR4 Smart Probe 1stローンチ戦略への移行

- **文書番号**: ADX-REP-20261108-01
- **起案日**: 2026-11-08
- **ステータス**: 確定・移行開始
- **対象**: ADXプロジェクト全体戦略、製品ロードマップ、マーケティング・ローンチ計画

---

## 1. エグゼクティブサマリー

ADXプロジェクトは、当初予定していた「ADX COREボード（CORE-U / CORE-A）の先行製品化」を取りやめ、開発・運用インフラである**「RPR4 Smart Probe」を独立した1st Productとして先行ローンチする**戦略的ピボットを決定した。

本決定は、以下の本質的な洞察に基づいている：
1. **フォームファクタのブレイクスルーの前に、書込・デバッグのブレイクスルーが不可欠である。**
2. **マイコンボード市場（レッドオーシャン）に直接飛び込むのではなく、現場とWebを直結するスマートツール（ブルーオーシャン）として市場を切り拓く。**
3. **「DMX512 × PWA（Web MIDI）」を突破口とし、単独プロダクトとしてCrowd Supply等での爆発的なPVとコミュニティ獲得を狙う。**
4. **RPR4をADXから完全に別リポジトリ化・別Hackadayプロジェクト化し、過去のスコープ肥大化による長期延期リスクを完全に断ち切る。**

---

## 2. 転換の背景と根本的課題

### 2.1 「ボードにUSBを載せる」という前提の破綻
ADX CORE-Uの設計完了後、量産発注への躊躇が生じた原因を突き詰めた結果、**「マイコンボード1枚ごとにUSBコネクタと通信回路を載せる」というMaker前提の設計思想そのものが、産業・現場用途への最大の足かせになっている**という結論に至った。

- **現場の物理的制約**: 盤内や設備、実環境では、USBのケーブル長制限（5m）、振動に弱いコネクタ、防塵防水性の低さ、1台ごとにPCを差し替える運用の非現実性が致命傷となる。
- **大手メーカーの限界**: Arduino OptaやM5Stamp PLCが産業用途に完全浸透しきれない根本要因も、開発体験（USBや無線前提）をそのまま現場に持ち込もうとしている点にある。
- **結論**: 現場の標準である**RS-485マルチドロップ**を前提とし、ボード側からはUSBを排除して極小・低コスト・高信頼に徹するべきである。そのためには、外付けの共通管理インフラ（RPR4）が先に存在しなければならない。

### 2.2 過去のトラウマ（スコープ肥大化による2028年延期）の解消
過去の検討（`revival_of_RPR4.md`）において、Crowd Supplyでの単価引き上げのために「RPR4 + CORE-Aのスターターキット」を計画した際、開発要素（RPR4ハード、COREハード、PWA、書き込みプロトコル、コンパイル環境）が多重結合し、リリースが2027年〜2028年へと大幅延期された。

今回の戦略転換は、**「セット販売」ではなく「RPR4単体の先行完全独立ローンチ」**とすることで、この依存関係を断ち切り、最小のスコープで最速の市場投入を実現する。

## 4. RPR4 Smart Probeの製品価値とキラーユースケース

### 4.1 コア・アーキテクチャ
- **MCU**: Raspberry Pi RP2040（デュアルCortex-M0+、PIO搭載）
- **インターフェース**:
  - ホスト側: USB Type-C（USB-MIDI Class準拠）
  - ターゲット側: ガルバニック絶縁RS-485トランシーバ
- **操作環境**: スマートフォン（iOS Safari / Android Chrome）およびPCのモダンブラウザ（PWA）
- **通信技術**: **Web MIDI API**を採用（iOS Safariでも追加アプリ・ドライバ不要で双方向バイナリ通信が可能な唯一のWeb標準）

### 4.2 キラーユースケース：「DMX512 × PWA」による視覚的突破口
1. **SNS・PVでの圧倒的な映え（1秒で伝わる価値）**:
   - スマホの画面でカラーピッカーをなぞると、背後のフルカラーLEDバーが滑らかに色を変える。
   - フェーダーを動かすとムービングライトが首を振る。
   - 「アプリのインストール不要。ブラウザを開いてType-Cケーブルを挿すだけ」。
2. **現場プロの切実なペイン解消**:
   - 舞台・イベント・店舗照明の現場で、灯体のアドレス確認や点灯試験のためだけに重い照明卓やノートPCを持ち込む苦痛を解消。
   - ポケットからスマホとRPR4を出し、その場で数秒で点灯チェックができる「ポケットテスト卓」。
3. **RP2040 PIOによる完璧な信号生成**:
   - DMX512固有のBreak信号（88μs以上）とMAB（8μs以上）を、OSのUSB遅延に影響されずナノ秒精度でハードウェア自律生成。

### 4.3 3大コミュニティの交差点ハブ
```
       【照明・舞台・設備エンジニア】
         （現場でスマホから直接叩きたいプロ）
                     ▲
                     │
                     ▼
【RP2040・自作ハード界隈】 ◄───► 【Web / PWA開発者】
（絶縁RS-485ボードとして欲しい）    （HTML/CSS/JSでリアルハードを動かしたい）
```

## 5. マーケティング・ローンチ展開（Crowd Supply & Hackaday.io）

### 5.1 なぜCrowd Supplyで強力なのか？
- Crowd Supplyのバッカー層（プロエンジニア、ハッカー）は、「また新しいマイコンボードが出た」には反応が鈍いが、**「実用的でポケットに入る特化型ツール（Bus Pirate、Glasgow等の系譜）」には極めて熱狂的にお金を出す**。
- 35〜50ドルの適正単価を設定することで、目標額（10,000ドル前後）に対して200〜250台程度の健全なロット数でキャンペーンを成立させられる。

### 5.2 Hackaday.io の完全切り分け戦略
- **Hackaday本誌（ブログ）へのFeature率最大化**:
  「RP2040 PIOとWeb MIDIを使い、iOS Safariから直接DMX照明を叩くハック」として単独プロジェクト化することで、Hackaday編集部の目に留まり、トップページ記事として取り上げられる可能性が飛躍的に高まる。
- **コンテスト応募**:
  Tooling / Test Equipment部門やRP2040関連コンテストに「RPR4」単体でエントリー可能。
- **開発ログ（Tech Credibility）の構築**:
  Crowd Supply審査およびバッカーに向け、純粋なプローブ開発ログ（PIO実装、絶縁回路設計、Web MIDI通信）を集中蓄積する。

### 5.3 キャッチコピー案
> **"No Drivers. No App Store. Just Plug USB-C & Open the PWA."**  
> **"The Pocket-Sized Isolated RS-485 & DMX Smart Probe."**

## 6. プロジェクト分離とリポジトリ構成

共倒れを防ぎ、最速でプロダクトを市場投入するため、プロジェクトおよびコードベースを完全に分離する。

```
【Repository: rpr4-smart-probe】（独立リポジトリ / 独立Hackaday）
  ├── hardware/          # RP2040 + 絶縁RS-485 + Type-C 回路・基板設計
  ├── firmware/          # TinyUSB MIDIスタック + PIO (DMX / RS-485 / LN-485)
  └── web-pwa/           # GitHub Pagesホスティング (ユーザー名.github.io/rpr4)
        ├── apps/dmx/       # DMX512 Controller / Monitor
        ├── apps/modbus/    # Modbus RTU Tester / Sniffer
        └── apps/adx/       # ADX Node Flasher / Manager (★将来プラグイン)

【Repository: ADX】（ハードウェアプラットフォーム）
  ├── specs/             # ADX物理仕様・ピン定義
  ├── hardware/          # ADX CORE, EXT, Carrierボード群
  └── bootloaders/       # ATtiny1616 LN-485対応RS-485ブートローダ
```

## 7. ロードマップ（3ステップ展開）

1. **Step 1: RPR4 Smart Probe 単独ローンチ（最優先）**
   - RPR4ハードウェアの設計確定・試作
   - ファームウェア（Web MIDI ↔ PIO DMX/RS-485）の実装
   - 基本PWA（DMXコントローラ ＋ RS-485スニッファ）の公開
   - Hackaday.io 独立プロジェクト開設・開発ログ発信
   - Crowd Supply プレローンチ＆クラウドファンディング実施
2. **Step 2: LN-485通信およびADX書き込み機能のPWA統合**
   - RPR4のPWAに「ADX Node Manager」アプリを追加
   - RPR4ユーザー全員が、意識せずとも「ADXの書き込み環境を手元に持っている状態」を構築（トロイの木馬戦略）
3. **Step 3: ADX COREボード（RS-485ネイティブ版）の投入**
   - USBコネクタを完全排除した、極小・高密度・高信頼なRS-485専用COREボードを市場投入
   - RPR4ユーザーに対して「これに挿せばそのまま動く」と訴求し、まとめ買いを促進

## 8. 結論

「基板のフォームファクタで革命を起こす前に、書込・デバッグのインフラで革命を起こす。」

ADX CORE-Uの発注を立ち止まったことは、ADXプロジェクトを単なる「マイコンボード愛好家の趣味的企画」から、**「世界中の現場とWebを繋ぐ本格的なプラットフォーム事業」へと進化させる極めて重大な転換点**となった。今後は、RPR4 Smart Probeの単独完成と早期ローンチに向けてリソースを集中する。
