## 3. ADX CORE-A の革新（引き算の美学）

### 3.1 5V専任とトリプル・アイソレーション
- 24V/48V等の高電圧・発熱源をコアボードから完全に追放。
- 高電圧は「Power CARD」側がトランス絶縁してクリーンな5VとしてCORE-Aに供給。
- メインボード自身が「フローティング・安全地帯」となるため、**現場の強電設備に通電したまま作業用PCをType-C接続してもPCが絶対に壊れない**。

### 3.2 O-ring Controller 不要の「逆流阻止バルブ」
- USB入力に超低損失な理想ダイオードIC（TI `LM66100` / $V_f$ 降下わずか 20mV）を配置。
- USBから基板共通VDDおよび拡張カードへは無損失で給電し、**外部電源からPCへの逆流を瞬時100%遮断**。
- 手動切替ジャンパもゴツいO-ring ICも全廃し、部品点数・故障リスク・コストを最小化。

### 3.3 フルIndustrial Grade耐熱（-40℃〜+105℃）
- メインMCU（ATtiny1616）およびBMC（ATtiny412）は Microchip 工業用Nグレード（-40℃〜+105℃）。
- 絶縁RS-485（TDA51S485HC）: -40℃〜+105℃。
- LED: 車載規格 AEC-Q102 準拠（-40℃〜+110℃）。
- コネクタ: 20P Eject Header（-55℃〜+105℃）、DB142Rスプリング端子台（-40℃〜+105℃）。
- USB Type-C: -40℃〜+85℃（3,000 cycles、入手性無限）。
- 自己発熱がほぼゼロのため、**真夏の密閉IP67防水ボックスや車内日陰で105℃に耐え抜く**。

### 3.4 ラッチ付き Eject Header
- 5V/2A の電源幹線バスを担うため、MIL規格ラッチ付きイジェクトヘッダを採用。
- 車載や工場の激しい振動下でもリボンケーブルの「半抜け・脱落」を物理的に完全防止。逆挿しも100%排除。

## 4. 拡張エコシステム（CARDシリーズ）

CORE-Aの20P Eject Headerは、上下にスタックされるCARDによって変幻自在に変形する。
「電源の保護・変換・昇圧・降圧は、電源を供給するCARD側が責任を持つ」という単一責任の原則を貫く。

1. **AAA 2S Power CARD（乾電池自律運用）**:
   - 単4アルカリ電池×2本から、超低暗電流DCDCでクリーンな5Vを生成してIDC Pins 1〜4へ供給。
   - スリープ時は、BMCからの制御信号でDCDCのENピンを倒して昇圧回路を完全停止（暗電流ナノアンペア化）。
   - 電池生電圧をIDCのアナログピンへ接続し、MCUで正確な残量モニタリング。
2. **DC 12V〜48V Power CARD（産業・インフラ電源）**:
   - 工場配電盤（24V）、PLC設備、車載（12V/24V）、および通信基地局（-48V）等の広入力電圧をトランス絶縁。
   - クリーンな絶縁5VをIDC Pins 1〜4へ供給。
   - TVS・バリスタ・ヒューズをCARD側に集約し、雷サージや短絡事故からCORE-Aを鉄壁ガード。
3. **Prototyping CARD（ユニバーサル試作）**:
   - 20Pバス信号をすべて引き出し、2.54mmピッチの試作エリアでセンサーや自作回路を自由に実装。

## 5. RPR4 Smart Probe の使命（RS-485のブラックボックス粉砕）

### 5.1 現場エンジニアの最大のペイン
Arduinoや組み込み開発のコミュニティで頻発する最大の悩み：
> **「RS-485通信が通らない……」**
> **「既設機器が何を喋っているか分からない（Modbus？ ボーレートは？ なぜ応答がない？）」**
> **「現場にオシロやロジアナを持ち込むのは重いし、高額すぎて買えない！」**

RPR4 Smart Probe（$25）は、この悩みを一撃で解決するキラーツールとなる。

### 5.2 RP2040 PIO による超リアルタイム解析 ＆ PWA
- **Auto-Baud 検出**: PIOが信号のパルス幅をナノ秒単位でサンプリングし、通信ボーレート（9600, 19200, 115200等）を即座に自動特定。
- **プロトコル自動デコード**: パケットヘッダやチェックサムを解析し、「Modbus RTU」「DMX512」「LN-485」を自動判別してスマホ画面に可視化。
- **RS-485 特化型ロジアナ PWA**: スマホのブラウザ上で、通信波形・トラフィック密度・CRCエラー・フレーム衝突を視覚的にリアルタイム表示。
- **完全絶縁によるスマホ保護**: 内蔵のTDA51S485HC（2500V耐圧）により、現場の怪しい通信線に接続しても作業員のスマートフォンが絶対に壊れない。

## 6. ソフトウェア・エコシステム（PWA ＋ クラウドAPI）

Androidネイティブアプリ（ArduinoDroid等）が抱える「16KBページサイズ問題」「OSセキュリティ制約」「終わりのないメンテ地獄」を完全に回避。

```
┌────────────────────────────────────────────────────────┐
│  ①【クラウド API】(Linux / arduino-cli)               │
│     - コードを受信 ➔ 1秒でコンパイル ➔ .hex を返送     │
│     - サーバー側でコア・ツールチェーンを一元管理       │
└───────────────────────────┬────────────────────────────┘
                            │ .hex (数KB〜数十KB)
                            ▼
┌────────────────────────────────────────────────────────┐
│  ②【スマホ PWA】(ブラウザ 1本で動作)                   │
│     - インストール不要、iOS / Android / PC 全対応      │
│     - RPR4 Smart Probe へ .hex をWebSerial転送         │
└───────────────────────────┬────────────────────────────┘
                            │ USB (WebSerial)
                            ▼
┌────────────────────────────────────────────────────────┐
│  ③【RPR4 Smart Probe】➔【ADX CORE-A】                 │
│     - 完全絶縁 RS-485 OTW で 3秒でファームウェア更新    │
└────────────────────────────────────────────────────────┘
```

- **現場の定数調整**: コンパイルすら不要。PWAからRS-485経由でATtiny1616のEEPROMパラメータを直接書き換え（所要時間0.1秒、オフライン対応）。
- **完全自動OTW書き換え**: RPR4がBREAK信号を送出すると、CORE-AのBMCが検知して自動ブート起動。**盤のフタを開ける必要すらなく、外付け端子台から3秒でスケッチ更新**。
