## 1. コア・ビジュアル哲学

> **「白の紙面（設計図）× 漆黒の銘板（工業構造）× JIS CUD 黄の一点（精密計器の目盛り）」**

ARLE.cc / ADX は「はたらく Arduino（The Working Arduino）」として、ホビー用ガジェットの派手さやゲーミング的な装飾を排し、**計測器・制御盤・設計図面が持つ清潔な秩序感と、現場の道具としての頼もしさ** をビジュアルで表現します。

### 3 つの設計根拠
1. **白ベースを正本とする（世界の PLC 標準への適合）**:
   - 暗色レジスト基板の実機写真・CAD 図面・高密度なスペック表・工場照明下や紙/PDF 印刷での視認性を最優先し、**純白 `#FFFFFF` ＋ 工業ライトグレー（RAL 7035 系）** をメインエリアとする。
2. **「色まで規格で選ぶ」一貫性（JIS Z 9103 採用）**:
   - アクセントカラーには、2018 年改定 **JIS Z 9103（安全色彩：CUDO 協働のカラーユニバーサルデザイン準拠規格）** のデジタル推奨黄 **`#F2E700`** を採用する。
   - 「なんとなくの好み」ではなく工学的・CUD（色覚多様性）根拠のある色を採用することで、規格体系全体およびピンアウト図の安全色と完全に調和させる。
3. **「白・黒・黄」の 3 色と 82 : 15 : 3 の引き算**:
   - 漆黒の工業銘板（`#12151C`）で画面の輪郭を締め、モノクロの「背景に消える」弱点を解消しつつ、JIS 黄の面積を **画面全体の約 3%（最大 5% 未満）** に厳格に絞ることで、工事現場の警告縞（トラ柄）ではなく **精密計器・スイス工業デザイン** の品格を保つ。

### 2.2 セマンティック・図面カラー（JIS Z 9103 / CUD v4 統一ファミリー）

UI の装飾色には使わず、**「工学的・安全上の意味がある場所（ピンアウト図 SVG、規格ステータス、警告バナー）」** だけに厳格に割り当てます。

| 意味・用途 | 図形・塗り用 HEX | 白地小文字用 HEX | ADX 20-Pin Bus 対応例 |
| :--- | :---: | :---: | :--- |
| **危険・禁止・主電源** | `#FF4B00` *(JIS 朱赤)* | `#C43800` | `VBUS` (Pins 17–20 / 5V 2–3A)、`MUST` 禁止事項、エラー |
| **警告・注意・アナログ** | `#F6AA00` *(JIS 橙・黒文字載せ)* | `#9A6700` | `P01 / AIN`、注意バナー（Caution） |
| **正常・安全・I2C** | `#00B06B` *(JIS 緑)* | `#007A4B` | `P05–P06 (I2C)`、検証完了バッジ（Gerber Verified） |
| **指示・必須・SPI** | `#1971FF` *(JIS 青)* | `#005A9C` | `P07–P10 (SPI)`、情報ノート（Note）、補助リンク候補 |
| **補助通信・UART** | `#4DC4FF` *(CUD v4 空色・黒文字載せ)* | `#006B9E` | `P03–P04 (UART)` |
| **クロック・特殊信号** | `#990099` *(JIS 紫)* | `#7A007A` | `P02 / EXTCLK (SWCLK)` |
| **システム専用・予約** | `#5B6472` *(＋斜線併用)* | `#47505E` | `S00 / OWD`（Card N.C. 必須） |
| **グラウンド・シールド** | `#12151C` | `#12151C` | `GND` (Pins 1, 4, 6, 11, 16) |

### 2.3 `#F2E700` 運用の 4 大禁止ルール（工事現場化・視認性低下の防止）

`#F2E700` は白背景上でのコントラスト比が **約 `1.3 : 1`** と極めて低く、同時に視覚的エネルギーが非常に強い色です。以下を厳守します：

1. **【MUST NOT】白地 `#FFFFFF` の上に `#F2E700` の文字・アイコン・細い 1px 枠線を直接置かない。**
2. **【MUST】`#F2E700` は必ず漆黒 `#12151C` と対で使う**（黒背景上の黄、または黄背景上の黒文字＝コントラスト `14.1 : 1`）。
3. **【MUST NOT】画面内の全バッジや全ボタンを黄色にしない**（黄色面積が 10% を超えると警告・工事現場のトラ柄に見える。常に **3% 前後** に抑える）。
4. **【MUST】色だけに情報を依存させない（CUD 二重符号化）**：ピンアウト図・警告枠・状態表示は必ず「色 ＋ 文字ラベル（`VBUS`, `MUST`, `8858`）＋ 枠線／アイコン／斜線」を組み合わせ、白黒印刷や多様な色覚でも 100% 判読可能にする。

## 3. 構図・レイアウト設計（採用パターン：① 主軸 ＋ ④ LP ハイブリッド）

検討の結果、**全ドキュメント共通の基本構図として「① 黒銘板ヘッダ＋白ベース（3 色完結）」** を採用し、**トップ LP（`arle.cc/`）のみ「④ 黒ヒーロー帯 → 純白セクション」** を組み合わせるハイブリッド構成を標準とします。

### 3.1 ドキュメント全ページ共通構図（① 黒銘板ヘッダ型）

```text
══════════════════════════════════════════════════════════════════════════  ← 2px #F2E700 ヘアライン
■ ARLE.cc / ADX          Hardware  Enclosure  Circuit      [Search] EN|JA  ← 黒銘板ヘッダ (#12151C)
──────────────────────────────────────────────────────────────────────────
│ [サイドバー]           │  [8858 ALPHA]  ADX-BUS-v4.2
│  #F8F9FB / 白基調      │  ▎ADX CORE-U rev4          ← 見出し左 4px #F2E700 バー
│                        │
│  ▎Overview             │  本文は純白 (#FFFFFF) ＋ 濃黒文字 (#12151C)
│   Standards            │  リンクは黒太字＋黄下線（ホバーで淡黄マーカー）
│   Hardware             │
│                        │  [ Pinout & Spec → ]  [ Gerber / STEP ]
│                        │    ↑ 黒背景＋下辺2px黄    ↑ #F4F5F7＋1px枠線
```

- **最上端ヘアライン**: サイト全幅に `2px` の `#F2E700` ラインを 1 本だけ通す。
- **グローバルヘッダー（工業銘板）**:
  - 背景 `#12151C`、左端に `10×10px` の `#F2E700` 精密スクエア刻印＋白反転した `ARLE.cc` ロゴ。
  - アクティブなナビ項目のみ下線 `2px solid #F2E700`。
- **サイドバー**: 白または極薄グレー（`#F8F9FB`）。選択中ページは左端 `3px solid #12151C`（＋背景 `#EAECEF` または極小の黄ドット）で、白地上で霞まず明確に示す。
- **ボタン階層**:
  - **Primary CTA**: 背景 `#12151C`、文字 `#FFFFFF`、下辺 `2px solid #F2E700`（矢印アイコンのみ `#F2E700`）。
  - **Secondary CTA**: 背景 `#F4F5F7`、文字 `#12151C`、枠線 `1px solid #B8C0CC`。
- **スペック表・ピンアサイン表**:
  - 表頭を `#181C24`（白文字）または `#EAECEF`（黒文字＋下線 `2px solid #12151C`）とし、数値・型番・ピン ID は等幅フォントで揃える。

### 3.2 トップ LP 構図（④ 黒ヒーロー → 純白セクションのハイブリッド）

- **`https://arle.cc/` および `/ja/` のファーストビューのみ**、漆黒パネル `#111318`（微細な 24px 設計グリッド背景）を採用し、`THE WORKING ARDUINO` ラベルとプライマリ CTA（`#F2E700` 背景＋`#111318` 文字）で強いブランド印象を残す。
- ヒーロー帯の下端に `2px solid #F2E700` の境界線を引き、その下の **3 本柱カード（Hardware / Enclosure / Circuit）**・運営母体（古川企画）フッター・および `/adx/...` 全ドキュメントは **完全な白ベース（① 型）** へ切り替える。

### 3.3 本文リンク表現のポリシー

- **基本方針（完全 3 色完結）**:
  - 通常時：文字 `#12151C`（`font-weight: 600`）＋ 下線 `2px solid #F2E700`（`text-underline-offset: 3px`）＋ ごく薄い淡黄下地（`#FAF7B8` を下端 30% のみ）。
  - ホバー時：背景を `#FAF7B8`（または `#F2E700`）の蛍光マーカー塗りへ変化。
  - **利点**: 白地に対して文字コントラスト `18.1 : 1`（AAA）を維持したまま、UI から青を排除し、青・緑・赤をピンアウト図と安全表示専用に温存できる。
- **運用上の調整余地**:
  - 長文仕様書（M2 同期後）でリンクが密集して読みづらく感じる場合のみ、CSS トークン `--arle-link` 1 箇所を JIS 系の濃青 `#005A9C`（白地比 `7.1 : 1`）へ切り替えられる設計にしておく。

## 4. タイポグラフィ・形状・写真プレゼンテーション

### 4.1 タイポグラフィ
- **欧文・UI サンセリフ**: `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- **和文サンセリフ**: `'Hiragino Sans', 'Hiragino Kaku Gothic ProN', 'Noto Sans JP', 'Yu Gothic', sans-serif`（初期は軽量性優先でシステムフォント活用）
- **等幅（工学諸元・コード・型番）**: `'JetBrains Mono', ui-monospace, SFMono-Regular, monospace`
  - 外形寸法（`88.0 × 58.0 mm`）、ピン名（`S00`, `P01`–`P10`, `ADX_P01`）、定格（`3.3V LVCMOS`, `5.0V / 2.0A`）、ドキュメント ID（`ADX-BUS-SPEC-v4.2`）は必ず等幅表記とし、テーブル内の数値には `font-variant-numeric: tabular-nums` を適用する。

### 4.2 形状・境界線・影（CAD / 制御盤の規律）
- **角丸（Border Radius）**: シャープに抑制する。
  - バッジ・タグ・テーブル: `2px`
  - ボタン・入力欄: `3px〜4px`
  - カード・コールアウト枠: `4px〜6px`（12px 以上の大きな丸みは使わない）
- **影（Box Shadow）**: 原則不使用。領域の区切りは **`1px solid #D8DCE3`** の明快な境界線で行う。

### 4.3 実機基板写真・SVG 図面の見せ方
- **基板写真（暗色レジスト＋白シルク＋ENIG パッド）**:
  - 純白の紙面の中に `#F4F5F7`（RAL 7035 台座）＋ `1px solid #D8DCE3` のフレームを設け、その中央に基板写真を配置する。暗色基板の輪郭と ENIG パッド・金属コネクタが最も立体的に際立つ。
- **SVG 図面（ピンアウト図・8858 寸法図）**:
  - 背景 `#FFFFFF`、寸法線・外形線 `#12151C`、色分けは第 2.2 節の JIS/CUD カラーのみ使用。ラベルは英語・記号で統一し、日英ページで同一 SVG を共有する。

## 5. ライト / ダークモード方針（Astro Starlight 実装指針）

- **正本テーマ（デフォルト）**: **Light（白ベース）**。
  - 工場・実験室の照明下、タブレット確認、PDF 印刷、実基板写真閲覧のすべてにおいて白ベースが基準となるため、Starlight の初回既定テーマを Light とする。
- **ダークモード（任意切替）**:
  - 夜間開発やダーク好みユーザー向けに Starlight 標準のテーマ切替を残す。
  - ダーク側のトークンは背景 `#0E1117`・サーフェス `#161B24`・本文 `#F4F4F5`・アクセント `#F2E700` とする。`#F2E700` は暗背景上でもコントラスト `14 : 1` 以上でそのまま破綻なく機能するため、ライト／ダーク間でブランド色がブレない。

## 6. 次のアクション（`site/` 適用チェックリスト）

本規定の方向性で問題なければ、以下の順で `site/`（Astro Starlight）へ反映します：

1. **Starlight デフォルトを Light テーマ化**（`site/astro.config.mjs` のヘッドスクリプトまたはカスタムテーマ初期化で初回既定を白ベースに設定）。
2. **`site/src/styles/custom.css` を本規定のトークンへ全面刷新**：
   - 上端 `2px` `#F2E700` ヘアライン＋黒銘板ヘッダー `#12151C`＋白ベース本文 `#FFFFFF`＋RAL 7035 サーフェス `#F4F5F7`。
   - トップ LP（`/` および `/ja/`）のヒーロー帯のみ漆黒パネル `#111318`（④ ハイブリッド）とし、配下を純白へ接続。
   - 3 色完結リンク（黒太字＋黄下線／ホバー淡黄マーカー）およびシャープな角丸・等幅数値を適用。
3. **ファビコン（`site/public/favicon.svg`）の色を `#F2E700` へ統一**（現行の緑ドット → JIS CUD 黄ドット）。
4. **M2（`docs/` SSOT 同期）および M3（JIS/CUD ピンアウト SVG 作成）** で本規定のカラーシステムをそのまま横展開する。
