# ADXとはなにか？

ADXはまずArduino UnoフォームファクタやRaspberry pi フォームファクタなどが持つ筐体に対する適合性の問題を解決しようとして始まった。
ADXでは、ワッシャーを使える十分なクリアランスと確実に締結できるネジ穴、ターミナルなどを引き出すための一貫したI/F辺の定義、拡張端子にIDCケーブルを用いることにより、基板間を柔結合としつつ、シールドのようにチェーンできるようにするこで、ボードの製造性を向上させ、また、家庭用3Dプリンタなど製造精度の低い装置でも容易に筐体を作れるようにすることを狙った。Arduino IDEなどの既存の開発UXを維持しながらも、スムーズに筐体への導入へと移行し、現場据付できることを目指している。

これらの要件から、8748フォームファクタを定義した。また、防水ボックスや電工ボックスへの取付、さらに専用筐体ではボードをスロットインできることを目指している。
