## 2. 「色まで規格で選ぶ」ARLE.cc の白×黒×JIS CUD 黄が、すごく ADX らしい

そして今日のお昼〜夕方にかけて、これまで1枚 HTML だった `site/` が **Astro 5 ＋ Starlight ＋ Cloudflare Pages** で `https://arle.cc` として本格開通しましたね。

なかでも読んでいて「うわ、これ上手いな」と唸ったのが、ビジュアル・トンマナの決め方です。

- 世界の主要 PLC メーカー 13社（Siemens、Beckhoff、WAGO、Phoenix Contact、ABB、KEYENCE、OMRON、三菱電機、横河電機など）＋ Arduino Pro まで並べて調べた結果、**「赤（重工）」と「緑・ティール（欧州モダン＋Arduino本家）」は超レッドオーシャン** だと見抜いたこと。
- そこで選んだのが、「なんとなく好きな黄色」ではなく、**2018年改定 JIS Z 9103（安全色彩・CUDO 協働の CUD 規格）のデジタル推奨黄 `#F2E700`**。しかも面積を **3%** に縛って、工事現場のトラ柄化を防ぎながら「白（設計図）× 黒（工業銘板）× 黄（精密計器の目盛り）」に落とし込んだこと。
- ついインディー電子工作サイトがやりがちな「黒背景＋ネオン緑」（旧 `site/index.html` もそうでしたね）を潔く脱ぎ捨てて、**あえて Light（白ベース）を正本テーマ** に据えたこと。

「はたらく Arduino」を名乗るサイトが、**色まで JIS と CUD の規格番号から引いてくる** のは、8858 の寸法や `ADX_P01` の命名と完全に同じ手つきで、すごく筋が通っているなと思いました。

### 煙を眺めながら、ちょっとだけ気になったこと（タスクではない雑談）

1. **「黒太字＋黄色下線（`#F2E700`）」の 3 色完結リンク、長文仕様書でどう見えるんだろう？**
   UI から青を排除して、青・緑・赤を全部ピンアウト図と安全表示のために温存する発想は、めちゃくちゃストイックで美しいです。
   ただ、M2 で `docs/spec/ADX_PINOUT.md` みたいな高密度な長文仕様書を流し込んでリンクが並んだとき、白地の上の `#F2E700` 下線が「リンク」としてスッと目に入るのか、それとも「蛍光ペンで大事な語句に線を引いた箇所」に見えて迷うのか（あるいは液晶によっては少しチカチカするのか）は、実物ページで長文を読んでみないと分からない紙一重のラインかもな、と思いました。
   （`site/dev_memo.md` に最初から「見づらければ `--arle-link` 1箇所を JIS 濃青 `#005A9C` へ切替再評価」と逃げ道が書いてあるのがさすがです。）
2. **トップページのステータスバーに「`白 / 黒 / JIS CUD 黄`」って書いてあるのがちょっと可愛い**
   `site/src/content/docs/index.mdx` と `ja/index.mdx` の上部に、`ADX 公式ドキュメントポータル · 白 / 黒 / JIS CUD 黄`（英語：`WHITE / BLACK / JIS CUD YELLOW`）とカラーパレットの設計仕様そのものが堂々と名乗られているのを見て、ちょっとクスッときました。制作中の名札っぽくもあり、「うちは色まで規格だぞ」という宣言っぽくもあり、初見の訪問者がどう受け取るのか少し面白いです。
3. **ちょっとした現場あるある 2 つ**
   - `site/dev_memo.md` の未完了チェックリストに「問題なければコミット・`main` push」と残ったまま、その 2 分後に `dev_memo.md` 自体がコミット＆push されているの、開発の勢いが出てて好きです（笑）。
   - ロゴ PNG 3点が `site/public/assets/logos/` と `site/src/assets/logos/` の両方に住んでいる（Astro の `logo` 設定と生 `<img>` タグの都合ですね）ので、将来ロゴを更新する日が来たら「あれ、片方だけ古いままだった！」の罠がひそかに待っていそうだな、と壁の隅にメモしておきます。

## 3. 喫煙所に来る 1 分前の「`SMD/THT` の1行と、線2本」がいちばんグッときた話

今日いちばん「あ、これぞハードウェア屋だなあ」と勝手に胸が熱くなったのが、実は **喫煙所に来るちょうど 1 分前（22:47 JST / 13:47 UTC）のコミット `af30379`** です。

公式サイトを開通し、34本の旧ドキュメントを片付け、図解付きの英語ブログ（`2026-11-23.md`）とヒーロー画像を出し、Hackaday ログ（`542 views`、じわじわ伸びてますね！）をつけ、Podcast Ep.04 まで書き上げた――そんな濃密な一日の終わりに、黙々と EasyEDA Pro に戻って **`Gerber_PCB1_2026-11-23.zip` の TopSilkscreen だけ** を微調整している。

ちょっと差分を覗き見してしまったんですが、変わっていたのは本当にピンポイントの3箇所だけでした。

1. `IDC Expansion Header 2x10P` のすぐ下に、**`SMD/THT`** の1行を追加
2. 左上 M3 穴（`6, 52`）の真下へ伸びる、クリアランス参照の縦線 1 本（`y = 47..52`）を追加
3. 右下 DataMatrix（M4）の上端を区切る横線 1 本（`x = 78..85, y = 17`）を追加

ブログ用の綺麗な 3D レンダリング画像（`adx_reference_card_v0_2026-11-23.png`）は、もうとっくに出し終わっているんですよね。
それでも画像を眺めながら「あ、ヘッダは `SMD/THT` 両対応ってシルクに書いといた方が親切だな」「右下のマーカー枠、上の線1本抜けてるな」って気づいてガーバーを出し直している。

それって、この基板を **「ブログ映えするレンダリング画像」ではなく、「実際に工場へ投げて、物理の FR4 として手元に置く本物」として見ている目** ですよね。
実際、あの緑基板に白シルクで全寸法・ピン表・キラル光学マーカーがびっしり刷られた姿は、リファレンス基板というより **「8858 規格そのものを印刷した FR4 製エンジニア定規」** みたいで、普通に机の端に1枚置いておきたいカッコよさがあります。
