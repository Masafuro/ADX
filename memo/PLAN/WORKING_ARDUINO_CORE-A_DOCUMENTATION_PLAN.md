## 1. 背景と再編の目的

### 1.1 背景
直前の検討において、大衆向けホビーボード（CORE-U）を安価（$19台）に提供しようとした試みは、競合（Arduino UNO R4 Minima等）の半導体スペック・価格競争に巻き込まれ、ADX本来の良さを削ぎ落とす懸念が生じた。
同時に、`r/Arduino` の一般的なユーザーは「そもそも基板を箱に入れない」ことも多く、単なる「ケースに入れやすいだけのマイコンボード」では付加価値が伝わりにくい現実がある。

そこで、安売り競争から身を引き、**プロジェクトの主役を「ADX CORE-A」および「RPR4 Smart Probe」へと差し戻す**決定を下した。

### 1.2 目的：「はたらくArduino」という等身大の提案
ただし、難解で高価な「産業用PLC・重電設備」の看板を掲げるのではない。
`r/Arduino` の住人（メイカー、DIYer、学生、エンジニア）に向けた、その少し手前にある等身大のコンセプト――**「Arduinoシリーズよりちょっとタフで、箱にいれやすい」＝「はたらくArduino (The Working Arduino)」** を提唱する。

## 2. コア・コンセプト：「はたらくArduino (The Working Arduino)」

### 2.1 コンセプトの定義
> **「The Working Arduino とは、Arduinoシリーズよりちょっとタフで、箱にいれやすいボードです。」**

机の上でブレッドボードを使ってLEDを光らせたりセンサーを試すのはとても楽しい体験です。  
しかし、そのスケッチを**部屋の隅、ガレージ、店舗のディスプレイ、家庭菜園の棚などに実際に置いて長く動かそうとしたとき**、多くの人が次のような小さな困りごとに直面します：

1. **固定しづらい**: ネジ穴の周りに余裕がなく、M3ネジを締めるとパターンを傷つけそうになる。
2. **箱に入らない**: 前後左右から線が飛び出していて、小さなケースに収めにくい。
3. **配線や熱が心配**: 長い配線を繋いだり夏場の密閉ケースに入れたりすると、ノイズや熱で不安定にならないか不安。
4. **現場での手直しが億劫**: ちょっとコードを直したいだけなのに、設置場所までノートPCを抱えていくのが大変。

「The Working Arduino」は、こうした**「机の上から、実際の暮らしや制作物の現場へ」ステップアップする際のちょっとした不便を、無理なく解消する道具**を目指します。

```
［ 机の上のホビー (Playground) ］        【 はたらくArduino (Workplace) 】        ［ 重厚長大な産業用 (Industry) ］
  - Arduino UNO / 各種互換機                - ADX 規格 ＋ CORE-A / RPR4             - 各社 産業用PLC
  - ブレッドボード / 卓上実験               - 部屋の隅、ガレージ、店舗、家庭菜園     - 数十〜数百万円、巨大制御盤
  - 壊れたら挿し直せばよい                  - 「ちょっとタフで、箱にいれやすい」     - 専用ラダー言語、ブラックボックス
  - 安価だが現場設置には工夫が必要          - 手の届く価格で現場据付しやすい         - 導入・維持コストが極大
```

### 2.2 身近で親しみやすい活用シーン
初学者が「これなら自分もやってみたい」と思える、地に足のついた用途を中心とします：
* **ガレージ・作業場**: 温度連動の換気ファン制御、ツール使用時の集塵機自動連動
* **店舗・ギャラリー**: ショーウィンドウの間接照明タイマー、作品の小さなからくり演出
* **ベランダ・家庭菜園**: 土壌水分センサーを使った自動水やり、日照データの定点ログ
* **部屋のインテリア**: 3Dプリントケースに収めた自作時計、壁掛け環境モニター

## 3. ドキュメント執筆における「3大黄金律」

### 原則 1: 初学者を絶対に萎縮させない（性能誇示の厳禁）
* **「たとえ真実であっても、性能を誇る表現は慎む。」**
* 「2500V耐圧」「-40℃〜+105℃耐熱」「自己発熱ゼロ」「鉄壁の保護」「完全絶縁」といった過剰で強烈な言葉は、初学者に「自分には関係のないプロの怖い世界だ」と感じさせ、引き返させてしまいます。
* 難解な数値やスペックを自慢するのではなく、**「配線が抜けにくい端子台」「熱がこもりにくい低消費電力の工夫」「誤配線したときのダメージを和らげる回路の配慮」**といった、誰もが安心できる優しい言葉に翻訳します。

### 原則 2: 思想（Concept）と個別仕様（Specs）の疎結合
* **トップレベル（README等）**: 「The Working Arduino」の考え方、8748規格の箱への入れやすさ、現場での使いやすさに集中します。
* **個別仕様（hardware/）**: CORE-AやRPR4の回路図、部品選定、測定データなどは個別ドキュメントに切り離し、トップレベルからリンクで誘導します。

### 原則 3: 開発中ステータス（Active R&D）の誠実な開示
* ADX CORE-A および RPR4 は**現在鋭意開発・試作中（Active R&D）**であり、最終仕様は未確定です。
* まだ検証中の機能（スマホからの書き換え機能など）を「すでに完成している標準機能」のように断定せず、「より便利に使えるよう研究開発を進めているツール」として等身大に伝えます。

## 4. 全体アーキテクチャと役割分担

```
       ════════════════════════════════════════════════════════════════════
                     【 ADX HARDWARE STANDARD (共通規格) 】
        ・8748 Form Factor (87.0 mm × 48.0 mm / M3ネジ4点固定 / 掴み幅)
        ・Unidirectional I/F Edge (外部接続を一辺に集約し、ケース加工を容易に)
        ・20-Pin Robust Bus (直スタック ＆ フラットリボンケーブル対応)
       ════════════════════════════════════════════════════════════════════
                                       │
            ┌──────────────────────────┴──────────────────────────┐
            ▼                                                     ▼
   【 現場で動かすメイン基板 】                          【 現場用アダプタープローブ 】
     ADX CORE-A (Active R&D)                              RPR4 Smart Probe (Active R&D)
     ・箱に入れやすく、配線しやすい設計                   ・PCやスマホと繋ぐための小型アダプタ
     ・抜けにくい端子台 ＆ 接続保護の配慮                 ・現場での点検や手直しを快適にする検証機
     ・(※最新状況は hardware/CORE-A/ 参照)                 ・(※最新状況は hardware/RPR4/ 参照)
```

* **ADX Standard (規格)**: ケースへの組み込みやすさと配線のしやすさを支えるオープンなハードウェア規格。
* **CORE-A (メイン基板)**: 設置場所で安定してスケッチを実行し続けるための、ちょっとタフなメイン基板（開発中）。
* **RPR4 (スマートプローブ)**: 設置場所にノートPCを持ち込まず、スマホ等から手軽にスケッチを更新・確認できる未来を目指した検証ツール（開発中）。

## 5. 新 `README.md` の章立て・ワイヤーフレーム案

### 1. Catchphrase & Hero Visual
- **Hero Visual**: ケースや端子台に綺麗に収まったボードと、手軽に接続できるプローブの落ち着いた図。
- **Catchphrase**:
  > **“ADX CORE-A: The Working Arduino”**  
  > *A tougher, enclosure-friendly board for running your Arduino sketches in the real world.*  
  > （Arduinoよりちょっとタフで、箱にいれやすい。あなたのスケッチを現場で動かすためのボード）

### 2. Overview: From Workbench to Workplace (物語と課題意識)
- ブレッドボードから、実際の設置場所（部屋、ガレージ、店舗、ベランダなど）へ連れ出すときの困りごと（ネジ止め、配線、ノイズ、手直しの手間）。
- 「The Working Arduino」という考え方の提示。

### 3. The Foundation: ADX Hardware Standard (規格としての性質)
- **8748 Form Factor**: M3ネジ4隅止め（Φ5.0mmワッシャークリアランス）、スナップフィット対応マージン。
- **Unidirectional I/F Edge**: 配線を1辺に集約し、ケースの開口加工をシンプルに。
- **20-Pin Bus**: リボンケーブル接続に対応し、ケース内の配置が自由。

### 4. The Flagship Solutions (現在開発中のハードウェア)
- **ADX CORE-A (Main Board - In Active R&D)**:
  - 現場据え付けを意識したメインボード。
  - ネジ不要で抜けにくいスプリング端子台、外部接続に対する保護の工夫。
  - *（※最新の回路設計や検証状況は [hardware/CORE-A/concept.md](hardware/CORE-A/concept.md) を参照）*
- **RPR4 Smart Probe (Adapter Probe - In Active R&D)**:
  - 現場でのメンテナンスを身軽にするための実験的アダプターツール。
  - スマホのブラウザ（WebSerial）から端子台経由でスケッチ更新や通信確認を行う仕組みを研究開発中。
  - *（※開発状況と仕様は [hardware/RPR4/](hardware/RPR4/) を参照）*

### 5. Arduino IDE Compatibility
- 慣れ親しんだArduino言語（スケッチ）の知識をそのまま活用可能。

### 6. The Modular CARD Ecosystem
- 電池カード（AAA 2S）、ユニバーサル試作カード（Prototyping CARD）など、目的に応じたモジュール拡張。

### 7. Documentation & Open Hardware Links
- 規格書、ハードウェア個別仕様書、ピン配置への誘導リンク。
