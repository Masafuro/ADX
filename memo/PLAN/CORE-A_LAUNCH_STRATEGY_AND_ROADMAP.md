### 戦略の核心：2つの時間軸の完全な同期（Synchronization）
1. **「CORE-AとRPR4の開発・成熟には時間がかかる」**
2. **「産業・現場・耐環境・完全絶縁という本質的価値を理解するコミュニティの育成にも時間がかかる」**

この2つの時間軸を**「1年間」という同じスパンで重ね合わせる**ことで、「来春に間に合わせる」という人為的な焦りから生じていた無理・無駄・妥協をすべて排除し、製品・製造・コミュニティ・UXを美しく統合する。

## 2. 背景と内省：CORE-Uの検討を通じて得られた決定的教訓

### 2.1 早期ローンチへの焦りと「安売り競争」の罠
来春のローンチに間に合わせ、かつ `r/Arduino` のような大衆メイカーコミュニティに親しみやすい顔で参入するため、一時的に「CORE-U（Arduino IDE直結・ケース親和型ボード）」の復活を検討した。
しかし、その検討過程で以下の構造的矛盾に直面した：
* Arduino UNO R4 Minima（$20.00 / 32bit Cortex-M4）に対抗するため、「$19台で売らねばならない」という価格競争の罠に陥った。
* 原価を下げるために、大電流給電USBを削り、CH342K（Dual UART）を削り、自社でOptiboot書き込み工程を背負い込むという**「機能を削って社内工数を増やす（無理・無駄・斑）」**本末転倒を引き起こした。

### 2.2 大衆（r/Arduino）コミュニティの冷徹な現実
なぜ「ケース親和型（Enclosure-Friendly）」というCORE-Uの付加価値が、価格競争に巻き込まれてしまったのか？
その根本的な原因は、顧客生態系の現実にあった：
* **「r/Arduinoの大多数のユーザーは、そもそも基板を箱に入れない。」**
* だからこそ、Arduino社は20年間、四方コネクタでネジ穴が不揃いなあの歪なUNOフォームファクタを使い続けて平気でいられる。
* 「箱に入れない人々」に対してどれだけケース組込性をアピールしても付加価値として認識されず、**「半導体チップのスペック（Flash容量・クロック・価格）」の比較軸でしか見てもらえない**。

### 2.3 結論：他人の土俵（大衆ホビー）に降りてはならない
ADXが提供すべき真の価値は、ホビーマイコンのスペック競争ではなく、**「現場で絶対に壊れないインフラ品質」「-40℃〜+105℃耐熱」「完全絶縁」「スマホで現場保守できる新体験」**である。
大衆に迎合するのではなく、**「このタフさを痛切に求めている現場のエンジニアやプロ」**に向き合うことこそが王道である。

## 3. この戦略によって得られる「4大統合メリット」

### 3.1 ローンチ時SKUの極小化（Minimal & Powerful SKU）
* CORE-Uという派生モデルを排除し、**「CORE-A（$28.00）」＋「RPR4 Smart Probe（$25.00）」** という2大SKUに全精力を集中する。
* 100pcs固定ロットの小ロット生産体制において、製造ライン・部品調達・検査治具・個別梱包・マニュアル作成のすべてをシンプルに維持できる。

### 3.2 競合不在のブルーオーシャン確立
* **vs Arduino**:
  * 「机上でLチカして遊ぶならArduinoへどうぞ。車載、冷凍庫、屋外展示、工場、雷サージやノイズが怖い本気の設備ならADXへ」と、全く争わずに住み分けられる。
* **vs 産業用PLC**:
  * 数十万円して専用ラダー言語が必要な重厚長大なPLCに対し、「Arduino IDEで直感的に書けて、完全絶縁で、スマホから3秒で直せるタフな基板」という新世代の選択肢を提供する。

### 3.3 ハード・ファーム・Web PWA・現場UXの完全な一体感
* 急造品では絶対に達成できない**「RPR4 Smart Probe（RP2040 PIO） ＋ スマホWebSerial PWA ＋ CORE-A（BMC/ATtiny1616）」のシームレスな統合体験**を、1年かけて極限まで磨き上げられる。
* 現場の制御盤のフタを開けずに、外付け端子台からスマホで3秒OTW書き換えができる「魔法のようなUX」を実現する。

### 3.4 事前ニーズの確実な吸い上げとファン形成
* 1年という時間を使って、現場で実際に制御盤を組んでいるエンジニアや、過酷環境で展示を作っているクリエイターと対話し、フィードバックを製品に還元できる。

## 4. 1年間の実行ロードマップ（4フェーズ）

```
┌─────────────────┬─────────────────┬─────────────────┬─────────────────┐
│   Phase 1 (Q1)  │   Phase 2 (Q2)  │   Phase 3 (Q3)  │   Phase 4 (Q4)  │
│  設計・試作FIX  │  PWA ＆ 国内検証│  待機列・CS準備 │  世界ローンチ   │
└─────────────────┴─────────────────┴─────────────────┴─────────────────┘
```

### Phase 1: ハードウェア確定 ＆ 極限耐久テストの発信（3ヶ月）
* **ハードウェア**:
  * **ADX CORE-A rev2**: アートワーク設計FIX、JLCPCB試作発注（100pcs）。
  * **RPR4 Smart Probe**: RP2040 ＋ 絶縁RS-485トランシーバー回路の試作FIX。
* **技術マーケティング（種まき）**:
  * 「-40℃（冷凍庫）〜 +105℃（加熱炉）での耐久動作テスト」
  * 「2500V耐圧サージをRS-485線に放電してもPCが絶対に死なない実験」
  * Redditの `r/embedded`, `r/electronics`, `r/PLC` 等へ、技術的な事実に基づく検証動画・記事を発信。

### Phase 2: スマホPWAの洗練 ＆ 国内現場アルファテスト（3ヶ月）
* **ソフトウェア**:
  * RPR4 WebSerial PWA アプリのUI/UX完成（自動ボーレート検出、Modbus自動デコード、OTWファーム書込）。
  * クラウドコンパイルAPIの整備。
* **実地検証（アルファテスト）**:
  * 100pcsの初期ロットを活用し、国内の信頼できるエンジニア、大学研究室、展示クリエイター等へ10〜20台を先行配布。
  * 実際の現場での使用感、フィードバック、改善点を収集。

### Phase 3: コミュニティ待機列形成 ＆ 最終ブラッシュアップ（3ヶ月）
* **コミュニティ・マーケティング**:
  * アルファテストでの現場導入事例、推薦の声（Testimonials）、実働動画を公開。
  * **Crowd Supply Pre-launch（事前登録）ページ** を公開。
  * 目標: ローンチ前に **1,000名以上のメールアドレス登録（待機列）** を獲得。
* **量産体制準備**:
  * 100pcs固定ロットを前提としたサプライチェーン（JLCPCB / 部品在庫）の最終点検。
  * 個別包装資材（ESD袋、Mouser/Crowd Supply対応バーコードラベル）の準備。

### Phase 4: Crowd Supply 世界ローンチ ＆ 配送（3ヶ月）
* **ローンチ構成**:
  1. **ADX CORE-A (単体)**: **$28.00**
  2. **RPR4 Smart Probe (単体)**: **$25.00**
  3. **ADX Field Starter Kit (CORE-A + RPR4 + 20P Cable + CARD)**: **$53.00 〜 $59.00**
* **グローバル展開**:
