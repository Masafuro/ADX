## 1. 文章トーン＆マナー（Style & Voice）チェック

| チェック項目 | 合格基準 | チェック |
| :--- | :--- | :---: |
| **ペイン煽りの排除** | 「〜で困っていませんか？」「〜で失敗した経験は？」などのうさんくさいLP風マーケティング表現、ネガティブな語り口が冒頭や本文に一切ないこと。 | [ ] |
| **誇大広告・ハイプの排除** | "Revolutionary", "Ultimate", "Indestructible", "Next-Gen Standard", "Arduino Killer" などの煽り文句が一切使われていないこと。控えめで具体的な事実ベースであること。 | [ ] |
| **誠実なスペック開示<br>（Radical Candor）** | 「Arduino UNO を完全代替」と謳っていないこと。ATtiny1616（Flash 16KB）の制約を開示し、「小〜中規模の制御・センサー・モーター駆動向け」というスコープが正直に書かれていること。 | [ ] |
| **「Arduino互換」誤認の防止** | 単に「Arduino-compatible（Arduino互換）」と名乗らず、**「Arduino-programmable（Arduino IDE対応 / Arduino IDEで開発可能）」**と表現していること（※UNOシールドやピン配置の物理互換であると誤認させないため）。 | [ ] |
| **平易で直感的な解説** | 難解な回路理論や威圧的な専門用語を押し付けず、中学生や初学者でも「なぜその工夫がされていて、何が嬉しいのか（Why）」が1秒で理解できること。 | [ ] |
| **クラフトマンシップの品格** | 自慢や売り込みではなく、「電子工作を綺麗に箱へ収めるための誠実な道具」としての落ち着いた温かみがあること。 | [ ] |

## 2. 規格（Standard）と製品（CORE-U）の分離チェック

| チェック項目 | 合格基準 | チェック |
| :--- | :--- | :---: |
| **産業用看板の完全撤去** | トップページや主題から「産業用」「工業規格」「PLC代替」「Modbus」などの重い言葉が完全に排除され、「Arduino派生ボード」としての顔になっていること。 | [ ] |
| **CORE-A の位置づけ** | CORE-A（耐熱・絶縁RS-485）が主題に混ざっておらず、最下部の将来展望（Future Horizon）に「同じCARDが使えるタフな派生ボードも出るかも？」程度に小さく添えられていること。 | [ ] |
| **ADX規格（Form Factor & Bus）の独立記述** | 8748外形、M3ネジ穴＋Φ5.0mmワッシャークリアランス、掴み幅、単一I/F辺集約、20P IDCケーブル接続という「規格としての性質」が、CORE-Uの個別仕様と混ざらず独立して章立てされていること。 | [ ] |
| **CORE-U（個別MCUボード）の独立記述** | 「Arduino IDE ＋ megaTinyCore ＋ USB Type-C で開発できるコアボード」として明確に章立てされ、電源や回路等の流動的な詳細仕様は断定せず「詳細は各ハードウェアドキュメントを参照」という形で切り分けられていること。 | [ ] |

## 3. 「筐体フレンドリー（Enclosure-Friendly）」表現チェック

| チェック項目 | 合格基準 | チェック |
| :--- | :--- | :---: |
| **特定ケース誤解の防止** | 「タカチ等の特定既製ケースに無加工でポン付けできる」と誤認させる表現がないこと。 | [ ] |
| **あらゆる筐体への組付け性** | 自作3Dプリントケース、既製ボックス、電工・防水ボックスなど、「あらゆる筐体への組み込み設計を容易にするための3大要素（固定保持・I/F辺集約・IDCケーブル配置）」として論理的に語られていること。 | [ ] |
| **IDCケーブルトポロジーの明記** | 20P拡張バスが直スタックだけでなく「市販フラットIDCケーブル接続」も標準規格であり、薄型ケース横並びや立体配置など筐体内部の空間形状に自由に適応できることが書かれていること。 | [ ] |

## 4. CORE-U ボード＆開発環境チェック

| チェック項目 | 合格基準 | チェック |
| :--- | :--- | :---: |
| **Arduino IDE ネイティブ体験** | ブートローダー不要、megaTinyCore ＋ USB Type-C による安定した開発環境で、手持ちのArduino IDEから即座にスケッチを焼ける安心感が伝わること。 | [ ] |
| **ハードウェア詳細への誘導** | 電源構成（理想ダイオード、Type-Cポート数等）やピンアサイン等の詳細仕様はトップレベルで断定的に語りすぎず、`hardware/CORE-U/` 配下の個別ドキュメントを参照する構成になっていること。 | [ ] |
| **誠実なスペック・スコープ** | ATtiny1616（Flash 16KB）を採用した軽量・コンパクトなボードであり、小〜中規模の制御・センサー・モーター駆動向けであるというスコープが明確であること。 | [ ] |
