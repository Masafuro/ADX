# ADX 市場進出戦略（Go-to-Market Strategy）

- **対象プロジェクト**: ADX Modular Hardware Ecosystem (`8858 Form Factor`)
- **最終ゴール**: Crowd Supplyでのクラウドファンディング成功を経由した、**Mouser Electronicsでの世界流通**
- **検討日**: 2026-11-24

---

## 1. 背景と課題：日本からCrowd Supplyへ出ようとする際に衝突する「構造的な矛盾」

個人が日本（地方）を拠点として、米国のCrowd Supply経由でMouser流通を目指そうとした場合、以下の4つの矛盾（デッドロック）に衝突し、単一プロダクトのままでは動きが取れなくなる。

### 矛盾①：「事前のユーザー実績」と「事前販売の制約」のジレンマ
- Crowd Supplyはキュレーション型プラットフォームであり、審査通過およびキャンペーン成功のために**「申請前の需要証明・ユーザーのフィードバック（Community実績）」**を強く求める。
- 一方で、すでにTindie等で一般販売されている同一製品を持ち込むことは、クラウドファンディングの趣旨（「量産・スケールアップのために今支援する理由」）に反するとして審査で不利になるほか、出荷完了までの並行販売禁止などの制約がある。
- ハードウェアとして完成度が高く「わざわざv2へ改版する必然性がない」場合、先行販売（v1）→ 改版してクラファン（v2）という王道ルートが取りづらい。

### 矛盾②：地理的制約と国際送料コストの壁（物理サンプル配布の困難）
- 米国現地で直接手渡ししてテスターを募ることは物理的に不可能。
- SNS（X等）のDMで見知らぬ海外ユーザーから住所を聞き出して発送するのは、双方の心理的ハードル・手続き負荷が高すぎる。
- 米国の組み込みSIerや設計会社へ「評価サンプル（Engineering Sample）」を直送する案も、**無償配布では国際送料コストが個人開発者の負担として直撃する**ためスケールしない。

### 矛盾③：無名状態からのオンラインPRの限界（閑古鳥問題）
- GitHubやHackaday.ioに仕様書や開発ログを順次公開しても、実機や導入実績がない段階では基本的に閑古鳥になる。
- Reddit等への投稿はスパム回避のため連投できず、実質的に「1回勝負」に近い。無名のまま投稿しても良くて数件のコメント、悪ければ無反応で終わり、Crowd Supplyの審査に耐えうるコミュニティ実績にならない。
- 海外ハードウェアメディア（Hackaday等）への売り込みも、実績や強い絵面がない段階では採用されるかどうかが不確実（運要素が大きい）。

### 矛盾④：単体マイコンボードの単価・差別化ハードル
- Crowd SupplyおよびMouser流通は物流・SKU管理コストが発生するため、低単価なマイコンボード「1枚単体」では採算が合いにくく、審査を通過しにくい。
- また、8858フォームファクタの真価（M3ネジ穴による筐体固定、20ピンバスによるスタック・ラック収容）はボード単体では伝わりにくく、エコシステムとしての提示が必須になる。

---

## 2. 解決策：プラットフォーム別「製品ライン完全分離」戦略

同一製品の「評価版／量産版」というグレーゾーンで悩むのではなく、**Tindie向け製品とCrowd Supply向け製品を「MCUおよび製品構成ごと完全に別製品」として分離する**ことで、上記の矛盾をすべて解消する。

| 項目 | Phase 1: Tindie（布石・検証・実績作り） | Phase 3: Crowd Supply / Mouser（本命・世界流通） |
| :--- | :--- | :--- |
| **メインボード** | **ADX CORE-C** (`CH32X035` / RISC-V) | **ADX CORE-U** (`ATtiny1616-MNR` / AVR) |
| **拡張カード** | **Prototype CARD**（ユニバーサル基板型）のみ | **AAA拡張カード**等の実用拡張カード群を本格展開 |
| **販売形態** | CORE-C ＋ Prototype CARD のセット販売 | CORE-U ＋ 実用拡張カード群のシステム／キット構成 |
| **位置づけ** | 8858規格を手軽に試すためのDIY・評価用エントリー | 長期供給・実務投入を見据えたモジュラー制御プラットフォーム |
| **狙い** | 買い手負担の送料・売上でコスト回収しつつ、実ユーザーからのフィードバックと販売実績を獲得する | Tindieと完全別製品とすることで規約リスクを排除し、十分な単価とエコシステム性で審査・Mouser流通を突破する |

### この分離が有効な理由
1. **規約・審査上のリスクがゼロになる**: `CH32X035` と `ATtiny1616-MNR` はアーキテクチャ・回路・ファームウェアともに完全な別製品であり、並行販売や既存品持ち込みの問題が発生しない。
2. **送料コスト問題を自然に解決できる**: Tindieを経由することで、商品代・国際送料ともに買い手負担となり、かつ「送料を払ってでも8858を試したい」という本気度の高いユーザーから質の高いフィードバックを得られる。
3. **本命の弾を温存できる**: 実用的な拡張カード群（AAA拡張カード等）をTindieに出さず温存することで、Crowd Supplyローンチ時の新規性と注目度を最大化できる。
4. **市場適性とチップ選定が一致する**: 安価で手軽なWCH製RISC-VはTindieのアーリーアダプター層と相性が良く、Microchip製・5V動作・長期供給のATtiny1616はMouserを利用する実務エンジニア層と相性が良い。

## 3. 実行ロードマップ

### Step 1: Tindieでの初期展開（実績とフィードバックの獲得）
- **対象製品**: `ADX CORE-C` (CH32X035) ＋ `Prototype CARD` セット
- **アクション**:
  - まずはTindie向けに小ロットで製造・出品を開始する。
  - 実用拡張カードは出さず、ユニバーサル基板型のPrototype CARDとの組み合わせにより「8858規格での物理固定＋20ピンバス拡張」の基本体験を提供する。
  - 購入者からのフィードバックを収集し、8858規格の使い勝手や要望をドキュメント・次期カード設計へ反映する。

### Step 2: 実績を伴うメディア・コミュニティ展開
- **タイミング**: Tindieで一定の販売実績・実機写真・ユーザーからの反応が得られた段階。
- **アクション**:
  - 「仕様書の段階」ではなく、「すでにTindieで実機が販売・利用されているオープン規格」というファクトを添えて、海外メディア（Hackaday Tip Line、CNX Software等）へ情報提供を行う。
  - メディア露出や実機デモの公開と足並みを揃えて、Reddit（`r/embedded`, `r/hardware` 等）やSNSへ展開し、コミュニティの議論と認知を広げる。

### Step 3: Crowd Supply申請 → Mouser流通
- **対象製品**: `ADX CORE-U` (ATtiny1616-MNR) ＋ 拡張カード群（`AAA拡張カード` ほか）
- **アクション**:
  - Step 1・2で得られた「8858規格の実際の販売実績・ユーザーフィードバック・コミュニティの反響」を申請書のCommunity欄および実績として提示する。
  - 単体ボードではなく「実用拡張カードを備えたエコシステム／スターターキット」として適正な価格帯・ボリュームを設計し、Crowd Supplyでのファンディング成功とMouserでの継続流通を目指す。

## 4. 実際の検討結果

まず、CORE-Cが成り立たない。CH32X035、CH32V003、CH552などを色々探すが、ATtiny1616 + CH342K の代わりになるようなものが見当たらない。
もし、CORE-UをTindieに出すならば、Crowd Supplyで出す場合、CORE-Uがメインのローンチプロジェクトとして使えないということになる。
仮に、Tindieは終了した、と言いはるとしても、別のMCUボードが必要になるのか、それとも、AAA CARDやDC24V/48V iso CARDなどで新しい拡張カードやスターターキットとしてローンチしうるのか。やはり無理が出てしまう。
かといって、CORE-AとRPR4は開発には長い時間がかかる。
RP2040やESP32をベースとしてCOREボードを考えてもよいが、如何せん、SKUが増えてしまう。
