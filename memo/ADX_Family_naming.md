# ADXファミリー命名規則

## 結論
ADX CARD | 製品識別名 | グレード
ADX CORE | 製品識別名 | グレード

### 例
ADX CARD
機能・仕様を表す名称 ＋ 必要に応じてグレード

ADX CARD Power AAA 2S
ADX CARD Power DC12V24V ISO EX
ADX CARD Expansion Pi Zero
ADX CARD DC12V/24V I/O EX
ADX CARD Ethernet
ADX CARD DC-48V ISO EX


ADX CORE
モデル・プラットフォームを表す名称 ＋ 必要に応じてグレード

ADX CORE A EX
ADX CORE RP
ADX CORE ESP32
ADX CORE U
