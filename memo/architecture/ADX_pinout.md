# ADX Pinout Specification (v3)

## 1. 概要 (Overview)
ADX Pinout は、ADX エコシステムのコアボード（CORE-A、CORE-R 等）および拡張カード（CARD シリーズ）共通で利用可能な **20ピン（2×10ピン 2.54mmピッチ）拡張コネクタ規格** である。

産業現場での長期信頼性を担保するため、**「VSYS 幹線大動脈（大電力給電 / 3.8V〜5.5V 許容） ＋ 3.3V 信号神経網（低ノイズ・近代半導体直結）」** という二層アーキテクチャを採用している。

---

## 2. コネクタ・電気仕様 (Connector & Electrical Specification)

* **形式:** 2×10ピン 2.54mmピッチ ピンヘッダ / ソケット（ラッチ付き Eject Header 推奨）
* **幹線電源電圧 (VSYS):** **公称 5.0V DC（動作許容範囲: 3.8V 〜 5.5V DC）**（Pins 1〜4 束ね、最大 2.0A〜3.0A 双方向給電）
  * USB 5V 入力からのショットキーダイオード降下（0.3V〜0.5V）やポリスイッチ（PTC）、長配線による電圧ドロップを前提とした準安定・粗電源幹線。
* **信号論理電圧 (Logic):** **3.3V LVCMOS 準拠**（VIH_min = 2.0V, VIL_max = 0.8V）
* **保護要件:**
  * 信号線（Pins 6〜19）は全ピン TVS ダイオードアレイ（ESD 保護 ±15kV）の実装を推奨。
  * 高速通信線（SPI等）は 22Ω〜33Ω の直列ダンピング抵抗の実装を推奨。
* **各基板の電源設計ルール (Point of Load):**
  * 各拡張カードおよびコアボードは Pins 1〜4 の `VSYS` を受電し、オンボードの安価な小型 LDO（ME6211 等）でローカルにクリーンな 3.30V を生成して使用する。

## 3. ピン配置図 (Header Pinout Layout)

```text
                    【 ADX Pinout v3 (20P Eject Header) 】

         VSYS (主電源幹線)   [ 1]  [ 2]   VSYS (主電源幹線)
         VSYS (主電源幹線)   [ 3]  [ 4]   VSYS (主電源幹線)
         N.C. (短絡防止帯)   [ 5]  [ 6]  ADC0 (3.3V アナログ入力 / GPIO)
         ADC1 (3.3V AIN)     [ 7]  [ 8]  GND (シールド ①)
         EXTCLK / PWM / GPIO [ 9]  [10]  GND (シールド ② / 通信分離)
         UART_TX (3.3V 出力) [11]  [12]  UART_RX (3.3V 入力)
         I2C_SCL (3.3V)      [13]  [14]  I2C_SDA (3.3V)
         SPI_SCK (3.3V 出力) [15]  [16]  SPI_MISO (3.3V 入力)
         SPI_MOSI (3.3V 出力)[17]  [18]  SPI_CSn (3.3V 出力)
         GPIO / INT (3.3V)   [19]  [20]  GND (シールド ③)
```

## 5. 設計上の配慮 (Design Rules)

1. **VSYS 幹線ゾーン（Pins 1〜4）と Pin 5 短絡防止帯:**
   * Pins 1〜4 は基板上でベタパターン（プレーン）として接続し、配線抵抗を最小化すること。
   * Pin 5 は意図的に未接続（N.C.）とし、VSYS 強電部と Pin 6 アナログ信号線の物理的沿面距離を確保。
2. **クロストーク低減グラウンド配置:**
   * Pin 8, 10, 20 に GND を分散配置し、リボンケーブルのフラット配線時において、クロック信号や通信線間のシールド効果を発揮する。
3. **完全なる 3.3V 直結性:**
   * すべての信号線は 3.3V ネイティブであるため、ATtiny1616（3.3V駆動）、RP2040、ESP32、STM32 等の MCU、および各種最新センサーチップとレベルシフタなしで 100% 直結可能。
4. **電源保護と調停の極小化 (Point of Load 思想):**
   * VSYS が 3.8V〜5.5V の範囲で変動することを許容するため、高価な理想ダイオード等は不要。USB 入力部にショットキーダイオード（逆流阻止）とポリスイッチ（短絡保護）を直列に置くだけで、低コストかつ完全な PC 保護が成立する。
   * 各カード・コアボードは手元で小型 3.3V LDO によりローカルレギュレーションを行い、ノイズ伝播と電圧降下を完全に遮断する。
