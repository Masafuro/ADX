# 寸法ってなんの？規格と1mmの攻防

最近、ADXのIDC 20P Box Headerのフォームファクター上の位置を1mm、Y方向にずらした。
ADXではこういうことばかりやっていて、全然、完成しない（笑）ECHOにもよく怒られているかも。
そして、1mmずらせば、規格は全部ずれる。過去のボードも全部やりなおしだ（笑）
しかし、この1mmという寸法の違いが全然異なる世界を生む。
今回のIDC box headerについて言えば、元々のX,Yが44, 48mmから44,47mm座標に変更された。元々の44,48mmでも、IDC 20P Box headerとEject Headerの両方に対応していたが、47mmにすることで、それらの対応は残しつつ、新たにSMD Box Headerを利用できるようになった。1mmずらすだけで使える部品の幅は全く異なる。

この問題の厄介さは、長さという寸法が、実際には無限の可能性を持っていることに由来している。例えば、あなたが定規を作ることを考えてみてほしい。さて、何cmや何インチの定規を作るだろうか？20cmくらい（Podcastではインチ系で表現すべきかも？）60cmくらい？そして、仮に、10cmから100cmの間にすると決めたとしても、そこには無限の可能性がある。
市販の定規もたくさんある。小さくすれば収まりはよく持ち運びやすいと言える。でも大きな長さはうまく測れない。では大きくすれば？今度は箱やバッグに入らなくなる。実際には、寸法そのものは適当に決めることができるけれども、市販のペンケースのサイズや工具箱のサイズは色々ある。ある寸法なら、100種類の工具箱に入るけど、5mm長いというだけで、20種類の工具箱にしか入らない、ということもある。
そして、さらにはそこに製造性と輸送性も関わってくる。安い郵便の規格に入るだろうか？工場ではどうやって作るのか？例えば、1000mmのバーから定規を切り出す時、何個取れるのか。スティーブジョブズの親が木工をしていたというが、これを木工では「木取図」という。そして、ADXのようなマイコンボードはパネリングの製造となって表れてくる。

ちなみに、ソニーの開発18か条（ソニーの法則18ヶ条）」
第3条：サイズやコストは可能性で決めるな。必要性・必然性で決めろ。

というマントラもある。
ADXでは端子を出すI/O Edgeの66mmを規定しているが、この66mmにはEthernetのRJ45端子が何個入るのか、産業用のSpring Clamp Terminalなら何ピン設置できるのか。RS-232CのD-SUB9ピンはどうか？という戦いの中で揉まれて、作られている。そして、ボード全体のサイズを規格する8854フォームファクターでも、この基板を入れる筐体込にDINレールに設置するPLCの100mm*100mm以内に収まるようにしている。

ともかく、ここで言えることは、寸法を決めることに終わりはないということだ（笑）
