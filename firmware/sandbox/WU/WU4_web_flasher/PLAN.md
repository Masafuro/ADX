# WU-4 開発計画書: 市販安価ドングル ＆ WebSerial (PWA) 直結実証

## 1. 開発の背景と目的

MR32 プロトコル仕様書（[`ADX_FIELD_NETWORK_SPECIFICATION_PROPOSAL.md`](../../../../memo/ADX_FIELD_NETWORK_SPECIFICATION_PROPOSAL.md)）の核心思想は、**「専用の高価なライターや独自ドングルを全廃し、市販の数百円の USB-RS485 ドングルとスマートフォン／PC の標準ブラウザだけで、フィールド機器の点検・ファームウェア更新を完結させる」** ことにあります。

先ほど Milestone 4 (M4) において、Python による 12KB OTW 書き換え（5.96秒）とユーザーアプリ自動起動が実機（ADX Core-D）で完全実証されました。

本 **WU-4 (Warm Up 4)** では、この成果をブラウザ環境へと一気に昇華させます：
- **環境構築ゼロ**: Python もドライバ設定も pip も不要。Chrome や Edge でページを開くだけで接続可能。
- **PWA (Progressive Web Apps)**: オフライン動作、ホーム画面へのインストール、Android スマホ対応。
- **リッチ・サイバーコンソール UI**: 工業用サイバーパンク調のダークグラスモーフィズムデザインで、プログレスバー、生パケット可視化、リアルタイム診断を提供。

## 3. アプリケーション機能要件 (Web Flasher PWA)

### 3.1 接続・通信管理
- **ワンクリック接続 (`navigator.serial.requestPort`)**:
  - ポート選択ダイアログを表示し、COM22（CH340）を選択して 115,200 bps 8N1 で即座にオープン。
  - 接続状態インジケータ（ステータス LED、接続先ポート情報、切断ボタン）。
  - 自動バッファフラッシュとタイムアウト管理。

### 3.2 デバイス診断 ＆ 健全性チェック
- **[Ping] ボタン (`CMD_BOOT_PING: 0x10`)**:
  - デバイス応答（ATtiny1616, Flash 16KB, Page 64B）を取得し、RTT を表示。
- **[Protection Test] ボタン**:
  - 保護領域 Page 0 への書き込みを試行し、`STATUS_ERR_PARAM (0x03)` による安全拒絶を確認。

### 3.3 12KB フル OTW ファームウェア更新
- **ファイル入力**:
  - `.bin` / `.hex` ファイルのドラッグ＆ドロップ、またはファイル選択。
  - **プリセット一発ロード機能**: M4 で実証した LED 交互点滅アプリ（`app_12k.bin`）を内蔵し、ファイルを選ばずとも「デモファームを書き込む」をワンクリックで実行可能。
- **ストリーミング書き込み**:
  - 192 ページ（768 チャンク）を連続ストリーミング送出。
  - 円形／リニア・デュアルプログレスバー、転送速度（KB/s）、経過時間、推定残り時間をリアルタイム表示。
  - 各ページの Flash ハードウェア CRC16 を即時照合。

### 3.4 ユーザーアプリケーション起動 (`CMD_BOOT_APP_EXEC: 0x14`)
- **[Launch App] ボタン**:
  - 書き込み完了時（または手動クリック時）にコマンド `0x14` を発行。
  - Core-D を `0x1000` へジャンプさせ、LED 交互点滅を即座に開始させる。

### 3.5 パケットインスペクター（生データ可視化）
- 送受信したすべての MR32 パケット（32バイト固定長）を HEX および ASCII でリアルタイム表示。
- コマンド種別ごとのカラーバッジ（Ping: Cyan, Write: Gold, CRC: Green, Exec: Purple, Reject: Red）。

## 6. 実機検証シナリオ ＆ 合格基準

| ステップ | 操作内容 | 期待される挙動 | 合格基準 |
| :---: | :--- | :--- | :---: |
| **Step 1** | ブラウザで Web Flasher を開く | リッチな UI が表示され WebSerial が利用可能 | 画面正常表示 |
| **Step 2** | 「Connect」をクリックし COM22 を選択 | RS-485 ポートが 115,200 bps で接続される | 接続インジケータ点灯 |
| **Step 3** | 「Ping」をクリック | Core-D からデバイス情報（ATtiny1616）返信 | RTT 表示 ＆ PASS |
| **Step 4** | 「12KB OTW Flash」を実行 | 192 ページがプログレスバーと共に連続転送 | **6 秒前後で 100% 完了** |
| **Step 5** | 「Launch App」を実行 | コマンド 0x14 送信後、Core-D がジャンプ | **LED 交互点滅開始** |
