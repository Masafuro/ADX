## 4. トラブルシューティング ＆ よくある要因

| 現象 | 推定要因 | 推奨対策 |
| :--- | :--- | :--- |
| ドングルを挿しても OS ダイアログが出ない | スマホの OTG 機能が OFF | 一部の端末（OPPO, OnePlus, Vivo等）は「設定 > その他の設定 > OTG接続」をオンにする必要があります。 |
| ステータスが `NO_DEVICE` のまま | USB-OTG アダプタの接触不良 | アダプタやケーブルを抜き差しし直すか、充電専用ケーブルになっていないか確認してください。 |
| ポートは開くが応答が返らない (Timeout) | 配線または電源の未接続 | ターゲットマイコンに電源が供給されているか、TX/RX がクロス結線（ドングル TX ─ マイコン RX, ドングル RX ─ マイコン TX）になっているか確認してください。 |
| CRC エラーが表示される | ボーレートまたは極性の乱れ | ターゲット側の通信クロック（19,200bps）および Common GND の接続を確認してください。 |
