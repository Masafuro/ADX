# PL4モデム PC-マイコン島（Control Island）設計仕様書

## 1. 設計コンセプト

PCとのインターフェース、全体制御、および絶縁境界を越えた計測データの集約を担う。USB 5Vをソースとする「絶縁電源」をフィールド側へ供給することで、48V入力の有無に関わらず、システム全体の死活監視と設定を可能にする。
## 2. 電源供給・分配アーキテクチャ
### 2.1 PC島内給電
- **ソース**: USB Type-C (5V)
- **供給先**: 
    - CH340E (USB-UARTブリッジ)
    - ATtiny1616 (メインMCU)
    - デジタルアイソレータ (一次側)
    - 絶縁DC-DCコンバータ (一次側入力)

### 2.2 絶縁電源供給 (Bridge Power)
- **コンポーネント**: 絶縁DC-DCコンバータ (5V入力 / 5V出力、1W級)
- **役割**: PC側の5Vを絶縁して「通信島/電力島」のロジック電源として供給。
- **供給先（絶縁側）**: 
    - RS-485トランシーバ (VCC)
    - INA238パワーモニタ (VCC/VBus)
    - デジタルアイソレータ (二次側電源)
- **利点**: 外部48V電源を接続する前に、PCからINA238のレジスタを読み取り、安全を確認する「プリフライト・チェック」が可能。

## 3. 通信・プログラミング機構 (CH340E共有設計)
CH340EのTX/RXを、物理スイッチまたはジャンパによって「書き込み」と「運用」で切り替える。

※たぶんここはCH342Kを利用して2ポートデバイスとして認識させる方向になる気がする。
### 3.1 SerialUPDIモード (Programming)
- **接続先**: ATtiny1616 PA0 (UPDI)
- **回路**: CH340E TXとRXの間に **4.7kΩ抵抗** を配置し、1線化した信号をPA0へ。
- **用途**: ファームウェアの書き換え。専用プログラマ不要でUSB経由の書き込みを実現。
### 3.2 RUNモード (Operation)
- **接続先**: ATtiny1616 GPIO (Software Serial割当ピン)
- **用途**: PCからのATコマンド受信および計測データの出力。
- **理由**: ハードウェアUSART0を信頼性が求められるRS-485側に予約し、PC側は低速なSoftware Serialで運用する。
## 4. 絶縁境界信号アサイン (ATtiny1616)

| ピン番号        | 機能               | 接続先             | 絶縁の要否  | 役割               |
| :---------- | :--------------- | :-------------- | :----- | :--------------- |
| **PA0**     | **UPDI**         | CH340E (SW経由)   | 不要     | ファームウェア書き込み      |
| **PB2/PB3** | **SoftSerial**   | CH340E (SW経由)   | 不要     | PCとのATコマンド対話     |
| **PA1/PA2** | **USART0**       | RS-485トランシーバ    | **必要** | フィールド通信 (LN-485) |
| **PB0/PB1** | **TWI (I2C)**    | INA238 (パワーモニタ) | **必要** | 電圧・電流・電力の取得      |
| **PC0/PC1** | **GPIO**         | RS-485 DE / RE/ | **必要** | 半二重/エコーバック制御     |
| **PA3**     | **External IRQ** | INA238 ALERTピン  | **必要** | 過電圧・過電流の即時警告     |

## 5. ソフトウェア・ブリッジ機能
1. **電力監視**: 定期的に絶縁I2C経由でINA238をサンプリング。`AT+PWR?` に対して「電圧・電流・電力」を整形して返却。
2. **通信制御**: PCからのデータをUSART0へ転送。送信完了タイミングを監視し、RS-485のDE（送信有効）ピンを精密に制御。
3. **安全管理**: 48Vラインの異常（ALERT）を検知した場合、PC側へ即座に非同期メッセージを送信。

## 6. 基板レイアウト上の考慮事項
- **絶縁溝 (Isolation Barrier)**: PC島とフィールド島（電力＋通信）の間に最低5mmの空間を確保し、スリット（長穴）を設けて沿面距離を最大化。
- **GND分離**: USB GNDとフィールド共通GND ($V^-$) を完全に分離。絶縁DC-DCおよびデジタルアイソレータのみがこの溝を跨ぐ。
