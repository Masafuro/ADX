# AWC (Analog WAV Converter) 基板 Analog Discovery 3 動作試験計画書

## 1. 目的
本試験は、製造・実装が完了したAWC（Analog WAV Converter）基板に対し、Analog Discovery 3（以下AD3）を用いて電気的特性の検証を行い、回路設計通りの動作（発振の有無、ゲイン、Rail-to-Rail特性、各chの独立性）を満たしているかを確認・判定することを目的とする。

## 2. 必要機材およびソフトウェア
- **テスト対象**: 実装済みAWC基板
- **電源**: 9V乾電池（006P型）
- **計測器**: Analog Discovery 3 (AD3) 本体および付属フライワイヤ（バラ線）ケーブル
- **制御PC**: 専用ソフトウェア「WaveForms」がインストールされたPC

## 3. 事前準備・安全確認（電源単体テスト）
1. AWC基板に9V乾電池（BT1）を接続する。
2. 基板上の電源スライドスイッチ（SW1）を「ON」にする。
3. **判定基準**: 基板上の電源インジケーター（LED1）が適切な明るさで点灯することを確認する。
   - ※点灯しない、または異常に眩しい・発熱している場合は直ちにスイッチをOFFにし、はんだショートやタンタルコンデンサ（C4）の極性逆入れを疑うこと。

## 4. AD3との結線ガイド（全チャンネル共通構成）
AD3の各種ピンを、AWC基板の各端子台（CN11: センサー入力 / CN12: H6出力）へ接続する。まずは代表として **チャンネル1 (Ch1)** のテスト結線を示す。

| AD3 側ワイヤ色 / 信号名 | 接続先基板コネクタ / ピン番号 | 回路上のネット名 | 役割 |
| :--- | :--- | :--- | :--- |
| ⬛ **GND** (黒) | CN11 - 16番ピン (または任意のGND) | GND | 基準電位の共通化 |
| 🟨 **Wavegen 1** (黄) | CN11 - 15番ピン | A1 | 疑似センサー信号入力 |
| 🟧 **Scope 1 +** (橙) | CN11 - 15番ピン (Wavegen1と共締め) | A1 | 入力波形のモニタリング |
| ⬜ **Scope 1 -** (橙/白ストライプ) | CN11 - 16番ピン (GNDへ接続) | GND | Scope 1 の差動マイナス側固定 |
| 🟦 **Scope 2 +** (青) | CN12 - 1番ピン | OUTA1 | オペアンプバッファ出力モニタ |
| ⬜ **Scope 2 -** (青/白ストライプ) | CN12 - 2番ピン (GNDへ接続) | GND | Scope 2 の差動マイナス側固定 |

## 5. WaveForms ソフトウェア設定値
WaveFormsを起動し、以下の通り各ツールを設定する。

### ① Wavegen（波形発生器）設定
- **Type (波形)**: `Sine`（正弦波）
- **Frequency (周波数)**: `1.00 kHz`
- **Amplitude (振幅)**: `1.00 V`（ピーク・ツー・ピークでは2.00 Vppとなる）
- **Offset (オフセット)**: `2.50 V`
- ※この設定により、電圧が **1.50V 〜 3.50V** の範囲でスイングする安全なアナログ疑似信号が生成される。

### ② Scope（オシロスコープ）設定
- **Time/Div (時間軸)**: `200 µs/div`（1kHzの波形が画面に約2周表示される設定）
- **Channel 1 (入力側モニタ)**:
  - Offset: `-2.5 V` / Range: `1 V/div`
- **Channel 2 (出力側モニタ)**:
  - Offset: `-2.5 V` / Range: `1 V/div`
- **Trigger**: Type: `Edge` / Source: `CH1` / Level: `2.5 V`

## 6. 試験手順および合格判定基準

### 【手順1】基本バッファ動作および発振検証（基本テスト）
1. AWC基板の電源をONにする。
2. Wavegenの出力を「Run」にし、Scopeの計測を「Run」にする。
3. Scope画面上で、CH1（橙）とCH2（青）の波形を重ね合わせて観察する。

#### 💡 合格判定基準
- [ ] **ゲイン1倍の確認**: CH1とCH2のサイン波の振幅（高さ）が寸分の狂いもなくピッタリと一致していること（TLV9064のボルテージフォロワが正常動作している証明）。
- [ ] **位相の確認**: 入力と出力の間で時間的なズレ（遅延や進み）が目視で確認できないこと。
- [ ] **異常発振の確認**: 青い線（CH2）の軌跡が太くボヤけたり、高周波のギザギザノイズが重畳していないこと（タンタルコンデンサのESRによる位相補償が正常に機能している証明）。

### 【手順2】Rail-to-Rail 特性検証（限界テスト）
1. Wavegenの設定を以下に変更し、オペアンプの限界性能をテストする。
   - **Amplitude (振幅)**: `2.40 V`
   - **Offset (オフセット)**: `2.50 V`
   - ※これにより、電圧が **0.10V 〜 4.90V** という、電源電圧の限界スレスレまでスイングする。

#### 💡 合格判定基準
- [ ] **上下クリップの検証**: 0.1Vの谷、および4.9Vの山において、出力波形（CH2）の頂点が平らに潰れる（クリップする）ことなく、綺麗なサイン波を維持して追従していること。

### 【手順3】複数チャンネルの水平展開
1. チャンネル1の合格を確認後、Wavegen1(黄)・Scope1+(橙)のペア、およびScope2+(青)を、それぞれ **チャンネル2（CN11-11番ピン / CN12-5番ピン）** へ盛り替える。
2. 同様の手順で、**チャンネル3、チャンネル4** まで独立してテストを繰り返す。

#### 💡 合格判定基準
- [ ] 全4チャンネルにおいて、上記【手順1】【手順2】の基準をすべてクリアすること。

## 7. トラブルシューティング（不合格時のチェックリスト）

- **症状：出力（CH2）に強烈なノイズ、または数kHz〜数MHzの綺麗なサイン波が常時出ている**
  - **原因**: オペアンプが出力コンデンサの特性（ESR不足等）により異常発振している可能性が高い。
  - **対策**: 出力側（+5Vライン）に繋いだコンデンサが、本当に選定したKyocera製タンタルコンデンサ（C4 / ESR 2.3Ω）になっているか、SAMSUNG製のMLCC（C2）とテレコ（逆配置）になっていないか再確認する。

- **症状：波形の上が4V付近で平らに潰れてしまう、または出力が常に0Vのまま**
  - **原因**: オペアンプ（U5）の電源ピン（4番ピン）に5Vが供給されていない、またははんだ不良（浮き）。
  - **対策**: テスターでU5の4番ピン-11番ピン間に確実に5.0Vが来ているか測定する。AMS1117周辺のはんだ付け、およびパスコン（C3）の接続状態を確認する。
