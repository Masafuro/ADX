# ADX Core V0: Hot Test（動的試験）手順書

## 基本方針 (Philosophy)
* **無駄・斑の排除**: 測定器のプローブ繋ぎ変え（挿抜工程）を最小化し、1つのSetup（結線状態）で可能な限りのテストを連続して行う。
* **The Bravery of Suspention（勇気ある停止）**: 各Setupにおいて、過電流や期待値外の挙動（Real）に気付いたら、直ちにAD3の電源出力をOFFにして真因を追求する。

---

## 🟢 Setup 1: 電源とMCUの生存確認
AD3から安全な5Vを供給し、ダイオード通過後のマイコン電源（VDD）とUPDI通信を確認する。

### 1-1. 結線 (Wiring)
（※AD3の電源を入れる前に、以下の通り接続を固定する）
- [ ] **電源供給**: 
  - AD3 `V+` (赤) ➡️ **`CN12` Pin 3** (`VIN_7V_48V`)
  - AD3 `GND` (黒) ➡️ **`CN12` Pin 4** (`GND_IN`)
- [ ] **電圧観測 CH1 (VDD)**:
  - AD3 `1+` (オレンジ) ➡️ **`CN1` Pin 1** など (`VDD`)
  - AD3 `1-` (オレンジ/白) ➡️ **`CN1` Pin 2** など (`GND_5V`)
- [ ] **UPDIプログラマ**:
  - 信号線 ➡️ **`H9` Pin 1** (`PA0` / UPDI)
  - GND線 ➡️ **`H9` Pin 2** (`GND_5V`)

### 1-2. テスト実行 (Execution)
- [ ] **HT_1A**: AD3の「WaveForms」で `V+` を **5.0V** に設定し、電源をONにする。
  - **【判定】**: 電流値が数十mA程度で安定していること。100mA以上の大電流は異常とみなし即停止。
- [ ] **HT_1B**: Scope計器でCH1（VDD）の電圧を確認する。
  - **【判定】**: 約4.5V〜4.7V付近（5V - LMR36506のドロップアウト - ダイオードのVf）で安定していること。
- [ ] **HT_1C**: 電源を入れたまま、UPDIプログラマからデバイスシグネチャを読み取る。
  - **【判定】**: Device ID（ATtiny1616の場合は `0x1E 0x94 0x21`）が正しく読み取れること。

## 🔵 Setup 2: RS-485 通信ラインの波形確認
MCUの生存が確認できたら、CH1のプローブを外し、RS-485のA/Bラインの出力波形確認へ移行する。

### 2-1. 結線変更 (Wiring Change)
（※AD3の電源を一度OFFにしてから繋ぎ変える）
- [ ] **電源とUPDI**: Setup 1のまま固定。
- [ ] **電圧観測 CH1 (RS-485 A)**:
  - AD3 `1+` (オレンジ) ➡️ **`CN12` Pin 2** (`RS-485_A`)
  - AD3 `1-` (オレンジ/白) ➡️ **`CN12` Pin 4** (`GND_IN`)
- [ ] **電圧観測 CH2 (RS-485 B)**:
  - AD3 `2+` (青) ➡️ **`CN12` Pin 1** (`RS-485_B`)
  - AD3 `2-` (青/白) ➡️ **`CN12` Pin 4** (`GND_IN`)

### 2-2. テスト実行 (Execution)
- [ ] **HT_2A**: AD3の電源を再度ONにし、UPDI経由で「RS-485送信テストプログラム（L/Hを繰り返す矩形波出力など）」をマイコンに書き込み、実行する。
- [ ] **HT_2B**: Scope計器でCH1（A）とCH2（B）の波形、および Math機能による「A - B（差動電圧）」を観測する。
  - **【判定】**: 
    - CH1(A)とCH2(B)が互いに反転した波形を出力していること。
    - A - B の差動電圧がTHVD2450の仕様（5V動作、無負荷時に約3.3V〜5V振幅）を満たしていること。
