# RS-485 Hot Test (Setup 2) スケッチ仕様書

## 1. 目的 (Purpose)
ATtiny1616からTHVD2410へUARTデータを連続送信し、RS-485バス (A/Bライン) に期待される差動波形が正常に出力されることをAnalog Discovery 3のオシロスコープ機能で確認する。

## 2. ピン割り当て (Pin Assignments)
ハードウェアの結線に基づく使用ピンは以下の通り。
* **TXD (USART0代替ピン)**: `PA1` ➡️ THVD2410 の `D` ピン
* **RXD (USART0代替ピン)**: `PA2` ➡️ THVD2410 の `R` ピン
* **DE (Driver Enable)**: `PA4` ➡️ THVD2410 の `DE` ピン (ハードウェアにて10kΩでGNDへプルダウン済)
* **RE (Receiver Enable)**: `PA3` ➡️ THVD2410 の `RE` ピン (ハードウェアにて10kΩでVDDへプルアップ済)

## 3. 初期化処理 (Initialization)
波形観測の「斑」をなくすため、以下の順序で初期化を行う。

1. **クロック設定**: 
   * デフォルト設定のまま使用する。ヒューズ設定により内部オシレータの6分周（約2.66MHzまたは3.33MHz）で起動するため、クロック変更のコードは記述しない（無駄の排除）。
2. **PORTMUX (ピン多重化) の設定**: 
   * `PORTMUX.CTRLB` レジスタの `USART0` ビットを `1` に設定し、USART0の通信ピンをデフォルトのPB2/PB3から代替ピンである `PA1/PA2` へ切り替える。
3. **GPIO (汎用入出力) の設定**:
   * `PA4 (DE)` ピンを出力モードに設定し、論理レベルを `HIGH` に固定してTHVD2410の送信ドライバを常に有効化する。
   * `PA1 (TXD)` ピンを出力モードに設定する。
4. **USART0 の設定**:
   * **ボーレート**: `9600 bps` 程度に設定する。搭載されているTHVD2410の最大データレートは500kbpsであるため、AD3で波形なまりやスルーレートを余裕を持って観測できる標準的な速度とする。
   * **フレームフォーマット**: 8ビットデータ、パリティなし、1ストップビット (デフォルト設定)。
   * `USART0.CTRLB` レジスタで送信機能 (`TXEN`) を有効化する。

## 4. メイン処理 (Main Loop)
オシロスコープのトリガーを安定させ、正確な差動波形を観測するための周期的なテストパターンを送信する。

1. USART0の送信データレジスタ (`USART0.TXDATAL`) に、テストデータ `0x55` (文字 `'U'`) を書き込む。
   *(※ `0x55` は2進数で `01010101` となり、High/Lowが交互に繰り返されるため、波形の健全性確認に最適である)*
2. `10ms` 程度のディレイ (待機) を実行する。
3. 上記を無限ループで繰り返す。
