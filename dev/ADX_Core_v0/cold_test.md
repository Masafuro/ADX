# ADX Core V0: 電源投入前試験（Cold Test）計画書

## 基本方針 (Philosophy)
* **The Bravery of Suspention（勇気ある停止）**: テスト中に異常や異変（Real）に気付いたら、すぐに作業を止めること。最も尊いことは真因（Root）の追求である。
* **The Noticeable System**: 「NS」や「R > 96kΩ」といった明確な判定基準（KAIZEN）により、誰でも確実かつ客観的に異常を発見できる仕組みとする。

## 判定基準の定義
* **NS (Not Short)**: 数Ω以下のショート（短絡）がないこと。コンデンサのチャージによる過渡的な導通は許容する。
* **R > 96kΩ**: 測定値が96kΩ以上の高インピーダンス、またはテスターの測定限界（O.L）であること。20kΩなどの値が出た場合は異常（チップ破損や実装不良）とみなす。

## 1. 電源回路 (LMR36506) 周辺
- [ ] **CT1: VIN - GND** 【判定: `NS` 】
      （測定ポイント：LMR36506直近のVINバイパスコンデンサ部）
- [ ] **CT2: VOUT - GND** 【判定: `NS` 】
      （測定ポイント：ダイオード直前にあるVOUT出力コンデンサ部）
- [ ] **CT3: VCC - GND** 【判定: `NS` 】
      （測定ポイント：VCCピン直近の内部LDO出力 1μFコンデンサ部）
- [ ] **CT10: BOOT - SW** 【判定: `NS` 】
      （測定ポイント：CBOOTコンデンサの両端パッド）

## 2. マイクロコントローラ (ATtiny1616/3216) 周辺
- [ ] **CT4: MCU_VDD - GND** 【判定: `NS` 】
      （測定ポイント：VDDピン直近のバイパスコンデンサ部）
- [ ] **CT5: UPDI - GND** 【判定: `NS` 】
      （測定ポイント：外部に引き出されたUPDIとGNDのピンソケット部）

## 3. RS-485通信 (THVD2410/2450) 周辺
- [ ] **CT6: 485_VCC - GND** 【判定: `NS` 】
      （測定ポイント：VCCピン直近のバイパスコンデンサ部）
- [ ] **CT7: A - B 間** 【判定: `R > 96kΩ` 】
      （測定ポイント：RS-485バスの Aライン - Bライン間）
- [ ] **CT8: A - GND** 【判定: `R > 96kΩ` 】
      （測定ポイント：RS-485バスの Aライン - GND間）
- [ ] **CT9: B - GND** 【判定: `R > 96kΩ` 】
      （測定ポイント：RS-485バスの Bライン - GND間）
