# ADX Core V0 ハードウェア検証報告書

自作 ATtiny1616 ボード「ADX Core V0」の初回起動における不具合解析および、AD3（Analog Discovery 3）を用いた電気的特性の確認記録。
## 1. システム構成
*   **MCU:** ATtiny1616 (16MHz 内部クロック運用)
*   **開発環境:** Arduino IDE (megaTinyCore)
*   **電源経路:** PC -> USB -> W-checker(4.58V) -> USBアイソレータ -> USB-UPDI変換器 -> |ADX| ->保護ダイオード -> VDD
*   **計測器:** Analog Discovery 3 (WaveForms)
## 2. 発生した問題と原因解析

### ① VDD投入時の電源遮断（アイソレータの保護動作）
*   **現象:** VDDをONにした瞬間、USBアイソレータの保護機能が働きシャットダウンする。
*   **解析:** 
    *   基板単体の VDD-GND 間抵抗は **1.28 MΩ** であり、基板側は正常。
    *   使用した **既製品IDCケーブル** の VDD-GND 間を測定したところ **7.6 Ω** の異常な低抵抗を検出。
*   **結論:** 購入したIDCケーブル内部の製造不良（圧接ミス等）によるショートが原因。
### ② ピンアサインの不一致
*   **現象:** プログラムしたパルス幅と、観測されるピンの場所が一致しない。
*   **解析:** 
    *   当初、リバース（表ー裏）タイプのIDCケーブルを暫定使用したため、ピンアサインが鏡合わせに反転していた。
*   **対策:** AD3のフライワイヤをIDCボックスヘッダに直接接続し、ケーブルを介さない検証を実施。
*   **結果:** **PA6 = 60ms** のパルスを確認し、設計上のシルク印刷とマイコン内部のピンアサインが正しく一致していることを証明した。
## 3. 電源品質の検証 (AD3 Scopeによる測定)
設計上の保護ダイオードによる電圧降下を考慮した上で、ボード上の実効電圧およびノイズを測定。

| 項目             | 測定値           | 備考                              |
| :------------- | :------------ | :------------------------------ |
| **実効電圧 (VDD)** | **約 4.02 V**  | W-checker(4.58V)からの降下。設計想定通り。   |
| **負荷変動 (下り)**  | **-22.39 mV** | ΔX: 9.293 µs。パスコンにより非常に抑制されている。 |
| **電圧回復 (上り)**  | **+25.01 mV** | ΔX: 3.581 µs。非常に高速かつ安定した回復。     |

### 判定
電源品質は極めて良好。16MHz動作におけるATtiny1616の動作電圧（推奨3.8V以上）をクリアしており、安定した動作マージンを確保している。

## 4. 最終結論
ADX Core V0 は、初期不良ケーブルによる外部要因を除き、ハードウェア設計・製造ともに比較的正常な印象を受ける。引き続き調査する。
