# ADX Hardware Mapping: WCH CH32X035
(Target Board: ADX CORE-CX3)

**Standard Reference**: [ADX 20-Pin Bus Specification (ADX_PINOUT.md)](../ADX_PINOUT.md) (Standard: `ADX-BUS-SPEC-v4.0`)  
**Target MCU**: WCH CH32X035G8U6 (QFN-28)  
**Core Architecture**: QingKe 32-bit RISC-V4C (RV32IMAC), up to 48 MHz  
**Memory Configuration**: 62 KB Flash, 20 KB SRAM  
**Operating Condition**: 3.3V DC (Onboard LDO) / 48 MHz Internal Oscillator with USB Clock Auto-Trimming  

---

## 1. Overview

This document specifies the hardware interconnect and peripheral assignment mapping the universal **ADX 20-Pin Bus (v4.0)** to the **WCH CH32X035** RISC-V microcontroller on the **ADX CORE-CX3** board.

The CH32X035 integrates an internal USB 2.0 Full-Speed PHY with clock trimming, eliminating the need for an external crystal and external USB-UART bridge IC, while providing 5V-tolerant GPIOs operating natively at 3.3V LVCMOS levels.

## 4. Bootloader & Production Programming Architecture

### 4.1 Automated Factory Test & Flashing (Pin 2: OWD)
During assembly at the automated test bench, the 20-pin IDC Eject Header connects to a WCH-LinkE programming fixture:
1. Slices power onto `VBUS` (Pins 17–20).
2. Connects to `PD7 (SWDIO / SDI)` via Pin 2.
3. Performs hardware self-test routines and checks GPIO continuity.
4. Flashes the custom **ADX UF2 USB Mass Storage Bootloader** into the lower 10 KB of Flash memory.

### 4.2 Field Maintenance & Sketch Flashing (Dual Type-C)
- **Zero-Install Maintenance**:
  When a user enters bootloader mode (holding the BOOT button while plugging in the communication Type-C cable), the board enumerates as a standard **USB Mass Storage Device (`ADX-CX3`)**.
- **Cross-Platform Compatibility**:
  Firmware updates require only dragging and dropping a compiled `.uf2` binary into the folder. No vendor drivers, OS-specific flashing utilities, or browser permissions are required, ensuring long-term maintainability across changing operating system generations.

## 5. Power Domain & Dual-Port Isolation

To eliminate PC port tripping and ground loops in industrial field deployments:
1. **Communication Port (16P Type-C)**:
   - Protected by a 500 mA PTC resettable fuse and low-$V_F$ Schottky barrier diode (SBD).
   - Allows standalone bench flashing from a PC without external supplies.
   - SBD prevents high-current reverse flow from `VBUS` back into the host PC.
2. **Power Port (6P Type-C)**:
   - Dedicated high-current power input routed directly through a 2.0A–3.0A PTC fuse into `VBUS` (Pins 17–20).
   - Feeds onboard 3.3V LDO and external Card modules on the 20-pin bus.
