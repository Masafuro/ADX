# ADX Pinout 設計・解説ガイド (Architecture Guide)

[ English (../en/ADX_pinout.md) | **日本語** ]

> [!IMPORTANT]
> **仕様定義の真実の単一ソース (Single Source of Truth: SSOT):**  
> ピンアサインの最新定義表、厳密な電気定格、信号タイミング、物理寸法については、規格マスタードキュメント **[`docs/spec/ADX_PINOUT.md`](../spec/ADX_PINOUT.md)**（英語・アルファベット表記）を参照してください。  
> 本ガイドラインは、その工学的な設計意図（Why）、産業盤トポロジー適合電源配置、シールド構造、および拡張 Card 設計時の実践ルールを解説するものです。

---

## 1. 概要と設計思想 (Overview & Philosophy)

ADX 共通拡張バスは、**2×10ピン（20ピン）2.54mm ピッチ IDC コネクタ** を採用した、Core ボード（マイコン主基板）と Card モジュール（拡張基板）を結ぶ標準バックプレーン規格です。

ホビー向けのピンヘッダー直挿しやブレッドボード配線では困難だった**「振動への耐性」「盤内配線ダクトとの直線的一致」「大電流の安定供給」「高周波ノイズの放射抑制」「フラットケーブル圧接時の短絡保護」**を同時に達成するため、制御盤の配線原則やフラットケーブル芯線の並び順まで綿密に計算された配置設計となっています。

```text
                  【 20-Pin Shrouded Box Header (Top View) 】

                         ┌───────[ Center Key ]───────┐
              GND   [ 1]  │  ●   ●  │  [ 2]  OWD / PROG  ─── 【最外端シールド ＆ システムデバッグ】
              AIN   [ 3]  │  ●   ●  │  [ 4]  GND         ─── 【AIN ガード ＆ クロック分離】
           EXTCLK   [ 5]  │  ●   ●  │  [ 6]  GND         ─── 【EXTCLK / SWCLK コプレーナシールド】
          UART_TX   [ 7]  │  ●   ●  │  [ 8]  UART_RX     ─── 【UART 通信ペア】
          I2C_SCL   [ 9]  │  ●   ●  │  [10]  I2C_SDA     ─── 【I2C オープンドレインペア】
              GND   [11]  │  ●   ●  │  [12]  SPI_CS      ─── 【I2C / SPI 中継シールド】
         SPI_MOSI   [13]  │  ●   ●  │  [14]  SPI_MISO    ─── 【高速 SPI バス群】
          SPI_SCK   [15]  │  ●   ●  │  [16]  GND         ─── 【短絡防止壁 (VBUS 防火壁)】
             VBUS   [17]  │  ●   ●  │  [18]  VBUS        ─── 【大電流電源幹線 (2×2 底面クラスタ)】
             VBUS   [19]  │  ●   ●  │  [20]  VBUS
                         └────────────────────────────┘
```

## 2. 主な工学的メリットと構造解説 (Engineering Rationale)

### 2.1 産業盤トポロジー適合電源配置 (`VBUS`: Pins 17〜20)
Pins 17〜20 に大電流幹線（`VBUS`）を集中配置したのは、制御盤・産業機器の鉄則である**「弱電（計装・通信）は上、強電（主電源・動力）は下」**という配線公理に、基板内部および前面端子配置を完全に一致させるためです。

1. **前面 I/O 端子台との直進ルーティング (Straight-Through Alignment):**  
   制御盤内の配線ダクトは「上部＝通信・センサー線」「下部＝電源・動力線」で分離されています。20-Pin IDC の最下段に `VBUS` を置くことで、基板下辺の太いベタ銅箔パターンを通じて、前面最下部の電源受電端子台へ一直線に最短配線できます。盤内ダクトからモジュール端子台への引き込み線が盤内で不必要に交差（クロス）するリスクが全廃されます。
2. **基板内クロスオーバーの全廃 (Zero Signal Crossings):**  
   大電流プレーンが基板の下層・下半分で完結するため、基板上部を走る微弱なアナログ計測（AIN）や高速通信（SPI/UART）のパターンを大電流ラインが横切る必要が一切ありません。大電流スイッチングノイズや IR ドロップによる通信・アナログ妨害を根本から防ぎます。
3. **副次的な重力物理安全性の確保:**  
   この底面配置の副次的メリットとして、縦型スロット配置時に万一ネジ端子台から給電線が緩んで外れた場合でも、電線は自然と下部の配線ダクト側へ垂れ下がるため、上方の通信端子台へ接触・混触する事故が構造的に防止されます。
4. **2×2 正方形ベタプレーン:**  
   Pins 17〜20 は完全な $2 \times 2$ 正方形を形成しているため、PCB CAD 上で表裏のベタ電源プレーンを形成しやすく、低インピーダンスで最大 2A〜3A 連続の電力供給と優れた放熱性を両立します。

### 2.2 保護境界壁 (`Pin 16: GND`)
- **短絡時の安全遮断:**  
  大電流電源クラスタ（Pins 17〜20）の直上に `Pin 16 (GND)` を配置しています。フラットケーブル圧接時の位置ズレや芯線ヒゲの接触が発生した場合でも、VBUS は直上の GND へ短絡するため、給電側の保護回路（PTC ヒューズやロードスイッチ）が即座に動作し、上部の微小信号線（Pins 1〜15）に高電圧が漏れるのを物理的に遮断します。

### 2.3 最外端ガード ＆ AIN コプレーナ・シールド (`Pins 1〜4`)
- **ケーブル端の静電保護:**  
  フラットケーブルの最端（芯線 #1）に `GND` を配置。盤内の金属フレームとの摩擦や外部ノイズによる影響を外縁部でシャットアウトします。
- **微弱アナログの完全隔離:**  
  Pin 3 (`AIN`) は、外周側の Pin 1 (`GND`) と内周側の Pin 4 (`GND`) によって挟み込まれたコプレーナ・ウェーブガイド（シールド）構造を形成します。隣接する Pin 5 (`EXTCLK`) などの高速デジタルスイッチングノイズが微弱なアナログ計測値に飛び込むのを防ぎます。

### 2.4 クロック伝送シールド (`Pins 4〜6`)
- 高速クロック線 Pin 5 (`EXTCLK`) は、両隣の Pin 4 (`GND`) および Pin 6 (`GND`) で挟み込まれたコプレーナ導波路構造です。外部システムクロックや同期デバッグクロック（`SWCLK`）の空間ノイズ放射（EMI）を抑え、隣接するアナログ線や通信バスへのクロストークを完全に遮蔽します。

### 2.5 システムデバッグ・出荷検査バス (`Pins 2 & 5`)
- **1線式および2線式プログラミングの完全統合:**  
  8-bit MCU から 32-bit RISC-V/ARM まで多様なアーキテクチャをサポートするため、Pin 2 と Pin 5 をシステム制御ペアとして定義しています。
  - **CORE-A5 (ATtiny1616)**: Pin 2 に `PA0` (UPDI) を割り当て、1線で出荷検査・書き込みを実施。
  - **CORE-CX5 (CH32X035)**: Pin 2 に `PC18` (SWDIO)、Pin 5 に `PC19` (SWCLK) を割り当て、**20-Pin IDC ヘッダーを治具に 1 本挿すだけで給電と 2-wire SDI 書き込みが 100% 完結**（ポゴピン治具が不要）。
- **製造と現場保守のシナリオ:**  
  工場検査時は 20P IDC ヘッダーから自動テストとブートローダー（UF2等）の書き込みを実施し、現場運用時は通信ポート経由でドラッグ＆ドロップ保守を行う運用を標準化します。

## 3. 拡張 CARD 設計ガイドライン (Design Guidelines for Cards)

ADX 準拠の拡張 Card（アドオン基板）を設計する際は、以下のルールを遵守してください：

1. **電源受電および PoL（Point of Load）レギュレーション:**
   - Pins 17〜20 の VBUS は必ず 4 ピンすべてをベタ銅箔パターンへ結合してください。
   - **3.3V 電源はバス上を供給されません**。Card 上で 3.3V ロジック電源が必要な場合は、VBUS（Pins 17〜20）を受けて Card 上の LDO または DC-DC レギュレータで降圧・生成してください。
2. **Pin 2 (OWD) の接続禁止 (MUST):**
   - 一般の拡張 Card は **Pin 2 を未接続（N.C.）** としてください。
   - **GND への直結禁止**: タクトスイッチやプルダウン回路を直接 Pin 2 に接続してはなりません（デバッグパケットの破壊や治具通信の衝突を防ぐため）。
3. **Pin 5 (EXTCLK) の 0Ω アイソレーション設計 (RECOMMENDED / SHOULD):**
   - Card 側から外部発振器等でクロックを注入・駆動する場合、または監視回路を接続する場合、**直列に 0Ω 抵抗（例: `R_EXTCLK`）またはソルダージャンパを配置し、未実装（DNP: Do Not Populate）で電気的に完全切断できる構造とすることを強く推奨**します。
   - **相互運用性の担保**: ATtiny1616 構成では 0Ω を実装してクロックを供給し、CH32X035 構成では 0Ω を未実装（DNP）とすることで、Core 側の内蔵クロック運用やデバッグピン利用との衝突を完全に防止できます（同一の Card 基板で全 Core ボードに対応可能）。
4. **I2C プルアップ抵抗の配置:**
   - Pin 9 (`I2C_SCL`) および Pin 10 (`I2C_SDA`) には、Core ボード側でプルアップ抵抗を実装していない場合があります。Card 側またはバス全体で 1 箇所のプルアップ（2.2kΩ〜4.7kΩ @ 3.3V）を設けてください。
5. **リターンパスと高周波配線:**
   - 高速な SPI バス（Pins 12〜15）やクロック配線は、直近の GND（Pin 11, 16）と近接させてリターンパスを確保してください。
