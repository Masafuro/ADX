# ADX Pinout 設計・解説ガイド (Architecture Guide)

[ English (../en/ADX_pinout.md) | **日本語** ]

> **仕様定義の真実の単一ソース (Single Source of Truth: SSOT):**  
> ピンアサインの最新定義表、厳密な電気定格、信号タイミング、物理寸法については、規格マスタードキュメント **[`docs/spec/ADX_PINOUT.md`](../spec/ADX_PINOUT.md)**（英語・アルファベット表記）を参照してください。

## 1. 概要と設計思想 (Overview & Philosophy)

ADX 共通拡張バスは、**2×10ピン（20ピン）2.54mm ピッチ IDC コネクタ** を採用した、Core ボード（マイコン主基板）と Card モジュール（拡張基板）を結ぶ標準バックプレーン規格です。

ホビー向けのピンヘッダー直挿しやブレッドボード配線では困難だった**「振動への耐性」「現場での脱落事故防止」「大電流の安定供給」「高周波ノイズの放射抑制」「フラットケーブル圧接時の短絡保護」**を同時に達成するため、重力方向やフラットケーブル芯線の並び順まで綿密に計算された配置設計となっています。

```text
                  【 20-Pin Shrouded Box Header (Top View) 】

                         ┌───────[ Center Key ]───────┐
              GND   [ 1]  │  ●   ●  │  [ 2]  OWD / PROG  ─── 【最外端シールド ＆ 1-Wire保守】
              AIN   [ 3]  │  ●   ●  │  [ 4]  GND         ─── 【AIN ガード ＆ クロック分離】
           EXTCLK   [ 5]  │  ●   ●  │  [ 6]  GND         ─── 【EXTCLK コプレーナシールド】
          UART_TX   [ 7]  │  ●   ●  │  [ 8]  UART_RX     ─── 【UART 通信ペア】
          I2C_SCL   [ 9]  │  ●   ●  │  [10]  I2C_SDA     ─── 【I2C オープンドレインペア】
              GND   [11]  │  ●   ●  │  [12]  SPI_CS      ─── 【I2C / SPI 中継シールド】
         SPI_MOSI   [13]  │  ●   ●  │  [14]  SPI_MISO    ─── 【高速 SPI バス群】
          SPI_SCK   [15]  │  ●   ●  │  [16]  GND         ─── 【短絡防止壁 (VBUS 防火壁)】
             VBUS   [17]  │  ●   ●  │  [18]  VBUS        ─── 【大電流電源幹線 (2×2 正方形)】
             VBUS   [19]  │  ●   ●  │  [20]  VBUS
                         └────────────────────────────┘
```

## 2. 主な工学的メリットと構造解説 (Engineering Rationale)

### 2.1 重力フェイルセーフ構造 (`VBUS`: Pins 17〜20)
制御盤や DIN レールラックにおいて、ユニットを縦型（バーチカル）にスロットイン配置する場合、配線の物理的な脱落リスクへの配慮が不可欠です。
- **落線事故の物理的遮断:**  
  大電流・外部電源ライン `VBUS` をコネクタの最下部（Pins 17〜20）に配置しています。現場での振動や端子台ネジの緩みによって万一電源線が外れた場合でも、電線は自重で直下の底面シャーシ（FG）や配線ダクトへ垂れ落ちます。上部に配置された通信線（RS-485/UART/SPI）やアナログ信号線へ物理接触することが原理的になく、盤全体の連鎖破損事故を未然に防ぎます。
- **2×2 正方形ベタプレーン:**  
  Pins 17〜20 は完全な $2 \times 2$ 正方形を形成しているため、PCB CAD 上で表裏のベタ電源プレーンを形成しやすく、低インピーダンスで最大 2A〜3A 連続の電力供給と優れた放熱性を両立します。

### 2.2 保護境界壁 (`Pin 16: GND`)
- **短絡時の安全遮断:**  
  大電流電源クラスタ（Pins 17〜20）の直上に `Pin 16 (GND)` を配置しています。フラットケーブル圧接時の位置ズレや芯線ヒゲの接触が発生した場合でも、VBUS は直上の GND へ短絡するため、給電側の保護回路（PTC ヒューズやロードスイッチ）が即座に動作し、上部の微小信号線（Pins 1〜15）に高電圧が漏れるのを物理的に遮断します。

### 2.3 最外端ガード ＆ AIN コプレーナ・シールド (`Pins 1〜4`)
- **ケーブル端の静電保護:**  
  フラットケーブルの最端（芯線 #1）に `GND` を配置。盤内の金属フレームとの摩擦や外部ノイズによる影響を外縁部でシャットアウトします。
- **微弱アナログの完全隔離:**  
  Pin 3 (`AIN`) は、外周側の Pin 1 (`GND`) と内周側の Pin 4 (`GND`) によって挟み込まれたコプレーナ・ウェーブガイド（シールド）構造を形成します。隣接する Pin 5 (`EXTCLK`) などの高速デジタルスイッチングノイズが微弱なアナログ計測値に飛び込むのを防ぎます。

### 2.4 クロック伝送シールド (`Pins 4〜6`)
- 高速クロック線 Pin 5 (`EXTCLK`) は、両隣の Pin 4 (`GND`) および Pin 6 (`GND`) で挟み込まれています。高周波クロックの空間ノイズ放射（EMI）を抑え、通信線やアナログ線へのクロストークを低減します。

### 2.5 One-Wire デバッグ・出荷検査バス (`Pin 2: OWD`)
- **役割の明確化:**  
  旧仕様の「SYS_RST」を改め、検査治具およびマイコン直接保守専用の 1-Wire バスとして再定義しました。
  - **CORE-A5 (ATtiny1616)**: `PA0` (UPDI)
  - **CORE-CX3 (CH32X035)**: `PD7` (SDI / SWDIO)
- **製造と現場保守のシナリオ:**  
  工場検査時は 20P IDC ヘッダーから自動テストとブートローダー（UF2等）の書き込みを実施し、現場運用時は通信ポート経由でドラッグ＆ドロップ保守を行う運用を標準化します。

## 3. 拡張 CARD 設計ガイドライン (Design Guidelines for Cards)

ADX 準拠の拡張 Card（アドオン基板）を設計する際は、以下のルールを遵守してください：

1. **電源受電および PoL（Point of Load）レギュレーション:**
   - Pins 17〜20 の VBUS は必ず 4 ピンすべてをベタ銅箔パターンへ結合してください。
   - **3.3V 電源はバス上を供給されません**。Card 上で 3.3V ロジック電源が必要な場合は、VBUS（Pins 17〜20）を受けて Card 上の LDO または DC-DC レギュレータで降圧・生成してください。
2. **Pin 2 (OWD) の接続禁止 (MUST):**
   - 一般の拡張 Card は **Pin 2 を未接続（N.C.）** としてください。
   - **GND への直結禁止**: タクトスイッチやプルダウン回路を直接 Pin 2 に接続してはなりません（デバッグパケットの破壊や治具通信の衝突を防ぐため）。
3. **I2C プルアップ抵抗の配置:**
   - Pin 9 (`I2C_SCL`) および Pin 10 (`I2C_SDA`) には、Core ボード側でプルアップ抵抗を実装していない場合があります。Card 側またはバス全体で 1 箇所のプルアップ（2.2kΩ〜4.7kΩ @ 3.3V）を設けてください。
4. **リターンパスと高周波配線:**
   - 高速な SPI バス（Pins 12〜15）やクロック配線は、直近の GND（Pin 11, 16）と近接させてリターンパスを確保してください。
