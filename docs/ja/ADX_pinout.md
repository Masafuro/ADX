## 1. 概要と基本思想 (Overview & Philosophy)

ADX 共通拡張バスは、**2×10ピン（20ピン）2.54mm ピッチ IDC コネクタ** を採用した、Core ボード（マイコン主基板）と Card モジュール（拡張基板）を結ぶ標準インターフェース規格です。

ホビー向けのピンヘッダー直挿しやブレッドボード配線では困難だった「**振動への耐性**」「**大電流の安定供給**」「**高周波ノイズの放射抑制**」「**フラットケーブル圧接時の短絡事故防止**」を同時に達成するため、ミリ単位・ピン単位で綿密に計算された配置設計となっています。

## 2. 主な電気的・構造的メリット (Design Rationale)

```text
                  【 20-Pin Shrouded Header (Top View) 】

                        ┌───────[ Center Key ]───────┐
           VBUS   [ 1]  │  ●   ●  │  [ 2]  VBUS
           VBUS   [ 3]  │  ●   ●  │  [ 4]  VBUS
           N.C.   [ 5]  │  ●   ●  │  [ 6]  AOUT / DAC
           AIN    [ 7]  │  ●   ●  │  [ 8]  GND
         EXTCLK   [ 9]  │  ●   ●  │  [10]  GND
        UART_TX   [11]  │  ●   ●  │  [12]  UART_RX
        I2C_SCL   [13]  │  ●   ●  │  [14]  I2C_SDA
            GND   [15]  │  ●   ●  │  [16]  SPI_CS
       SPI_MOSI   [17]  │  ●   ●  │  [18]  SPI_MISO
        SPI_SCK   [19]  │  ●   ●  │  [20]  GND
                        └────────────────────────────┘
```

### 2.1 双方向電源幹線 `VBUS` (Pins 1〜4: 2×2ブロック)
- **大動脈給受電 (4.5V〜5.0V / 2A 級):** 4ピンを電源専用に割り当てることで、フラットケーブル（AWG28）接続時でも電圧降下を抑え、最大 2A 連続の電力供給を実現します。
- **2×2 正方形ベタプレーン:** ピン 1〜4 が 2×2 の正方形に配置されているため、PCB CAD 上で正方形のベタ電源プレーンを形成でき、配線性・放熱性・インピーダンス特性が大幅に向上します。
- **双方向運用:** Core ボードから Card 群へ給電するだけでなく、Power Card（DC 12V/24V 絶縁受電やバッテリーカード）から VBUS に電力を注入してスタック全体を駆動することも可能です。

### 2.2 短絡防止緩衝帯 (Pin 5 N.C.)
- **アイソレーション機能:** 大電流が流れる VBUS 電源ゾーン（Pins 1〜4）と、繊細なアナログ・GPIO 信号（Pin 6）の間に、物理的な **N.C.（未接続ピン）** を配置しています。
- **事故防止:** フラットケーブルの圧接ズレ、芯線のヒゲ短絡、コネクタ斜め挿しが発生しても、高圧・大電流電源がマイコンの信号ポートへ直接接触してチップが全損する事故を物理的に防ぎます。

### 2.3 3.3V LVCMOS ネイティブ統一
- **全 GPIO の統一:** すべての信号線（Pins 6, 7, 9, 11〜14, 16〜19）は **3.3V LVCMOS** で統一されています。
- **シフタ全廃:** 拡張 Card モジュールは 3.3V 前提で設計でき、基板上に煩雑なレベルシフタを搭載する必要がありません。

### 2.4 クロックシールド構造 (Pins 8〜10)
- **コプレーナ GND サンドイッチ:** 高周波信号線 `EXTCLK` (Pin 9) の両隣を `GND` (Pin 8, 10) で挟み込むシールド構造を採用。
- **EMI 放射低減:** リボンケーブル伝送時や基板配線時のクロックノイズ放射（EMI）を抑え、隣接するアナログ信号やデジタル通信へのクロストークを遮断します。

### 2.5 デジタル通信ゾーンの隔離とシールド (Pins 11〜20)
- Pin 10 (GND) によりクロックラインと通信群を隔離。
- Pin 15 (GND) により I2C ペアと高速 SPI 群を中継シールド。
- Pin 20 (GND) によりバス終端をシールド。

## 3. 拡張 CARD 設計ガイドライン (Design Guidelines for Cards)

ADX 準拠の拡張 Card（アドオン基板）を設計する際は、以下のデザインルールを推奨します：

1. **電源プレーン設計:**
   - Pins 1〜4 は必ずビアを打ち、Card 基板上の電源ベタプレーンへ結合してください。
   - Pin 5 はランドのみ配置し、いかなるパターンとも接続しないでください（N.C. 厳守）。
2. **プルアップ抵抗の配置 (I2C):**
   - Pin 13 (`I2C_SCL`) および Pin 14 (`I2C_SDA`) には、Core ボード側でプルアップ抵抗を実装していない場合があります。Card 側またはバス全体で 1 箇所のプルアップ（2.2kΩ〜4.7kΩ @ 3.3V）を設けてください。
3. **信号線インピーダンス・保護:**
   - 高速な SPI やクロック信号は、Pin 8, 10, 15, 20 の GND と近接させてリターンパスを確保してください。
