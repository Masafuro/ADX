# ADX (Advanced Devices eXtended)

[ English (../../README.md) | **日本語** ]

<p align="center">
  <img src="../images/hero_no_photo.svg" alt="ADX CORE-U Arduino IDE対応の筐体親和型ボード" width="100%">

**ADX CORE-U** は、自作の電子工作プロジェクトを「本物の箱（エンクロージャ）」へ美しく、手軽に、確実に収めるためにゼロから設計された、Arduino IDEで開発できる筐体親和型ボードです。

---

## 1. 概要：ブレッドボードから「箱」へ

ブレッドボードの上で回路を組み立てて動かすのはとても楽しい体験です。しかし、それを綺麗なケースに収めたとき、工作は真の「完成品」へと進化します。

従来のプロトタイピング基板をケースに入れようとすると、ネジ止め時にパターンを削りそうになったり、配線が四方八方に飛び出したり、サーボやモーターを動かそうとしてPCのUSBポートを落としてしまったりと、特有の難しさに直面しがちでした。

**ADXは、この課題を2つの階層で解決します：**
1. **ADX ハードウェア規格**: 自作の3Dプリントケース、市販のプラスチックボックス、電工ボックスなどへの組付けやすさを極めた、オープンな機械・バス規格（8748 Form Factor）。
2. **ADX CORE-U**: 誰もが使い慣れた **Arduino IDE と `megaTinyCore`** を用い、**USB Type-C** 経由で直感的に開発・実験できる旗艦MCUボード。

## 2. 共通の土台：ADX ハードウェア規格

ADX規格は、マイコンや拡張モジュールがあらゆる筐体へ自然に収まるように設計された、オープンな物理仕様です。

```
       ══════════════════════════════════════════════════════════════════
                         【 ADX ハードウェア規格 】
         ・8748 フォームファクタ (87.0 mm × 48.0 mm 外形)
         ・四隅の M3 取付穴 ＆ Φ5.0 mm ワッシャークリアランス
         ・レール滑り込み（スロットイン）や爪留め（スナップフィット）用の掴み幅
         ・単一の「I/F辺」に外部コネクタを集約（パネル穴あけが1面で完結）
         ・20ピン拡張バス（直スタック ＆ 市販フラットIDCケーブル両対応）
       ══════════════════════════════════════════════════════════════════
                                       │
            ┌──────────────────────────┴──────────────────────────┐
            ▼                                                     ▼
   【 旗艦MCUボード 】                                   【 モジュール式 CARD群 】
     ADX CORE-U (筐体親和型ボード)                         ADX CARD エコシステム
     ・ATtiny1616 ＋ USB Type-C                            ・Prototyping CARD (ユニバーサル)
     ・Arduino IDE ＋ megaTinyCore ネイティブ              ・AAA 2S Battery CARD (乾電池)
     ・保護に配慮した電源アーキテクチャ                    ・3Dプリント用ケース / マウントSTL
```

### 2.1 8748 フォームファクタと固定の自由度
- **外形寸法**: `87.0 mm × 48.0 mm`。
- **M3 ネジ止め設計**: 四隅のM3ネジ穴（`77.0 mm × 38.0 mm` ピッチ）の周囲に、**Φ5.0 mm のゆとりあるワッシャークリアランス**を確保。ネジの頭やワッシャーをしっかり締め込んでも、基板の配線パターンを傷つける心配がありません。
- **外形部掴み幅（エッジマージン）**: 基板の外周に部品を配置しないクリアランスを設けており、ケース側レールへの**スロットイン（滑り込み固定）**や、3Dプリント爪による**スナップフィット**にも干渉なしで対応します。

### 2.2 I/F辺の明示的な規格化
外部と接続するコネクタ（USB Type-C等）は、**基板の単一の一辺（I/F辺）に集約**されています。
コネクタが四方八方に飛び出さないため、3Dプリントケースのポート開口部や既製ケースのパネル穴あけ加工が「1面だけ」で完結します。

### 2.3 20ピンバスと柔軟な筐体内配置（IDCケーブル接続）
拡張モジュール（CARD）とは、共通の20ピン拡張バス（5V VDD, GND, GPIO, ADC, DAC, I2C, SPI, UART）で接続します。
- **リジッドな直スタック**: 標準的な2.54mmピンヘッダを用いて、コア基板の上や下にカチッと重ねて省スペースに固定できます。
- **IDCフラットリボンケーブル対応**: 市販の**MILフラットIDCリボンケーブル**による接続を標準仕様としてサポート。薄型ケースなら「横並び」、深型ボックスなら「上下配置」、段違いのボスなら「ケーブルで逃がす」など、筐体内部の空間形状に合わせた自由自在なレイアウトが可能です。

## 3. 旗艦ボード：ADX CORE-U

**ADX CORE-U** は、メイカー、学生、開発者が最も手軽に電子工作を楽しめるよう設計された、ADXエコシステムの主役となるマイコンボードです。

```
┌────────────────────────────────────────────────────────────────────────┐
│                   【 ADX CORE-U 】(筐体親和型ボード)                   │
│  - Microchip ATtiny1616-MNR MCU (16KB Flash / 2KB SRAM / 20MHz)        │
│  - WCH CH342K USB-UARTブリッジ (SerialUPDI 自動書き込み対応)           │
│  - Arduino IDE ＋ megaTinyCore ネイティブ対応 (ブートローダー不要)      │
│  - PC保護に配慮した USB Type-C インターフェース                        │
│  - ADX 20ピン拡張バスヘッダ標準搭載                                    │
└────────────────────────────────────────────────────────────────────────┘
```

### 3.1 Arduino IDE でのシームレスな開発体験
- **即座にLチカ（Blink）**: ハードウェアSerialUPDIに対応した WCH `CH342K` を搭載。普段使いのArduino IDEと `megaTinyCore` から、USBケーブル1本で直接スケッチを書き込めます。
- **ブートローダーのラグなし**: UPDI方式によりフラッシュメモリへ直接プログラムを書き込むため、起動時の待ち時間（ブートローダー遅延）がなく、電源投入と同時にスケッチが立ち上がります。
- **誠実なスペックの開示**: ATtiny1616（Flash 16KB、SRAM 2KB）を採用しているため、センサー読み取り、サーボやNeopixelの制御、リレー駆動といった小〜中規模のプロジェクトに最適化されています。余計な待機電力を抑え、コンパクトなサイズを維持しています。

### 3.2 電源・保護設計への配慮（仕様策定中・検証ノート）
サーボモーターやLEDテープなどの大電流負荷を動かす際にも、開発PCのUSBポートを安全に保護できるよう、理想ダイオード等を用いた給電回路を現在最適化・検証中です。
- *回路ブロック図、給電トポロジー、最新のハードウェア検討ノートについては、[hardware/CORE-U/concept.md](../../hardware/CORE-U/concept.md) をご参照ください。*

## 4. モジュール式 CARD エコシステム

CORE-Uは、同じ8748外形を持つ拡張CARDを重ねたり繋いだりすることで、機能をスマートに拡張できます：

- **Prototyping CARD**: 20ピンバスの全信号を引き出した2.54mmピッチのユニバーサル試作基板。自作センサー回路をすっきりスタックできます。
- **AAA 2S Battery CARD**: 単4アルカリ電池×2本からクリーンな5Vを昇圧供給する自律・モバイル運用用カード。
- **3Dプリント用ケース ＆ マウントデータ**: 各種マウントブラケットやスナップフィットケースのオープンソースSTL/STEPデータを公開。

## 6. 将来展望：現場・産業への拡張性

*※エコシステムの拡張に関する注記:*  
ADXの20ピンバスと8748外形は、長期的なモジュール性を考慮して設計されています。将来的には、同じ拡張CARDやマウント機構をそのまま共有できる、より過酷な環境や現場に向けたタフな上位ボード（完全絶縁RS-485版など）もラインナップに加わる可能性があります。
