### *はたらくArduino (The Working Arduino)*
> **Arduinoよりちょっとタフで、箱にいれやすい。あなたのスケッチを現場で動かすためのボード。**

**ADX CORE-A** は、ブレッドボードの上で作った電子工作プロジェクトを実際の暮らしや現場の空間へ連れ出し、ケースに収めて安心して長く動かし続けるために生まれたオープンハードウェアのマイコン基板です。

---

## 1. 概要：机の上から、実際の設置場所へ

ブレッドボードの上で回路を組み立てて動かすのはとても楽しい体験です。

しかし、そのスケッチを**部屋の隅、ガレージ、店舗のディスプレイ、家庭菜園の棚などに実際に置いて長く動かそうとしたとき**、多くの人が次のような物理的な困りごとに直面します：

1. **固定しづらい**: 取付穴の周囲に余裕がなく、M3ネジを締め込むと基板パターンを削りそうになる。
2. **箱に入らない**: 前後左右から線が飛び出していて、ケースの穴あけ加工が難しくフタが閉まらない。
3. **配線が抜けやすい**: ブレッドボード用のジャンパ線だと、ちょっとした振動や引っ掛かりで抜けてしまう。
4. **現場での手直しが億劫**: ちょっとコードを直したいだけなのに、設置場所まで重いノートPCを抱えていくのが大変。

**ADXは、この課題に対して「はたらくArduino (The Working Arduino)」という等身大の考え方でアプローチします。**  
高価で大げさな産業用PLCではなく、誰もが親しんできたArduinoの良さをそのままに、「ちょっとタフで、箱にいれやすい」相棒として設計されています。

## 2. 共通の土台：ADX ハードウェア規格

ADXの土台となるのは、マイコンやモジュールが様々なケースに無理なく収まるように設計された、オープンな物理規格です。

```
       ════════════════════════════════════════════════════════════════════
                         【 ADX ハードウェア規格 】
         ・8748 フォームファクタ (87.0 mm × 48.0 mm 外形)
         ・四隅の M3 取付穴 ＆ Φ5.0 mm ワッシャークリアランス
         ・レール滑り込み（スロットイン）や爪留め（スナップフィット）用の掴み幅
         ・単一の「I/F辺」に外部配線を集約（加工面が1面で完結）
         ・20ピン堅牢バス（直スタック ＆ 市販フラットIDCケーブル両対応）
       ════════════════════════════════════════════════════════════════════
                                       │
            ┌──────────────────────────┴──────────────────────────┐
            ▼                                                     ▼
   【 現場で動かすメイン基板 】                          【 モジュール式 CARD群 】
     ADX CORE-A (Active R&D)                               ADX CARD エコシステム
     ・箱に入れやすく、配線しやすい設計                    ・Prototyping CARD (ユニバーサル)
     ・スプリング端子台 ＆ 接続保護の配慮                  ・AAA Battery CARD (乾電池)
     ・(最新状況は hardware/CORE-A/ 参照)                  ・3Dプリント用ケース / マウントSTL
```

### 2.1 8748 フォームファクタと確実なネジ固定
- **外形寸法**: `87.0 mm × 48.0 mm`。
- **M3 ネジ止めスペース**: 四隅のM3ネジ穴（`77.0 mm × 38.0 mm` ピッチ）の周囲に、**Φ5.0 mm のゆとりあるワッシャークリアランス**を確保。ネジの頭や座金をしっかり締め込んでも、パターンを痛めません。
- **外形部掴み幅（エッジマージン）**: 基板の外周に部品を配置しないクリアランスを設けており、ケースのレールへの**スロットイン（滑り込み固定）**や、3Dプリント爪による**スナップフィット**に対応します。

### 2.2 I/F辺の集約によるケース加工の単純化
外部配線と接続する端子部は、**基板の単一の一辺（I/F辺）に集約**されています。  
コネクタが四方八方に飛び出さないため、ケースの開口加工や3Dプリントケースのフタ設計が「1面だけ」で完結します。

### 2.3 20ピンバスと柔軟な配置（IDCリボンケーブル対応）
拡張モジュール（CARD）とは、共通の20ピン拡張バス（VDD, GND, GPIO, ADC, DAC, I2C, SPI, UART）で接続します。
- **直スタック**: 基板同士を上下に重ねて省スペースに固定可能。
- **フラットIDCケーブル対応**: 市販の**フラットIDCリボンケーブル**による接続を標準サポート。薄型ケースなら「横並び」、深型ボックスなら「上下配置」など、ケースの形状に合わせた柔軟なレイアウトが可能です。

## 3. 開発中のハードウェア（Active R&D）

ADXでは、「はたらくArduino」を形にするためのハードウェアを現在鋭意開発・検証しています。

```
┌────────────────────────────────────────────────────────────────────────┐
│             【 ADX CORE-A 】(メイン基板 — 鋭意開発・試作中)             │
│  - Microchip ATtiny1616-MNR MCU 搭載 (Flash 16KB / SRAM 2KB)           │
│  - 振動でも抜けにくい、ネジ不要のスプリング端子台                      │
│  - 外部配線からの予期せぬトラブルを和らげる保護回路の配慮              │
│  - 四隅M3ネジでしっかり固定できる 8748 フォームファクタ                │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 外部接続
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│         【 RPR4 Smart Probe 】(アダプタープローブ — 鋭意開発・試作中)   │
│  - ブラウザの WebSerial を使った手軽な接続を検証する実験的ツール       │
│  - 設置場所に重いノートPCを抱えていかず、手軽に手直しできる未来を目指す│
│  - ポケットに入れて持ち歩けるコンパクトなサイズ                        │
└────────────────────────────────────────────────────────────────────────┘
```

### 3.1 ADX CORE-A (メイン基板)
現場への据え付けを意識して設計を進めているメイン基板です。
- **スプリング端子台**: ドライバーを使わずに電線を差し込むだけでしっかり留まり、長期間の振動でも緩みにくい端子台を採用。
- **保護への配慮**: 外部との通信ラインにアイソレーションや保護回路を工夫し、現場でのノイズや誤配線による影響を和らげる回路構成を検討しています。
- *回路ブロック図、保護トポロジー、最新のハードウェア検証ノートについては、[hardware/CORE-A/concept.md](../../hardware/CORE-A/concept.md) をご参照ください。*

### 3.2 RPR4 Smart Probe (アダプタープローブ)
設置場所でのメンテナンスを身軽にするために研究開発を進めている実験的ツールです。
- ブラウザ（WebSerial）経由で手軽にスケッチの更新や通信状態の確認を行える仕組みを探求し、脚立の上や狭い場所での作業負担を減らすことを目指しています。
- *プロトタイプの開発状況については、[hardware/RPR4/](../../hardware/RPR4/) をご参照ください。*

## 4. Arduino IDE での親しみやすさ

特別な専用ツールや難解な言語を新しく覚える必要はありません。

- **慣れ親しんだスケッチ**: 普段使いのArduino言語やライブラリ（`megaTinyCore`）を使って直感的に開発できます。
- **軽量で低消費電力**: ATtiny1616を採用し、無駄な発熱や待機電力を抑え、電源投入と同時に素早く動き始めます。

---

## 5. モジュール式 CARD エコシステム

同じ8748外形を持つ拡張CARDを繋ぐことで、目的に応じて機能を拡張できます：

- **Prototyping CARD**: 20ピンバスの信号を引き出したユニバーサル試作基板。自作回路をきれいに固定できます。
- **AAA 2S Battery CARD**: 単4電池×2本から5Vを生成し、電源のない場所でも動かせるバッテリーカード。
- **オープン3DプリントSTL**: ケースや固定用マウントブラケットのオープンソースデータ。
