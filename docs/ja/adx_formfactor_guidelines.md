# ADX ハードウェア・フォームファクタ開発ガイドライン
(ADX Hardware & FormFactor Design Guidelines)

[ [English](../en/adx_formfactor_guidelines.md) | **日本語** ]

---

## 1. 概要と設計哲学 (Overview & Philosophy)

本ガイドラインは、ADXエコシステムにおけるコアボード（旗艦機: **ADX CORE-U** 等）および拡張カード（**CARDシリーズ**）を設計・開発するエンジニアのための標準設計指針である。

本規格は、以下の2つの価値を両立することを最優先哲学とする：
1. **オープンソースとしての自由闊達な開発（敷居の低さ）**:
   - ホビー工作、研究試作、DIYユーザーが安価・手軽に自由な発想で拡張カードを自作できること。
2. **機器としての安全性（堅牢性）**:
   - どのような拡張カードが接続されても、重大な事故（火災、電池破裂、PCの焼損、電源短絡）を未然に防止すること。

この両立を実現するため、本ガイドラインでは **RFC 2119** に基づく3段階の要件レベルを定義する。

---

## 2. 要件レベルの定義 (Requirement Levels)

| レベル | キーワード | 定義と適用範囲 |
| :--- | :---: | :--- |
| **レベル 1** | **【MUST】必須**<br>*(Shall / Mandatory)* | **火災・物理的破壊・人体危険を防ぐための必須制約。**<br>公式・サードパーティ・DIY自作基板を問わず、すべてのADXハードウェアが例外なく遵守しなければならない。 |
| **レベル 2** | **【SHOULD】公式標準**<br>*(Recommended)* | **「ADX公式製品（Official Grade）」が満たす高信頼性基準。**<br>DIY基板や特定用途カードでは逸脱（省略・ダウングレード）が許容される。 |
| **レベル 3** | **【MAY】自由選択**<br>*(Optional)* | **開発者のアイディア・目的・コストに応じて自由に選択してよい領域。** |

## 3. 電源・電気的安全性ルール (Power & Safety Rules)

### 3.1 共通電源幹線 (`VBUS`) の基本仕様
- **バス許容動作電圧範囲（全 Core / CARD 耐性）【MUST】**: **`4.5V 〜 5.5V DC`（公称 `5.0V ±10%`）**。USB Type-C `vSafe5V` 上限（`5.50V`）および 2A 給電時のケーブル・コネクタ電圧降下（`~4.5V`）の両端をカバーする。すべての Core ボードおよび拡張 CARD は、この全範囲で破損・誤動作・保護誤作動なく安全に動作するよう設計しなければならない。
- **電源供給側の出力電圧範囲（Core / Power CARD）**:
  - **許容出力範囲【MUST】**: `4.5V 〜 5.5V DC`（過電圧保護 OVLO は `5.5V` 定常で誤遮断せず、異常過電圧を確実に遮断すること）。
  - **推奨出力精度【SHOULD】**: 絶縁 24V/48V→5V Power CARD 等の自前給電モジュールは **`4.75V 〜 5.25V DC`（`5.0V ±5%`）** を目標精度とし、軽負荷浮き・重負荷降下の双方に余裕を持たせること（USB-C スルー給電の最大 `5.50V` も規格内として許容）。
- **狭レンジ 5V 部品の直結禁止【MUST】**: `4.75V 〜 5.25V` 等、`4.5V〜5.5V` 全域に耐えられない 5V 駆動 IC・絶縁モジュールを CARD に搭載する場合は、`VBUS` へ直結せず CARD 内で昇降圧・安定化回路を介して吸収すること（または `3.15V〜5.5V` 等の広入力対応品を選定すること）。
- **定格電流**: **最大 2.0A〜3.0A**（Pins 17〜20 の 2×2 ピンブロックによる給電）
- **双方向性**: コアボード（USB Type-C）からCARDへ供給される場合と、Power CARDからコアボードへ供給される場合がある。
- **Point of Load (PoL) 原則 ＆ レギュレータ耐圧指針**:
  - 3.3V ロジック電源は 20P バス上には供給されない。Card 側で 3.3V が必要な場合は `VBUS` から自基板上の LDO / DC-DC で生成する。
  - **【SHOULD】高耐圧レギュレータ選定**: `5.5V` 定常時の活線挿抜リンギングや負荷急変スパイクに備え、絶対最大定格 `6.0V` クラスの LDO を避け、**動作入力耐圧 `≥ 10V`（推奨 `12V〜30V` クラス）** の LDO / DC-DC を選定すること。また `5.5V` 時には LDO 発熱が `5.0V` 比で約 +29% 増加するため、3.3V 系で目安 `150〜200mA` 超を消費する CARD は降圧 DC-DC の採用を推奨する。

### 3.2 Power CARD の設計規則（最も重要な責務の分離）

```text
                  【両面防壁 (ダブル・チェックバルブ) 構造】

  [ コアボード (USB Type-C / 外部電源) ]
         │
    [ ⛔ 逆流阻止・保護 (eFuse / 理想ダイオード等) ⛔ ] ──► (VBUSからPC側への逆流を阻止)
         │
         ▼
  ┌────────────────────────────────────────────────────────┐
  │  共通 5V VBUS 幹線 (Pins 17〜20 / 2×2 底面クラスタ)     │
  └────────────────────────────────────────────────────────┘
         ▲
         │
    [ ⛔ 逆流阻止 (ダイオード/FET) ⛔ ] ──► 【MUST】Power CARDの必須義務！
         │                                (VBUSから外部電源・電池への逆流遮断)
  [ ⚡ 電源保護・サージ吸収・昇降圧 ⚡ ]
         │
  [ 外部電源 (乾電池 / ACアダプタ / 産業用 DC24V 等) ]
```

1. **【MUST】Power CARD の「逆流阻止」義務（必須要件）**:
   - 20Pバス（Pins 17〜20: `VBUS`）に電力を注入する CARD は、**必ず出力端に逆流阻止回路（ショットキーダイオード、理想ダイオード、または逆流阻止機能付き同期整流DCDC）および過電流・短絡保護を自基板内に設けなければならない**。
   - *（理由: コアボード（CORE-U等）に机上で USB 給電が接続された際、5.0V が CARD 側の外部電池へ逆流充電されて発生する **乾電池の破裂・液漏れ事故** や、DCDC 出力素子の逆バイアス破損を物理的に防止するため）*
2. **【MUST】Pin 16 (`GND`) 短絡防止防火壁 ＆ RS-485 `P03 (UART_DE)` プルダウンの厳守**:
   - 大電流 `VBUS` クラスタ（Pins 17〜20）直上の **Pin 16 (`GND`)** および各シールド GND（Pins 1, 3, 5, 11）は必ずベタ GND プレーンへ接続すること（フラットケーブル圧接ズレ時に信号線へ 5V が漏れるのを防ぐ）。
   - `P03`（Pin 6: `UART_DE`）を利用する RS-485 拡張 Card は、MCU リセット・未書込時のバス占有を防ぐため **必ず `P03` に `10kΩ〜100kΩ` のプルダウン抵抗（to GND）を実装** し、デフォルトを受信状態（`DE = LOW`）に固定すること。
3. **【SHOULD】高電圧電源（DC12V/24V/48V系）のトランス絶縁**:
   - **ADX公式品**: 工場配電盤やフィールドネットワークのコモンモードノイズ、地電位差、雷サージを遮断するため、**トランス絶縁型 DCDC（絶縁5V出力）** を採用すること。
   - **DIY / ホビー用途（MAY）**: 同一電位・室内・実験用途であれば、安価な非絶縁降圧 DCDC を採用してもよい。乾電池カードも非絶縁でよい。
4. **【SHOULD】外部電源端子の保護回路**:
   - 外部電源（24V/48Vや電池）の入力部には、サージ保護（TVS/バリスタ）、短絡保護（ヒューズ/PTC）、逆接保護（P-MOSFET等）を CARD 側で完備すること。

## 4. コネクタ・機械設計ルール (Mechanical & Connector Rules)

### 4.1 20P 拡張バスコネクタ (`ADX-BUS-SPEC-v5.0`)
- **【MUST】ピン配置の電気的合致**:
  - すべてのカードは、[ADX 20-Pin Bus Specification (SSOT: v5.0)](../spec/ADX_PINOUT.md) および [設計・解説ガイド](ADX_pinout.md) に完全準拠すること。
  - *（注意：`v5.0` では旧 `S00` をオミットし、Pins 3〜6 で信号線と `GND` が入れ替わったため、旧 `v4.x` 試作基板とは電気的に非互換です。基板シルクに `ADX-BUS v5.0` を明記してください）*
- **プログラミング経路の分離（Core 側自己完結）**:
  - `v5.0` では書込・デバッグ線（UPDI / SWD）を 20P バスから完全に除外したため、旧 `v4.2` で必要だった `S00` N.C. 制約や `P02` への `0Ω` DNP 挿入は不要となり、`P01`〜`P11` の全 11 ピンを自由に利用できます。
- **コネクタ種別の選定**:
  - **公式標準【SHOULD】**: 車載や激しい振動による脱落防止、および手探り現場での逆挿しや1列ズレ挿しを防止するため、**MIL-DTL-83503互換 ラッチ付き Eject Header（牛角）** またはシュラウド付きボックスヘッダを標準採用とする。
  - **DIY / 一般拡張【MAY】**: 薄型化や超低コスト化を優先する場合、通常のボックスヘッダや単純なピンヘッダを採用してもよい。

### 4.2 外形寸法とスタック構造
- **公式標準【SHOULD】: 8858 Form Factor 準拠 (正式 α 版・現行標準)**:
  - 基板外形寸法: **`88.0 mm × 58.0 mm`**
  - 取付穴: **4 隅 M3 ネジ対応（Φ3.30 mm NPTH）**
  - 取付穴ピッチ: **`76.0 mm × 46.0 mm`**（外形端から `6.0 mm`、座面クリアランス $\Phi 10.0\,\text{mm}$）
  - 20P 垂直 IDC 中心: **`(44.0, 51.0) mm`**（長辺中央、上端から `7.0 mm`）
  - 角部面取り: **C0 (直角・完全矩形、全方向ストレート V カット対応)**
  - 下面構造: **I/O Edge (66mm) 外側に下面 SMD Only ゾーン（`36.0 × 8.0 mm × 2`）を確保**（スロットイン爪潜り込み・光学マーカー予約対応）
  - 光学アライメントマーカー【MAY / 公式 SHOULD】: 四隅 `M1〜M4`（ピッチ **`76.0 × 30.0 mm`**、M3 穴と X 座標一致）
  - *(詳細仕様は [8858 Form Factor 仕様書](8858_formfactor.md) 参照、旧規格は [8854 Form Factor](8854_formfactor.md) / [8748 Form Factor](8748_formfactor.md) 参照)*
- **サードパーティ / 自由形状【MAY】**:
  - 20P コネクタの電気的・物理的位置さえ合致すれば、小型ドーターボード型、大型シールド型、L字型など、独自の基板外形を採用してよい。

## 5. 耐熱・熱設計ルール (Thermal & Environment Rules)

1. **【MUST】熱源の分離（コアボード保護）**:
   - 高電圧降圧 DCDC、リレー駆動回路、大電力スイッチング等の発熱源は CARD 側に配置し、コア基板へ熱を伝導させないスリットや放熱プレーン設計を行うこと。
2. **耐熱グレード選定**:
   - **高信頼グレード【SHOULD】: Industrial Grade（-40℃ 〜 +105℃）**:
     - 高い環境耐性を求める公式 CARD は、X7R コンデンサ、厚膜抵抗、工業用 IC による -40℃〜+105℃ 構成を推奨とする。
   - **DIY / 一般拡張【MAY】: Commercial Grade（0℃ 〜 70℃ / -20℃ 〜 85℃）**:
     - 室内用、プロトタイプ、教育用カードでは、入手性の高い民生用部品を自由に使用してよい。

## 6. オプション機能の活用ルール (Optional Feature Rules)

以下の信号線は、用途に応じて自由に活用してよい（**【MAY】**）。全 Core ボード共通のピン指定には論理ピン ID（`P01`〜`P11` / コードマクロ `ADX_P01`〜`ADX_P11`）を使用する。

1. **バッテリー残量・電源電圧監視**:
   - 外部電源やバッテリーの生電圧を 3.3V 以下へ分圧し、**`P01`（IDC Pin 2 / `AIN`）** へ入力してマイコンでモニタリングしてよい。
2. **未使用バスの汎用 GPIO / スリープ制御流用**:
   - SPI / UART / I2C を使用しない Card では、該当ピン（例：**`P08` [IDC Pin 12 / `SPI_CS`]** 等）を CARD 側 DCDC のイネーブル（EN）ピンや LED・スイッチ駆動などの汎用 3.3V GPIO として自由に流用してよい。

## 7. 開発者向けセルフチェックリスト (Developer Checklist)

基板製造（PCBA発注）を行う前に、以下の項目を必ずセルフチェックしてください：

- [ ] **【MUST】** 電源を供給する Power CARD の出力端に、逆流阻止回路および過電流・短絡保護回路を実装したか？
- [ ] **【MUST】** `VBUS` 許容動作範囲 **`4.5V 〜 5.5V`（`5.0V ±10%`）** 全域での安全動作を確保したか（狭レンジ 5V 部品の非直結、および `VBUS` 直結 LDO/保護素子の入力耐圧・過渡マージン確認）？
- [ ] **【MUST】** 20P コネクタの `VBUS`（Pins 17〜20）を 2×2 ベタ銅箔で結合し、直上の Pin 16（`GND` 防火壁）および各シールド GND（Pins 1, 3, 5, 11）を確実に GND プレーンへ接続したか？
- [ ] **【MUST】** RS-485 拡張 Card で **`P03`（Pin 6: `UART_DE`）** を使う場合、起動・リセット時のバス占有防止用プルダウン抵抗（`10kΩ〜100kΩ` to GND）を実装したか？
- [ ] **【MUST】** 20P コネクタのピンアサイン（`P01`〜`P11`, `GND`, `VBUS`）が **`ADX-BUS-SPEC-v5.0`**（[`docs/spec/ADX_PINOUT.md`](../spec/ADX_PINOUT.md)）と一致し、旧 `v4.x` との混在防止のためシルクに `ADX-BUS v5.0` を明記したか？
- [ ] **【SHOULD】** 工場24V/48V等の高電圧を扱う場合、トランス絶縁型 DCDC を採用したか？
- [ ] **【SHOULD】** 耐振動性が必要な現場向けの場合、ラッチ付き Eject Header を選定したか？
- [ ] **【SHOULD】** 8858 筐体（または旧 8854 / 8748 筐体）に組込・スタックする場合、M3 取付穴ピッチ（8858: `76.0 mm × 46.0 mm` / 旧 8854: `76.0 × 42.0 mm` / 旧 8748: `77.0 × 38.0 mm`）に合致しているか？
