# ADX ハードウェア・フォームファクタ開発ガイドライン
(ADX Hardware & FormFactor Design Guidelines)

[ [English](../en/adx_formfactor_guidelines.md) | **日本語** ]

---

## 1. 概要と設計哲学 (Overview & Philosophy)

本ガイドラインは、ADXエコシステムにおけるコアボード（旗艦機: **ADX CORE-U** 等）および拡張カード（**CARDシリーズ**）を設計・開発するエンジニアのための標準設計指針である。

本規格は、以下の2つの価値を両立することを最優先哲学とする：
1. **オープンソースとしての自由闊達な開発（敷居の低さ）**:
   - ホビー工作、研究試作、DIYユーザーが安価・手軽に自由な発想で拡張カードを自作できること。
2. **機器としての安全性（堅牢性）**:
   - どのような拡張カードが接続されても、重大な事故（火災、電池破裂、PCの焼損、電源短絡）を未然に防止すること。

この両立を実現するため、本ガイドラインでは **RFC 2119** に基づく3段階の要件レベルを定義する。

---

## 2. 要件レベルの定義 (Requirement Levels)

| レベル | キーワード | 定義と適用範囲 |
| :--- | :---: | :--- |
| **レベル 1** | **【MUST】必須**<br>*(Shall / Mandatory)* | **火災・物理的破壊・人体危険を防ぐための必須制約。**<br>公式・サードパーティ・DIY自作基板を問わず、すべてのADXハードウェアが例外なく遵守しなければならない。 |
| **レベル 2** | **【SHOULD】公式標準**<br>*(Recommended)* | **「ADX公式製品（Official Grade）」が満たす高信頼性基準。**<br>DIY基板や特定用途カードでは逸脱（省略・ダウングレード）が許容される。 |
| **レベル 3** | **【MAY】自由選択**<br>*(Optional)* | **開発者のアイディア・目的・コストに応じて自由に選択してよい領域。** |

---

## 3. 電源・電気的安全性ルール (Power & Safety Rules)

### 3.1 共通電源幹線 (`VBUS`) の基本仕様
- **電圧仕様**: **DC 5.0V (±10%)**（4.5V 〜 5.0V 動作範囲、推奨 4.75V〜5.25V）
- **定格電流**: **最大 2.0A〜3.0A**（Pins 17〜20 の 2×2 ピンブロックによる給電）
- **双方向性**: コアボード（USB Type-C）からCARDへ供給される場合と、Power CARDからコアボードへ供給される場合がある。
- **Point of Load (PoL) 原則**: 3.3V ロジック電源は 20P バス上には供給されない。Card 側で 3.3V が必要な場合は `VBUS` から自基板上の LDO / DC-DC で生成する。

### 3.2 Power CARD の設計規則（最も重要な責務の分離）

```text
                  【両面防壁 (ダブル・チェックバルブ) 構造】

  [ コアボード (USB Type-C / 外部電源) ]
         │
    [ ⛔ 逆流阻止・保護 (eFuse / 理想ダイオード等) ⛔ ] ──► (VBUSからPC側への逆流を阻止)
         │
         ▼
  ┌────────────────────────────────────────────────────────┐
  │  共通 5V VBUS 幹線 (Pins 17〜20 / 2×2 底面クラスタ)     │
  └────────────────────────────────────────────────────────┘
         ▲
         │
    [ ⛔ 逆流阻止 (ダイオード/FET) ⛔ ] ──► 【MUST】Power CARDの必須義務！
         │                                (VBUSから外部電源・電池への逆流遮断)
  [ ⚡ 電源保護・サージ吸収・昇降圧 ⚡ ]
         │
  [ 外部電源 (乾電池 / ACアダプタ / 産業用 DC24V 等) ]
```

1. **【MUST】Power CARD の「逆流阻止」義務（必須要件）**:
   - 20Pバス（Pins 17〜20: `VBUS`）に電力を注入する CARD は、**必ず出力端に逆流阻止回路（ショットキーダイオード、理想ダイオード、または逆流阻止機能付き同期整流DCDC）および過電流・短絡保護を自基板内に設けなければならない**。
   - *（理由: コアボード（CORE-U等）に机上で USB 給電が接続された際、5.0V が CARD 側の外部電池へ逆流充電されて発生する **乾電池の破裂・液漏れ事故** や、DCDC 出力素子の逆バイアス破損を物理的に防止するため）*
2. **【MUST】Pin 16 (`GND`) 短絡防止防火壁 ＆ `S00` (Pin 2: `OWD`) の厳守**:
   - 大電流 `VBUS` クラスタ（Pins 17〜20）直上の **Pin 16 (`GND`)** は短絡防止壁として必ずベタ GND プレーンへ接続すること（フラットケーブル圧接ズレ時に信号線へ 5V が漏れるのを防ぐ）。
   - 一般の拡張 Card はシステム専用線 **`S00`（Pin 2: `OWD`）を必ず未接続（N.C.）** とし、GND への直結やスイッチ接続を行ってはならない。
3. **【SHOULD】高電圧電源（DC12V/24V/48V系）のトランス絶縁**:
   - **ADX公式品**: 工場配電盤やフィールドネットワークのコモンモードノイズ、地電位差、雷サージを遮断するため、**トランス絶縁型 DCDC（絶縁5V出力）** を採用すること。
   - **DIY / ホビー用途（MAY）**: 同一電位・室内・実験用途であれば、安価な非絶縁降圧 DCDC を採用してもよい。乾電池カードも非絶縁でよい。
4. **【SHOULD】外部電源端子の保護回路**:
   - 外部電源（24V/48Vや電池）の入力部には、サージ保護（TVS/バリスタ）、短絡保護（ヒューズ/PTC）、逆接保護（P-MOSFET等）を CARD 側で完備すること。

## 4. コネクタ・機械設計ルール (Mechanical & Connector Rules)

### 4.1 20P 拡張バスコネクタ (`ADX-BUS-SPEC-v4.2`)
- **【MUST】ピン配置の電気的合致**:
  - すべてのカードは、[ADX 20-Pin Bus Specification (SSOT: v4.2)](../spec/ADX_PINOUT.md) および [設計・解説ガイド](ADX_pinout.md) に完全準拠すること。
- **【SHOULD】`P02`（Pin 5: `EXTCLK`）の 0Ω アイソレーション設計**:
  - `P02` を駆動・利用する Card は、2-wire SWD デバッグを使う Core ボード（CORE-CX5 等）との互換性を保つため、直列 0Ω 抵抗（DNP 可）またはソルダージャンパの配置を推奨する。
- **コネクタ種別の選定**:
  - **公式標準【SHOULD】**: 車載や激しい振動による脱落防止、および手探り現場での逆挿しや1列ズレ挿しを防止するため、**MIL-DTL-83503互換 ラッチ付き Eject Header（牛角）** またはシュラウド付きボックスヘッダを標準採用とする。
  - **DIY / 一般拡張【MAY】**: 薄型化や超低コスト化を優先する場合、通常のボックスヘッダや単純なピンヘッダを採用してもよい。

### 4.2 外形寸法とスタック構造
- **公式標準【SHOULD】: 8854 Form Factor 準拠 (次世代推奨標準)**:
  - 基板外形寸法: **`88.0 mm × 54.0 mm`**
  - 取付穴: **4隅 M3 ネジ対応（Φ3.3 mm NPTH）**
  - 取付穴ピッチ: **`76.0 mm × 42.0 mm`**（外形端から `6.0 mm`、座面クリアランス $\Phi 10.0\,\text{mm}$）
  - 角部面取り: **C0 (直角・完全矩形、全方向ストレートVカット対応)**
  - 下面構造: **I/O Edge (66mm) 外側に下面SMD Onlyゾーンを確保**（スロットイン爪潜り込み対応）
  - *(詳細仕様は [8854 Form Factor 仕様書](8854_formfactor.md) 参照、旧規格は [8748 Form Factor 仕様書](8748_formfactor.md) 参照)*
- **サードパーティ / 自由形状【MAY】**:
  - 20P コネクタの電気的・物理的位置さえ合致すれば、小型ドーターボード型、大型シールド型、L字型など、独自の基板外形を採用してよい。

## 5. 耐熱・熱設計ルール (Thermal & Environment Rules)

1. **【MUST】熱源の分離（コアボード保護）**:
   - 高電圧降圧 DCDC、リレー駆動回路、大電力スイッチング等の発熱源は CARD 側に配置し、コア基板へ熱を伝導させないスリットや放熱プレーン設計を行うこと。
2. **耐熱グレード選定**:
   - **高信頼グレード【SHOULD】: Industrial Grade（-40℃ 〜 +105℃）**:
     - 高い環境耐性を求める公式 CARD は、X7R コンデンサ、厚膜抵抗、工業用 IC による -40℃〜+105℃ 構成を推奨とする。
   - **DIY / 一般拡張【MAY】: Commercial Grade（0℃ 〜 70℃ / -20℃ 〜 85℃）**:
     - 室内用、プロトタイプ、教育用カードでは、入手性の高い民生用部品を自由に使用してよい。

## 6. オプション機能の活用ルール (Optional Feature Rules)

以下の信号線は、用途に応じて自由に活用してよい（**【MAY】**）。全 Core ボード共通のピン指定には論理ピン ID（`P01`〜`P10` / コードマクロ `ADX_P01`〜`ADX_P10`）を使用する。

1. **バッテリー残量・電源電圧監視**:
   - 外部電源やバッテリーの生電圧を 3.3V 以下へ分圧し、**`P01`（IDC Pin 3 / `AIN`）** へ入力してマイコンでモニタリングしてよい。
2. **未使用バスの汎用 GPIO / スリープ制御流用**:
   - SPI / UART / I2C を使用しない Card では、該当ピン（例：**`P07` [IDC Pin 12 / `SPI_CS`]** 等）を CARD 側 DCDC のイネーブル（EN）ピンや LED・スイッチ駆動などの汎用 3.3V GPIO として自由に流用してよい。

## 7. 開発者向けセルフチェックリスト (Developer Checklist)

基板製造（PCBA発注）を行う前に、以下の項目を必ずセルフチェックしてください：

- [ ] **【MUST】** 電源を供給する Power CARD の出力端に、逆流阻止回路および過電流・短絡保護回路を実装したか？
- [ ] **【MUST】** 20P コネクタの `VBUS`（Pins 17〜20）を 2×2 ベタ銅箔で結合し、直上の Pin 16（`GND` 防火壁）および各シールド GND（Pins 1, 4, 6, 11）を確実に GND プレーンへ接続したか？
- [ ] **【MUST】** 一般拡張 Card でシステム専用ピン **`S00`（Pin 2: `OWD`）** を未接続（N.C.）としたか？
- [ ] **【MUST】** 20P コネクタのピンアサイン（`S00`, `P01`〜`P10`, `GND`, `VBUS`）が **`ADX-BUS-SPEC-v4.2`**（[`docs/spec/ADX_PINOUT.md`](../spec/ADX_PINOUT.md)）と一致しているか？
- [ ] **【SHOULD】** `P02`（Pin 5: `EXTCLK`）を使う Card で、2-wire SWD Core 互換のための直列 0Ω 抵抗（DNP 可）を設けたか？
- [ ] **【SHOULD】** 工場24V/48V等の高電圧を扱う場合、トランス絶縁型 DCDC を採用したか？
- [ ] **【SHOULD】** 耐振動性が必要な現場向けの場合、ラッチ付き Eject Header を選定したか？
- [ ] **【SHOULD】** 8854 筐体（または従来の8748筐体）にスタック・組込する場合、M3 取付穴ピッチ（8854: `76.0 mm × 42.0 mm` / 旧8748: `77.0 mm × 38.0 mm`）に合致しているか？
