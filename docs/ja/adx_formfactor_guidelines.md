# ADX ハードウェア・フォームファクタ開発ガイドライン
(ADX Hardware & FormFactor Design Guidelines)

[ English (../en/adx_formfactor_guidelines.md) | **日本語** ]

---

## 1. 概要と設計哲学 (Overview & Philosophy)

本ガイドラインは、ADXエコシステムにおけるコアボード（例: **ADX CORE-A**）および拡張カード（**CARDシリーズ**）を設計・開発するエンジニアのための標準設計指針である。

本規格は、以下の2つの価値を両立することを最優先哲学とする：
1. **オープンソースとしての自由闊達な開発（敷居の低さ）**:
   - ホビー工作、研究試作、DIYユーザーが安価・手軽に自由な発想で拡張カードを自作できること。
2. **社会インフラ・産業機器としての絶対的な安全性（堅牢性）**:
   - どのような拡張カードが接続されても、重大な事故（火災、電池破裂、PCの焼損、高電圧短絡）が物理的・電気的に絶対に発生しないこと。

この両立を実現するため、本ガイドラインでは **RFC 2119** に基づく3段階の要件レベルを定義する。

---

## 2. 要件レベルの定義 (Requirement Levels)

| レベル | キーワード | 定義と適用範囲 |
| :---: | :---: | :--- |
| **レベル 1** | **【MUST】必須**<br>*(Shall / Mandatory)* | **火災・物理的破壊・人体危険を防ぐための絶対的制約。**<br>公式・サードパーティ・DIY自作基板を問わず、すべてのADXハードウェアが例外なく遵守しなければならない。 |
| **レベル 2** | **【SHOULD】公式標準**<br>*(Recommended)* | **「ADX公式製品（Official Grade）」が満たす産業品質・高信頼性基準。**<br>車載・過酷環境・社会インフラでの運用を想定。DIY基板や特定用途カードでは逸脱（省略・ダウングレード）が許容される。 |
| **レベル 3** | **【MAY】自由選択**<br>*(Optional)* | **開発者のアイディア・目的・コストに応じて自由に選択してよい領域。** |

## 3. 電源・電気的安全性ルール (Power & Safety Rules)

### 3.1 共通電源幹線 (VDD) の基本仕様
- **電圧仕様**: **DC 5.0V (±10%)**（4.5V 〜 5.5V）
- **定格電流**: **最大 2.0A**（2×2 ピンブロックによる給電）
- **双方向性**: コアボード（USB Type-C）からCARDへ供給される場合と、Power CARDからコアボードへ供給される場合がある。

### 3.2 Power CARD の設計規則（最も重要な責務の分離）

```
                  【両面防壁 (ダブル・チェックバルブ) 構造】

  [ USB Type-C 6P ]
         │
    [ ⛔ 逆流阻止 (LM66100) ⛔ ] ──► (VDDからPCへの逆流を瞬時遮断)
         │
         ▼
  ┌────────────────────────────────────────────────────────┐
  │  共通 5V VDD バス (Pins 1〜4)                           │
  └────────────────────────────────────────────────────────┘
         ▲
         │
    [ ⛔ 逆流阻止 (ダイオード/FET) ⛔ ] ──► 【MUST】Power CARDの必須義務！
         │                                (VDDから外部電源・電池への逆流遮断)
  [ ⚡ 電源保護・サージ吸収・昇降圧 ⚡ ]
         │
  [ 外部電源 (乾電池 / 工場24V / 基地局-48V) ]
```

1. **【MUST】Power CARD の「逆流阻止」義務（絶対遵守）**:
   - 20Pバス（Pins 1〜4: VDD）に電力を注入する CARD は、**必ず出力端に逆流阻止回路（ショットキーダイオード、理想ダイオード、または逆流阻止機能付き同期整流DCDC）を自基板内に設けなければならない**。
   - *（理由: CORE-A に机上で USB Type-C が接続された際、USB 5.0V が CARD 側の外部電池へ逆流充電されて発生する **乾電池の破裂・液漏れ事故** や、DCDC 出力素子の逆バイアス破損を 100% 物理遮断するため）*
2. **【MUST】Pin 5（N.C.）短絡防止アイソレーション帯の厳守**:
   - VDD 強電ゾーン（Pins 1〜4）と信号線ゾーン（Pin 6以降）を隔てる **Pin 5（N.C.）には、いかなるパターン、銅箔ベタ、配線も接続してはならない**。
   - フラットケーブル圧接時のズレや基板加工公差による電源ショート事故を防止する。
3. **【SHOULD】高電圧電源（DC12V/24V/48V系）のトランス絶縁**:
   - **ADX公式品**: 工場配電盤やフィールドネットワークのコモンモードノイズ、地電位差、雷サージを遮断するため、**トランス絶縁型 DCDC（絶縁5V出力）** を採用すること。
   - **DIY / ホビー用途（MAY）**: 同一電位・室内・実験用途であれば、安価な非絶縁降圧 DCDC を採用してもよい。乾電池カードも非絶縁でよい。
4. **【SHOULD】外部電源端子の保護回路**:
   - 外部電源（24V/48Vや電池）の入力部には、サージ保護（TVS/バリスタ）、短絡保護（ヒューズ/PTC）、逆接保護（P-MOSFET等）を CARD 側で完備すること。

## 4. コネクタ・機械設計ルール (Mechanical & Connector Rules)

### 4.1 20P 拡張バスコネクタ (ADX Pinout v2)
- **【MUST】ピン配置の電気的合致**:
  - すべてのカードは、[ADX Pinout 仕様書 (v2)](ADX_pinout.md) に完全準拠すること。
- **コネクタ種別の選定**:
  - **公式標準【SHOULD】**: 車載・工場の激しい振動による脱落防止、および手探り現場での逆挿し・1列ズレ挿しを完全排除するため、**MIL-DTL-83503互換 ラッチ付き Eject Header（牛角）** を標準採用とする。
  - **DIY / 一般拡張【MAY】**: 薄型化や超低コスト化を優先する場合、**通常のボックスヘッダ（シュラウド付）や単純なピンヘッダを採用してもよい**。

### 4.2 外形寸法とスタック構造
- **公式標準【SHOULD】: 8748 Form Factor 準拠**:
  - 基板外形寸法: **`87.0 mm × 48.0 mm`**
  - 取付穴: **4隅 M3 ネジ対応（Φ3.3 mm）**
  - 取付穴ピッチ: **`77.0 mm × 38.0 mm`**（外形端から `5.0 mm`）
  - 角部面取り: **C3 面取り**
  - *(詳細仕様は [8748 Form Factor 仕様書](8748_formfactor.md) 参照)*
- **サードパーティ / 自由形状【MAY】**:
  - 20P コネクタの電気的・物理的位置さえ合致すれば、小型ドーターボード型、大型シールド型、L字型など、独自の基板外形を採用してよい。

## 5. 耐熱・熱設計ルール (Thermal & Environment Rules)

1. **【MUST】熱源の分離（コアボード保護）**:
   - 高電圧降圧 DCDC、リレー駆動回路、大電力スイッチング等の発熱源は CARD 側に配置し、CORE-A へ熱を伝導させないスリットや放熱プレーン設計を行うこと。
2. **耐熱グレード選定**:
   - **公式標準【SHOULD】: Industrial Grade（-40℃ 〜 +105℃）**:
     - 産業・インフラ向け公式 CARD は、X7R コンデンサ、厚膜抵抗、工業用 IC による -40℃〜+105℃ 構成を基本とする。
   - **DIY / 一般拡張【MAY】: Commercial Grade（0℃ 〜 70℃ / -20℃ 〜 85℃）**:
     - 室内用、プロトタイプ、教育用カードでは、入手性の高い民生用部品を自由に使用してよい。

## 6. オプション機能の活用ルール (Optional Feature Rules)

以下の信号線は、用途に応じて自由に活用してよい（**【MAY】**）。

1. **バッテリー残量・電源電圧監視**:
   - 外部電源やバッテリーの生電圧を分圧し、IDC Pin 7（`PA5/AIN5`）等のアナログピンへ入力してマイコンでモニタリングしてよい。
2. **BMC連動スリープ制御**:
   - 超低消費電力待機を実現する場合、IDC Pin 18（`PC3` 等）の制御信号を CARD 側 DCDC のイネーブル（EN）ピンに接続し、スリープ時に電源回路ごと完全遮断してよい。不要な場合は常時プルアップ/直結でよい。

## 7. 開発者向けセルフチェックリスト (Developer Checklist)

基板製造（PCBA発注）を行う前に、以下の項目を必ずセルフチェックしてください：

- [ ] **【MUST】** 電源を供給する Power CARD の出力端に、逆流阻止回路（ダイオード等）を実装したか？
- [ ] **【MUST】** 20P コネクタの Pin 5（N.C.）に配線やベタが接触していないか？
- [ ] **【MUST】** 20P コネクタのピンアサイン（電源、GND、UART、I2C等）が ADX Pinout v2 と一致しているか？
- [ ] **【SHOULD】** 工場24V/48V等の高電圧を扱う場合、トランス絶縁型 DCDC を採用したか？
- [ ] **【SHOULD】** 耐振動性が必要な現場向けの場合、ラッチ付き Eject Header を選定したか？
- [ ] **【SHOULD】** 8748 筐体にスタックする場合、M3 取付穴ピッチ（`77.0 mm × 38.0 mm`）に合致しているか？
