💡 端子台配線 & 極性診断メモ
  • 基本配線: Core-D 端子台の A, B, GND を USB-RS485 アダプタに接続します。
  • A/B 逆接時の診断シグネチャ: Core-D の電源を入れた瞬間に 「赤 LED（PB2）がチカチカ点滅せず、即座に消灯する」 場合は、A と B が逆接されています。端子台で A と B の線を入れ替えてください。
