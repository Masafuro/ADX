**ADX (Advanced Devices eXtended)** は、**ARLE.cc** が開発する筐体親和型（Enclosure-Native）のオープンハードウェア・モジュラーエコシステムです。

合言葉は **「はたらく Arduino（The Working Arduino）」**。ブレッドボードや机の上で動かしたスケッチを、実際のケースや設置場所へ無理なく収め、長く安心して動かし続けるための物理・電気規格として設計されています。

<Aside type="note" title="ドキュメントポータル構築状況">
  現在、実基板の試作進捗に合わせて公式ポータルを段階的に立ち上げています。最新の仕様書やガーバーデータは <a href="https://github.com/Masafuro/ADX">Masafuro/ADX GitHub リポジトリ</a> にて常時公開しています。
</Aside>

## 共通の土台となる 2 つのオープン規格

ADX のすべての Core ボードと拡張 CARD は、以下の 2 つのオープン規格を共有します。

| レイヤー | 現行規格 | 主な特徴 |
| :--- | :--- | :--- |
| **物理・機械規格** | **8858 フォームファクタ**（正式 α 版） | `88.0 × 58.0 mm` 完全矩形（C0）、M3 取付穴ピッチ `76.0 × 46.0 mm`＋`Φ10.0 mm` 座面クリアランス、左右 `3.0 mm` カードガイド、片辺集約 `66.0 mm` I/O Edge、`M1–M4` キラル光学マーカー |
| **共通拡張バス** | **ADX 20 ピンバス**（`ADX-BUS-SPEC-v5.0`） | 2×10P 2.54mm ラッチ対応ボックスヘッダー、MCU 非依存の論理ピン ID（`P01`–`P11`）、RS-485 専用 `UART_DE`（`P03`）、連続 GND コプレーナ保護（`Pins 1, 3, 5`）、底面大電流 `VBUS`（`4.5–5.5V`, `2A–3A`）、Pin 16 `GND` 防火壁、`3.3V` ネイティブ論理 |
