# Memo

## 切り欠きノッチ
2026/08/26
筐体を3Dプリンターで造形でき、かつスナップフィットによるスロットイン構造を検討した。結果として、C3面取りのため、スナップフィットが難しくなるため、切り欠きノッチが必要であると思われた。
検討したところ、ノッチは幅3mm、直線深さ1.5mm、先頭半径1.5mmのU字形がよいと思われた。

## 8854規格での解決（スナップフィットとVカットの両立）
2026/11/09
C3面取りをオミットし完全矩形（88.0 mm × 54.0 mm）としたことで、ストレートVカットによる量産性を確保すると同時に、外形全周に均一なガイド当たり面を確保した。
さらに、下面の中央66.0 mm I/O Edge外側領域を「SMD Only（スルーホールリード突出禁止）」と定義したことにより、基板下部に筐体スナップフィット爪やスライドレールを干渉なく潜り込ませることが可能となった。これにより、基板側への特殊な切り欠きノッチ加工を行うことなくスロットイン固定を実現した。

## 8858規格（正式 α 版）への進化（パネライズ正方形化・PLC縦挿し・光学マーカー統合）
2026/11/23
長辺 88.0 mm（I/O Edge 66.0 mm・筐体込み 100mm クラス）を完全維持しつつ、短辺を 54.0 mm → **58.0 mm** へ +4.0 mm 拡張し、**8858 Form Factor 正式 α 版** として採択した。
- 200mm 角安全圏での 2×3 = 6 面付け（4 辺 5mm レール込み `186 × 184 mm`）がほぼ 1:1 の正方形となりリフロー安定性が向上。
- 縦横比 `1.52 : 1`（ブリッジサイズ・トランプおよび Raspberry Pi Model B と同等比率）を保ちつつ、CM0 の正面 USB-C 配置・Pi Zero の M3 座面間通過（36mm）・PLC 型縦挿しラックでの裏面 CM4/CM5 放熱実装・W=70 クラス市販筐体（`MB7-5-10` 等）での背面 IDC ケーブル逃がし幅（約 6mm）を両立。
- 下面 SMD Only ゾーン上下端（M3 穴と X 座標一致の `X = 6.0 / 82.0 mm`、ピッチ `76.0 × 30.0 mm`）に、キラル表裏自動判別対応の光学アライメント＆Board ID マーカー規格を正式統合。

詳細は [8858 Form Factor 仕様書（正式 α 版）](../../docs/ja/8858_formfactor.md)、[8858 検討書](../CARD/Reference/8858ff_plan.md) および [ADX Reference CARD 仕様書](../CARD/Reference/concept.md) を参照（旧規格：[8854 Form Factor](../../docs/ja/8854_formfactor.md)）。
