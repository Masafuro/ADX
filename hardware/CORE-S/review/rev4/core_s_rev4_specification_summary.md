# ADX CORE-S (Rev4) 主要仕様書（構想ドラフト）

## 1. 基本コンセプト・位置づけ

- **製品名称**: **ADX CORE-S** (Rev4)
  - ※ 従来の自己責任型プロ向け「CORE-S-P」を統合・解消し、一般・プロシューマー向け標準機として再定義。
- **製品コンセプト**:
  - **「音響機器のような手軽さでフィールドネットワークが敷設できるプログラマブルコントローラー」**
- **ターゲット用途**:
  - 舞台演出・音響照明連動、展示・空間演出、店舗・設備制御、小規模自動化、メイカー/プロシューマー向けIoT。
- **設計思想の転換**:
  - 産業用PLCの「過剰な耐熱・耐振動スペック」を削ぎ落とし、現場での**「誤配線耐性」「直感的な施工性」「低価格・高入手性」**に徹底集中。

## 2. システム・電源アーキテクチャ

### 2.1 電源仕様概要
| 項目 | 仕様・定格 | 備考 |
| :--- | :--- | :--- |
| **入力電圧範囲** | **DC 12V 〜 24V** (公称)<br>推奨動作: 10V 〜 28V | 12V/24V汎用スイッチング電源、バッテリー等に対応。 |
| **絶縁方式** | **完全ガルバニック絶縁** (電源 ＋ RS-485) | フィールド側と内部MCU/拡張側を電気的に完全分離。 |
| **内部ロジック電源** | **DC 5.0V / 最大 600mA (3.0W)** | 絶縁DC-DCモジュール (B0505S-3WR2) 出力。 |
| **実質外部給電能力** | **約 570mA** (@5V) | 本体消費（約25mA）を除く。Arduino UNO同等以上の余力。 |
| **逆接保護** | **LV1 保護** (直列ショットキーダイオード) | 幹線逆接時に電流を完全阻止。基板・ICは100%無傷。 |
| **サージ保護** | 24V系対応 TVS ダイオード (SMAJ26A/28A等) | 電源入力初段に配置。 |

### 2.2 電源ツリー (Plan A 構成)
```
[フィールド電源 12V/24V]
       │
       ▼ [SS34等: 逆接阻止ダイオード] ＋ [TVS: 24Vサージ保護]
       │
       ▼ [初段: 非絶縁降圧DC-DC (TPS5430等)] (12V/24V → 5V / 最大2A)
       │
       ├───► [非絶縁 5V] ───► RS-485 トランシーバー (二次側/バス側電源)
       │
       └───► [絶縁DC-DCモジュール: B0505S-3WR2] (5V → 絶縁5V / 600mA, 3W)
                 │
                 └───► [完全絶縁 5V] ───► MCU (ATtiny1616)
                                     ───► デジタルアイソレータ (一次側)
                                     ───► 内部拡張 Box Header (ADX Shield)
```

## 3. 通信アーキテクチャ (RS-485)

| 項目 | 仕様 |
| :--- | :--- |
| **物理層** | ガルバニック絶縁型 RS-485 (半二重) |
| **最大通信速度** | **最大 12Mbps**<br>・**DMX512 (250kbps)** ネイティブ完全対応<br>・**OTW (ファームウェア更新)** 超高速書き換え (1Mbps〜2Mbps動作) |
| **絶縁構成** | 12Mbps 高速絶縁RS-485トランシーバー (または デジタルアイソレータ＋高速トランシーバー) |
| **絶縁耐圧** | 1.5kV 以上 (PCBアイソレーションスリット設計) |
| **電源供給** | 一次側（MCU側）: 内部絶縁5V / 二次側（バス側）: 初段の非絶縁5V |
| **保護・終端** | 差動ライン保護 TVS、フェイルセーフバイアス、終端抵抗（ジャンパ/スイッチ切替） |

## 4. コネクタ・配線インターフェース (UI/UX)

### 4.1 フィールドネットワーク側端子
- **端子形状**: **Spring Clamp Terminal（スプリングクランプ端子台） 2P × 5（計10極）**
  - ネジ締め不要（レバーまたはプッシュ式）。増し締めトルク管理不要、耐振動性向上。
- **送り配線（デイジーチェーン）最適化**:
  - 1つの穴に2本共締めするのではなく、**1機能あたり2極ペア（IN/OUT）** を用意。
- **端子アサイン構成案**:
  1. `VIN` (IN) / `VIN` (OUT)
  2. `GND` (IN) / `GND` (OUT)
  3. `RS-485 A` (IN) / `RS-485 A` (OUT)
  4. `RS-485 B` (IN) / `RS-485 B` (OUT)
  5. `ISO_GND` (IN) / `ISO_GND` (OUT) （またはシールド線）
- **FG端子**: オミット（不要な混乱・GNDループ要因を排除）

### 4.2 内部拡張インターフェース (ADX Shield)
- **コネクタ形状**: **2.54mmピッチ 20P Box Header**（SMDまたはTHT、入手性最優先）
  - Ejectラッチを廃止し、低背化・コスト削減・部品調達性を劇的に向上。
- **耐振・抜け止め機構**:
  - Box Header の両脇に **タイラップスロット（スリット穴）** を基板に配置。
  - 結束バンド（タイラップ）1本でケーブルを確実にロック可能。
- **電源供給ルール**:
  - CORE-S本体からShieldへの「クローズド片方向給電」に限定。
  - 外部電源から拡張端子への逆給電機能はオミット（事故要因の排除）。

## 6. テスト・検査治具基準 (DFT)

- **2.54mm グリッドTPルール**:
  - 基板上の全テストポイント（TP）は、**「ADXフォームファクタ準拠の2.54mmピッチユニバーサル基板（スルーホール）」のグリッド座標に完全一致**して配置する。
- **検査治具の自作・運用性**:
  - 専用の検査PCBを都度外注せず、汎用ユニバーサル基板＋ポゴピンで安価・迅速に治具を製作・保守可能。
  - ENIG表面処理との組み合わせにより、ポゴピンの接触不良や酸化を根絶。
