# ADX CORE-S (Rev4) 主要仕様書（構想ドラフト）

## 1. 基本コンセプト・位置づけ

- **製品名称**: **ADX CORE-S** (Rev4)
  - ※ 従来の自己責任型プロ向け「CORE-S-P」を統合・解消し、一般・プロシューマー・現場エンジニア向け標準機として再定義。
- **製品コンセプト**:
  - **「The Strong Arduino Concept — アート＆インタラクションを過酷な現実空間へ拡張するプログラマブルコントローラー」**
  - （タグライン: *Take It Outside — Be a Real Hacker.*）
- **ターゲット用途**:
  - 屋外展示・フェス等の雨中インスタレーション、舞台・音響照明連動、広大な建築空間・展示、温室・農業IoT、店舗・設備制御、小規模自動化、実験治具。
- **設計思想の転換**:
  - 100pcsロットを前提とし、Basic Partの制約を解除。
  - **「完全ガルバニック絶縁」「60V耐圧/3A降圧」「全素子 -40℃〜+105℃ インダストリアル耐熱」「防水筐体・長距離配線適合」** を兼ね備えた、真にタフなオープンハードウェアへ昇華。

## 2. システム・電源アーキテクチャ

### 2.1 電源仕様概要
| 項目 | 仕様・定格 | 備考 |
| :--- | :--- | :--- |
| **入力電圧範囲** | **DC 12V 〜 24V** (公称)<br>実動作可能範囲: **4.3V 〜 60V** | 12V鉛蓄電池の過放電ドロップから24V系現場サージまで完全対応。 |
| **絶縁方式** | **完全ガルバニック絶縁** (電源 ＋ RS-485) | フィールド側と内部MCU/拡張側を電気的に完全分離（耐圧1.5kV以上）。 |
| **初段降圧DCDC** | **TI `LMR16030SDDAR`**<br>(入力耐圧 60V / 最大出力 3.0A) | SO PowerPAD-8パッケージ。定常負荷率わずか約27%で超低発熱。 |
| **内部ロジック電源** | **DC 5.0V / 最大 600mA (3.0W)** | 絶縁DC-DCモジュール (B0505S-3WR2) 出力。 |
| **実質外部給電能力** | **約 570mA** (@5V) | 本体消費（約25mA）を除く。Arduino UNO同等以上の余力。 |
| **逆接保護** | **100V耐圧 ショットキーダイオード** (SS310 / B3100等) | 幹線逆接時に電流を完全阻止。基板・ICは100%無傷。 |
| **サージ保護** | 24V系対応 TVS ダイオード (SMAJ26A/28A等) | クランプ電圧（42V〜45V）に対し、初段DCDC（60V）が約15Vの余裕マージンで完封。 |

### 2.2 電源ツリー (Rev4 確定構成)
```
[フィールド電源 12V/24V]
       │
       ▼ [SS310等: 100V耐圧 逆接阻止ダイオード] ＋ [TVS: 24Vサージ保護]
       │
       ▼ [初段: 60V耐圧・3A 降圧DC-DC (TI LMR16030SDDAR)] (12V/24V → 5V / 最大3.0A)
       │
       └───► [絶縁DC-DCモジュール: B0505S-3WR2] (5V → 絶縁5V / 600mA, 3W)
                 │ (1.5kV 完全ガルバニック絶縁バリア)
                 └───► [完全絶縁 5V] ───► MCU (ATtiny1616, -40〜105℃)
                                     ───► 基板管理BMC (ATtiny412)
                                     ───► DC-DC内蔵 絶縁RS-485 (CA-IS3082W, 一次側)
                                     ───► 内部拡張 Box Header (ADX Shield)
                                     ───► 各種耐熱LED (Pow, VDD, GPIO)
```
※ RS-485はDC-DC内蔵型絶縁トランシーバーを採用し、初段の非絶縁GNDを外部から完全密閉（孤島化）。幹線逆接時でもバイパス短絡ループが形成されない鉄壁の構造。

## 3. 通信アーキテクチャ (RS-485)

| 項目 | 仕様 |
| :--- | :--- |
| **物理層** | ガルバニック絶縁型 RS-485 (半二重) |
| **最大通信速度** | **最大 12Mbps**<br>・**DMX512 (250kbps)** ネイティブ完全対応<br>・**OTW (ファームウェア更新)** 超高速書き換え (1Mbps〜2Mbps動作) |
| **絶縁構成** | **Chipanalog `CA-IS3082WX`**（または TI `ISO1410` 等、DC-DC内蔵・12Mbps高速絶縁トランシーバー） |
| **絶縁耐圧** | 1.5kV 以上 (PCBアイソレーションスリット設計) |
| **保護・終端** | 差動ライン保護 TVS、フェイルセーフバイアス、終端抵抗（ジャンパ/スイッチ切替） |

## 4. コネクタ・配線インターフェース (UI/UX)

### 4.1 フィールドネットワーク側端子
- **端子形状**: **Spring Clamp Terminal（スプリングクランプ端子台） 2P × 5（計10極）**
  - ネジ締め不要（レバーまたはプッシュ式）。増し締めトルク管理不要、耐振動性向上。
- **送り配線（デイジーチェーン）最適化**:
  - 1つの穴に2本共締めするのではなく、**1機能あたり2極ペア（IN/OUT）** を用意。
- **端子アサイン構成**:
  1. `VIN` (IN) / `VIN` (OUT)
  2. `GND` (IN) / `GND` (OUT)
  3. `RS-485 A` (IN) / `RS-485 A` (OUT)
  4. `RS-485 B` (IN) / `RS-485 B` (OUT)
  5. `ISO_GND` (IN) / `ISO_GND` (OUT) （通信用シールド線）

### 4.2 インジケータLED配置
- **搭載数**: 3灯（Power, VDD, GPIO/Status）
- **仕様**: 耐熱Extended品（-40℃ 〜 +105℃対応）を採用。駆動電流は1〜2mAに設計し自己発熱をゼロ化。
- **配置場所**: スプリング端子台の直後（内側上面）、または基板上面中央の見晴らしの良いエリアに配置。透明フタの防水ケース越し、およびケース開放時に真上からクリアに視認可能。

### 4.3 内部拡張インターフェース (ADX Shield)
- **コネクタ形状**: **2.54mmピッチ 20P Box Header**（SMDまたはTHT）
- **耐振・抜け止め機構**: Box Header の両脇に **タイラップスロット（スリット穴）** を基板に配置し結束バンドでロック可能。
- **電源供給ルール**: CORE-S本体からShieldへの「クローズド片方向給電」に限定。

## 6. テスト・検査治具基準 (DFT)

- **2.54mm グリッドTPルール**:
  - 基板上の全テストポイント（TP）は、**「ADXフォームファクタ準拠の2.54mmピッチユニバーサル基板（スルーホール）」のグリッド座標に完全一致**して配置する。
- **検査治具の自作・運用性**:
  - 10pcs / 1Panel の面付け基板をそのままセットし、ポゴピン治具で全数自動テストを実施。
  - Lead Free HASLのフラットパッドにより、ポゴピンの確実なコンタクトと経済性を両立。
