## 🔍 詳細確認ガイドと画面操作手順

### 1. 主要 IC 類の確認（ピン1ドットの位置）

```text
       【3-MCU: QFN-20】                【5-BMC: SOIC-8】              【4-RS485: SOIC-8】
     +-------------------+              +---------------+              +---------------+
     |                   |              |             ●1|              |              4|
     |                   |              |               |              |               |
     |                   |              |               |              |               |
     |●1                 |              |4              |              |1●             |
     +-------------------+              +---------------+              +---------------+
     ピン1: 左下 (Rot: 0°)             ピン1: 右上 (Rot: 180°)         ピン1: 右下 (Rot: 90°)

       【1-DCDC: ESOP-8】              【2-P_SW: UDFN-8】
     +---------------+                  +-----------+
     |             ●1|                  |●1         |
     |   [Thermal]   |                  |  [PAD]    |
     |     [Pad]     |                  |           |
     |4              |                  |4          |
     +---------------+                  +-----------+
     ピン1: 右上 (Rot: 270°)           ピン1: 左上 (Rot: 0°)
```

- **確認ポイント**:
  - 各 IC のピン1 マーク（●ドット、面取り、切り欠き）が、上記アスキーアートおよび基板上のシルクスクリーンマークと完全に一致しているか確認してください。
  - 特に `5-BMC`（180°）と `1-DCDC`（270°）は一般的な 0° 配置とは異なるため、逆向きになっていないか重点確認してください。

---

### 2. ダイオード・TVS の極性確認（カソードラインの向き）

ダイオードの逆実装は、**電源投入の瞬間に即短絡・焼損・発火を引き起こす最も危険なミス** です。

```text
    【0-D1: 逆流防止ダイオード (SS54)】          【1-D2: キャッチダイオード (SS54)】
          (基板内側)        (端子台側)                      (GND側)
             [K]               [A]                            [A]
          +-------+         +-------+                      +-------+
          | |||   |---------|       |                      |       |
          | |||   |---------|       |                      +-------+
          +-------+         +-------+                          |
          カソード帯: 左側を向いていること                     |
                                                               |
                                                           +-------+
                                                           | |||   |
                                                           | |||   | カソード帯: 下側
                                                           +-------+
                                                              [K]
                                                           (PH端子側)
```

- **`0-D1` (SS54, 逆流防止)**:
  - カソード（白帯）が **「左（基板内側）」**、アノードが **「右（端子台 `+7_16V` 側）」** です。
  - ※もし逆（カソードが右）になっていると、電源を入れても基板に給電されません。
- **`1-D2` (SS54, DC-DC キャッチダイオード)**:
  - カソード（白帯）が **「下（TPS5430 PH端子 / インダクタ側）」**、アノードが **「上（GND側）」** です。
  - **⚠️ 警告**: これが逆になると、電源投入時に DC-DC のスイッチングピンが GND に直結し、TPS5430 が一瞬で爆裂破壊します。
- **`0-D2` (SMAJ20A, TVS ダイオード)**:
  - カソード（白帯）が **「上（+7_16V 電源ライン）」**、アノードが **「下（GND）」** です（単方向 TVS）。
  - **⚠️ 警告**: これが逆になると、通常通電時に順方向ダイオードとして機能してしまい、電源を短絡してヒューズ `0-F3` が溶断します。

---

### 3. 有極性コンデンサ・LED の確認

- **`1-C7` (220uF 16V 固体電解コンデンサ)**:
  - 缶天面の有色マーキング（黒または青の帯）は **「マイナス端子（GND）」** を示します。
  - マイナス帯が **「上側（GND）」**、プラス端子が **「下側（5V 出力）」** に向いていることを確認してください。
- **`9-LED-5V` (白) & `9-LED-VDD` (赤)**:
  - チップ LED のカソードマーク（裏面の緑色ライン、または表面のドット/T字）が **「下側（GND側）」** を向いていることを確認してください。

---

### 4. DNP（未実装）部品の確認

- **`H1`, `H2`, `H3` (1P ピンヘッダ)**:
  - 手はんだ用のテストピン／UPDI ピンです。
  - JLCPCB のプレビュー上で部品が割り当てられていないこと（No Component / DNP）、またはチェックを外して **「DNP」** に設定されていることを確認してください。

---

### 5. パッシブ部品（0402 / 0603 / 1206）のアライメント確認

- 抵抗・積層セラミックコンデンサ（MLCC）に極性はありませんが、**パッドの中央から大きく偏芯（オフセット）していないか** をざっと全体プレビューで確認してください。
- 特にインダクタ `1-L4`（HCMA-0630）や 1206 サイズのコンデンサ `3-C1`, `3-C9` が隣接パッドとショートしそうな位置にずれていないか確認します。

## 🛠️ プレビュー画面でズレや回転を発見した場合の修正方法

JLCPCB の Component Placements 画面で部品のズレや回転を見つけた場合は、以下の手順で画面上から直接修正できます：

1. **回転角（Rotation）の修正**:
   - ズレている部品を行リストまたはプレビュー上でクリックします。
   - 画面右側のプロパティ欄にある **「Rotation」**（または `+90°`, `-90°`, `180°` ボタン）をクリックして、シルクマークと合致する角度に修正します。
2. **位置（Offset）の修正**:
   - ランドから中心がずれている場合、**「Offset X」** / **「Offset Y」** に数値を入力（例: `+0.2mm` など）するか、矢印ボタンでパッド中央に移動させます。
3. **未実装（DNP）への切り替え**:
   - `H1`〜`H3` などのテストピンに誤って部品が割り当てられている場合は、該当行の **「Do Not Place (DNP)」** にチェックを入れます。
