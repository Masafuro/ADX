# PL-N規格：緊急停止・安全保護レイヤー設計案 
## 1. 概要

PL-N (Power Line Network) は、1,000mの長距離伝送と48V給電を前提とした産業・農業向けフィールドネットワーク規格である。本資料では、ATtiny1616の周辺機能（CCL, Event System）を活用した、ソフトウェアを介さない超速緊急停止および復旧シーケンスについて定義する。

---
## 2. 三段階の緊急停止アーキテクチャ

### 第一層：ローカル・ハード・シャットダウン (Internal Layer)

各ノード（ADXボード）内部で完結する物理保護。CPUのフリーズやバグの影響を受けない。
- **トリガー:** 現地緊急停止ボタンの押下、過電流検知、または通信線異常（L固定）。
- **実現手段:** 
  - **CCL (Configurable Custom Logic):** 複数の異常入力の論理和（OR）をハードウェアゲートで合成。
  - **Event System:** CCLの出力をCPUを介さず、直接タイマーユニット（TCA0/TCB0）のFault入力へ転送。
- **結果:** 数ナノ秒〜数マイクロ秒でPWM出力を強制遮断（Hi-ZまたはL固定）。
### 第二層：グローバル・フィジカル・シャットダウン (Network Layer)
一箇所のエラーをネットワーク全体に「物理現象」として波及させる仕組み。
- **トリガー:** いずれかの子機による異常検知。
- **実現手段:** 
  - **ドミナント・エラー出力:** 異常を検知した子機が、RS-485のTXを強引に「Lレベル（ドミナント）」で固定し、バス全体を引き倒す。
- **結果:** 
  - **マスター:** 自身の送信信号との不整合（ISF）をUSARTハードウェアが検知し、即座に送電ブレーカーを遮断。
  - **他スレーブ:** バスが一定時間以上L（Break状態）であることを検知し、出力を安全側に固定。
  - **通信遅延:** 1,000mの往復遅延（約10マイクロ秒）以内での全系停止を実現。
### 第三層：ロジカル・セーフティ (Application Layer)
LN-485プロトコル上での制御。
- **実現手段:** マスターからの定期ポーリング（スケジュールサイクル）による生存確認。
- **結果:** 軽微な異常やステータス変化に基づき、計画的な停止・隔離を行う。
---
## 3. 復旧（リカバリ）シーケンス

動力線（パワー）と制御線（ロジック）の管理を分離したPL-N特有の復旧手順。
1. **微弱給電診断モード:** 
   マスターは動力用大電流を遮断したまま、制御用電力を供給可能な制限電流モードでバスを加圧。
2. **分散IDスキャン:** 
   ATtiny1616たちが目覚め、マスターが「誰がバスを落としたか（ドミナント発動の有無）」を順次問い合わせる。
3. **原因特定:** 
   子機はEEPROM等に保持された「停止トリガー情報」を回答。マスターは現場の安全を確認。
4. **段階的再印加:** 
   全ノードの出力をソフト・ハード両面でロックした状態を確認後、マスターが48Vフルパワーを印加。その後、個別にロックを解除。

## 4. ハードウェア資源の最適化（ATtiny1616）
スケッチ容量（16KB）とRAM（2KB）の節約のため、以下の周辺機能を「ライブラリ化」して実装する。

| 機能ブロック             | 役割                | 恩恵                    |
| :----------------- | :---------------- | :-------------------- |
| **CCL**            | 異常信号の物理合成         | ソフトウェアロジックの排除、バグ耐性    |
| **Event System**   | 信号の高速道路（直結）       | CPU負荷ゼロ、超低レイテンシ       |
| **USART (LINモード)** | Break検知・Auto-baud | 1,000mの波形歪み・クロックズレの吸収 |
| **ACMP / ADC**     | 電圧・電流のWindow監視    | 低電力診断モードの自動判定         |
  

---
## 5. 結論

PL-N規格 v1.4 は、**「IP解決を排した物理直結の安全性」**と**「DCS（分散制御システム）による自律性」**を両立する。これにより、既存のEthernetベース産業規格では困難な、1,000m四方の過酷な環境における「絶対的な安心」を、極めて低コストで提供する。
