## 2. 今回の準備運動で EasyEDA AI API に対して検証したい 6 要素

[status_summary.md](../../../agent/easyeda/status_summary.md) の M4 PoC（「Hello Circuit」）では、受動部品＋LED の計 5 部品を 15mil・トップ層のみ・ビアなしで一気通貫させることに成功しました。次の段階（M5 への橋渡し）では、以下の 6 要素を「壊してもいい SANDBOX」で踏み抜いておくのが最も価値があります。

1. **多ピン IC の配置とファンアウト**：TQFP-32 / SOP-16 / モジュール等、2 端子部品以外のピン座標実測とネット接続。
2. **USB Type-C 周りの定番回路**：CC1/CC2 の 5.1kΩ プルダウン、D+/D- 配線、LDO 電源生成とパスコン配置。
3. **2 層配線＋ビア＋両面 GND ベタ**：交差の回避、ビア（`pcb_PrimitiveVia`）生成、表裏 GND プレーンとステッチング。
4. **厳密なメカ寸法・取付穴・コネクタ座標のコード生成**：任意多角形や斜めカットの外形、ミリ/ミル指定のヘッダ配置（ADX 8858 外形＋20P IDC 自動化の直接練習）。
5. **大量のピン名シルク印刷の自動配置**：`D0..D13` / `A0..A5` 等を規則的に並べるスクリプト化。
6. **AI と人間の「損益分岐点（分業点）」の体得**：どこまで JS スクリプトで自動化すると気持ちよく、どこから人間が GUI で配線・仕上げをした方が速く美しいかを見極める。

> [!NOTE]
> **JLCPCB 製造コスパの前提**: `100 × 100 mm` 以内の 2 層基板（`1.6mm`）はベア基板製造が最安帯。Economic PCBA では**片面 SMT 実装・受動部品は 0603/0402 Basic Part 統一・端面スルーホール（Castellated holes）回避**がコストを抑える鍵になります。MCU や USB-UART IC 等の Extended Part は 1 種類につき `$3` のセットアップフィーが掛かるため、ユニークな Extended 部品の種類数が少ないほど安価になります。

## 4. 各候補の詳細分析

### 候補 1：【最有力・王道】Arduino UNO R3 現代風パチモン（仮称：`UNOMODOKI`）

- **参考対象**: Arduino UNO R3（`68.6 × 53.4 mm`、オープンハードウェア CC BY-SA 4.0）
- **パチモンとしての割り切り構成（推奨）**:
  - 本家の巨大 USB-B・ATmega16U2・DC ジャック・オペアンプ自動電源切替を潔くカットし、中華互換機でも定番の **「USB-C 専任 ＋ CH340C（水晶レス）＋ ATmega328P-AU（TQFP-32）＋ 16MHz セラロック（or 水晶）＋ 3.3V LDO（AMS1117-3.3）＋ 各種 LED・リセット SW・ソケット/ピンヘッダ」** へ簡略化。
- **なぜ AI API の 1 枚目に最強か**:
  1. **面積の余裕が圧倒的**: 約 `3,660 mm²` と、Nano（`810 mm²`）や XIAO（`374 mm²`）の数倍〜約 10 倍の広さがある。2 層基板でも信号線・電源線を余裕を持って引き回せるため、「密集しすぎてスクリプト配線が詰む」事故を避けつつ、ビア＋表裏 GND ベタの基本をしっかり試せる。
  2. **ピッチが優しい**: `ATmega328P-AU`（TQFP-32）は `0.8mm` ピッチ、`CH340C`（SOP-16）は `1.27mm` ピッチ。2 層標準ルール（線幅 6〜10mil / クリアランス 6mil）で余裕でファンアウト可能。
  3. **メカ座標生成の最高の教材**: 右端の特徴的な斜めカット外形、非対称な 4 つの M3 取付穴、そして歴史的経緯で有名な **D7 と D8 間の 160mil（4.06mm）ズレ（「Arduino Gap」）** を数値座標スクリプトで寸分違わず生成でき、「既存の UNO シールドが本当に刺さる！」という明確な合格基準が持てる。
  4. **ADX 本丸への直結度が高い**: `USB-C` ＋ `WCH USB-UART` ＋ `LDO` ＋ `AVR マイコン` ＋ `ピン番号シルク大量配置` という構成は、[ADX CORE-U rev6](../../CORE-U/rev6/spec.md)（Dual USB-C + CH342K + ATtiny1616）の設計要素と驚くほど重なる。
- **注意点**:
  - ピンヘッダ（6P/8P/8P/10P）や 6P ICSP ヘッダは THT 部品なので、PCBA するなら SMT のみ工場実装＋ヘッダは手はんだ（または THT なしベア基板確認）と割り切ると Economic 枠に収まる。
  - ATmega328P の新品チップにはブートローダーが入っていないため、実機動作まで行う場合は ICSP 6P ヘッダを残しておくと手持ちライタで焼ける。

### 候補 2：【超穴場・最速実用】Wemos / LOLIN C3 Mini パチモン（仮称：`C3-MODOKI`）

- **参考対象**: Wemos / LOLIN C3 Mini（D1 Mini フォームファクタ：`34.3 × 25.4 mm`）
- **構成**:
  - **ESP32-C3-MINI-1**（Wi-Fi / BLE / 4MB Flash / 40MHz 水晶 / RF 整合 / PCB アンテナ / 日本技適をすべて内包）
  - **USB Type-C**（ESP32-C3 内蔵の USB Serial/JTAG に `D+`/`D-` 直結、5.1kΩ CC 抵抗×2 → **USB-UART チップ不要！**）
  - **3.3V LDO**（AMS1117-3.3 または ME6211 系）＋パスコン
  - `EN` プルアップ＋遅延コンデンサ、`BOOT` / `RST` スイッチ×2、電源/ユーザー LED（または WS2812B 1個）、左右 2×8P ピンヘッダ
- **強み**:
  - **部品数がたった 15〜22 点前後**で、回路が拍子抜けするほどシンプル。
  - Extended 部品が実質 `ESP32-C3-MINI-1` と `USB-C`（Basic の USB-C を使えばモジュール 1 種のみ！）程度に収まり、**JLCPCB PCBA コストが極めて安い**。
  - 出来上がったものがそのまま Arduino IDE / ESP-IDF / MicroPython で動く Wi-Fi マイコンになり、遊び道具としての満足度が高い。
- **注意点**:
  - **アンテナ Keep-out ルール**: モジュールのアンテナ部直下および周囲には銅箔・配線・GND ベタを一切置かない（基板端から少し突き出すか、外形カット・禁止領域をスクリプトで定義する良い練習になる）。
  - **日本国内での電波法（技適）**: 実際に日本で Wi-Fi/BLE を吹く場合、技適認証番号（TELEC）取得済みの正規品モジュール（`ESP32-C3-MINI-1` 等）を使い、Espressif のリファレンス通りの電源・アンテナ周辺配置を守ること。

---

### 候補 3：【実利最速・最小ステップ】USB-C UART / SerialUPDI 変換アダプタ（仮称：`UART-MODOKI`）

- **参考対象**: SparkFun Serial Basic Breakout / Adafruit FTDI Friend（`~35 × 18 mm`）
- **構成**:
  - `USB-C` ＋ `CH340C`（または CORE-U rev6 と同じ **`CH342K`**！）＋ 3.3V/5V 切替ジャンパ（or LDO）＋ TX/RX/PWR LED ＋ 保護抵抗・ダイオード ＋ 6P ピンヘッダ（＋ UPDI 4.7kΩ 抵抗ジャンパ）
- **強み**:
  - **12〜18 部品**で確実に 1 日で一気通貫（回路図 → PCB → Gerber → BOM/CPL）を完走できる。
  - もし `CH342K` を使えば、**CORE-U rev6 に載せる USB-UART チップの LCSC 選定・フットプリント・ピン座標・配線ノウハウを事前に 100% 検証できる**。
  - 作った基板がそのまま ATtiny1616（ADX）の SerialUPDI ライタ／USB デバッガとして手元で役立つ。
- **弱み**:
  - 「有名マイコンボードのパチモンを作った！」というエンタメ性・視覚的インパクトは UNO や Pico に一歩譲る。

---

### 候補 4：【定番コンパクト】Arduino Nano v3 現代風パチモン

- **参考対象**: Arduino Nano v3（`45.0 × 18.0 mm`）
- **特徴**:
  - 回路は UNO 現代風パチモンとほぼ同等（25〜32 点）。
  - ただし幅 `18mm` の両縁に 15P×2 列のピンヘッダ（間隔 `15.24mm`）が並ぶため、**内側の実効幅がわずか約 `12〜13mm`** しかない。その狭い回廊に TQFP-32 と SOP-16 と 30 本の引き出し線を収める必要があり、2 層配線難易度は UNO より明確に高い。
- **評価**:
  - 「狭い基板で AI API の配置・配線限界を試したい」なら面白い題材。初手の気持ちよさ重視なら UNO に軍配。

---

### 候補 5：【超軽量マイコン】Arduino Pro Mini / CH32V003 ミニボード（WeAct 風）

- **参考対象**: Arduino Pro Mini（`33.0 × 18.0 mm`、ATmega328P 単体） / WeAct CH32V003（`26.0 × 16.0 mm`、TSSOP-20）
- **特徴**:
  - USB-UART ブリッジを持たないため部品数が 12〜20 点と極小。特に CH32V003 はチップ単価が十数円で、内蔵 RC を使えば水晶すら不要。
- **評価**:
  - 「M4 の 5 部品から、まずは 15 部品＋多ピン IC 1 個だけ試す」用途には手軽。ただし USB-C や UART の練習が抜けるため、ADX への準備運動としてはやや物足りない。

---

### 候補 6：【ネイティブ USB AVR】SparkFun Pro Micro パチモン

- **参考対象**: SparkFun Pro Micro（`33.0 × 18.0 mm`、ATmega32U4、CC BY-SA 4.0）
- **特徴**:
  - ATmega32U4 が USB 機能を内蔵しているため、CH340 なしでそのまま USB キーボード／マウス（HID）になる楽しさがある。
- **弱み**:
  - ATmega32U4 自体が現在やや高価かつ 44 ピンで、幅 `18mm` の基板に収める配線密度も高め。手軽さとコスパでは UNO / C3 Mini に譲る。

---

### 候補 7：【親指サイズ造形美】Seeed Studio XIAO / Adafruit QT Py パチモン

- **参考対象**: Seeed XIAO / Adafruit QT Py（`21.0 × 17.8 mm`、左右 7P×2）
- **特徴**:
  - 見た目が最高に可愛く、ピン数も 14 本と少ない。中身を ADX と縁のある `CH32X035` や `ATtiny1616` に差し替える遊び（「XIAO の皮を被った ADX 系マイコン」）も映える。
- **注意点**:
  - 基板面積が UNO の約 1/10 と極小なうえ、USB-C レセプタクルだけで面積の約 1/4 を占めるため、**2 層での配置・配線パズル難易度は高い**。
  - 本家通りの端面スルーホール（Castellated holes）を JLCPCB に発注すると追加製造費がかかるため、遊ぶなら通常のスルーホールピンヘッダに簡略化するのが現実的。

---

### 候補 8：【ロマン枠・第 2 弾ボス戦】Raspberry Pi Pico 簡略パチモン（仮称：`PICO-MODOKI`）

- **参考対象**: Raspberry Pi Pico（`51.0 × 21.0 mm`）および公式ドキュメント *Hardware Design with RP2040*（Minimal Design）
- **簡略化案（現実解）**:
  - 本家の Buck-Boost DCDC（RT6150B＋インダクタ）を **3.3V LDO（AMS1117-3.3 等）** に置き換え、端面スルーホールは通常の 2.54mm スルーホールに変更（いわゆる RP2040-Zero 的な LDO 割り切り構成）。
- **強み**:
  - Raspberry Pi 公式が KiCad リファレンスと詳細なハードウェア設計ガイドを公開しており、「正解の教科書」の完成度は全候補中ナンバーワン。
  - 見た目のカッコよさと「RP2040 を自力（＋AI API）で起こした！」というロマンは抜群。
- **初手として避けるべき理由（第 2 弾推奨）**:
  1. **0.4mm ピッチ QFN-56**（底面 GND サーマルパッド＋サーマルビア群）は、2 層基板でのファンアウト・電源デカップリング配置（IOVDD / DVDD / USB_VDD / ADC_AVDD）がシビア。
  2. 外付け QSPI Flash（`W25Q16` / `W25Q128`）、12MHz 水晶、USB 差動ペア（27Ω 直列抵抗付き）など、**配置制約の厳しい高速・アナログ系ブロックが同時に 3 つ入る**。
  3. まず UNO や C3 Mini で「EasyEDA AI API の癖（ビア・ベタ・部品回転・シルク・人間との分業境界）」を掴んだあとに挑むと、消耗せず最高に楽しめる。

### （番外・変化球アイデア）「異種移植パチモン」

もし純粋な互換機よりも少し ADX 寄りの遊び心を加えたければ、次のような変化球も面白いです。

- **「皮は完全に UNO R3、中身は ATtiny1616 + CH342K」**:
  - 外形・取付穴・160mil ズレピンヘッダは UNO 互換のまま、中身だけ [CORE-U rev6](../../CORE-U/rev6/spec.md) の主要石（ATtiny1616 + CH342K）の最小構成に差し替える。
  - 遊び心 100% でありながら、CORE-U rev6 の実チップ・LCSC 部品・配線テストを丸ごと先取りできる一石二鳥の実験になります。

## 5. おすすめの進め方（2 つの推奨ルート）

### ルート A：王道「見た目・楽しさ・準備運動」全部取り（おすすめ）
1. **第 1 弾：`UNOMODOKI`（Arduino UNO R3 現代風・USB-C 専任パチモン）**
   - 広い 2 層基板で、30 部品規模の回路図自動生成 → 正確な外形・穴・160mil ズレヘッダ配置 → 大量シルク自動生成 → 「どこまで API 配線して、どこから GUI 手直しするか」の分業点を検証。
2. **第 2 弾（気が向いたら）：`PICO-MODOKI`（RP2040 LDO 簡略版）**
   - QFN-56・外付け Flash・水晶・高密度 2 層（または 4 層）にステップアップ。

### ルート B：超ライト「まず 1日で完走して手触りを掴む」
1. **第 1 弾：`C3-MODOKI`（ESP32-C3-MINI-1 載せ D1 Mini 風）** または **`UART-MODOKI`（CH342K / CH340C 変換アダプタ）**
   - 15〜20 部品の軽量構成で、ビアあり 2 層基板＋USB-C を最速で完走。

## 6. 制作に入る前に押さえておくべき権利・運用ルール

公開リポジトリ（ADX）の `hardware/SANDBOX/cloning/` に成果物を置いていくにあたり、以下 4 点を最初からルール化しておくと後でトラブルになりません。

1. **クリーンルーム実装（ライセンス衝突の回避）**
   - [hardware/README.md](../../README.md) は `CERN-OHL-P-2.0` を採用している一方、Arduino UNO・SparkFun Pro Micro・Digispark 等の公式 CAD ファイルは `CC BY-SA` 系です。
   - 公式 EAGLE/KiCad ファイルをそのまま流用・変換してリポジトリに含めると ShareAlike 条項とライセンスが衝突する恐れがあるため、**公開されている外形寸法・ピン配列・電気的仕様のみを参照し、EasyEDA AI API スクリプトでゼロから独自に回路図・PCB を生成する**方針にします（API 検証の目的とも完全に一致します）。
2. **商標・公式ロゴの不使用**
   - シルク印刷・プロジェクト名・ドキュメントに `Arduino`、`Raspberry Pi` 等の登録商標や公式ロゴは入れず、堂々とパチモン名義（例：`UNOMODOKI`、`C3-MODOKI`、`PICO-MODOKI`）を使います。
3. **SANDBOX の位置づけ明記**
   - `hardware/SANDBOX/` は「EasyEDA AI API 実験・遊び用の非公式領域（ADX 規格準拠・動作保証の対象外）」であることを、実作開始時にディレクトリ直下の短い README に明記します。
4. **EasyEDA ローカル専用プロジェクト運用**
   - [agent_rules.md](../../../agent/easyeda/agent_rules.md) に従い、本番の ADX クラウドプロジェクトには一切触れず、ローカルのテスト用 `.eprj3` プロジェクト上で生成・検証（SCH DRC 0 / PCB DRC 0 / 未配線 0 / PNG 目視確認）を行います。
