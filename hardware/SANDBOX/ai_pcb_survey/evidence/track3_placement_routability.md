# Track 3 エビデンス調査：自動配置（力学的・Component-Centric）× 配線不可能性フィードバック

- **調査日**: 2026-11-28
- **位置づけ**: `UNOMODOKI R3` 課題 4-1（磁石ポテンシャル場構想）および課題 4-3（配線不可能性と配置-配線協調最適化）の先行研究・アルゴリズム精査

---

## 1. リサーチクエスチョン（RQ）

1. PCB 自動配置において、**Force-Directed（力学・静電場）**・**RL（強化学習）**・**Component-Centric（核中心階層）**・**最適化（MILP/SA）** はそれぞれどこまで到達しているか？
2. VLSI 配置と異なる PCB 固有の難題（**異種サイズ・離散回転 $0/90/180/270^\circ$・Courtyard 非重複・コネクタ固定・両面実装**）はどう解かれているか？
3. **「配置が悪いせいで物理的に配線不能（Unroutability）」** をどう事前検知し、部品の回転・再配置へ自動フィードバックするか？
4. 30〜100 部品級（`CORE-U rev6` 規模）の基板に対し、ADX が学習データなしで実装できる最適な配置エンジンは何か？

## 2. 先行研究から得られた一次エビデンス

### 2.1 PCB 自動配置の最新 SOTA（2023–2026）

1. **`Cypress`（Zhang, Agnesina, Ren et al. / Cornell Univ. & NVIDIA, ISPD 2025 Best Paper Award）**
   - VLSI 向け GPU 解析配置（`DREAMPlace` 系譜：**ネット引力＝ばね／HPWL、部品重なり斥力＝静電ポテンシャル場**）を PCB 固有制約へ拡張。
   - **技術的ポイント**:
     - グローバル配置では「ソフト重なり」を許しながら力学／静電場で滑らかに位置と回転を最適化。
     - 後段の **リーガライゼーション（Legalization）** で Courtyard 重なりゼロ・外形内収容を厳密保証。
   - **意味合い**: ADX の「磁石 N/S ポテンシャル場」直感は、まさに **Analytical / Electrostatic Force-Directed Placement** の王道そのもの。ただし **「ポテンシャル場単体では Courtyard 非重複が保証されず、必ずリーガライゼーション段が必要」** というのが数理上の鉄則。

2. **`PCBAgent`（Chen et al., ASP-DAC 2025, DOI: `10.1145/3658617.3697736`）**
   - **LLM（制約・優先度の対話的解釈）＋ RL 配置エージェント** を組み合わせた高密度 PCB 配置フレームワーク。
   - **核心アイデア（Component-Centric 構造化）**:
     - 全 50 部品をフラットに最適化するのではなく、**主要 IC（MCU / PMIC / コネクタ等）を核として周囲に衛星部品（デカップリングコンデンサ・プルアップ・水晶・シャント等）をグルーピング配置** することで探索空間を劇的に縮小し、人間らしい高密度配置を実現。
   - **ADX への示唆**: これは `UNOMODOKI R3` 課題 2 の **「3 階層マッス設計」** の数理的正当化に他ならない！しかも **30〜100 部品規模なら、RL を訓練しなくても「LLM によるマッス＆核部品グルーピング ＋ 決定的 Force-Directed / Simulated Annealing 局所最適化」で同等の構造的メリットが得られる**。

3. **`RL_PCB`（Vassallo & Bajada, DATE 2024, GitHub: `LukeVassallo/RL_PCB`）**
   - PCB 配置を MDP（マルコフ決定過程）として定式化し、PPO/SAC/TD3 で配線長＋混雑度ペナルティの適応報酬を学習。従来 SA（焼きなまし）より二桁 % の配線長短縮を達成。
   - **ADX にとっての現実的制約**: 訓練コストと未知ボード形状・特殊メカ制約（`8858 Form Factor` の四隅 M3 穴・20P IDC 固定・デュアル USB-C 端面固定など）への汎化コストが高く、少量多品種の自社基板 R&D にはオーバースペック。

4. **`NS-Place`（Cheng et al., [arXiv:2210.14259](https://arxiv.org/abs/2210.14259)）— Net Separation & Margin Maximization**
   - **配線しやすさ（Routability）を配置段階で直接最大化** する数理フレームワーク。
   - 座標降下＋MILP リーガライゼーションにより、高密度ネット間に意図的な配線余白（マージン）を確保し、ビア数と配線長を同時削減。

### 2.2 配線不可能性（Unroutability）・交差最小化・回転最適化のメカニズム

先行研究を総合すると、配置が原因で配線不能になるパターンは主に **3 種類** あり、いずれも **配線前の軽量な決定的評価関数** で大幅に事前検出できる：

1. **トポロジ的ねじれ（Pin-Out Crossing / Rotation Mismatch）**
   - IC やヘッダ・抵抗の回転角（$0/90/180/270^\circ$）が悪いだけで、隣接バス（例：`ATtiny1616` ⇄ `IDC 20P`）のラッツネストが何重にも交差（Edge Crossing）し、2 層基板ではビア渋滞で即詰む。
   - **対策（グラフ平面化・交差数最小化）**: 配置評価関数に **「総配線長（HPWL）」だけでなく「ラッツネスト線分の 2D 交差数（Crossing Count）」** を組み込み、**各部品（特に QFN MCU や多ピン IC・抵抗アレイ）の 4 方位回転を自動探索** するだけで、2 層配線の難度が劇的に下がる。
2. **局所配線チャネル枯渇（Congestion Bottleneck）**
   - 部品 Courtyard 同士は重なっていなくても、隙間が `15 mil` しかなく 5 本の信号線（必要幅 `~60 mil`）が通れないケース。
   - **対策（粗グリッド混雑マップ＋マージン確保）**: ボードを粗いグリッド（例：`50〜100 mil` セル）に分割し、各ネットの L 字／バウンディングボックス通過密度（RUDY: Rectangular Uniform wire DensitY）を計算。セル容量を超過した領域に斥力をかけて部品を広げる（`NS-Place` や古典的混雑駆動配置のエッセンス）。
3. **ピン・対・固定コネクタの閉ループフィードバック（Placement–Routing Co-Optimization）**
   - 実際にヘッドレスルーター（FreeRouting 等）を **短時間（数パス・数秒）テスト実行** し、「未配線ネット（Unrouted Airwires）」「ビア集中座標」「最大迂回率ネット」を抽出して、**その周辺部品の回転変更または位置シフト（斥力増大）を自動試行する閉ループ** が、学習ベース混雑予測モデルよりも 30〜100 部品規模でははるかに正確かつ実装が軽い！

### 2.3 グラフ描画（Force-Directed Graph）による試作の有効性と限界

- ネットワーク可視化・グラフ描画（ばねモデル、Fruchterman-Reingold、Cola.js / 制約付き力学レイアウト等）を **「第 1〜2 階層（マッス間フロアプランニング ＆ ラッツネスト交差最小化の視覚的試作）」** に使うアプローチは、以下の理由で非常に合理的である：
  - 部品間の接続強度（バス本数・電流・差動ペア重み）をエッジ重み、固定コネクタ（USB-C / IDC 20P / M3 穴）をピン留めノード（Fixed Anchor）として表現でき、**人間と AI の双方が「どこで配線がねじれているか」を数秒で俯瞰・試行錯誤できる**。
- **ただし絶対に忘れてはいけない限界（転写時の罠）**：
  - 一般グラフ描画は「ノード＝点（中心座標）」だが、実 PCB は **「ピン位置が外周に偏在する剛体（回転すると交差数が激変する）」** かつ **「Courtyard 厳密非重複・配線チャネル幅」** が支配する。
  - したがって、**「グラフ力学＝フロアプラン＆粗配置の下書き」→「ピン座標ベース回転最適化＋Courtyard リーガライゼーション＋交差数・RUDY 評価」→「EasyEDA Pro 転写」** という **2 段パイプライン** にするのが数理的に正しい。

## 3. Track 3 判定：Adopt / Adapt / Build（ADX 向け）

| 要素 | 判定 | ADX（EasyEDA Pro / `CORE-U rev6`）での具体方針 |
| :--- | :---: | :--- |
| **独自 RL 配置モデルのゼロ訓練（`RL_PCB` 型）** | **Do Not Adopt** | 30〜100 部品の少量自社設計ではデータ・訓練コストが割に合わない。 |
| **Component-Centric マッス配置（`PCBAgent` エッセンス）** | **Adopt（設計原則）** | LLM が主要 IC（`ATtiny1616`, `TPS259470A`, `CH342K`, `TP181A2`）を核とするマッス＋衛星部品の相対関係（例：デカップリングコンデンサ `< 2 mm`）を定義。 |
| **Force-Directed フロアプラン ＋ ピン基準回転探索 ＋ Courtyard リーガライゼーション** | **Build（軽量ソルバー）** | 固定メカ（8858 外形・M3 穴・IDC 20P・Dual USB-C）をアンカー固定し、**① HPWL ＋ ② 2D 交差数（Crossing Count）＋ ③ RUDY 混雑度 ＋ ④ Courtyard 非重複** を最小化する軽量 Node/Python ソルバー（SA / Force-Directed）を構築。 |
| **ヘッドレス短時間ルーティングによる「不可能性→再配置」フィードバック** | **Adapt / Build** | 候補配置に対しヘッドレス FreeRouting（短パス）を自動試行し、未配線ネット・高ビア集中ネットに関与する部品の回転・間隔を自動修正する閉ループを実験する。 |
| **グラフベース可視化・試作ツールによる人間協調フロアプラン** | **Adapt（試作推奨）** | マッス配置・交差解消の直感的デバッグ＆人間レビュー UI として活用し、ピン座標リーガライザー経由で EasyEDA Pro へ転写する。 |
