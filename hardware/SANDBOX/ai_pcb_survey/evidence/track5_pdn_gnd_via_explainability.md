## 2. 先行研究・SI 権威・ツールから得られた一次エビデンス

### 2.1 電磁界物理の鉄則（Rick Hartley / Eric Bogatin の定説）

1. **「信号線は角を恐れない。基準プレーンを失うことを恐れる」**
   - 高周波成分（クロック・USB・立ち上がりエッジ）のエネルギーは銅箔と基準プレーン間の誘電体内を電磁界として伝播し、リターン電流は信号線の直下（インダクタンス最小経路）を流れる。
   - 信号線が **GND プレーンの切れ目（スリット／ボイド／別信号線の裏抜き）を跨ぐ** と、リターン電流が大きく迂回して巨大な電流ループを形成し、ループアンテナとして EMI 放射・クロストーク・GND バウンスを引き起こす。
2. **2 層基板 vs 4 層基板の決定的な構造差**
   - **2 層基板**：表裏両面で信号配線すると必ず裏面 GND プレーンが分断され、AI 配線でも孤立島救済のモグラ叩き（`UNOMODOKI R3` U4-c〜f で実体験済み）が発生しやすい。
   - **4 層基板（例：`L1 Signal` – `L2 Solid GND` – `L3 Power / GND` – `L4 Signal`）**：`L2` に一切分断のないベタ GND 基準プレーンを置けるため、①リターンパス保証が劇的に簡単になり、② **AI オートルーターの配線成功率・ビア数・孤立島問題が一気に激減** し、③ `-40〜+85℃` 産業現場での耐ノイズ・放熱性能が大幅に向上する。
   - **ADX 向けコスト視点**: `CORE-U rev6`（`88 × 58 mm`・目標製造原価 `≤ $6.50` / 120 pcs）では、JLCPCB 4 層標準基板の差額を BOM 原価（現在想定 `$5.70〜$5.95`）と照合し、**「2 層で複雑な GND 救済に苦しむ vs 4 層で L2 連続 GND を確保して AI 自動配線の安定性と産業耐性を取る」** の定量トレードオフ評価を行う価値が極めて高い。

### 2.2 GND ビア配置の定量的ルール（電気的・熱的・機械的意味論）

先行の SI/EMC/熱設計標準を、AI がそのまま自動配置・自動監査できる **5 つの意味論クラス（Via Semantic Taxonomy）** に整理できる：

| ビア意味論クラス | 電気的／熱的／機械的根拠（一次知見） | 定量ルール（自動配置・監査パラメータ） | `CORE-U rev6` での具体適用箇所 |
| :--- | :--- | :--- | :--- |
| **`RETURN_TRANSITION`**<br>*(リターン電流橋渡し)* | 信号ビアが基準層を跨ぐ際、リターン電流の垂直帰路を提供（Rick Hartley / Eric Bogatin 原則）。 | 高速・クロック・USB 差動・高 $di/dt$ 信号ビアから **`≤ 0.5〜1.0 mm`（1〜2 線幅以内）** に GND ビアを 1〜2 個対称配置。 | `USB-COM` 差動 (`D+/D-`)、`IDC 20P` 高速通信線（SPI/UART）の層遷移箇所。 |
| **`THERMAL_PAD`**<br>*(熱拡散＆低インダクタンス GND)* | QFN 露出パッド・電源 IC の熱を内層／裏面 GND プレーンへ逃がし、同時にダイの低インダクタンス基準を確保。 | **穴径 `0.20〜0.25 mm`**（`>0.3 mm` 未穴埋めはリフロー時はんだ吸い込み＝ボイドの原因となるため回避）。グリッド配置＋テンティング／Via-in-Pad 検討、GND プレーンへは弱サーマルスポークではなく直結または太幅スポーク。 | `ATtiny1616-MNR`（QFN-20-EP 3×3 mm）、`TPS259470A` eFuse（2A 連続発熱源）、`10mΩ` シャント周辺。 |
| **`SHIELD_FENCE`**<br>*(外周・マッス境界シールド)* | 基板端からの放射漏れ・外部ノイズ侵入、および電源／デジタル→アナログ計測領域への結合を遮断。 | 波長基準 $\lambda / 20 \sim \lambda / 10$（実務デジタル標準ピッチ **`1.0〜2.5 mm`** 間隔）で基板外周・マッス境界へ規則配置。 | `8858` 基板外周（外形からクリアランス確保）、アナログ計測マッス（`TP181A2` + `10mΩ`）とデジタル／USB マッス境界。 |
| **`DECAP_GROUND`**<br>*(デカップリング最短帰路)* | デカップリングコンデンサの GND 側インダクタンスを最小化し高周波インピーダンスを低減。 | デカップリングコンデンサ GND パッド直近（`< 0.8 mm`）へ専用 GND ビアを最短接続（他ネットと共有しない）。 | `ATtiny1616` VDD、`TPS70933` 入出力、`CH342K`、`TP181A2` の全バイパスコンデンサ。 |
| **`PLANE_STITCH`**<br>*(表裏プレーン等電位化・孤立島解消)* | 2 層／4 層の表裏 GND ベタを等電位化し、不要な共振・孤立島を排除。 | 局所フラッドフィルで未到達・高アスペクト比半島を検出し、規則グリッド（例：`3〜5 mm`）＋孤立島救済を機械配置。 | 全基板の空き GND 領域（ただし他の 4 クラス配置後の仕上げとして実行）。 |

### 2.3 商用 EMC DRC（`HyperLynx DRC`）とオープンソース「説明可能レイアウト監査」のエッセンス

- **`Siemens HyperLynx DRC` のアプローチ**
  - 重い 3D フルウェーブ電磁界解析を毎回回す代わりに、**幾何エンジン＋ドメインルール（90 種以上）** で以下を高速自動検知する：
    1. **Reference Plane Split Crossing**（信号線が直下 GND プレーンの切れ目・ボイドを跨いでいないか）
    2. **Via Transition Without Return Via**（層遷移信号ビア近傍に GND リターンビアがあるか）
    3. **Via Clustering / Plane Perforation**（ビア密集によるリターンプレーンのチーズ穴化＝スイスチーズ効果）
- **オープンソース実装パターン（`shapely` 等の幾何交差チェック）**
  - フルウェーブ解析（`openEMS` / `gerber2ems`）は最終検証や特殊 RF 向けであり、通常ループでは **「信号線ポリライン vs 隣接層 GND ポリゴン（銅箔マイナス抜き）」の 2D 空間交差判定** で 8 割以上のリターンパス異常を数秒で検知できる。
- **Explainable Layout Review（説明可能レビュー・偽陽性フィルタ）**
  - すべての配線に一律警告を出すと警告洪水で使えなくなるため、**「ネットクラス（DC / 低速 / 2A 電源 / アナログ / USB 差動 / クロック）」と幾何チェックを結合** し、
    - *「ネット `USB_DP` が層遷移ビア `(x, y)` の 1.0 mm 以内に GND リターンビアを持たない」*
    - *「GND ビア `V14` の設置意図：`SHIELD_FENCE`（アナログマッス外周、ピッチ 2.0 mm）」*
    のように **理由・影響・修正案を人間可読な Markdown レポート＋色分け可視化 SVG/PNG で出力する** のが最新のベストプラクティス。

## 3. Track 5 判定：Adopt / Adapt / Build（ADX 向け）

| 要素 | 判定 | ADX（EasyEDA Pro / `CORE-U rev6`）での具体方針 |
| :--- | :---: | :--- |
| **GND ビア 5 クラス意味論スキーマ（`via_semantics.json`）** | **Build（ADX 独自強み）** | EasyEDA へ投入する全 GND ビアを `RETURN_TRANSITION` / `THERMAL_PAD` / `SHIELD_FENCE` / `DECAP_GROUND` / `PLANE_STITCH` の 5 クラスでメタデータ管理し、クラス別に色分けした **「意図可視化レビュー PNG/SVG」** を自動生成する。 |
| **リターンパス＆プレーン分断の 2D 幾何自動監査（`HyperLynx DRC` エッセンス）** | **Build（軽量実装）** | `UNOMODOKI R3` で構築したローカル 2 層グリッド・フラッドフィル資産を発展させ、**「重要ネット（USB / アナログ / 2A 電源 / クロック）直下の GND 連続性チェック」＋「リターンビア距離チェック」＋「ネットクラス別フィルタ付き説明可能レポート」** を Node/Python で実装。 |
| **QFN サーマルビア小径ルール（`0.20〜0.25 mm` 穴径）** | **Adopt** | `ATtiny1616-MNR`（QFN-20-EP）および `TPS259470A` に対し、はんだ吸い込み防止の標準サーマルビア規約を適用（JLCPCB 最小標準ビア径との整合も同時確認）。 |
| **`CORE-U rev6` の 2 層 vs 4 層アーキテクチャ評価** | **Adapt（設計判断推奨）** | M5 着手前に、JLCPCB 120 pcs コスト差額と「L2 連続 GND プレーンによる AI 自動配線成功率・リターンパス品質・`-40〜+85℃` 放熱改善」を比較評価し、層構成を正式決定する。 |
| **フルウェーブ 3D 電磁界解析（`openEMS` 等）の毎ループ組込み** | **Do Not Adopt** | 計算負荷過大であり 10MHz / USB Full-Speed 帯域では 2D 幾何リターンパス監査＋SPICE で十分。 |
