## 1. ポジショニングと設計思想

### 1.1 背景と課題意識
USB 型の ADX CORE は、これまで CORE-U など様々な構想が検討されてきました。しかし、従来の ATtiny1616 構成では以下の課題に直面し、実用性と価格競争力の両立が困難でした：
1. **スペックの制約**: Flash 16KB / SRAM 2KB では、USB スタックを載せるとユーザーの制御ロジック領域が圧迫される。
2. **部品点数と原価の増大**: USB シリアル変換 IC（CH340/CH342 等）や外付け発振子が必要となり、BOM コストが跳ね上がる。
3. **電源共有の取り回しの難しさ**: PC からの給電と外部電源（ADX VBUS）が不用意に衝突・逆流し、現場組み込み時のデバッグや保守で PC ポートの遮断や素子破壊を招きやすかった。

### 1.2 CORE-CX3 のブレークスルー
本構想 **ADX CORE-CX3** は、メイン MCU に **WCH CH32X035**（32-bit RISC-V4C, 48MHz）を採用します。
- **1チップ化による圧倒的な原価低減**:  
  MCU 内蔵の USB 2.0 Full-Speed PHY と自動クロックトリミング機能により、**USB-UART ブリッジ IC および外付けクリスタルを全廃**。
- **桁違いのスペック向上**:  
  Flash 62KB（約4倍）、SRAM 20KB（10倍）。実用的な制御プログラムが余裕を持って動作します。
- **5V トレラント ＆ 3.3V ネイティブ**:  
  ADX Pinout の 3.3V LVCMOS 規格に準拠しつつ、万一の 5V 混触時にも高い耐量を持ちます。

## 2. ハードウェア基本仕様 (Baseline Specs)

| 項目 | 仕様 | 備考 |
| :--- | :--- | :--- |
| **フォームファクタ** | **ADX 8748** (`87.0 mm × 48.0 mm`) | M3 ネジ穴 (77×38mm ピッチ)、スロットイン対応 |
| **メイン MCU** | WCH **`CH32X035G8U6`** (QFN-28) | 32-bit RISC-V, 48MHz, Flash: 62KB, SRAM: 20KB |
| **拡張バス規格** | **ADX 20-Pin Bus v4.0** 準拠 | 重力フェイルセーフ (Pins 17–20: VBUS), Pin 2: OWD |
| **USB ポート構成** | **デュアル Type-C ポート** | 通信専用 16P ＋ 電源専用 6P による完全分離 |
| **論理レベル** | **3.3V LVCMOS ネイティブ** | 全 GPIO 5V トレラント入力対応 |
| **クロック源** | 48MHz 内蔵高精度 HSI | USB クロック自動トリミング（外付け水晶発振子不要） |
| **保守・書込方式** | **USB Mass Storage (UF2)** | OS 非依存・ゼロインストール（ドラッグ＆ドロップ書込） |
| **製造・検査 I/F** | **20P IDC Pin 2 (`OWD`)** | 治具検査時に WCH-LinkE (SDI) 経由で UF2 を自動書き込み |

## 3. 電源トポロジー：通信と電源の完全分離

現場組み込み時の「PC 逆流破損事故」を根本から防止するため、USB ポートを用途別に物理分離します。

```text
［ 通信専用 16P Type-C ］── [ D+ / D- ] ────────────────────────➔ CH32X035 (USB PHY)
    (PC 接続・保守用)
         │
      (VBUS 5V)
         │
         ▼
     [ PTC 500mA ] ── [ 低VF ショットキー SBD ] ──┐
                                                 │
［ 電源専用 6P Type-C ］                          │
    (大電流給電専用)                              │
         │                                       │
      (VBUS 5V)                                  │
         │                                       │
         ▼                                       │
     [ PTC 2.0A〜3.0A ] ─────────────────────────┴─➔ ADX VBUS (Pins 17〜20)
                                                       │
                                                       ├─➔ オンボード 3.3V LDO ─➔ MCU
                                                       │
                                                       └─➔ 拡張 Card・サーボ・大電流負荷
```

1. **卓上開発時（通信 16P のみ接続）**:
   PC の USB から PTC（500mA）と SBD を経由して MCU 単体に給電。PC ケーブル 1 本でスケッチの書き込み・デバッグが可能。
2. **現場・ユニット組み込み時（電源 6P または外部給電時）**:
   大電流外部電源が `VBUS` を駆動。PC を接続しても **SBD により PC 側への逆流は確実に阻止** されます。
3. **過電流防止**:
   万一通信 16P のみで大電流 Card を駆動しようとしても、PTC（500mA）がトリップして PC ポートを保護します。

## 4. ブートローダーと長期保守アーキテクチャ

現場で 5 年〜10 年と稼働するユニットにおいて、PC 側 OS の変化やドライバ署名トラブルによる「書き換え不能」を防ぎます。

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   【 工場出荷時 (自動検査治具) 】                      │
│   20P IDC Eject Header (Pin 2: OWD / SDI) 経由で治具が接続             │
│   ➔ 自己診断テスト合格後、Flash 下位 10KB に UF2 ブートローダーを書込 │
└────────────────────────────────────┬───────────────────────────────────┘
                                     │
                                     ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   【 現場運用・長期保守 (5年後) 】                     │
│   通信 16P Type-C を挿入 (BOOT ボタン押下起動)                         │
│   ➔ PC / スマホに USB ドライブ `ADX-CX3` が自動マウント                │
│   ➔ `firmware.uf2` をドラッグ＆ドロップするだけで即座に書換完了       │
│   ※ ブラウザ・専用アプリ・ドライバ・管理者権限は一切不要               │
└────────────────────────────────────────────────────────────────────────┘
```

## 5. 製造コスト見通しと経済性

JLCPCB PCBA（部品実装・弊社宛送料込）をベースにした 100 台ロットでの原価試算です。

- **製造パラメータ**: Green, 1.6mm 厚, OSP, 両面 SMT
- **ロット規模**: 10 パネル（100 枚分）
- **PCBA 込・送料込製造原価**: **$269.30 (1 枚あたり $2.69)**
- **想定販売価格 (4 倍算)**: **$10.76** (約 1,600 円前後)

### ポジショニング
単なるマイコン開発ボード（Raspberry Pi Pico 等）と比較するのではなく、**「8748 産業用フォームファクタ ＋ 20P 拡張バス ＋ 筐体組込完結型エッジコントローラ」** として、他にない確固たるコストパフォーマンスと実用性を確立します。
