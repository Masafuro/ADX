# CORE-U コンセプト rev5

## 状況
ADX CORE-Uの筐体フレンドリーを中核とし
電流電圧等の状況監視が可能なAIフレンドリー機能を持ち
USB直結でのデバッグ時を除く、組込稼働時に十分な耐熱性を持つマイコンボード
をCORE-U rev5のコンセプトとする。

## 詳細
- IDC Eject Headerの採用
  - CORE-Uの端子は３つしかない。USB-COM, USB-POW, IDC 20P
  - Eject Headerを採用するのは、USB-COM及びUSB-POWのどちらも挿入していない場合の利用シーンにおいて、拡張ボード等から電力供給を前提として、耐熱及び耐振動性を発揮できるマイコンボードとするためである。
  - このモードを「Full embedded mode」と呼ぶ
- LEDについて
  - LEDについては耐熱性を第一優先とする。
  - すなわち、「Full embedded mode」において稼働可能であること。
  - もし、余剰GPIOが不足した場合、CORE-A等の3P LEDのうち、一つを、例えばBをN.Cとして、PowをG、GPIO1をRとすることも許容する。
  - PWMはあることが望ましいが、無理に用いる必要はない。
  - Full Color LEDのGPIO 1P駆動については、そのLEDの耐熱性、入手性、コストが許容範囲に収まる場合にのみ、選択肢とする。
- 内部状態監視について
  - 電流電圧の計測については、AIによる利用を想定し、できる限り正確にデータを取得しうることが望ましい。
  - ただし、耐熱性を第一優先とする。
  - FLTに関する問題で、優先順位は第一に耐熱性、第二に観測性、第三にLED表示灯とする。
- 販売価格
  - 最大許容販売価格を$26とし、許容最大原価は$6.5とする。

## 3 Mode
1. Full embedded mode
  - USB-COM, USB-POWが非接続状態であること。
  - IDC Eject Headerは接続されている。
  - 十分な耐熱性と耐振動性を主張可能であること。
2. Semi embedded mode
  - USB-COMが非接続状態であること。IDC Eject Headerは接続されている。
  - USB-POWが接続されているため、耐振動性ではFull embedded modeに劣る構造的限界を有する。
  - 耐熱性では、Full embedded modeに近い水準であることが望ましい。
3. Debug mode
  - USB-COM, USB-POW, IDC Eject Headerが接続されている。
  - 耐熱性、耐振動性について、１や２の水準である必要はないが、可能な限りそれぞれの水準を引き上げるよう努めること（努力目標）
