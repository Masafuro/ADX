# ADX CORE-U

## 幾版を越えて
 ADX CORE-Uの構想は何度も練り直された。そして、現行版において、私は悟った。すなわち、Arduino UNO R4 Minimaに負けを認める、と。この点において、ADX CORE-UはArduino UNO R4 Minimaと同程度の$20価格帯となり、かつ、MCUがATtiny1616-MNR/10MHzと性能面で大きく劣らざるを得ない。しかし、それで行く。逆に、これより安価にしようとしたり、機能を足したりしようとすれば、どこかに無理が出てしまう。例えば、CH340KとOptiboot_xにすれば、原価は下がるが、UPDIはRESETにしなければならず、HVの問題も出てきてしまう。もはや、Arduino UNO R4 Minimaに対して、同程度の価格でADX CORE-Uをユーザーが選択する理由はいないかもしれない。さらには、ATtiny1616のブレイクアウトボードは$6前後だったりと極めて安価なものが流通しており、これにも全然勝てない。勝てないずくしだが、しかし、結論として、当面、このボードを製品化して販売する方向に決めた。もはや、合理性はないのかもしれない。
