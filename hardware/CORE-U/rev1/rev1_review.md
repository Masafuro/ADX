# ADX CORE-U rev1 レビュー ＆ rev2 想定定格・選定基準

**対象リビジョン:** `CORE-U rev1` ([Netlist_PCB1_2026-11-15_wip.enet](Netlist_PCB1_2026-11-15_wip.enet))  
**起点ドキュメント:** [concept.md](concept.md)

---

## 1. rev1 レビュー結論

[concept.md](concept.md) の問い：
> **「CORE-U rev1 は定格試験条件を策定しえるか？ もし策定しえなければ、それはなぜか？ どの部品の曖昧さが試験可能性のボトルネックを生じているのか？」**

に対するレビュー結果は以下の通りである。

### 結論
**rev1 の部品構成のままでは、ボード全体の一貫した定格試験条件（特に耐振動・連続通電）を策定することが困難である。**  
ただし、仕様曖昧な民生・汎用互換端子を整理してボトルネックを 1 点（USB Type-C）に集約すれば、**rev2 において ADX ラインナップ条件である「試験可能性」を十分に満たし得る**。

---

## 2. rev1 で判明したボトルネック（曖昧さの連鎖）

rev1 ネットリストを監査した結果、以下の 3 点が試験可能性を阻害していることが明確になった。

### 2.1 Grove (`ZX-HY2.0-4PWZ`)・`XH-4AW` による曖昧さのチェーン
- **`HY2.0`（Grove 互換端子）の問題:**  
  韓国 Yeonho SMH200 系をベースに広くクローン製造されている汎用規格であり、グローバルな統一メーカー仕様や耐振動規格が存在しない。また相手側（市販 Grove ケーブル等）は 26 AWG 等の細線や接圧・メッキ精度のバラつきが大きく、ボード単体で試験条件・保証境界線を引くことが不可能。
- **`XH-4AW` の問題:**  
  JST 純正 XH（`S4B-XH-A` 等）であっても公開カタログ表に振動定格の数値はなく、ノンロック（フリクションロック）構造である上、市販の汎用 XH ハーネスが接続された瞬間に相手側品質の曖昧さがボード側の試験責任に連鎖する。

### 2.2 USB Type-C（特に電源専用 6P `UC17-0B06F68011`）の仕様と物理的限界
- rev1 では `02-USB_Pow` に 6-pin 中華系品（`-20℃〜+85℃`）を採用しているが、6-pin 品はローカル仕様に近く、EIA-364-28 準拠等の試験根拠が薄い。
- 物理構造的にも、USB Type-C は「引っ掛かった際に外れること」を前提とした民生規格であり、ラッチを持たない。CORE-U は `USB_Pow` を常時稼働する主電源とするため、**どう設計しても USB Type-C がボード全体の最弱点（Weakest Link）になる**。

### 2.3 温度定格のばらつきと BOM 上の未定義項目
rev1 ネットリスト記載の温度範囲には大きなばらつきがあり、一部部品は温度特性が未記入（`-`）となっている：
- `+105℃` 対応：`ATTINY1616-MNR`（`-40℃〜+105℃`）、`SFN-1407PA7.6`（`-40℃〜+105℃`）、`2.54-2*10P简牛`（`-55℃〜+105℃`）
- `+85℃` 上限：`CH342K`（`-40℃〜+85℃`）、`SK6812SMINI-ER`（`-40℃〜+85℃`）、`01-USB_Com`（`-45℃〜+85℃`）、`02-USB_Pow`（`-20℃〜+85℃`）、`PortA/B/NEOP`（`-25℃〜+85℃`）
- ネットリスト温度未記載（`-`）：`03-eFuse` (`AP22814AW5-7`)、`D1` (`1N4148W`)、積層セラミックコンデンサ（`CL10A106KP8NNNC`, `CL05B104KO5NNNC` 等）

## 3. rev2 アーキテクチャ方針（試験可能性の確立）

**「ボード全体の定格は最も弱い鎖の環（Weakest Link）で決まる」**という前提に立ち、rev2 では以下の方針を採用する。

### 方針 1：外部 I/O・LED 端子を「16P IDC ボックスヘッダ（ライトアングル）」へ統合
`PortA`（HY2.0）、`PortB/sC`（HY2.0）、`NEOP`（XH）の 3 コネクタを廃止し、**2.54mm 2列 16P（2×8P）IDC ボックスヘッダ（ライトアングル）1 個に統合**する。

* **物理構造の強み:** 2列 IDC ボックスヘッダ（シュラウド＋ラッチ）は物理的保持力に安全率を確保しやすく、ボード全体の定格試験に耐えやすい。
* **なぜ 16P か（20P / 10P との比較）:**
  * `20P` はメインバス（`05-ADX_exHeader`）との**物理誤挿しリスク**（Pins 17–20 の 5V VBUS が他信号へ当たる危険）があるため不採用。
  * `10P` は理論最小値だが、`NEOP` の `5V 2.0A` を IDC 定格（1A/ピン、AWG #28 基準）で流すと余裕がなく、`3V3` のケーブル分岐も必要になるため見送り。
  * **`16P` であれば誤挿しが物理的に起きず、電源並列化による電流余裕と「4本・4本・8本」へのケーブル分割性を両立できる。**
* **M5Unit / Grove との付き合い方:**  
  16P リボンケーブル側を 4本・4本・8本に裂いて変換ハーネス（または端子接続）とする運用に逃がすことで、**ボード側の責任範囲を「IDC 嵌合部まで」にクリーンに閉じる**。

### 方針 2：ボード全体の最弱点を「USB Type-C」に 1 点集約
曖昧な小コネクタを排除したことで、ボード全体の定格（温度・耐振動・連続通電）のボトルネックを **仕様明確な USB Type-C コネクタ** に 1 点集約し、その定格と設置条件をボード全体の仕様として定義する。

## 4. CORE-U rev2 想定定格（目標仕様 ＆ 試験条件案）

※ 以下は rev2 部品選定を前提とした**目標定格・試験条件案**であり、最終確定値は rev2 試作機の恒温・振動・連続運転試験により確定する。

| 試験項目 | rev2 想定定格（目標） | 定格の根拠・決定ボトルネック | 試験条件・合格基準（案） |
| :--- | :--- | :--- | :--- |
| **動作周囲温度** | **`-20℃ 〜 +70℃`**<br>（部品統一により `-40℃` 下限も可） | 上限 `+85℃` 部品（`CH342K`, `SK6812SMINI-ER`, USB-C）に対し、通電時の自己発熱（LDO 損失・VBUS 2A 通電）のディレーティングを見込む。 | 恒温槽内で想定最大負荷を印加し、連続運転中に熱暴走・シャットダウン（`AP22814A`/`ME6211`）・通信断が発生しないこと。 |
| **主電源・連続通電** | **`5.0V DC / 最大 2.0A`**<br>（周囲温度に応じディレーティング） | `USB_Pow`（16P Type-C 並列ピン給電）＋ `AP22814AW5-7`（電流制限/過熱保護）＋ `ME6211C33M5G-N`（3.3V 最大 500mA）。 | 目標周囲温度上限下で VBUS 負荷・3.3V 負荷・UART/バス通信を連続稼働させ、電圧ドロップや過熱トリップが起きないこと。 |
| **耐振動性** | **IEC 60068-2-6 相当**<br>（例：`10〜55 Hz`, 片振幅 `0.35〜0.75 mm`, 3軸） | 最弱点は `USB_Pow` / `USB_Com`（EIA-364-28 準拠品選定＋ケーブル固定前提）。IDC 側は 10〜55Hz 仕様品と整合。 | **必須前提:** USB ケーブルは筐体/治具側でコネクタ近傍を機械固定。基板 4 隅 M3 ねじ止め。<br>**判定:** 加振中に電源リセット・通信エラーなし、試験後にはんだクラック（特に `SFN-1407PA7.6`, USB-C タブ, 大型 MLCC）なし。 |

## 5. CORE-U rev2 部品選定基準（BOM 監査ルール）

rev2 で新たに部品を選定・確定する際は、以下の基準をすべて満たすことを条件とする。

### 5.1 USB Type-C コネクタ（`USB_Pow` / `USB_Com` 共通化）
1. **6-pin 省ピン品の禁止:** `USB_Pow` も **16-pin（または 16+8 ダミー）** の標準品へ統一し、D+/D- ピンは NC とする（BOM 品種も 1 種類に集約）。
2. **必須仕様:**
   - **EIA-364-28** 等の環境・振動試験条件がメーカー仕様書に明記されていること。
   - 動作温度範囲が **`-40℃ 〜 +85℃` 以上** であること。
   - 基板剥離を防ぐため、**シェルにスルーホール貫通タブ（THT 補強足）** を持つこと。
3. **候補例:**
   - **GCT `USB4105-GF-A`**（ハイブリッド実装、LCSC 流通あり、`-40℃〜+85℃`、EIA-364-28 Condition VII Letter D 明記）
   - **Molex `217179-0001`**（`-40℃〜+85℃`、Product Spec にて EIA-364-28 規定）
   - **Hirose `CX90B` / `CX90M` 系** 等

### 5.2 IDC ボックスヘッダ（20P メインバス ＆ 16P 外部 I/O ポート）
1. **誤挿し防止:** メインバスは `20P`、外部 I/O 統合ポートは `16P` とし、極数差で物理的に誤挿しを不可能にする。
2. **1A/ピン上限の遵守（AWG #28 標準リボンケーブル基準）:**  
   `VBUS_PROT`（最大 2.0A）の供給には、必ず 2 本以上（推奨 3 本並列）の電源ピンと、同数以上の `GND` ピンを割り当てる。
3. **部品グレード:**
   - 振動試験の根拠を部品単体仕様書から積み上げる場合は、**OMRON `XG4A` シリーズ**（`XG4A-1634` / `XG4A-2034`：`-55℃〜+105℃`、ラッチ付き、システム定格 1A/ソケット時）等の MIL 準拠大手品を選定する。
   - 調達性・PCBA 都合で汎用 DC3 系ボックスヘッダを採用する場合は、**ラッチ（イジェクタ）付き**を選定した上で、ボード全体振動試験の安全率で担保する方針をとる。

### 5.3 全 BOM 温度定格の明示 ＆ MLCC 見直し
1. **温度未記載（`-`）の禁止:** ネットリストおよび BOM 登録時に全部品の動作温度範囲を確定・記載する。
2. **コンデンサ（MLCC）の温度特性確認:** `CL10A106KP8NNNC` 等の大容量品について誘電体特性（X5R は `+85℃` 上限、X7R は `+125℃` 上限）と高温・DC バイアスによる容量低下を確認し、連続通電の安定性を担保する。
3. **電源保護・スイッチ IC（`AP22814AW5-7` 等）およびダイオード（`1N4148W`）:** 動作接合部温度・周囲温度定格と、5V 2A 通電時の発熱を検証する。

### 5.4 重量・背高部品の実装強度確認
- 圧電サウンダー（`SFN-1407PA7.6`）やスルーホール部品は質量・重心の高さから振動ストレスが集中しやすいため、基板の M3 固定穴（8748 / 8854 フォームファクタ）からの位置関係とパッド強度を考慮する。

## 6. 参考：16P 外部 I/O 統合ヘッダ ピン配列（検討案）

| **1** | `PortA` (4本) | `PB0/SCL` | Grove 黄線相当 |
| **2** | `PortA` | `PB1/SDA` | Grove 白線相当 |
| **3** | `PortA` | `3V3` | Grove 赤線相当（3.3V LDO 共有、軽負荷センサ向け） |
| **4** | `PortA` | `GND` | Grove 黒線相当 |
| **5** | `PortB/sC` (4本) | `PA5/AIN` | Grove 黄線相当 |
| **6** | `PortB/sC` | `PA4/PWM` | Grove 白線相当 |
| **7** | `PortB/sC` | `3V3` | Grove 赤線相当（3.3V LDO 共有、軽負荷センサ向け） |
| **8** | `PortB/sC` | `GND` | Grove 黒線相当 |
