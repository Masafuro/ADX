# ADX CORE-U 比較分析・設計思想 (Competitive Analysis & Design Philosophy)
〜 Arduino UNO R3 / R4 Minima との対比から見る「筐体組み込み特化型 Arduino (rev4)」の必然性 〜

---

## 1. はじめに：「机の上の学習」から「自作筐体・現場で動く実用機」へ

Arduino は、世界中のメイカーや学生、エンジニアに「マイコンを動かす楽しさ」を教えてくれた最高のプラットフォームです。  
しかし、机の上のブレッドボードで動いたプロトタイプを、いざ **3D プリンターで作った自作筐体や現場の制御ボックス** へ組み込もうとすると、多くの開発者が共通の壁に直面します。

- **「モーターや LED テープを動かすと PC の USB 給電（500mA 前後）では電力が足りず、マイコンが落ちる」**
- **「外部電源を繋ぎながら PC でデバッグしようとすると、逆流や配線ミスが怖い」**
- **「スケッチがバグでハングすると、USB 認識が外れて PC から書き込めなくなる」**
- **「シリアルモニタを開いていると書き込みエラーになる」**
- **「ケースに収めたらリセットボタンや BOOT ボタンが押せない／ジャンパ線が振動で抜ける」**

**ADX CORE-U (rev4)** は、これらの「机の上から筐体・現場へ移行する際に生じる摩擦」を解消し、同時に **「マイコンボード側には機能を限りなく載せない」** という引き算の哲学を突き詰めた **「はたらく Arduino（The Working Arduino）」** です。

---

## 2. そもそも「何と比べるべきか」

CORE-U rev4 は、単なる「安価な汎用開発ボード」ではありません。

- **Raspberry Pi Pico 単体 / ESP32 ベアモジュールとの違い:**  
  数ドルのモジュール単体とクロックや RAM 容量で競争するボードではありません。Pico 等を 3D プリント筐体に組み込んで 10W（5V 2.0A）級の負荷と拡張性を確保しようとすると、結局キャリアボードや電源保護回路を自作することになります。CORE-U は最初からその電源・保護・拡張インフラを 1 枚に統合しています。
- **Adafruit Feather 系との違い:**  
  Feather は LiPo バッテリー駆動・携帯ガジェット・3.3V 低電力に最適化された規格です。一方 CORE-U は、AC アダプタ等から 5V 2.0A（10W）を供給して常設の筐体・装置を動かす用途に特化しています。

したがって CORE-U rev4 の本質的な比較対象は、**「Arduino UNO R3 / R4 Minima（＋シールド）」や「マイコン＋ブレークアウト基板一式」といった、装置・筐体組み込み用のコアプラットフォーム** です。

## 4. rev4 における 5 つの核心的な工学的アプローチ

### 4.1 引き算の徹底：「拡張は ADX 20P IDC 一本に集約」
初期案で検討していたオンボードのブザー、microSD、電源スイッチ端子台、複数系統の個別ピンヘッダ（XH / HY2.0 / PC 用フロントパネルヘッダ等）をすべて思い切って廃止しました。
- **迷い・誤配線の排除:** 拡張経路を `CN1`（2.54mm ピッチ 2×10P SMD IDC ヘッダ）1 箇所に統一することで、ユーザー側の拡張設計と出荷時の検品工程を極限まで簡素化しています。
- **全 SMD 化によるコスト低減:** IDC コネクタ・Type-C・LED まで含めて表面実装（SMD）ベースに統一し、JLCPCB PCBA 込みで 120 個ロット時 **$460.57（1 個あたり $3.83、4 倍算想定売価 $15.35）** を達成しています。

### 4.2 電源と通信の完全分離（ORing IC レスの明快さ）
従来のマイコンボードや 1 口 Type-C ボードで最大のトラブル源だった「PC の USB から大電力を引いてしまう問題」を、**物理的な分離** によって解決しました。
- **`USB-PWR` (`01-USB_Com1`, 5V 2.0A 定格):** AC アダプタ等から受電し、`AP22814AW5-7`（eFuse / ハイサイドスイッチ）経由で `VBUS_PROT`（最大 2.0A）を `CN1`（Pins 17〜20）および `3.3V` LDO へ供給します。
- **`USB-COM` (`01-USB_Com`, 通信専用):** Type-C の VBUS ピンを電源ラインから完全に切り離しており、PC 側からの電力供給・逆流が物理的に起きません。`CH342K` もボード側 `3.3V` で駆動するため、主電源 OFF 時の回り込み電流も防ぎます。
- **迷わない導入手順:** 「1. AC アダプタを `USB-PWR` に挿して電源 LED の点灯を確認 → 2. PC を `USB-COM` に繋いで開発」という 2 ステップで、電源不足やポート迷子のトラブルを根本から断ちます。

### 4.3 ハング耐性と独立 USB ブリッジ (`CH342K`)
UNO R4 Minima や RP2040 のような MCU 内蔵 USB 方式は、スケッチのバグで割り込み停止やメモリ破壊が起きると COM ポートごと消失し、物理ボタン操作（BOOTSEL や二重リセット）が必要になります。
- CORE-U は独立した USB-UART ブリッジ **`CH342K`** を採用しているため、MCU が暴走していても PC との USB 接続が切れません。
- `PA0` を RESET へヒューズ変更せず **UPDI のまま維持** しているため、工場での事前ブートローダ書き込み（`optiboot_x` 等）や 12V HV-UPDI 復旧作業が不要で、密閉ケース内でもソフトウェア側から確実に再書き込みできます。

### 4.4 シリアルモニタを開いたまま瞬時に書き込める開発体験
`CH342K` の独立 2 ポート構成により、**Port 0（SerialUPDI 書込）** と **Port 1（`Serial.swap(1)` デバッグモニタ）** を 1 本の USB-C ケーブル上で同時運用できます。  
Arduino IDE 1.8.x と組み合わせることで、シリアルモニタを一度も閉じることなく「コード修正 → 書き込み → ログ確認」を高速に回せます。

### 4.5 ハードウェア保護とミニマルな視覚 UI
- **`AP22814AW5-7` による過電流・短絡保護:** 過電流・過熱を検知する `PA7/FLG` ピンを MCU に接続しており、ソフトウェア監視だけでなく ATtiny1616 内蔵 CCL を使った自律保護も可能です。
- **3 色汎用 LED (`LED_R`, `LED_Y`, `LED_W`) ＋ `POW_LED` (緑):** 音（ブザー）は拡張側に譲りつつ、基板上には電源確認用の緑 LED と、ステータス・エラー・通信確認などに使える赤・黄・白の 3 色 LED を備えています。

## 5. トレードオフの開示（CORE-U rev4 が選ばなかったもの）

CORE-U rev4 は、低価格（$15.35 想定）・堅牢な電源・迷いのない拡張性を優先するため、以下を明確に割り切っています。

| 割り切った要素 | rev4 で選択した仕様 | 工学的理由・トレードオフ |
| :--- | :--- | :--- |
| **単体での直結端子** | ADX 20P IDC (`CN1`) のみ | ブザー・スイッチ・スクリュー端子等をボードに載せず、拡張ボード側へ完全に委譲してコストと検品負荷を削減。単体で外部機器を繋ぐには IDC 先の拡張ボード／変換基板が必要です。 |
| **PC 1 本での簡易起動** | `USB-PWR` と `USB-COM` を分離 | PC の 500mA 制限によるブラウンアウトや ORing IC コスト（TPS2116 等）を排除するため、書込・テスト時も `USB-PWR` への給電を前提としています。 |
| **CPU 処理性能・メモリ** | `ATtiny1616` (8-bit / 16KB / 2KB) | 3.3V 10MHz の低発熱・低消費電力・低コストを重視。大規模データ処理や豊富な 32-bit ライブラリ群の活用では UNO R4 Minima が優位です。 |
| **Wi-Fi / BLE 内蔵** | 非搭載 (有線・拡張委譲) | 金属筐体内での電波減衰や技適・認証コストを避け、コア基板をシンプルに保つため。 |

  机の上の学習・実験・ブレッドボード   ──▶   3D プリント筐体・現場の箱へ組むコア基板
  （ピンソケット・単一電源の限界）          （完全分離 2A 給電・UPDI 耐性・IDC 一本化・$15.35）

単体ボードとしての万能さではなく、**「電源保護された 10W 給電」「暴走しても書き直せる独立 UPDI」「IDC 20P 一本に集約されたモジュラー拡張性」** を約 $15 台のシンプルなコア基板に凝縮したのが、ADX CORE-U (rev4) です。
