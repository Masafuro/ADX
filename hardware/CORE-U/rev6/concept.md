# The flagship product of the ADX, CORE-U

## 概要
CORE-U rev5の検討で利用モードの明確な切り分け、Full embedded modeによる耐熱性耐振動性の獲得が視野に入ってきた。そして、これによりここまでの開発が根本的に逆転する可能性が見え隠れしてくる。
すなわち、CORE-Aの廃止である。
CORE-Aとは、ATtiny1616-MNRと絶縁RS-485や電源DC入力に耐熱耐振動性を与えたものだ。
しかし、CORE-UがFull embedded modeにおいて、十分な耐熱性、耐振動性を獲得できるのであれば、むしろ、絶縁RS-485や絶縁24V/48V電源入力は拡張カード側に持たせた方がよいということになってくる。

## 再検討すべきこと
- CORE-Uは結局のところ、Full embedded modeはどの程度の耐熱性を獲得できそうなのか？
  - 耐振動性については、IDC Eject Headerのみであれば十分な耐振動性を有すると見なせる。
  - CORE-Aと比べた場合、CORE-UのFull embedded modeの耐熱性はどうなるのか？
  - そしてそれは、業務量に利用するマイコンボードとして、また、車載や屋外での利用において十分な耐熱性を有していると言えるだろうか？
- ADX pinoutの再検討
  - RX/TXについて
    - RX/TXはオンボードをRS-485 + LINに使うために最適化していたが、CORE-U rev6 の構想ではこれが逆になる。つまり、ADX pinoutのRX/TX側がRX/TX + LIN に対応するようにする必要がある。
    - それでいて、ATtiny1616のマルチプレクサによってRX/TXを切り替えた場合でもUSB側のRX/TXがソフトウェアシリアルとしても再利用できることが望ましい。
  - UPDIについて
    - ADX pinoutにはUPDIを入れていた。これは製造時にブートローダーやサンプルスケッチの書き込み、試験を完了させるためだが、CORE-U rev5 型がフラッグシップとして制定されると、ADX pinoutにUPDIを入れるべきなのか？は再度検討しなければならない。ただし、ATtiny1616以外のMCUのCOREボードが開発される想定があること、ATtiny1616はRESET/UPDIが重複していることから、必ずしもUPDIをADX pinoutから除去すべきとは言えないが、除去すべき可能性もある。ここは丁寧に色々な可能性を評価して決める必要がある。
