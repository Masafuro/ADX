# CORE-U (rev6) `USB-POW` 規格外高電圧誤挿し ＆ TVS / OVLO 保護協調 検討メモ

- **作成日**: 2026-11-28
- **ステータス**: **検討メモ（回路図・最終 BOM 選定前に方針決定）**
- **親仕様書**: [ADX CORE-U (rev6) 技術仕様書](spec.md)（v0.6：`VBUS 4.5〜5.5V` MUST 要件のみを本体仕様書へ確定し、本論点を切り分け）

---

## 1. このメモの目的と切り分け方針

[spec.md](spec.md) 本体では、バス規格 [`ADX-BUS-SPEC-v5.0`](../../../docs/spec/ADX_PINOUT.md) に基づく **必須（MUST）アーキテクチャ要件** のみを規定している：
- `VBUS` 許容動作範囲：**`4.5V 〜 5.5V DC`（`5.0V ±10%`）** 全域で安全・正常動作すること
- 3.3V LDO：`6.0V` 絶対最大定格品（旧 `TLV75533` 等）を廃止し、動作入力耐圧 `≥ 10V`（第一候補 `TI TPS70933DBVR`: 30V 動作 / 32V 絶対最大）を採用すること
- `USB-POW` TVS：旧 `SMF5.0CA-MS`（$V_{RWM}=5.0\text{V}$、`5.5V` でリーク開始）を廃止し、**$V_{RWM} \ge 6.0\text{V}$** とすること
- `TPS259470` OVLO：公称 `~6.0V` とし、`5.5V` 定常＋リップルで誤遮断しないこと

一方、**「規格外の高電圧 USB Type-C 電源（9V / 12V / 15V 固定の PD トリガーケーブルや非準拠アダプタ）を `USB-POW` へ誤挿しした際に、無傷で弾くべきか／純 5V 前提に割り切るべきか」** は、MUST 規格とは独立した製品保護ポリシーの判断事項であるため、本メモへ切り分けて整理する。

## 2. 旧 `rev5` 仕様書に存在した設計誤認の整理（再発防止記録）

旧 [rev5/spec_proposal.md §4](../rev5/spec_proposal.md#L162) には、以下の記述が存在し、`rev6/spec.md` (v0.5 以前) にも「OVLO（9V〜12V 誤印加）時…」という文言が引き継がれていた：

> *「入力側 TVS (`SMF5.0CA-MS`) のブレークダウン電圧 $V_{BR} \approx 6.4\text{V}$ より低い `6.0V` 前後に `TPS259470` の OVLO 閾値を設定することで、誤って 9V/12V アダプタを接続した際に TVS 導通より先に高速遮断（~1.2µs）＆赤 LED 警告を行えます。」*

この記述には **2 つの誤り** があり、`spec.md` v0.6 にて削除・整理した：
1. **トポロジー上の誤認**：TVS は `TPS259470` の **上流（`USB_VBUS` 側）に並列接続** されている。そのため `TPS259470` が下流を遮断しても、上流 TVS には 9V/12V が印加され続ける。$V_{BR} \approx 6.4\text{V}$ の `SMF5.0CA`（または $V_{BR} \approx 6.67\text{V}$ の `SMF6.0A`）に 9V/12V が連続印加されると、TVS が連続アバランシェ導通して **数秒以内に焼損・ショート破損** する。
2. **USB Type-C 規格前提の混同**：`USB-POW` は `CC1`/`CC2 = 5.1kΩ`（`Rd`）・D+/D- 非接続・PD コントローラ非搭載の 6P Power-Only Type-C であるため、**USB-IF 規格準拠の充電器・PC からは `vSafe5V`（`4.75V〜5.50V`）以外が交渉されることはない**。

## 3. 現実世界における `> 5.5V` 印加シナリオの整理

規格準拠の USB-C 充電器からは 5V しか出ないが、実際の開発現場・フィールドでは以下の異常シナリオが存在する：

| シナリオ | 発生確率（肌感） | 想定電圧・時間 | 備考 |
| :--- | :---: | :--- | :--- |
| **① 活線挿抜リンギング / ESD** | **高（日常的）** | `6〜10V`（数 µs） / kV 級 ESD | 純 5V 運用でも必ず起きる → **高耐圧 LDO ＋ TVS で MUST 対策済** |
| **② 規格外「9V / 12V 固定 Type-C 電源・PD トリガーケーブル」誤挿し** | 中〜低（現場次第） | **9V / 12V（連続 DC）** | ルーター・小型機器・USB-C はんだごて（Pinecil / TS101 等）向けの 12V 固定ケーブルが机上に混在すると外見で見分けがつかない |
| **③ 充電器・車載 12V→5V アダプタの内部ショート故障** | 極低 | **12V（連続 DC）** | 降圧 IC ハイサイド FET 短絡故障時 |
| **④ 20V 固定 Type-C 誤挿し** | 低 | **20V（連続 DC）** | 20V トリガーケーブル等。`TPS259470` の動作上限（23V）付近のため TVS 協調は `SMF18A` ($V_C=29.2\text{V} > 28\text{V}$) で厳しくなり、12V〜15V 帯と難度が一段跳ねる |

## 4. `USB-POW` 上流 TVS の選定方針比較（2 案）

いずれも SOD-123FL（200W、`-55〜+150℃`）の単方向 TVS を想定する（単方向 `A` は双方向 `CA` と異なり、負側サージ・逆極性を `-0.7V` で即クランプできる利点がある）。

| 評価軸 | **方針 ①：純 5V Type-C 前提型**<br>(`SMF6.0A` / `SMF6.5A` / `SMF7.0A`) | **方針 ②：`TPS259470` 23V 耐圧活用型**<br>(`SMF12A` ※または `SMF15A`) |
| :--- | :--- | :--- |
| **逆動作電圧 $V_{RWM}$** | `6.0 V` / `6.5 V` / `7.0 V` | **`12.0 V`**（`SMF15A`: `15.0 V`） |
| **ブレークダウン $V_{BR}$ (Min)** | `6.67 V` / `7.22 V` / `7.78 V` | **`13.3 V`**（`SMF15A`: `16.7 V`） |
| **最大クランプ電圧 $V_C$ (@ $I_{PP}$)** | **`10.3 V`** / `11.2 V` / `12.0 V` | **`19.9 V`**（`SMF15A`: `24.4 V`） |
| **逆リーク電流 $I_R$ (@ $V_{RWM}$, 25℃)** | `400 µA` (`6.0A`) / `100 µA` (`7.0A`)<br>*(※+85℃ ではさらに増大)* | **`1.0 µA`（極めて小さい）** |
| **9V / 12V 誤挿し時の挙動** | TVS が連続導通して **自己犠牲ショート破損**（後段は守られるが TVS 交換要） | **TVS 完全無傷 → `TPS259470` OVLO (`~6.0V`) で安全遮断 → 赤 LED 警告 → 抜けば復帰** |
| **上流素子との保護協調** | `10〜12V << 28V` で余裕大 | `SMF12A`: `19.9V < 23V`（`TPS259470` 推奨動作内！）<br>`SMF15A`: `24.4V < 28V`（絶対最大内） |
| **必要な周辺設計条件** | 標準（`VBUS` MLCC `16V〜25V`） | ・`USB_VBUS` 側 MLCC は **`25V` X7R** 必須<br>・`TPS259470 FLT` ピン（絶対最大 `6.5V`）の **`4.7V〜5.1V` ツェナー保護** ＋ 赤 LED 抵抗の 12V 許容電力（例：`4.7kΩ` なら `0.02W` で 0603 余裕） |
| **コスト・実装面積差** | ベースライン（SOD-123FL ×1） | **差額ほぼ `$0`・同一フットプリント** |

## 5. あわせて検討すべき付帯論点：下流 `VBUS_PROT`（IDC 20P 側）TVS の要否

**Mode 1（Full embedded mode）** では、`USB-POW` ではなく **IDC 20P 経由で `VBUS_PROT` へ直接受電** される（`TPS259470` は逆流阻止状態）。

- **省略する案（基本案）**：ADX バス規格上、Power CARD 側に出力保護・サージ吸収を義務付けているため、CORE-U の `VBUS_PROT` 側は `25V` X7R MLCC ＋ 高耐圧 IC 群（`TPS70933`: 32V、`TPS259470` OUT: 28V、`TP181A2`: 42V）の耐圧余裕のみで受ける。
- **下流にも `SMF12A` を 1 個追加する案**：
  - 上流と同一型番 **`SMF12A`** を共用すれば BOM 種類数（Extended フィーダ費）が増えない。
  - リーク電流が **`1 µA`** と極小なため、Mode 1 ディープスリープ待機電力（`~180〜400 µA`）をほぼ悪化させない（逆に `SMF6.0A` を下流に置くと `400 µA` リークで深睡眠を台無しにするため **下流への `SMF6.0A` 配置は非推奨**）。
  - IDC 活線挿抜サージや ESD を CORE-U 単体側でも `19.9V` 以下へクランプでき、全下流 IC（耐圧 28〜42V）を確実に保護できる。
