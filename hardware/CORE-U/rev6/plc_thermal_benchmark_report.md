- **関連文書**: [concept.md](concept.md) / [rev5 技術仕様案](../rev5/spec_proposal.md) / [CORE-A5 仕様検討書](../../archive/CORE-A5/spec_study.md)

## 1. エグゼクティブ・サマリー

KEYENCE「KV Nano」をはじめとする国内外の主要メーカー製・小型エントリー産業用 PLC、オープンソース系マイクロ PLC、および高耐環境・車載特化 PLC の温度仕様を横断調査した結果、以下の明確な構造が浮かび上がった。

1. **産業用小型エントリー PLC の世界標準は「`0℃ 〜 +55℃`」**（国際規格 IEC 61131-2 基準）。最新ワイド温度モデルでも **`-20℃ 〜 +60℃ / +65℃`** が上限であり、**Arduino Opta (`-20〜+50℃`)** や **M5Stack StamPLC (`-10〜+50℃`)** は **`+50℃` が天井** である。
2. **「なぜ産業用 PLC は 55〜65℃ 止まりなのか？」の正体**は、IC 単体の限界ではなく、**① 電源・リレー・CPU の自己発熱（数 W〜十数 W）**、**② アルミ電解コンデンサ（10℃2倍則）・バックアップ電池・メカ式リレーの長期寿命劣化**、**③ 部品定格から 20〜30℃ 差し引く産業流ディレーティング** の 3 点にある。
3. **ADX CORE-U (rev6) は構造的に熱の弱点を持たない**：電解コンデンサゼロ（全 `X7R` MLCC）、電池ゼロ、メカ接点ゼロ、無線ゼロ、そして `Full embedded mode` 時の自己発熱は **約 35 mW（6〜7mA @ 5V）** と一般 PLC の 1/100 以下である。
4. **CORE-U rev6 の最適ゴール提案**：
   - 無理して `CH342K` 保存上限ギリギリの「`-40〜+105℃` 動作保証」を背伸びする必要はない。
   - **`Full embedded mode` の目標動作周囲温度を「`-40℃ 〜 +85℃`（全稼働部品 `-40〜+105℃〜125℃` 選定による 20℃ 以上の熱マージン設計）」** と定義すれば、**一般エントリー PLC 全機種（+55〜+65℃）および高価な極限環境 PLC（WAGO XTR / Siemens SIPLUS: +70℃）をも上回り、建機・車載モバイル PLC（ifm ecomatMobile: `-40〜+85℃`）に並ぶ圧倒的ポジション**を、工学的に一切無理なく・誠実に確立できる。

## 4. なぜ産業用 PLC は「+55℃〜+65℃」止まりなのか？（重要な工学的背景）

調査結果を読む際、**「部品定格」と「製品動作周囲温度」の違い** を正確に理解しておく必要がある。

1. **IEC 61131-2 規格と「盤内周囲温度 55℃」の慣習**:
   - PLC の国際規格 IEC 61131-2 では、制御盤内（Open Equipment）の標準環境として **`0℃ 〜 +55℃`** が基準となっている。一般工場の制御盤は周囲 40℃ 以下の屋内に置かれ、盤内温度上昇を +15℃ 以内に抑える設計（換気扇や盤用クーラー併用）が前提のため、メーカーも +55℃ を基準に最適コストで設計している。
2. **「部品定格（-40〜+85℃）」から 20〜30℃ 差し引く産業ディレーティング**:
   - 産業用 PLC に載っている MCU や一般 IC 自体は `-40℃〜+85℃` 品が多い。それでも製品定格が `+55℃` になるのは、以下の **構造的な熱ボトルネック** があるためである：
     - **自己発熱が大きい**: 内蔵 AC/DC・DC/DC 電源、複数 I/O、フォトカプラ、リレー励磁コイル、高速 CPU 等により筐体内部で数 W〜十数 W の熱が発生し、基板温度が周囲より **+15〜+30℃ 上昇** する（Siemens S7-1200 が縦置きで +60℃ → +50℃ に落ちるのは、下段の熱が上段に籠もるため）。
     - **アルミ電解コンデンサの寿命（10℃2倍則）**: 105℃・2,000〜5,000時間品の電解コンデンサは、10 年（約 87,600 時間）連続稼働を保証しようとすると、コンデンサ実温度を **+65〜+75℃ 以下** に抑えなければならない。
     - **バックアップ用リチウム電池・液晶・メカ接点**: これらが 70〜85℃ 以上で急速に劣化する。
3. **ホビー系ボードとの表記文化の違い**:
   - Arduino UNO R4（`-40〜+85℃`）は「載っている主要 IC の定格上限」をそのまま記載する開発ボード文化の表記であり、密閉筐体・高負荷連続運転での 10 年寿命を保証する PLC の `+55℃` と単純比較してはならない。
   - **ADX は「部品定格」ではなく「産業機器流のディレーティングを織り込んだ周囲温度」で語るべき**である。

## 5. ADX CORE-U (rev6) の耐熱性ゴール提案

### 5.1 結論：CORE-U rev6 の 3 Mode 温度ターゲット案

CORE-U rev5/rev6 構成（全稼働部品 `-40〜+105℃`〜`+125℃`、`CH342K` 無通電保存 `-55〜+105℃`、電解コンデンサ・電池・リレー全廃、待機自己発熱 **約 35 mW**）の物理特性と、上記 PLC ベンチマークを踏まえ、以下の **2層定義（実使用動作温度 × 部品設計クラス）** をゴールとして提案する。

| 運用モード | 推奨 動作周囲温度ゴール | 部品定格 / 熱マージン | 対 PLC ポジショニング |
| :--- | :---: | :--- | :--- |
| **Mode 1: Full embedded mode**<br>*(USB-COM/POW 非接続・IDC ラッチ受電)* | **`-40℃ 〜 +85℃`**<br>*(結露・氷結なきこと)* | 稼働全部品 **`-40〜+105℃` 以上**<br>(`+125℃` 電源/アナログ、`CH342K` 保存 `+105℃`)<br>→ **+85℃ 稼働時でも 20℃ の安全マージン** | **エントリー PLC 全機種 (+55〜+65℃) を圧倒**<br>**WAGO XTR / SIPLUS (+70℃) を凌駕**<br>**車載・建機 PLC (`-40〜+85℃`) クラス** |
| **Mode 2: Semi embedded mode**<br>*(USB-POW 接続・USB-COM 非接続)* | **`-20℃ 〜 +70℃`**<br>*(2A 連続時はディレーティング)* | `TPS259470` + シャント自己発熱（2A 時 ~0.16W）および市販 Type-C ケーブル耐熱（~80℃）を考慮 | **WAGO XTR / SIPLUS (+70℃) 同等**<br>（耐振動のみ USB-POW の構造限界あり） |
| **Mode 3: Debug mode**<br>*(USB-COM + USB-POW 接続)* | **`0℃ 〜 +55℃`** *(推奨)*<br>*(最大 `-20℃ 〜 +70℃` 目安)* | `CH342K` 動作上限 `+85℃` に対し十分なマージン確保 | **標準 PLC (`0〜+55℃`) 同等**<br>（机上・盤前デバッグ用途として十分） |
| **保存周囲温度（非通電）** | **`-40℃ 〜 +85℃`**<br>*(105℃ Type-C 採用時は `-40℃ 〜 +100℃` 可)* | `CH342K` 保存上限 `+105℃`・Type-C 定格に対し余裕を確保 | **一般 PLC 保存定格 (`-40〜+70/+75℃`) を大きく上回る** |

---

### 5.2 なぜ「`-40〜+105℃` 動作」ではなく「`-40〜+85℃` 動作（105℃ 部品設計）」が最強のゴールなのか？

1. **「背伸びゼロ」でデータシート上の矛盾がすべて消える**:
   - `CH342K` の保存温度上限は `+105℃`（絶対最大定格）。動作ゴールを `+85℃` に置けば、**`CH342K`・`ATtiny1616-MNR`・`C9039` のすべてに対して 20℃ の健全なディレーティング** が成立する。
   - 民生標準の LCP 製 USB Type-C コネクタ（動作・保存 `-40〜+85℃`）との整合も完璧に取れる（※さらに余裕を持たせるため、LCSC で安価に手に入る `-40〜+105℃` 品があれば優先選定する）。
2. **市場のあらゆる実用シーンを過不足なくカバーできる**:
   - **一般工場・制御盤・舞台・農業ハウス**: 盤内 55〜65℃ どころか **85℃ まで無冷却・密閉・縦横方向不問で動く**（S7-1200 のような縦置きディレーティングが不要！）。
   - **屋外防水ボックス（直射日光下の真夏）**: 箱内ピーク 75〜85℃ をカバー。自己発熱が ~35mW なので、**「箱に入れても中の温度がほぼ上がらない」** という唯一無二の武器になる。
   - **車載・農機・建機キャビン（アフターマーケット / 特装用途）**: `ifm ecomatMobile` と同じ `-40〜+85℃` 帯に入り、夏の駐車中キャビン内高温にも耐えられる（※純正 OEM のエンジンルーム 125℃ や AEC-Q100 認証は明確に対象外と線引きする）。
3. **「拡張 CARD 側がシステムの温度上限を決める」構造で CORE が絶対に足を引っ張らない**:
   - 今後作る絶縁 RS-485 CARD や 24V/48V 絶縁電源 CARD には、絶縁 DC-DC モジュールやサージ保護素子、場合によっては自己発熱の大きい部品が載るため、CARD 側の実動作上限は **`-40〜+70℃`〜`+85℃`** になる可能性が高い。
   - CORE-U rev6 が **`-40〜+85℃`（105℃ 部品ベース）** を担保しておけば、どんな産業用拡張 CARD を組み合わせても **CORE ボード側が熱的ボトルネックになることは絶対に起きない**。

---

### 5.3 このゴールを「誠実に」主張するために rev6 設計・検証で押さえるべき 4 項目

1. **実機熱評価の段階的ステップ（設計目標 → 検証済み定格）**:
   - 部品定格の積み上げだけでいきなり「-40〜+85℃ 保証」と謳わず、初期段階では **「設計目標（Design Target）: `-40℃ 〜 +85℃`（全稼働部品 `-40〜+105℃` 以上選定）」** と表記し、恒温槽（または高温エージング槽）での **+85℃ 連続稼働＆内蔵温度センサ・`VBUS_ISENSE`/`VSENSE`・LIN/UART 通信の疎通検証** を経て「検証済み動作温度」へ昇格させる。
2. **ATtiny1616 内蔵 RC 発振器（`OSC20M`）の温度ドリフト対策**:
   - `-40〜+85℃` 全域では内蔵 RC が数％ドリフトする。拡張バス側 UART での安定通信には、rev6 コンセプトで検討中の **LIN（Break + `0x55` 自動ボーレート補正）** または **内蔵温度センサ参照による `OSCCAL` 補正／外部クロック (`P02 EXTCLK`) オプション** のいずれかが効いてくる。
3. **未接続 USB Type-C ポート 2 個の環境保護**:
   - 屋外・車載・結露リスク環境での Full embedded mode 運用ガイドとして、**① THT シェル固定（耐振）かつ `-40〜+85℃`（望ましくは `+105℃`）LCP 品の選定**、**② シリコン製 Type-C 防塵キャップ装着または 8858 筐体でのポート密閉** を公式推奨事項に盛り込む。
4. **CORE-A の位置づけ整理との整合**:
   - `-40〜+85℃` 帯までを CORE-U rev6（フラッグシップ）＋ 拡張 CARD が完全にカバーすることで、旧 CORE-A の存在意義だった「一般現場・屋外・車載キャビンでの高耐熱」は CORE-U rev6 へ完全統合できる。
   - 逆に「**常時 +85℃〜+105℃ 連続稼働（密閉照明灯具内など）**」「**USB ポート開口部ゼロでの完全ポッティング／コンフォーマルコーティング**」「**1枚完結の超低コスト大量配備スレーブ**」といったニッチな特化要件のみを、付加価値型派生ボード（旧 CORE-A 相当）の領域として切り分けておけば、製品体系に一切の矛盾が残らない。
