# ADX CORE-U Hardware Concept & Architecture Note

- **ステータス**: DRAFT / 仕様策定・プロトタイプ検証中
- **対象ボード**: ADX CORE-U (The Enclosure Maker Board)
- **最新改訂日**: 2026-10-12

---

## 1. ポジショニングと設計思想

### 1.1 背景
ADXエコシステムにおいて、現場・産業用を想定したCORE-Aは極めて高い耐環境性を誇る一方、専用ドングルや特殊な通信インフラを要するため、一般的なメイカーやプロトタイピング用途には参入障壁が高すぎるという課題があった。

**ADX CORE-U** は、ADXのコア・アイデンティティである**「筐体フレンドリー（8748フォームファクタ × 20P拡張バス）」**をそのままに、最も親しみやすい**「Arduino IDE ＋ megaTinyCore ＋ USB Type-C」**で直感的に扱えるエントリーMCUボードとして位置付けられる。

### 1.2 コアバリュー
1. **Enclosure-Native by Design**:
   - 4隅のM3ネジ穴、ワッシャークリアランス、外形掴み幅、単一I/F辺コネクタ集約により、自作3Dプリントケースや既製ボックスへの組付け性が抜群。
2. **Instant "Blink" with Arduino IDE**:
   - ブートローダー不要。WCH `CH342K` による安定したSerialUPDI書き込みにより、手持ちのArduino IDEからUSBケーブル1本で即座に開発可能。
3. **CARD Ecosystem Modularity**:
   - 20Pヘッダ（直スタック ＆ フラットリボンケーブル対応）により、プロト基板や電池基板とスパゲッティ配線なしで接続。

## 2. ハードウェア基本仕様（Baseline Specs）

| 項目 | 仕様 | 備考 |
| :--- | :--- | :--- |
| **フォームファクタ** | **ADX 8748** (`87.0 mm × 48.0 mm`) | M3ネジ穴 (77×38mmピッチ)、Φ5.0mmワッシャークリアランス |
| **メインMCU** | Microchip **`ATTINY1616-MNR`** (QFN-20) | Flash: 16KB, SRAM: 2KB, 20MHz内蔵発振 |
| **USB-UARTブリッジ** | WCH **`CH342K`** (ESSOP-10) | オンボードSerialUPDI書き込み ＆ ハードウェアUARTデバッグ |
| **開発環境** | **Arduino IDE + `megaTinyCore`** | ブートローダー不要、標準ライブラリ利用可能 |
| **拡張バス** | **ADX 20-Pin Expansion Bus** (2×10ピン 2.54mm) | 5V VDD, GND, GPIO, ADC, DAC, I2C, SPI, UART |
| **外形・固定** | スロットイン / スナップフィット対応エッジマージン | 端面I/F集約 |

> [!NOTE]
> **スペックに関する誠実な開示**:
> ATtiny1616は軽量・高効率なMCUであり、センサー読み取り、LED制御、サーボ/モーター駆動といった小〜中規模の制御プロジェクトに最適化されています。Flash 16KBを超える重量級ライブラリや巨大ディスプレイ制御などの用途には適しません。

## 3. 電源アーキテクチャ検討ノート（Active R&D）

現在、ホビー工作やプロトタイピング現場での実用性を最大化するため、以下の電源回路トポロジーを試作・検証中である。

```
［ Debug USB (PC Type-C) ］───────────────➔ 【 CH342K 電源 】(PC接続時のみ動作)
      │
      ▼
   ［ PTC (500mA) ］
      │
      ▼
   ［ LM66100 (Debug用) ］
      │      ▲
      │      │ (Power接続時にDebug給電を自動遮断)
      ▼      │
   ══════════╪══════════════════════════════════ ADX 5V BUS (VDD)
             │                                     │
    ┌────────┴────────┐                            ├─➔ ATtiny1616 (VDD)
    │                 │                            │
 ［ LM66100 (Power用 2並列検討) ］                 └─➔ 20P コネクタ (Pin 2, 3)
    │                 │                                (サーボ・CARDへ大電流供給)
    └────────┬────────┘
             ▲
             │ (最大3Aパス検討)
      ［ Power USB (給電専用 Type-C) ］
```

### 3.1 検討中のキーフィーチャー
1. **デュアル Type-C ポート構成**:
   - **Port 1 (Debug)**: PCと通信・書き込みを行う16P Type-C（PTC過電流保護）。
   - **Port 2 (Power)**: サーボやLEDテープ等への大電流給電を受け入れる給電専用6P Type-C（最大3A）。
2. **理想ダイオード（TI `LM66100`）による保護と自動プライオリティ**:
   - **PC絶対保護**: Power側に大電力ACアダプタが挿入されても、PC側への逆流を瞬時に100%阻止。
   - **ホットプラグ瞬断防止**: デバッグ中に外部電源を挿抜しても、マイコンがリセットせずシームレスに切替。
   - **低電圧降下**: ダイオード損失を数十mVに抑え、サーボ起動時のブラウンアウトを防止。

*(※上記電源回路はプロトタイプでの動作確認・部品コスト・入手性検証に基づき、最終仕様を確定予定)*

## 4. 製造性とコスト見通し

- **部品調達性**: 主要部品（ATtiny1616, CH342K, LM66100, Type-C等）はJLCPCB / LCSCで常時数万個の巨大在庫を維持している部品を中心に選定。
- **PCBAコスト**: 初回試作ネットリストベースで、100pcs製造時において送料込み約$3.90〜$4.50/枚を達成見込み。
- **想定販売価格**: **$20.00 〜 $25.00 USD** 前後（Arduino UNO R3 同等のエントリー価格帯）。
