# ADX CORE-U revival CONCEPT

## CORE-Aへの統合からCORE-Uの再定義
CORE-Aに耐熱、絶縁RS-485、BMCというADXの基本形が集約された。
そして、CORE-Aのボード価格はArduino UNO R4 Wifi程度の28ドル前後となってきた。
ただし、BMCとRS-485の性質上、堅牢なRS-485 OTWを実現するには専用ドングルであるRPR4 Smart Probe, 25ドルが必要になった。これは非常によいが同時に一般のマイコンボードユーザーからすればADXへ参入する敷居は著しく高くなってしまったとも言える。スタートが28ドル＋25ドルで実質60ドル前後になってしまう。そもそもIndustrialな耐熱グレードのマイコンボードなんて市場にはほとんど存在しない。つまり現在のマイコンボード市場から考えればCORE-Aは不必要な高性能ボードであるともいえる。CORE-Aはマイコンボード市場から見るとこれまでなかった市場を切り開く役目があるが、同時にマイコンボード市場から見ると、あまりにしきいが高い。

そこで、よくよく考えるとCORE-Uを再生することでArduino UNO R4 minimaくらいの価格に押し込めるのではないか？と考えてやってみたところ、それなりにおさまった。

## CORE-Uの主な機能
USB TYPE-C,CH342Kによりブートローダーなし、ATtiny1616-MNRをArduino IDEでそのままスムーズに開発できる。
一方、理想ダイオードによるUSB側の逆流保護はそのまま残しているため、乾電池カードなどはCORE-Aと共通してそのまま使えるため、机上、ちょっとしたモバイルユニットを試作するのに最適。USBもCORE-Aと違い通信給電兼用を搭載でき、机上ユニットではそこをそのまま給電源とすることができる。
