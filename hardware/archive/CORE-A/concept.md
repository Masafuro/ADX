# ADX CORE-A (Alpha) rev2 コンセプト設計書
〜 工業耐熱・高信頼性スレーブに特化した $20 クラスのミニマル・エッジコントローラー 〜

## 1. 概要 (Overview)

**ADX CORE-A (Alpha) rev2** は、ADXエコシステムにおける **「高耐環境・大量配備向けエッジスレーブ」** です。

密閉された照明灯具内、車載コンソール、屋外防水ボックス、産業用配電盤など、**-40℃ 〜 +105℃（最大+125℃）** に達する過酷な現場で、長期間メンテナンスフリーで稼働し続けることを最優先要件として設計されています。

rev2 では、上位マスター機 **「ADX CORE-R (Romeo)」** の登場に伴い、製品の役割分担を抜本的に再定義しました。
机上プロトタイピングやPC連携といった汎用的な機能は CORE-R に集約し、CORE-A からは不要な周辺回路（給電用USB Type-C、BMCサブマイコン、eFuse等）を徹底的に削ぎ落としました。

その結果、**「ATtiny1616 ＋ 2500V ガルバニック完全絶縁 RS-485」** という最小限のコンポーネントで完結する極めてシンプルな構成となり、Arduino UNO R4 Minima と同等の **$20.00 USD クラス** の販売価格帯を実現します。

### 推奨ユーザー層と選定ガイドライン
* **ADX CORE-R を推奨するケース:**
  * 初めて ADX エコシステムを利用する場合
  * PC やスマートフォンと接続してシリアルモニタリングやプロトコル解析（Modbus/DMX）を行いたい場合
  * USB Type-C 経由で手軽にスケッチを書き換えたい場合
* **ADX CORE-A を推奨するケース:**
  * 密閉灯具や高温の制御盤内など、85℃ を超える過酷環境に常設する場合
  * 装置内に 10 台、20 台と多数のエッジノードを低コストに物量配置する場合
  * UPDI 書き込み環境を保有している、または CORE-R 経由の OTW 運用を行う場合

## 3. rev1 からの変更点と設計方針 (Architecture Decisions)

rev1 で課題となっていた「複雑性の増大」「部品調達リスク」「使用環境のミスマッチ」を解決するため、以下の 3 つの設計変更を実施しました。

### 3.1 サブマイコン (BMC: ATtiny412) の廃止
* **背景と課題:**  
  rev1 では、待機時超低消費電力モードの制御や RS-485 経由の遠隔リセットを担当させるため、サブMCU（ATtiny412）および eFuse を搭載していました。しかし、市場環境による部品欠品リスクを抱えることになり、ファームウェア管理や検査工程も二重化していました。
* **設計変更:**  
  常時電源が供給される有線フィールドネットワークのユースケースに焦点を絞り、BMC および eFuse 回路を全廃。後述の **内蔵ロジック（CCL）を活用したリセットシーケンス** へ移行することで、MCU を ATtiny1616 の 1 チップに集約しました。

### 3.2 給電用 USB Type-C および 逆流防止回路の廃止
* **背景と課題:**  
  机上テストの利便性のため 6ピン Type-C コネクタを搭載していましたが、通信線（D+/D-）がない給電専用ポートであったため、PC 接続時に認識不良と誤認される懸念がありました。また、105℃ の耐熱環境において樹脂コネクタや民生用USBケーブルの耐熱限界が課題となっていました。
* **設計変更:**  
  USB コネクタおよび逆流防止用の理想ダイオード（LM66100）を廃止し、**電源入力を 20P 拡張バス（Pins 1〜4: VDD_5V）に一本化** しました。
  * コネクタ開口部をなくすことで、完全密閉エンクロージャへの適合性や防湿コーティング（コンフォーマルコーティング）の施工性を高めています。
  * 現場運用時は **ADX POWER CARD**（DC 12V/24V 絶縁受電）から給電を行い、机上書き込み時はプログラマ治具から拡張バス経由で給電します。

### 3.3 内蔵ロジック (CCL) を活用した RS-485 OTW (Over-The-Wire)
* **設計思想:**  
  盤の蓋を開けずにファームウェアを更新する OTW は、現場運用において極めて重要です。
  通常、スケッチ実行中に通信経由でマイコンをリブートさせるには、ユーザーコード側で常に受信パケットを監視するか、外付けのリセット監視回路が必要でした。
* **CCL (Configurable Custom Logic) の活用:**  
  ATtiny1616 の RS-485 受信ピン（`PA2`）は、内部でプログラマブルロジック **CCL の LUT0-IN2** に直結されています。
  CPU の動作状態（スケッチの実行内容、割り込み禁止状態、ハングアップ等）に依存せず、ハードウェアロジックが通信ピンの波形を直接監視できます。
* **波形検出による自律リセット (実装方針):**  
  マスター機（CORE-R）の PIO を用いて、通常の UART 通信（8N1）では発生し得ない特定の物理波形（パルス幅変調やバーストシーケンス等）をバスに送出します。CCL がこの特定波形を検出して内部リセット（またはウォッチドッグトリガー）をかけることで、追加部品なしで安全にブートローダへ遷移させる構成を検証・実装します。

```text
【 CORE-A rev2 OTW リセット協調アーキテクチャ 】

  [ マスター機: CORE-R ]
    └─ RP2040 PIO: 通常通信と重複しない特殊波形シーケンスを生成・送出
         │
         │ (2500V ガルバニック絶縁 RS-485 バス)
         ▼
  [ スレーブ機: CORE-A ]
    └─ TDA51S485HC (絶縁トランシーバ)
         │ RXD (PA2 / LUT0-IN2)
         ▼
    ┌────────────────────────────────────────────────────────┐
    │ ATtiny1616                                             │
    │  ・CPU/スケッチ層: 通常の制御・通信処理を継続            │
    │  ・CCL ハードウェア層: PA2 の入力波形を非同期監視       │
    │       │ (特定のリブート波形パターンを検出)             │
    │       ▼                                                │
    │  [ 内部リセット発行 ] ──▶ ブートローダ (Optiboot) 起動 │
    └────────────────────────────────────────────────────────┘
```

## 6. まとめ (Conclusion)

ADX CORE-A rev2 は、徹底した「機能の引き算」により、現場で真に求められる性能にリソースを集中させたエッジコントローラーです。

* **$5.43 USD の PCBA 原価** による、$20 クラスの優れたコストパフォーマンス
* **USB・BMC の全廃** による、-40℃ 〜 +105℃ の完全な動作保証と小型化
* **CORE-R との協調アーキテクチャ** による、現場配線を活かした OTW メンテナンス性

初学者の入門機としては CORE-R を提供し、プロフェッショナルの現場実装機としては CORE-A を提供する——この明確な棲み分けにより、ADX エコシステムはホビープロトタイピングから本格的な産業・舞台設備まで、一貫した価値を提供します。
