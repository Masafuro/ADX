## 1. タスク概要と目的

回路図上で成立していても、基板アートワーク（レイアウト配線）の物理的なパターン幅不足、GND プレーンの分断、スイッチングノードのループ面積肥大化などがあると、**電源ドロップ、高周波ノイズ放射、通信エラー、熱暴走などの深刻な物理障害** を引き起こします。
本タスクでは、2層基板という制約下において、ノイズ・熱・電流容量の観点からレイアウト設計の品質を徹底検証します。

---

## 2. 詳細レビュー項目とチェックリスト (Review Items)

### 2.1 電源・GND パターンの電流容量とインダクタンス
- [ ] **大電流経路のパターン幅検証**:
  - 外部入力（+7_16V）からヒューズ `0-F3`、TVS `0-D2`、ショットキー `0-D1`、インダクタ `0-L4` を経て DC-DC `1-DCDC` 入力端子に至る経路のパターン幅（目標: 0.8mm以上 / 1A以上耐量）。
  - DC-DC 出力（+5V）から出力電解コンデンサ `1-C7`、ロードスイッチ `2-P_SW` に至る経路のパターン幅（目標: 1.0mm以上 / 3Aピーク耐量）。
  - ロードスイッチ出力（VDD）から MCU および IDC コネクタに至る電源ラインの幅。
- [ ] **ビアの電流容量**:
  - 電源ラインおよび大電流 GND で層間を渡る箇所のビア数（単一ビアではなく複数ビアでインダクタンス・抵抗を低減できているか）。

### 2.2 2層基板における GND プレーン連続性とリターンパス
- [ ] **Bottom 層ベタ GND の分断（スリット）検証**:
  - Bottom 層（GBL）において、横断する長い配線によって GND ベタが島状に分断されていないか。
  - 信号ライン（特に高速なクロック、UART、UPDI）の直下にリターンパスとなる連続した GND プレーンが存在しているか。
- [ ] **GND プレーン間接続（スティッチングビア）**:
  - Top 層のベタ GND と Bottom 層のベタ GND を結ぶスティッチングビアが十分な密度で配置されているか。

### 2.3 DC-DC スイッチング電源（TPS5430）のループ面積最小化
- [ ] **高周波スイッチングループの極小化**:
  - `TPS5430` の PH 端子（Pin 8）、キャッチダイオード `1-D2`（SS54）、出力インダクタ `1-L4`、入力バイパスコンデンサ `1-C1` で形成される高周波スイッチング電流ループの面積が最小化されているか。
- [ ] **ブートストラップコンデンサ配線**:
  - BOOT 端子（Pin 1）と PH 端子間のブートストラップコンデンサ `1-C3`（10nF）の配線長が短く、低インダクタンスに配置されているか。
- [ ] **フィードバックライン（VSENSE）のノイズ隔離**:
  - 分圧抵抗（`1-R5`, `1-R6`）から VSENSE 端子（Pin 4）に至る高インピーダンス配線が、インダクタや PH ノードから十分に離隔され、シールドされているか。

### 2.4 RS-485 差動ペア配線と通信品質
- [ ] **差動ペア（A / B ライン）の配線品質**:
  - コネクタ `0-P1` からトランシーバー `4-RS485` に至る A/B ラインが、平行・等長で配線されているか。
  - 差動ライン直下に連続した GND が確保されているか。
- [ ] **DC-DC ノイズ源との離隔**:
  - A/B 信号ラインが、DC-DC インダクタやスイッチングノードの直近を通過していないか。

### 2.5 熱設計（Thermal Design）
- [ ] **`TPS5430` PowerPAD（サーマルパッド）の放熱処理**:
  - IC 底面のサーマルパッドが基板の GND プレーンに十分な数の放熱ビア（Thermal Vias）で接続されているか。
- [ ] **キャッチダイオード `SS54` の放熱面積**:
  - カソード・アノード側の銅箔面積が十分確保され、放熱性が考慮されているか。

## 3. 検証手順と使用ツール

1. **ガーバー幾何解析スクリプト**:
   - `GTL`（TopLayer）および `GBL`（BottomLayer）の配線幅、ベタ面積、ビア座標（`DRL`）を解析。
2. **目視・レイアウト図精査**:
   - スイッチングループ、GND 分断、RS-485 差動ラインの物理的配置を目視・寸法計測で精査。
3. **IPC-2152 規格照合**:
   - パターン幅と許容温度上昇（$\Delta T = 10^\circ\mathrm{C}$ / $20^\circ\mathrm{C}$）に対する電流容量の照合。
