# ADX CORE-S rev2 ネットリスト 最終レビュー判定報告書 (Final Sign-off Report)

- **レビュー対象**: ADX CORE-S rev2 ネットリスト（[`Netlist_Schematic1_2026-09-16_rev2.enet`](../Netlist_Schematic1_2026-09-16_rev2.enet)）
- **レビュー完了日**: 2026-09-16
- **レビュアー**: ADX Hardware Review Team (AI Agent & System Developer)
- **最終判定**: **ALL PASS（完全合格：全フェーズ検証クリア）**
- **工程ステータス**: **Ready for PCB Layout（基板アートワーク・パターン設計着手承認）**

---

## 1. 総合評価エグゼクティブサマリー

改訂版ネットリスト **`rev2`** に対する全 4 フェーズの網羅的電気的検証（接続性、電源過渡特性、通信・規格整合性、BMC 制御シーケンス）がすべて完了しました。

初版（rev1）で抽出された重要課題（`BMC_RO` 配線ミス、ロードスイッチ突入電流リスク）が **100% 正確に改修・是正** されており、新たな配線漏れや回路デグレ（Regression）は一切確認されませんでした。

また、CORE-S の基本コンセプトである **「CORE-STANDARD（12V系 / バッテリー駆動 / Commercial / 低コスト）」** の設計方針に基づき、不要な過剰装備（TVS 等）をオミットしつつ、民生・標準用途として極めて高い堅牢性と電源品質が両立されています。

本報告をもって、ネットリスト `rev2` を **「設計凍結（Design Freeze）」** とし、次工程である **PCB パターンレイアウト設計（Artwork）への移行を正式に承認（Sign-off）** いたします。

## 3. 完成した CORE-S rev2 の設計ハイライト

定数計算およびデータシート照合により実証された、本ボードの主要性能指標です。

1. **極小の電源ノイズと超安定 DC-DC (`TPS5430`)**:
   - 出力電圧精度: **$4.995\,\mathrm{V}$（誤差 -0.10%）**
   - 導電性高分子固体電解コンデンサ（`1-C5`: 220μF 16V, **ESR = 24mΩ**, 許容リプル **2.9A**）により、出力スイッチングリップルはわずか **$9.3\,\mathrm{mV}_{p-p}$**。
   - 位相進みゼロ点周波数（$f_z \approx 30.1\,\mathrm{kHz}$）が TI 内部補償帯域と完璧に合致し、広範囲な負荷変動に対して無発振・高安定な給電を保証。
2. **無衝撃パワーゲーティング (`TPS22965` ＆ `2-C1`)**:
   - ロードスイッチ投入時の突入電流がわずか **$18.6\,\mathrm{mA}$** に制御され、上流 `+5V` バスの電圧ディップは皆無（$< 5\,\mathrm{mV}$）。BMC や RS-485 が動作中に MCU を ON/OFF しても一切の誤動作が発生しません。
3. **ADX Pinout 仕様書 (v2) への 100% 完全準拠**:
   - 2×10 IDC 拡張コネクタ（`GPIO-IDC`）の全 20 ピンが規格仕様と完全合致。Pins 1〜4（VDD 2×2 ブロック）、Pin 5（短絡防止 NC）、Pin 8/10（EXTCLK サンドイッチシールド GND）の構造が完全に成立。
4. **自律ブート＆遠隔管理シーケンスの完全確立**:
   - BMC（ATtiny412）による常時 RS-485 バス監視、`BOOT_REQ` 信号系（プルダウン 10kΩ ＋ 直列保護 10kΩ）、`VDD_SW` 制御（プルダウン 100kΩ）により、安全かつ高速な LN-485 遠隔ファームウェア書き込みが可能。

## 4. PCB パターンレイアウト設計（次工程）に向けた推奨ガイドライン

アートワーク設計者が留意すべき重要レイアウト推奨事項です。

1. **DC-DC (`1-DCDC: TPS5430`) の大電流ループ最小化**:
   - Pin 7 (VIN) $\to$ IC $\to$ Pin 8 (PH) $\to$ キャッチダイオード `1-D2` (SS54) $\to$ GND のスイッチングループ面積を極小に配線してください。
   - `1-DCDC` 底面の PowerPAD（放熱パッド）は、GND プレーンへ複数のサーマルビア（4〜6 穴）で直結してください。
2. **ロードスイッチ (`2-P_SW`) の CT コンデンサ配置**:
   - 追加された `2-C1` (1nF) は、TPS22965 の Pin 6 (CT) および Pin 5/EP (GND) の直近に最短で配線してください。
3. **IDC コネクタ (`GPIO-IDC`) の電源・シールドベタプレーン**:
   - Pins 1〜4（VDD）は 2×2 の正方形ベタパターンで結合し、給電インピーダンスを下げてください。
   - Pin 8 および Pin 10（GND）は、Pin 9（EXTCLK）を両側から挟み込むように GND ガードパターンを形成してください。
4. **シルク表示の追加**:
   - 端子台 `0-P1` の近傍（Top シルク層）に、**「7-16V DC ONLY」** または **「VIN: 7-16V」** の注意喚起シルクを配置してください。
