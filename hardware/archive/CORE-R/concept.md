# ADX Ecosystem Architecture & Product Strategy Note

## 1. 経緯と課題の変遷

### 当初の構想と直面した課題
* **構成:** 
  * 端末ボード **「CORE-A」** (ATtiny1616 / 5V GPIO / 絶縁RS-485)。
  * 通信・書き込み方式: 専用のLIN Breakを用いた独自プロトコル **「LN-485」** による OTW (Over-The-Wire)。
* **課題 1: 書込治具の不安定さ**
  * 一般的な市販 USB-RS485 ドングルでは、OS/ドライバ層のジッターやFTDI等の仕様制約により正確な LIN Break 生成が困難（ボーレートトリックは実行ホスト環境依存が激しい）。
* **課題 2: 専用ドングル「RPR4」の立ち上げと肥大化**
  * RP2040 の PIO を用いて高精度な Break 生成と DMX512 送受を担うドングル「RPR4」の開発に着手。
  * 絶縁トランシーバーや絶縁電源を搭載した結果、基板サイズが ADX 規格サイズに近づき、中途半端に大型化。
  * ADX 規格とは別外形・別端子のツールが初動で立ち上がり、製造・検品シーケンスの一貫性が損なわれる懸念が生じた。
* **課題 3: CORE-A 単体完結案の挫折**
  * CORE-A に CH340K を載せて USB-RS485 パススルーを兼ねさせようとしたが、ATtiny1616 のハードウェア USART は 1 系統のみ。
  * DMX512 (250 kbps) のトラフィックを Software Serial で USB 側へ流すのは、帯域・CPUサイクル・割り込み衝突の観点から性能的に不可能。
  * tinyAVR 2 (ATtiny1626 等、UART×2) は LCSC 等での部品入手性に難があり採用不可。

---

## 2. 解決策：RPR4 の ADX 正規モジュール化（「CORE-R」の誕生）

専用ドングルという枠組みを撤廃し、RP2040 搭載のインテリジェント・マスターモジュール **「CORE-R」** として ADX 規格の正規 SKU へ昇格させる。

### 設計上の要点
1. **ADX 規格の 5V GPIO を維持 (3.3V 規格への改悪を回避)**
   * システム全体の堅牢性・耐ノイズ性を守るため、ADX 規格の「5V GPIO」は堅持。
   * CORE-R 内部で 3.3V ⇔ 5V の辻褄を完結させる。
2. **デジタル信号のインターフェース設計**
   * ADX ピンアウト上のデジタル信号線は計 8 本 (UART×2, I2C×2, SPI×4)。
   * I2C: 双方向レベルシフタ (PCA9306 等)
   * UART / SPI: 単方向バッファ / レベルシフタ (74LVC / 74AHCT 系) または万能型シフタ (TXS0108E 等) を活用。
3. **CORE-R の書き込み仕様の割り切り**
   * CORE-R 自身は **Type-C 経由 (RP2040 ネイティブ USB / UF2 / CDC) で書き込み**。
   * RS-485 OTW (BMC スニッファ・ロードスイッチ等) は非搭載とし、BOM コストと基板面積を最適化。

## 3. CORE-A と CORE-R の棲み分け

| 項目 | **CORE-A** (現場の重装甲スレーブ) | **CORE-R** (現場の頭脳・解析マスター) |
| :--- | :--- | :--- |
| **主要 MCU** | ATtiny1616 (8-bit, 5V ネイティブ) | RP2040 (32-bit Dual, 3.3V + シフタ) |
| **販売想定価格** | 約 $28 クラス | 約 $35 クラス |
| **耐熱・環境耐性** | **Industrial / Automotive Grade**<br>(-40°C 〜 +105°C/+125°C、密閉灯具・盤内対応) | 通常産業〜プロユースグレード<br>(-20°C 〜 +85°C) |
| **OTW / 書込方式** | **RS-485 OTW (LN-485)**<br>(BMC スニッファ & ロードスイッチ搭載) | **USB 直接書き込み (UF2 / CDC)**<br>(RS-485 OTW は非対応と割り切り) |
| **主な役割** | ・DMX512 / LN-485 受信制御端末<br>・高熱環境下での高信頼性エンドノード | ・LN-485 フィールドネットワークマスター<br>・RS-485 現場スマートプローブ / 簡易ロジアナ<br>・PC ゲートウェイ / CORE-A 書込親機 |
| **ADX 規格整合** | 5V ネイティブ完全準拠 | オンボードシフタにより 5V 準拠 |

---

## 4. もたらされる連鎖的メリット

1. **製造・検品シーケンスの完全統一（「後工程はお客様」の実践）**
   * 基板外形・IDC 20 ピン端子配置・面付け・検査ソケットが完全に 1 系統に集約。
   * CORE-R がそのまま「CORE-A の書き込み・ファンクションテスター親機」として機能。
2. **ADX エコシステムの最大活用**
   * CORE-R は専用ドングルと異なり、ADX 共通エンクロージャや Power Card（乾電池パック、絶縁 DC 12V/24V 入力など）をそのまま利用可能。
   * PC レスで現場に持ち出せるスタンドアロンな診断機・DMX テスターが追加開発なしで実現。
3. **プロダクト価値の転換**
   * 「購入を強いられる $25 の専用ドングル」から、現場エンジニアが手元に持っておきたい「$35 の高付加価値スマートアナライザ＆マスター」へと製品価値が昇華。
4. **スターターキットの簡素化**
   * CORE-Aは組込スレーブとなるため、CORE-Rを持っている人はCORE-Rをチェーンして書きこむが、CORE-RはUSB書き込みでき、かつADXとの互換性があるため、ADXへの入門として最適、かつ、CORE-Rがあればたいていのことができる。
