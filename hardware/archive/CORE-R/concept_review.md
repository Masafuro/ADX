# ADX CORE-R コンセプトレビュー結果報告書 (Concept Review Report)
〜 ドングルの迷宮から解脱し、Arduino UNO R4 を凌駕する $28 産業旗艦コアへ 〜

---

## 1. エグゼクティブ・サマリー (Executive Summary)

`hardware/CORE-R/concept.md` にて提案された「RPR4 ドングルの正規モジュール化（CORE-R 構想）」について、工学・製造・運用・市場性の全方位から徹底的なコンセプトレビューを実施した。

### 結論と決定事項
1. **第 1 弾ローンチの単独フラッグシップ化（CORE-R 一本勝負）:**
   * 当初の「CORE-R（親機）と CORE-A（子機）の並立」および「専用ドングル（RPR4）」を完全に撤廃。
   * Crowd Supply 第 1 弾は、**「ADX CORE-R」単一 SKU** にリソースを 100% 集中する。
   * Day 1 での未踏領域（半二重 RS-485 OTW ブートローダーや独自プロトコル LN-485）のスコープを一旦外し、**USB Type-C 直挿し（UF2 / CDC）による確実かつ即座な開発 UX** を提供する。
2. **ADX バス規格の大統一（5V 幹線給電 ＋ 3.3V GPIO 直結）:**
   * 懸念されていた「5V レベルシフタの泥沼（74AHCT/74LVC/PCA9306）」を **完全撤廃**。
   * バスロジックを **3.3V ネイティブ** に再定義し、RP2040 ピンを直結（TVS 保護 ＋ 直列ダンピング抵抗）。
   * 幹線電源は **5V（Pins 1〜4 束ね、最大 2A〜3A）** を維持し、長配線による電圧降下に打ち勝つ流体的な電源トポロジーを確立。
3. **市場破壊的なポジショニング（Arduino UNO R4 WiFi キラー: $28.00）:**
   * レベルシフタ全廃と部品点数極小化により、BOM 原価を大幅に圧縮。
   * **Arduino UNO R4 WiFi と同等の「$28.00 USD」** での販売を射程に捉え、圧倒的スペック差（Dual 133MHz、完全絶縁 RS-485、スプリング端子台、Eject Header、8748 筐体適合）で市場を席巻する。
4. **CORE-A の位置づけの再定義:**
   * CORE-A（ATtiny1616）は「書き込み親機を必要とする不完全な子機」ではなく、**「過酷環境（-40℃〜+105℃）に特化した WiFi 子機のようなオプション機」** として第 2 弾へ温存する。

## 2. 議論と変遷の軌跡（なぜこの結論に至ったのか）

### 2.1 複雑性のピンポン玉（これまでの苦難の歴史）
ADX プロジェクトが直面してきた困難を客観的に辿ると、すべては **「現場の電線経由で Flash を書き換えたい（RS-485 OTW）」という要求から連鎖的に発生した『複雑性の押し付け合い』** であった。

```text
【原初の一撃】
  過酷な現場で絶対に壊れないコアボードを作ろう
  ➜ CORE-A (ATtiny1616 / 5V / 自己発熱ゼロ / -40℃〜+105℃) が誕生。
      │
      ▼
【理想の追求】
  盤のフタを開けずに電線からスマホで書き換えたい (RS-485 OTW)
  ➜ LIN Break を用いた独自プロトコル (LN-485) を考案。
      │
      ▼
【第1の破綻：治具の壁】
  市販の安物 USB-RS485 ドングルでは、OS のジッターで正確な Break が出ない！
  ➜ スマホ (PWA) から書き込めず、開発が泥沼化。
  ★「CORE-A を極限までシンプルにしたツケ」が「書込環境の不安定さ」へ転移。
      │
      ▼
【第2の破綻：治具の肥大化】
  RP2040 の PIO で完璧な Break を生成する専用ドングル「RPR4 Smart Probe」を開発。
  ➜ 絶縁電源や端子台を載せた結果、ドングル自体が大型化・高価格化 ($25)。
  ➜ 8748 とは別外形・別端子となり、製造・検品・外装のオペレーションが 2 重に分裂！
  ★「書込の複雑性」が「製造・出荷工程の悪夢」へ転移。
      │
      ▼
【第3の破綻：正規モジュール化の罠】
  RPR4 を 8748 規格の正規親機「CORE-R」に昇格させよう。
  ➜ RP2040 (3.3V) と ADX バス (5V) を繋ぐため、大量のレベルシフタが必要に。
  ➜ バッカーから見ると「なぜ同じようなボードが 2 枚あるのか？」と混乱。
  ➜「ボード（CORE-R）を買ってボード（CORE-A）に書き込む」という、
     昔の Arduino as ISP（Arduino で Arduino に書き込む工作）のような不自然な儀式に。
  ★「製造の二重苦を逃れたツケ」が「回路の複雑性とマーケティングの混乱」へ転移。
```

### 2.2 複雑性の結び目を解いた「4つのブレークスルー」
本レビューにおける徹底議論により、以下の本質的な気付きが得られ、複雑性のドミノが一気に解消された。

1. **Day 1 における OTW スコープの切り離し:**
   * USB Type-C 直結で PC から UF2 / CDC で 1 秒で書き込めるなら、初動での OTW は不要。
   * ボード上には完全絶縁 RS-485（TDA51S485HC）が載っているため、**Modbus RTU や Serial による相互通信は初日から 100% 稼働** する。
2. **「脆いのは 3.3V という電圧ではなく、微細化シリコンである」という真理:**
   * 5V が頑丈なのではなく、厚い酸化膜を持つ ATtiny1616 のシリコンが頑丈なだけ。
   * ATtiny1616 は 3.3V で動かしても、6.0V 破壊耐圧・105℃ 耐熱という戦車のようなタフネスは 1 ミリも失われない。
3. **「5V 幹線大動脈 ＋ 3.3V 信号神経網」という流体工学の勝利:**
   * 電源は太い 5V 幹線（4本束ね）で力強く配り、各カードの末端（LDO）で 3.3V を取り出す。これにより長配線での電圧降下に打ち勝ち、電源調停の理想ダイオードも 5V ラインの 1 個で完結する。
   * 信号線は電流が数 $\mu\text{A}$ しか流れないため、3.3V 直結でも電圧降下は実質ゼロ。
4. **CORE-U の教訓の昇華:**
   * かつて ATtiny1616 に USB を載せようとした「CORE-U」は、耐熱性を失った上に 8-bit の陳腐化でオミットされた。
   * CORE-R は、現代の強力な 32-bit Dual-Core RP2040 を載せることで、Arduino UNO R4 の RA4M1 を完全に圧倒するスペックを獲得した。

### 3.1 電源トポロジーの確定
* **幹線給電:** 20P コネクタの Pins 1〜4 をすべて束ね、**5V 単一幹線（最大 2A〜3A）** として定義。
  * 4 ピン並列配線により、接触・配線抵抗はわずか 20〜30m$\Omega$。1A 流れても電圧降下はわずか 30mV。
* **電源調停（理想ダイオード）の極小化:**
  * 逆流阻止バルブは、**Type-C 入力部の TI `LM66100`（1個）のみ** で完結。
  * 2 系統電源（5V と 3.3V）が混在することによる電源調停の泥沼化を完全に回避。
* **CARD 側の電源設計ルール:**
  * 拡張カードは 5V 幹線を受電し、安価な米粒 LDO（ME6211 等、SOT-23、約 $0.02）でローカルに 3.3V を生成（Point of Load 思想）。
  * 各カードの電源が局所的に安定し、ノイズアイソレーションが最大化される。

### 3.2 信号インターフェース（3.3V 直結）の確定
* **レベルシフタの全廃:**
  * 74AHCT125、74LVC125、PCA9306 を基板から **100% 撤廃**。
  * RP2040 の GPIO を 20P ヘッダへ直結。
* **プロ仕様の保護回路（TVS ＋ ダンピング）:**
  * コネクタ根元に **TVS ダイオードアレイ** を配置し、人体帯電静電気（$\pm 15\text{kV}$）やカード抜き差しのスパークから RP2040 を完全保護。
  * 各信号線に **22$\Omega$〜33$\Omega$ 直列ダンピング抵抗** を配置し、リボンケーブルの反射波・オーバーシュートを吸収。
  * RP2040 側のピン設定を「スルーレート Slow ＋ 8mA 駆動」とし、放射ノイズ（EMI）を抑えつつ容量負荷を力強くドライブ。

### 3.3 現場保守・デバッグ UX（通電中活線挿抜の神UX）
* **LM66100 逆流阻止バルブ** により、工場の 24V Power CARD や車載電源で **設備がフル稼働している真っ最中に、作業者のノート PC から Type-C ケーブルを直接カチッと挿抜可能**。
* PC 破損リスクは物理的に 0.00%。市販の RS-485 ドングルすら介さず、PC 画面で直接 `Serial.print` ログのモニタリングや UF2 ファーム更新が可能。

## 4. 商業性・製品戦略・ポジショニング評価

### 4.1 対抗ベンチマーク比較（Arduino UNO R4 WiFi との死闘）

| 比較項目 | Arduino UNO R4 WiFi | ADX CORE-R | ADX の決定的勝因 |
| :--- | :--- | :--- | :--- |
| **価格** | **$27.50 USD** | **$28.00 USD（想定）** | **完全な同価格帯でのガチンコ勝負** |
| **主要 MCU** | Renesas RA4M1 (48MHz, 32KB RAM) | **RP2040 (Dual 133MHz, 264KB RAM)** | **CPU 3倍、RAM 8倍の圧倒的パワー** |
| **通信機能** | 非絶縁 WiFi / BLE のみ | **2500V 完全絶縁 RS-485 標準搭載** | **工場・現場で絶対に壊れないタフネス** |
| **配線端子** | ピンソケット（振動脱落多発） | **前面スプリング端子台 ＆ Eject Header** | **現場の振動緩みゼロ・工具レス結線** |
| **筐体適合性** | むき出し（ケースにネジ留め不能） | **8748 規格（DINレール/ケース完全対応）** | **そのまま配電盤や壁面へ設置可能** |
| **電源適合性** | 非絶縁 DC ジャック（発熱の温床） | **USB Type-C ＋ 絶縁 24V/電池 CARD** | **自己発熱ゼロ ＆ 通電中 PC 完全保護** |

### 4.2 コスト構造と収益性（$28.00 販売時の成立性）
レベルシフタ 3 チップおよび周辺部品の全廃により、PCBA 原価は大幅に圧縮された。

* **PCBA 製造原価（100pcs ロット時）:** **約 $6.20 〜 $6.80 USD**
* **量産時 PCBA 原価（500〜1,000pcs 時）:** **約 $4.80 〜 $5.30 USD**
* **想定販売価格:** **$28.00 USD（粗利率 約 81〜83%）**
* **結論:** 健全極まりない粗利構造を維持したまま、Arduino UNO R4 WiFi と真っ向勝負できる価格競争力を獲得。
