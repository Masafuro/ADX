# ADX CORE-R 技術仕様書 (Hardware Specification)

本ドキュメントは、ADXエコシステムの旗艦マスターモジュール **「ADX CORE-R (Romeo)」** の回路・電気的仕様・ピンアサイン・部品選定基準を定義する技術仕様書である。

---

## 1. 基本電気仕様 ＆ プロダクト位置づけ

### 1.1 プロダクト概要
ADX CORE-R は、ADXエコシステムにおける **第 1 弾ローンチの単独フラッグシップ・コアボード** である。
Arduino UNO R4 WiFi と同等の **「$28.00 USD クラス」** でありながら、2500V 完全絶縁 RS-485、産業用スプリング端子台、MIL 規格ラッチ付き Eject Header、8748 筐体適合性を備え、プロが現場に持ち出せる圧倒的なタフネスを提供する。

### 1.2 電気仕様一覧

| 項目 | 定格 / 仕様 | 備考 |
| :--- | :--- | :--- |
| **主電源入力 (VDD_5V)** | **5.0V DC** (±10%) | Type-C または 20P拡張バス (Pins 1〜4) 受電時 |
| **内部ロジック電圧** | **3.3V DC** (MCU/Flash), **1.1V DC** (RP2040 Core) | オンボード高効率降圧 DCDC (2A級) により生成 |
| **拡張バス論理電圧** | **3.3V LVCMOS 準拠** (ADX Pinout v3) | **レベルシフタ全廃・RP2040 ネイティブ直結** |
| **動作保証温度範囲** | **-20℃ 〜 +85℃** | プロユース・一般産業用グレード準拠 |
| **保存温度範囲** | **-40℃ 〜 +125℃** | |
| **外形寸法** | **87.0 mm × 48.0 mm** | ADX 8748 フォームファクタ準拠 |
| **基板仕様** | 4層 FR-4, 厚み 1.6mm, 1oz銅箔 | 全面 GND プレーンによる高耐ノイズ性 |
| **消費電流 (通常動作)** | 約 25mA 〜 50mA @ 5.0V | デュアルコア 133MHz 稼働時 |

## 2. システム・アーキテクチャ ＆ 回路ブロック図

レベルシフタを基板から完全排除し、RP2040 のピンを TVS 保護ダイオードおよび直列ダンピング抵抗を介して 20P ヘッダへ直結する極限までシンプルなアーキテクチャを採用。

```text
                    【 ADX CORE-R 回路アーキテクチャ 】

  [ 前面 RS-485 端子台 ] (DB142R-5.08: A, B, GND_ISO)
         │
    [ ⚡ ガルバニック絶縁 2500V (Mornsun TDA51S485HC) ⚡ ]
         │
         │ RXD (3.3V) / TXD, DE, RE (3.3V PIO 直結)
         ▼
  ┌──────────────────────────────────────────────────────────────────┐
  │  RP2040 (Dual ARM Cortex-M0+ 133MHz / QFN-56)                   │
  │  ・USB 2.0 FS ネイティブ: UF2 書込 ＆ CDC シリアルモニタ          │
  │  ・PIO: 将来の OTW / 高精度 Break 生成 / 現場ロジアナ機能          │
  │  ・GPIO: スルーレート Slow ＋ 8mA 駆動設定                       │
  └──────┬───────────────────────────────────────────────────────────┘
         │
         │ (レベルシフタ完全撤廃 ➜ 3.3V ロジック直結)
         ├─▶ [ TVS ダイオードアレイ (PESD3V3 等) ] ──▶ 静電気 ±15kV 瞬時吸収
         ├─▶ [ 22Ω〜33Ω 直列ダンピング抵抗 ]       ──▶ 反射・リンギング吸収
         ▼
  ────────────────────────────────────────────────────────────────────
        ADX 20P 拡張バス (5V 幹線大動脈 ×4 ＋ 3.3V ネイティブロジック)
  ────────────────────────────────────────────────────────────────────
         ▲
         │ (5V 双方向受給電 / 最大 2A〜3A)
  ┌──────┴────────────────────────┐          ┌────────────────────────┐
  │ 電源マネジメント               │          │ USB Type-C (16P)       │
  │ ・TI LM66100 理想ダイオード   │◀─────────┤ ・PC 逆流 100% 完全保護 │
  │ ・高効率 3.3V 降圧 DCDC (2A級)│          │ ・通電中活線挿抜 OK    │
  └───────────────────────────────┘          └────────────────────────┘
```

## 4. 電源・保護回路 ＆ 現場保守 UX

### 4.1 USB 逆流阻止バルブ (TI LM66100) による通電中活線挿抜
* **現場の神 UX の実現:**
  * 盤内の 24V Power CARD から給電されて設備がフル稼働している最中に、**作業者がノート PC から USB Type-C ケーブルを直接カチッと直挿し可能**。
  * `LM66100` 理想ダイオード（Vf 降下わずか 20〜30mV、逆電圧印加時瞬時遮断）により、CARD からの 5V が PC 側へ逆流することを 100% 阻止。
  * **PC 破損リスクは物理的に 0.00%**。
* **市販ドングル不要のダイレクトデバッグ:**
  * Type-C を挿すだけで、PC 画面上に USB CDC シリアルポートが即座に開通。
  * リアルタイムログ（`Serial.print`）の確認、および UF2 ドラッグ＆ドロップによるファームウェア更新が現場で完結。
  * 作業完了後はケーブルを抜くだけで、設備は何事もなかったかのように動き続ける。

### 4.2 3.3V 降圧 DCDC (2A級 高効率同期整流)
* **採用コンポーネント:** SGMICRO `SGM61320` または Silergy `SY8089` (SOT-23-6)
* **定格出力:** 最大 2.0A @ 3.3V（変換効率 90% 以上）
* **自己発熱の極小化:** 高負荷時でも発熱は数 mW 程度。密閉エンクロージャ内でも基板温度の上昇を完全に抑え込む。
