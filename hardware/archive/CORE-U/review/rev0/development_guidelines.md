## 1. 開発背景とコア・フィロソフィー

### 1.1 Arduino UNO R4 Minima との差別化戦略
Arduino UNO R4 Minima は、広電圧入力 DCDC（Buckコンバータ）、Oring コントローラ、32-bit MCU（RA4M1）を搭載し、巨大な量産スケールによって約20ドルという低価格を実現しています。  
新規参入である ADX が同じ回路構成（降圧DCDC＋汎用電源切り替え）で真正面から競争した場合、UI/UX・コスト・製造性の面で勝ち目はありません。

そこで ADX CORE-U では、以下の発想の転換を行います：

1. **DCDC の完全放棄**:
   - 降圧・昇降圧 DCDC をボードから完全にオミット。
   - Raspberry Pi 等の普及によって市場に大量かつ安価に流通している **高品質な DC 5V（3A〜5A）AC アダプター** を主電源として前提化する。
2. **削ったリソースを「最強の保護ゲートウェイ」へ再投資**:
   - DCDC を削って浮いたコストと基板面積を、**大電流対応 eFuse（電子ヒューズ）および OVP（過電圧保護）** に全額再投資する。
   - 「5V 2A（10Wクラス）を安定して扱え、短絡しても過電圧を突っ込んでも絶対に死なない」世界一タフな 5V コアボードを実現する。
3. **ADX 8748 フォームファクタと拡張 CARD との分業**:
   - 多種多様なバッテリー（LiPo、乾電池、リン酸鉄等）への対応は、MCU 単体で抱え込まず「バッテリー拡張 CARD」側で 5V を生成して供給する。
   - これにより、Enclosure-Friendly（筐体一体型）なバッテリー駆動デバイスを最小コストで実現する。

## 2. 電源アーキテクチャと流路設計（システム不変条件）

ADX プラットフォームの整合性と長期的な信頼性を担保するため、電源流路に関する以下の 2 つの原則を **「絶対的な不変条件（Platform Invariant）」** として確立します。

### 2.1 原則①：IDC Pin 1〜4（VDD）は「出力専用」の一方通行とする
- **背景**:
  - ADX Pinout v2 において、IDC コネクタの Pin 1〜4 は Core ボードから拡張 CARD へ電力を届ける出力幹線（Power Delivery）として規定されている。
- **不可逆ルールの理由**:
  - もし拡張 CARD からの「IDC 逆給電（Backpowering）」を許容してしまうと、**今後開発されるすべての Core ボード（CORE-S, CORE-I, CORE-X 等）に逆流・異常電圧阻止回路の実装を義務付けることになり、プラットフォーム全体のコストと実装面積を圧迫する**。
  - 特に CORE-S のように入力側絶縁に特化したボードでは、背後の IDC から無保護の電力が逆流することで絶縁設計の前提が破壊される。
- **結論**:
  - **CORE-U を含むすべての Core ボードにおいて、IDC Pin 1〜4 は Core $\to$ CARD への出力専用とし、逆給電は仕様上禁止とする。**

### 2.2 原則②：単一 DC ジャックによる物理排他（メカニカル・インターロック）
XH コネクタやピンヘッダなどの多系統電源端子を併設せず、電源入力を **「オンボード DC ジャック（DC-005）」1 系統に完全集約** します。

```text
【運用モード 1：卓上デバッグ時】
[ 5V ACアダプター ] ──(DCプラグ)──┐
                                  │
【運用モード 2：エンクロージャ組込時】│
[ パネルマウントDC端子 ] ──(内部配線)─┼──> [ 単一 DC ジャック ] ──> [ eFuse + OVP ] ──> 内部 VDD
                                  │
【運用モード 3：バッテリーCARD駆動時】│
[ バッテリー拡張CARD ] ──(内部配線)─┘
```

#### 単一端子集約がもたらすメリット：
1. **電源衝突の完全撲滅（物理排他）**:
   - バッテリー CARD 接続中は DC ジャックが物理的に塞がれているため、ユーザーが誤って AC アダプターを同時挿入することが構造上絶対に起きない（Oring 回路不要）。
2. **逆接事故の撲滅**:
   - XH 等の自作圧着端子で多発する極性反転ミスを排除し、成形済み DC バレルプラグにより確実な極性を保証する。
3. **大電流耐性**:
   - 10W（5V/2A〜3A）を低接触抵抗・低発熱で安定伝送する。
4. **スタック配線**:
   - 内部配線には **L型（ライトアングル）DC プラグ** を採用することで、上部に CARD をスタックした際の高さ干渉を防止する。

## 3. 電源保護ゲートウェイ設計（eFuse & OVP）

DC ジャック直後に配置される保護回路は、システム全体（MCU、オンボード回路、IDC 下流の全 CARD）を守る **「唯一の門番」** です。以下の要件を満たす設計を行います。

### 3.1 要求保護機能一覧
| 保護機能 | 要求仕様 | 備考 |
| :--- | :--- | :--- |
| **定格入力電圧** | DC 5.0V (公称) | 推奨動作範囲: 4.5V 〜 5.5V |
| **連続許容電流** | **2.0A min** | ピーク 3.0A〜3.5A（サーボ・突入対応） |
| **過電流保護 (OCP)** | 2.5A 〜 3.5A にてトリップ | 自動復帰（Auto-retry）またはラッチオフ |
| **短絡保護 (SCP)** | 出力短絡時にマイクロ秒単位で遮断 | 発火・パターン焼損の完全防止 |
| **ソフトスタート** | 突入電流制限（Inrush Limiting） | 大容量パスコン接続時の電圧ディップ防止 |
| **過電圧保護 (OVP)** | **トリップ閾値: 5.7V 〜 6.0V** | **12V 誤挿入時の下流完全保護（絶対要件）** |

### 3.2 12V 誤挿入対策（OVP）の実装方針
デスク上に氾濫する 9V/12V AC アダプターの誤挿入から ATtiny1616（耐圧 6.0V）を確実に守るため、以下の 2 案から再選定・検証を行います。

- **案 A：TMI6240（18V耐圧）＋ ENピン外付け OVP 回路**
  - TMI6240 の低オン抵抗（50mΩ）、低コスト、JLCPCB 潤沢在庫を活かす。
  - EN ピン（Active High）の前に「5.1V ツェナーダイオード ＋ 汎用 NPN トランジスタ（または N-ch FET）」を配置。
  - 入力電圧が 5.8V を超えた瞬間にトランジスタが導通し、EN ピンを GND（Low）へ引き落として出力を完全遮断する。
- **案 B：5V 専用 OVP 内蔵 eFuse / ロードスイッチ IC への再選定**
  - 最初から 5.8V〜6.0V OVP 機能をワンチップに内包した保護 IC（SGMICRO、TI、Wayon 等）を採用する。
  - JLCPCB の常時在庫数（10,000 個以上）および単価を評価して最終決定する。

## 4. USB 通信と電源ドメイン設計 (CH342K vs MCU)

Type-C によるバスパワー給電をオミットし、USB は「UPDI 書き込みおよび UART デバッグ」専用とします。

### 4.1 寄生給電（ファントムパワー）の防止
- **課題**:
  - DC ジャック未接続の状態で PC と USB ケーブルを接続した場合、CH342K の通信ピン（TxD, RxD, UPDI）から ATtiny1616 の内部 ESD 保護ダイオードを経由して電源が回り込み、マイコンが異常な低電圧で中途半端に起動するリスクがある。
- **対策方針**:
  - 通信信号線への適切な直列抵抗（保護抵抗）の配置、または DC ジャックの通電（VDD）と連動したレベルシフト・バッファ構成を検討し、PC 接続のみでの不用意なマイコン暴走を防止する。
  - 「AC アダプター（またはバッテリー）給電時のみ USB 通信が有効になる」ことを仕様として明確にドキュメント化する。

## 5. 製造性・コスト目標

- **部品選定基準**:
  - すべての主要コンポーネントは **JLCPCB 在庫 10,000 個以上** を維持する部品から選定（サプライチェーン途絶の回避）。
- **目標製造原価**:
  - 100 pcs 発注時、PCBA および送料込みで **$4.00 〜 $4.50 / 台** を堅持する（rev0 実績: $4.03）。
- **想定販売価格**:
  - **$20 前後**（Arduino UNO R4 Minima と同等の普及価格帯）。

## 6. 次期リビジョン（rev1）に向けたアクションプラン

1. **eFuse / OVP 回路の確定**:
   - 案 A（TMI6240 + ツェナーシャットダウン）と 案 B（5V OVP 統合 IC）の回路シミュレーションおよび JLCPCB 在庫精査を行い、採用回路を決定する。
2. **CH342K 周りの回路図 FIX**:
   - USB データライン保護（SRV05-4 等の ESD 素子）、SerialUPDI 回路、寄生給電防止策を盛り込んだ回路図を完成させる。
3. **基板レイアウトとクリアランス検証**:
   - DC-005 ジャックの中央配置と L 型 DC プラグ、IDC コネクタ、外形マウント穴（77mm × 38mm）の物理干渉を 3D CAD / KiCad 上で検証する。
4. **rev1 ネットリストの出力とレビュー**:
   - 修正を反映したネットリストを出力し、接続漏れや絶縁・短絡がないかを全数検査する。
