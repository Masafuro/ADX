# ADX CORE-O

## 1. 概要
ADX CORE-O（コア・ワン）は、8748フォームファクタに準拠した、机上開発・室内常設・屋外自律稼働（乾電池）のすべてをシームレスに両立する次世代オープンソース・コントローラーである。
名前の由来は **「CORE-ONE」** で、数珠つなぎ（マルチドロップ・設備インフラ）を担うフラッグシップ機「CORE-S」に対し、1対1接続および単体自律稼働に特化した普及・モバイル標準機として位置づけられる。

## 3. 主要な設計特徴とアーキテクチャ

### 3.1 「T字配線トポロジーの呪い」を解く電源切り替えアーキテクチャ
Arduino UNOの長年の課題であった「USBとDC入力のT字配線による逆流・競合トラブル」を根本から排除し、部品追加ゼロ・ボトルネックゼロで解決するトポロジーを確立。

```
                【電源切り替えトポロジー】

  [USB Type-C 6P] ───────────────────────────► [Pin 1: DCIN]
  (逆接の概念が物理的に存在しない)                     │
                                                     ├── [ジャンパ] ──► [Pin 2: VIN] ──► [eFuse: P14C1S] ➔ VDD
                                                     │
  [BAT IN (XH-2AW)] ──► [P-MOS: 2301V (逆接保護)] ─► [Pin 3: BATIN]
  (ユーザーの誤挿入を100%遮断)
```

1. **外部給電: USB Type-C 6P (U4 / USB-TYPE-C-009)**:
   - 従来のDCジャック（外径5.5/内径2.1mm）における誤電圧（9V/12V/24V等）の挿入リスクを完全排除。
   - CC1/CC2それぞれに5.1kΩプルダウン抵抗を配置し、あらゆるType-C充電器・PC・モバイルバッテリーから確実にクリーンな5Vを受電。
   - 規格上逆接が物理的に存在しないため、逆接保護回路の介在による電圧ロスもゼロ。
2. **バッテリー入力: JST XH-2AW ライトアングル (CN1) ＋ P-MOSFET逆接保護 (Q1 / 2301V)**:
   - 市販の安価な両端圧着済み「XH-XHケーブル」を用いて、下層のAAAバッテリーCARDと工具レス・内職レス・ハンダ付けレスで最短直結。
   - ユーザーの電池逆接リスクに対しては、BATライン直後にP-MOSFET（低RDS(on) 95mΩ）を配置し、マイナス電圧を瞬時に完全遮断。
3. **電源切り替え: 1×3P ピンヘッダ (U5 / 2541WV-03P)**:
   - ジャンパソケット（定格3A）で [1-2: Type-C] または [2-3: BAT] を物理的に切り替え。
   - Oring Controllerや理想ダイオードのような半導体ボトルネック・電圧降下・コスト増がゼロ。
   - 物理排他により、Type-Cと乾電池が基板上で同時接続される事故を100%防止。
4. **過電圧・過電流保護: eFuse (U1 / Prisemi P14C1S)**:
   - 切替後の共通VINラインにeFuseを配置し、OVP（6.0V過電圧遮断）、OCP（過電流制限 1.0A〜1.2A）、OTP（過熱遮断）、UVLO（低電圧遮断）を1チップで提供。

### 3.2 BMC（ATtiny412）搭載によるブートローダー共通化と完全自動OTW
上位機種CORE-Sで確立された「BMC（Board Management Controller）アーキテクチャ」をCORE-Oにも完全採用。

1. **ブートローダー開発のエコシステム一本化**:
   - CORE-SとCORE-Oで共通のBMCファームウェア・共通のブートローダー通信スタックを採用。
   - ボード種別による書き込み手順の分岐を排除し、ファームウェア保守工数を半減。
2. **遠隔自動OTW書き換え（手動スイッチ操作の完全撲滅）**:
   - メインMCU（ATtiny1616）がスリープまたは電源OFF（VDD OFF）でも、超低暗電流（数µA）のBMCが常時RS-485バスを監視。
   - スマホPWA（RPR4 Smart Probe）からBREAK信号を受信した瞬間、BMCがeFuseをONにして `BOOT_REQ=HIGH` をアサートし、メインMCUをブートローダーで自動起動。
   - 書き込み完了後は自動でコールドリセットをかけ、新スケッチを即時実行。
   - **防水ケースのフタを開けたり、外付けスイッチを手動でカチカチする作業が完全消滅**。
3. **ソフト電源ボタン（THT 2Pスルーホール）**:
   - 外付けスイッチ端子はゴツい端子台を廃止し、基板上の `2.54mm THTスルーホール 2P (U3)` のみ（BOM除外で工賃ゼロ）。
   - BMCのGPIOでモーメンタリ押しボタンスイッチを受け付け、短押し起動・長押しシャットダウン等の洗練されたUXを実現。
   - スイッチ未接続（オープン）でも、BMCがパワーオンで自動起動するため即座に動作可能。
4. **バッテリー待機電力の完全遮断**:
   - スリープ時は、IDC 20Pヘッダ経由でバッテリーCARDの昇圧DCDCのENピンを制御し、昇圧回路ごと完全シャットダウン。待機電流をナノアンペア〜数マイクロアンペアに封じ込め、乾電池の消耗を防止。

### 3.3 施工性と堅牢性を両立する前面インターフェース（Front I/F）
1. **RS-485通信端子台 (DORABO DB142R-5.08 2P×2 / スルーホール)**:
   - ADX標準筐体やスロットインレールに組み込んだ際、前面パネルの窓から市販の電線を水平に挿し込み、マイナスドライバーでガッチリ締め付け可能。
   - ピンアサイン: `A`, `B`, `G (GND)`, `N.C.`。前面から確実に基準電位（GND）を取れるため、RPR4接続時のコモンモードノイズ耐性を担保。
2. **メカニカル・配線保護**:
   - タイラップ用スロット穴を配置し、ケーブルの根元を基板に縛り付けることで、振動や引っ張りによる端子台のハンダクラックを防止。

## 4. 網羅される3大利用シーン

1. **机上開発シーン (Desk-top Prototyping)**:
   - PCやスマホ充電器からUSB Type-Cケーブルを挿すだけで即座に給電・開発開始。ACアダプター不要。
2. **室内・常設ユニットシーン (Indoor Deployment)**:
   - Type-Cケーブルを常時給電ケーブルとして利用し、市販のUSB電源アダプタで美しく安定した常設デバイスとして稼働。
3. **屋外・自律稼働シーン (Mobile & Field Deployment)**:
   - ジャンパをBAT側に切り替え、AAAバッテリーCARDからXH-XHケーブル1本で受電。
   - タカチ等の防水ケースに収め、雨の屋外や移動体に完全コードレスで現場投入。
   - スケッチ更新はスマホからRPR4 Smart Probeを外付けRS-485端子に繋ぐだけで、完全自動OTW書き換え。
