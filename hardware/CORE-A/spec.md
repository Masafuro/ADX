## 3. インターフェース & ピンアサイン

### 3.1 前面端子台: RS-485 (DB142R-5.08 2P×2)
前面パネルから電線を水平に挿し込み、マイナスドライバーで締付固定可能なスプリングクランプ端子台。

| ピン番号 | 信号名 | 属性 | 説明 |
| :---: | :---: | :---: | :--- |
| **1** | **A** | 差動入出力 | RS-485 Non-inverting 通信線（絶縁側） |
| **2** | **B** | 差動入出力 | RS-485 Inverting 通信線（絶縁側） |
| **3** | **GND_ISO** | 基準電位 | RS-485 絶縁基準グラウンド (Signal Common) |
| **4** | **N.C.** | - | 未接続 (将来拡張 / シールド線固定) |

### 3.2 電源入力部 (USB Type-C 6P & 逆流阻止バルブ)

1. **USB Type-C 6P (U4 / 6Pin SMD, 耐熱LCP樹脂仕様)**:
   - 机上開発および室内給電用。VBUS, GND, CC1(A5), CC2(B5)。
   - CCピンには各5.1kΩ (±1%) をGNDへプルダウン。
2. **USB 逆流阻止バルブ (D1 / LM66100 または 低Vfショットキー)**:
   - USB VBUSから基板共通VDDプレーンへは低損失で給電。
   - 拡張カードからVDDに通電されている際の **PC側への逆流を瞬時100%遮断**。
3. **外付けソフトスイッチ端子 (U3 / 2.54mm THTスルーホール 2P)**:
   - Pin 1: `BMC_SW` (ATtiny412 PA1、内蔵プルアップ)
   - Pin 2: `GND`
   - *モーメンタリ押しボタンスイッチ接続用。未接続時はBMC常時ON。*

### 3.3 ADX 共通拡張バス (20ピン Eject Header / 2.54mm 2×10P)
[ADX Pinout 仕様書 (v2)](../../../docs/ja/ADX_pinout.md) 完全準拠。
**ラッチ付きイジェクトヘッダ（MIL-DTL-83503互換）** を採用し、車載・工場の激しい振動下でもリボンケーブルの半抜け・脱落を物理的に完全防止。センターキー溝により逆挿し・1列ズレ挿しも100%排除。

```
                    【ADX Pinout v2 (20P Eject Header 配置)】
      VDD (5V/2A双方向給電) [ 1]  [ 2]  VDD (5V/2A双方向給電)
      VDD (5V/2A双方向給電) [ 3]  [ 4]  VDD (5V/2A双方向給電)
        N.C. (短絡防止帯)   [ 5]  [ 6]  PA6/DAC0 (アナログ出力/AIN6)
          PA5/AIN5 (VREFA)  [ 7]  [ 8]  GND_5V (EXTCLKシールド①)
            PA3/EXTCLK      [ 9]  [10]  GND_5V (EXTCLKシールド②/通信分離)
        PB2/TXD (Alt UART)  [11]  [12]  PB3/RXD (Alt UART)
          PB1/SCL (I2C)     [13]  [14]  PB0/SDA (I2C)
               PC0          [15]  [16]  PC1
               PC2          [17]  [18]  PC3
             PA0/UPDI       [19]  [20]  GND_5V
```

- **Pins 1〜4 (2×2 VDDゾーン)**: 5V / 2A 超の双方向幹線プレーン。USB給電時は下層カードへ給電、拡張カード給電時はCORE-Aへ受電。
- **Pin 5 (N.C.)**: VDD強電ゾーンと信号線の物理短絡防止アイソレーション。

## 5. ファームウェア・BMC協調動作仕様

1. **コールドスタート時**:
   - 電源投入（Type-C挿入またはジャンパ接続）時、BMC（ATtiny412）が瞬時に起動。
   - BMCがeFuseのENをHIGHにし、メインMCU（ATtiny1616）にVDDを供給。
2. **遠隔OTW（Over-The-Wire）書き換えシーケンス**:
   - 保守員がRS-485バス経由でBREAK信号（またはマジックコマンド）を送信。
   - 絶縁RS-485レシーバ出力を常時監視しているBMCがこれを検知。
   - BMCが `BOOT_REQ` ピンをHIGHにし、メインMCUをリセット。
   - メインMCUはOptiboot等のブートローダーモードで立ち上がり、スケッチ書き換えを実行。
   - 書き換え完了後、自動コールドリセットにより新スケッチが即時起動。
3. **極低消費電力スリープモード**:
   - メインMCUが所定のタスク完了後、BMCへスリープ移行コマンドを送信。
   - BMCがeFuseをOFFにし、メインMCUおよび周辺回路への給電を完全遮断。
   - BMC自身は超低消費電力WDTモード（数µA）で待機。
   - 設定時間経過後、または外部スイッチ押下、RS-485パケット受信によってBMCが復帰し、再給電。
