# ADX CORE-A (Alpha)
〜 はじまりの普遍的タフネス・コア 〜

## 1. 概要と開発思想

**ADX CORE-A（コア・アルファ）** は、ADXエコシステムのあらゆる展開（机上開発・車載・農業・スマートファクトリー・冷凍設備）の起点となる、**8748フォームファクタ準拠の普遍的エッジコントローラー**である。

「CORE-O（廉価版）」と「CORE-S（標準版）」、「CORE-X（極限環境版）」という従来の階層的ラインナップを解体・再統合し、**「最もシンプルで、最もタフで、最も安価な1枚のコアにすべてを集約する」** というプラットフォーム戦略の結論として誕生した。

## 3. CORE-Aの4大アーキテクチャ革新

### 3.1 「5V専任」による熱源追放とトリプル・アイソレーション（安全地帯の創出）
従来の産業用ボードが抱えていた「24V/48V降圧回路による基板自己発熱とノイズ・サージ被害」を根本から解決。

1. **高電圧（24V/48V）をメイン基板に入れない英断**:
   - 24V→5V降圧DCDCや大型コイル・放熱板をコアボードから追放。
   - 24V/48Vが必要な工場や配電盤では、**「24V/48V 産業用電源拡張カード（Power Shield）」** をスタックし、トランス絶縁されたクリーンな5Vを受電。
   - 万が一の過電圧雷サージで破壊されるのは安価な電源カードのみ。メインボードは無傷で保護される。
2. **完全なるフローティング・セーフゾーン**:
   - 通信ライン（RS-485）はメインボード上の `TDA51S485HC` で完全絶縁。
   - 電源ライン（工場電源）は拡張カード側で完全絶縁。
   - メインボードとType-Cポートは完全に電気的浮遊状態（安全地帯）となるため、**現場の強電設備に通電・通信したまま、作業者のノートPCからType-Cを挿してもPCが絶対に破損しない**。

```
【現場の危険地帯 1】
  現場の長距離 RS-485 バス（サージ・ノイズ・異電位GND）
       │
   [ ⚡ ガルバニック絶縁 (TDA51S485HC: メインボード搭載) ⚡ ]
       │
┌──────▼─────────────────────────────────────────────────┐
│  ADX CORE-A (メインボード: 完全なる安全地帯)          │
│  - 自己発熱ほぼゼロ / クリーンな5Vロジック             │
│  - -40℃〜+100℃/105℃ 完全工業耐熱                       │
│  - 作業用PCやスマホをType-C接続しても絶対に壊れない     │
└──────▲─────────────────────────────────────────────────┘
       │
   [ ⚡ ガルバニック絶縁 (産業用絶縁DCDC: 拡張カード搭載) ⚡ ]
       │
【現場の危険地帯 2】
  工場の 24V / 48V 電源ライン（モーター逆起電力・インバータノイズ）
```

### 3.2 チップ1個で完結する「完全絶縁RS-485」（Mornsun TDA51S485HC）
- 外付けの大型絶縁DCDCモジュール（B0505等）や多数のフォトカプラを全廃。
- **絶縁トランス、絶縁DC-DCコンバータ、デジタルアイソレータ、RS-485ドライバ/レシーバを1チップ（SOP-16）に集積** した `TDA51S485HC` を採用。
- 耐電圧 2500VDC / 1500VAC。
- 定格動作温度: **-40℃〜+105℃（工業用）**。
- メイン基板のサイズ（8748）を圧迫せず、驚異的な高密度・低原価で完全絶縁通信を実現。

### 3.4 普遍的電源トポロジー（O-ring Controller不要の双方向VDDバス）

煩雑で高価な2系統切り替え用O-ring Controllerや手動ジャンパを全廃し、**「USB入力への逆流阻止バルブ（理想ダイオード）1個」** で完全な双方向性とPC保護を両立。

```
                    【CORE-A 共通電源バス構造】

  [USB Type-C 6P]
         │
    [ ⚡ 逆流阻止バルブ ⚡ ] ──► (理想ダイオード LM66100 / 低Vfショットキー)
         │                       (USBからVDDへはフル給電、逆流は瞬時100%遮断)
         ▼
  ┌────────────────────────────────────────────────────────┐
  │  CORE-A 共通 5V VDD バス ◄──────► IDC Pin 1〜4 (VDD)   │
  │  (BMC, 絶縁RS-485, eFuse➔MCU)    (下層拡張カードと直結) │
  └────────────────────────────────────────────────────────┘
```

1. **机上開発シーン (USBのみ接続)**:
   - USB Type-Cから電力が入り、逆流阻止バルブを通って `共通5V VDDバス` に供給。
   - CORE-AのMCU・BMCが起動すると同時に、**IDC Pin 1〜4 を通じて下層の拡張カード（センサーや試作カード）へもクリーンな5Vをそのまま配給**。
2. **現場運用シーン (拡張カードから給電、USB未接続)**:
   - 24V/48V Power ShieldやBattery Shieldから `IDC Pin 1〜4` 経由で5Vが入り、CORE-Aが動作。
   - バッテリーの逆接保護やDCDC制御は拡張カード側で自己完結。
3. **現場デバッグシーン (拡張カード通電中に、PCのUSBを挿入！) ★最重要**:
   - 拡張カード側の5V（例: 5.1V）がVDDバスに通電している状態で、ノートPCのType-C（例: 5.0V）を挿入。
   - 逆流阻止バルブが `VDD ＞ USB` の電位差を瞬時に検知してゲートを完全遮断。
   - **PCのUSBポート側には1マイクロアンペアも逆流せず、現場通電中の安全デバッグが100%保証される**。
4. **BMC（ATtiny412）による完全自動OTW（Over-The-Wire）書き換え**:
   - 常時監視を行う超低暗電流のBMCが、スマホPWA（RPR4 Smart Probe）からのBREAK信号を検知。
   - BMCがeFuseをONにしてメインMCUをブートローダーモードで自動起動。
   - **防水ケースの蓋を開けたり、タクトスイッチを押す作業を完全撲滅**。
   - スリープ時はeFuseでメインMCUの電源を遮断し、ナノアンペア級の超低消費電力を実現。

| 拡張カード名 | 主な機能と利用シーン | 給電方式 |

## 5. まとめ

ADX CORE-Aは、単なる「安価なマイコンボード」ではない。
- **無駄な高電圧と発熱源を徹底的に排除した「5V専任」の引き算の美学**
- **チップ1個で現場のサージとノイズを跳ね返す「完全絶縁RS-485」**
- **酷暑から極寒まで耐え抜く「-40℃〜+105℃ フル耐熱」**
- **Arduino UNO R4 WiFiと同等の「$26〜$28」という圧倒的破壊力**

これらすべてを兼ね備えた、**2020年代後半のオープンソース・ハードウェアにおける新たな絶対標準（Absolute Standard）**である。
