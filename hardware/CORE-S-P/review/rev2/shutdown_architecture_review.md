# 単一GND基板における逆接保護の原理的不可能性と配線手順の調和に関する理論的検討

## 1. 背景とトポロジーの定義
コスト最適化を目的とした単一GND（非絶縁）の標準メインボードにおいて、外部電源（鉛蓄電池等）からのDC入力と、外部とGNDを共有する通信・拡張インターフェース（RS-485等）を共存させるアーキテクチャを想定する。
現場施工における電源極性の逆接（ヒューマンエラー）は避けられない事象であるが、本トポロジーにおいてこれを電子回路単体で完全に防護することは物理法則上、極めて困難である。本稿ではその原理的限界を定義し、回路の機能的要件と運用手順（オペレーション）を融合させた解決フレームワークを提示する。

## 2. 逆接保護の原理的不可能性（GNDバイパス問題）
通常、基板への逆接・過電流保護デバイス（直列ダイオード、MOSFET、ヒューズ等）は、電源のプラス（+）ラインに直列に配置される。しかし、外部機器とGNDを共有する非絶縁システムにおいて電源が逆接された場合、以下の物理現象が発生する。

1. **GND電位の浮上:** バッテリーのプラス電圧が基板の「GND端子」に印加され、基板のGNDプレーン全体が電源電圧レベルに浮き上がる。
2. **バイパス経路の形成:** 電流は `電源(+) → 基板GNDパターン → 通信端子(G線) → 外部ケーブル → 外部機器のGND(0V) → 電源(-)` という巨大な短絡経路を形成する。
3. **保護回路の無効化:** この短絡経路は、プラスライン上に配置されたすべての保護デバイスを「完全に迂回」するため、いかなる保護素子も機能しない。
4. **連鎖破壊:** 結果として、基板のGNDパターンや通信ケーブルに数十アンペアの短絡電流が集中し焼損すると共に、相対的な過電圧によって通信IC等が連鎖的に破壊される。

**【理論的結論】**
GNDが外部ネットワークと接続されている状態において、プラスライン側の電気的保護のみで逆接短絡を防ぐことは原理的に不可能である。

## 3. 基本仕様の定義とティアリング戦略
上記の原理的限界を「ハードウェアの仕様」として明文化し、製品の提供価値を以下の通り階層化（ティアリング）する。

* **公理 1:** 非絶縁モデル（Standard版）において、GNDを共有する外部機器を接続した状態で電源線を逆接した場合、連鎖的な破壊が生じる。これは物理法則に基づく仕様であり、保護対象外とする。
* **公理 2 (PRO版への誘導):** 施工管理が困難な環境や、逆接時の連鎖破壊リスクをシステム側で完全に吸収する必要がある現場に対しては、電源および通信経路を完全に分断したフルアイソレーション設計（PRO版）を必須要件として定義する。

## 4. 回路要件と配線手順の調和による防衛フレームワーク
Standard版（非絶縁モデル）において、回路単体では防げない逆接破壊を「配線手順の制約」によって実質的に回避する理論的フレームワークを定義する。

### 4.1. 必須となる回路の機能要件
本フレームワークを成立させるため、基板の電源入力段には具体的な素子（MOSFETかダイオードか等）を問わず、以下の機能ブロックを実装する。

* **機能A（逆流阻止）:** 電源ライン（+）に配置され、逆接時に基板内への電流流入を物理的・電気的に遮断する素子。（例: 直列ショットキーダイオード、P-ch MOSFET等）
* **機能B（過電流保護）:** 順方向接続時における基板内・拡張ボード側の短絡故障からシステムを保護する素子。（例: PTCリセッタブルヒューズ、eFuse等）
* **機能C（状態表示）:** 正しい極性で通電され、システムが正常に起動したことのみを条件として点灯するインジケータ。（例: 5V Power LED）

### 4.2. 理論的防衛シーケンス（配線手順）
基板を一時的に「GNDの孤島」にすることで、2章で定義したバイパス経路を物理的に消滅させる。

1. **【経路遮断フェーズ】** RS-485や拡張ネットワーク等の外部と繋がるケーブルを**すべて未接続**とする。
2. **【電源投入フェーズ】** バリアターミナルに電源ケーブルを接続する。
   * *※理論的根拠：外部へのGND経路が存在しないため、逆接されたとしても電流の逃げ道がなく、入力段の「機能A（逆流阻止）」が完璧に機能し基板は保護される。*
3. **【正常性検証フェーズ】** 「機能C（状態表示）」の点灯を確認する。点灯しない場合は直ちに電源を取り外し、極性を確認する。
4. **【システム統合フェーズ】** 極性の正しさが完全に証明された状態においてのみ、通信・拡張ケーブルを接続する。

### 4.3. 通信ケーブル接続時の安全性検証
ステップ4（正常通電状態）における結線ミスの影響は以下の通り限定される。

* **非絶縁通信線（RS-485等）の信号線誤配線:** 通信トランシーバーIC自体が持つ短絡保護および絶対最大定格（同相入力電圧範囲）により、信号線レベルの結線ミスは通信エラーに留まり、ハードウェアの物理的破壊には至らない。
* **絶縁通信線（Ethernet等）の接続:** パルストランスによって直流的に完全絶縁されているため、接続のタイミングや誤配線に関わらずDC的な破壊リスクは存在しない。

## 5. 結論
非絶縁の単一GNDアーキテクチャにおいて、「GNDループによる連鎖破壊」を回路構成のみで解決しようとするアプローチは原理的矛盾を孕む。
本検討により、基板をGND的に孤立させる「運用シーケンス」と、そのシーケンス下においてのみ完璧に機能する「入力保護・状態表示回路」を統合することで、この問題が理論的に克服されることを証明した。これにより、部品コストを最小限に抑えつつ、実運用上きわめて堅牢なハードウェアシステムの構築が可能となる。
