# サブタスク 5: システム安全性・総合サインオフ仕様書 (Task 5: System Safety & Final Sign-off)

- **タスクID**: Task 5
- **対象**: 単一 GND 運用安全性、総合指摘事項集約、発注可否判定、修正推奨策
- **入力データ**:
  - `hardware/CORE-S/README.md`（電気的制約および運用配線シーケンス規定）
  - `hardware/CORE-S/review/rev3/memo/concept.md`（試作小ロット 5pcs の開発思想）
  - Task 1〜4 のレビュー結果ドキュメント（`task1_result.md` 〜 `task4_result.md`）

---

## 1. タスク概要と目的

全サブタスク（Task 1〜4）で抽出された検証結果・指摘事項を統括し、**システム安全性（特に非絶縁・単一 GND プレーン構造における連鎖破壊リスク防止）の観点から総合評価** を下します。
最終成果物として、設計者が JLCPCB 等へ小ロット試作（5pcs）の発注を行ってよいかどうかの **「最終発注判定（Go / No-Go / Conditional Go）」** を明確に示し、必要な修正策や発注時の注意事項を取りまとめます。

---

## 2. 詳細レビュー項目とチェックリスト (Review Items)

### 2.1 非絶縁運用における構造的・運用的安全性
- [ ] **共通 GND プレーンと端子台ピン配置の整合性**:
  - 端子台 `0-P1`（6ピン）において、電源 GND（Pin 2: `G`）と RS-485 GND（Pin 6: `FG` / `G`）が基板内部で直結されている物理構造が、[`hardware/CORE-S/README.md`](../../README.md) の警告規定と完全に整合しているか。
- [ ] **「厳守配線シーケンス」の実行容易性**:
  - 単体通電時に確認する **5V Power LED (`9-LED-5V`)** の視認性が基板上で確保されているか（端子台や IDC コネクタに隠れて見えにくくなっていないか）。
- [ ] **逆接続時の保護素子協調**:
  - 電源逆接続時、入力保護ダイオード `0-D1`（SS54: 逆耐圧 40V）が正常に遮断し、後段の DC-DC やマイコンを確実に防護できる配線トポロジーになっているか。

### 2.2 全指摘事項の統合とリスク格付け
- [ ] **指摘事項の全件集約と重要度判定**:
  - Task 1（回路・電気）、Task 2（アートワーク・熱）、Task 3（製造 DFM）、Task 4（実装 DFA）の全指摘事項を統合。
  - 重要度（CRITICAL / HIGH / MEDIUM / LOW）の格付けを行い、試作発注に対する影響度を精査。
- [ ] **ブロッカー（CRITICAL / HIGH）の特定**:
  - 試作基板の物理的破壊や回路不動作を招く要因が残存していないかを最終確認。

### 2.3 試作発注判定（Sign-off Decision）
- [ ] **発注判定の確定**:
  - **GO（承認）**: CRITICAL / HIGH の未解決課題がゼロであり、直ちに製造・実装を発注可能。
  - **CONDITIONAL GO（条件付き承認）**: HIGH の課題があるが、発注時のオプション指定や納品後の手修正、または運用ルールで安全に回避可能であり、試作 5pcs の目的に照らして発注を許可。
  - **NO-GO（発注保留・再設計）**: CRITICAL な欠陥が存在し、アートワークまたは回路図の修正と再出力が必須。

### 2.4 修正推奨策および発注時指示書の作成
- [ ] **設計修正の具体策提示**:
  - 指摘された項目について、EasyEDA Pro 上での具体的な修正箇所・推奨定数・配線変更案を提示。
- [ ] **発注時（JLCPCB）の注意事項チェックリスト**:
  - 基板仕様（FR-4, 2層, 板厚 1.6mm, 銅箔 1oz, 表面処理 HASL/ENIG）。
  - PCBA 仕様（Top 面実装、パーツ指定、治具穴、ピン1向きのプレビュー確認項目）。
