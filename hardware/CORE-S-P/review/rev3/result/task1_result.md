- **レビュー対象**: ADX CORE-S rev3 ネットリスト（`Netlist_PCB1_2026-09-19.enet`）および回路プロジェクト（`ProPrj_ADX_CORE-S_2026-09-19.epro2`）
- **比較対象**: rev2 ネットリスト（`Netlist_Schematic1_2026-09-16_rev2.enet`）
- **検証日**: 2026-09-19
- **総合判定**: **【PASS】合格（重大な電気的欠陥・デグレードなし）**

## 1. エグゼクティブサマリー

Task 1 の仕様書（[`../PLAN/task1_schematic_and_electrical.md`](../PLAN/task1_schematic_and_electrical.md)）に基づき、ネットリストの全数静的解析、rev2 からの差分照合、定格・過渡特性の理論計算を実施しました。

### 主要な検証結果ハイライト:
1. **rev2 改修事項の完全維持**:
   - `BMC_RO` 結線（RS-485 受信線を BMC が常時スニッフィングする配線）およびロードスイッチ `TPS22965` の CT 端子コンデンサ（1nF）は、rev3 でも漏れなく正確に維持されています。
2. **ネット完全性と未接続ピンの妥当性**:
   - 孤立ネット（Single-node net）は **0 件（ゼロ）**。
   - 未接続ピン（NC: 6ピン）は、データシート上で NC 指定されている端子（TPS5430 の Pin 2, 3, 5、ATtiny412 の Pin 3, 7、IDC の Pin 5）のみであり、全て設計通り正常です。
3. **電気的定格・保護協調の成立性**:
   - 入力保護（TVS `SMAJ20A` + 逆流防止ダイオード `SS54` + ヒューズ `CFS06V3T3R00`）の協調が成立しています。特に TVS が逆流防止ダイオードのカソード側に配置されたことで、**電源逆接続時に TVS が順方向ショート破壊するリスクが完全に排除** されています。
   - コンデンサ耐圧は、16V 入力段に 25V〜50V 品、5V/VDD 段に 16V〜50V 品が選定されており、ディレーティングマージンは極めて潤沢です。
4. **過渡特性・通信仕様**:
   - ロードスイッチの突入電流は理論値 **$3.55\,\mathrm{mA}$** に抑制され、5V バスのディップ（BMC の BOD 誤リセット）を防止できます。
   - RS-485 のフェイルセーフバイアス差動電位は **$+283\,\mathrm{mV}$**（規格閾値 $+200\,\mathrm{mV}$ 以上）を確保しています。

## 3. 回路ブロック別 詳細解析結果

### 3.1 入力保護・電源供給ブロック (Block 0 & 1)
- **接続経路**:
  $$\text{外部入力 } \texttt{0-P1} \xrightarrow{+7\_16V} \text{逆流防止ダイオード } \texttt{0-D1 (SS54)} \xrightarrow{\$6N84} \text{TVS } \texttt{0-D2 (SMAJ20A)} \ \& \ \text{ヒューズ } \texttt{0-F3 (3A)} \xrightarrow{\$6N83} \text{フェライト } \texttt{0-L4} \xrightarrow{+6V\_16V} \texttt{1-DCDC.7}$$
- **技術的考察**:
  1. **逆接保護の安全性**: TVS ダイオード `SMAJ20A` は単方向性のため、逆極性が印加されると順方向ダイオード（0.7V）として大電流が流れて焼損します。本回路では逆流防止ダイオード `0-D1` のカソード側に TVS が配置されているため、**外部逆接続時にも TVS に逆電流が一切流れず、安全に遮断** されます。
  2. **ヒューズ `0-F3` の配置**: 3A 表面実装ヒューズ `CFS06V3T3R00` が TVS の直後に配置されており、DC-DC コンバータ側の短絡・過負荷時に確実に溶断します。

### 3.2 降圧 DC-DC コンバータ `TPS5430` (Block 1)
- **出力電圧**: $R_1 = 6.8\mathrm{k}\Omega$ (`1-R5`), $R_2 = 2.2\mathrm{k}\Omega$ (`1-R6`), $V_{REF} = 1.221\mathrm{V}$
  $$V_{OUT} = 1.221 \times \left(1 + \frac{6800}{2200}\right) = 4.995\,\mathrm{V}$$
- **位相余裕と出力フィルタ**:
  - インダクタ: $15\,\mu\mathrm{H}$ (`HCMA-0630-150-M-K`, 定格飽和電流 4.0A 以上)
  - 出力コンデンサ: $220\,\mu\mathrm{F}$ 16V 固体電解 (`SS221M160E7R7R4Z00ZZ`, ESR $24\,\mathrm{m}\Omega$, リプル許容 $2.9\,\mathrm{A}$)
  - ESR ゼロ点周波数:
    $$f_z = \frac{1}{2\pi \cdot 24\,\mathrm{m}\Omega \cdot 220\,\mu\mathrm{F}} \approx 30.1\,\mathrm{kHz}$$
    TI アプリケーションノートの内部位相補償安定帯域（$10\,\mathrm{kHz} \sim 50\,\mathrm{kHz}$）の最適中央に位置しており、極めて安定したループ特性を示します。

### 3.3 ロードスイッチ `TPS22965` (Block 2)
- **突入電流抑制**:
  - CT 端子に $1\,\mathrm{nF}$（`2-C3`）を接続。データシート規定式より、立ち上がり時間は約 $10\,\mathrm{ms}$。
  - 後段の VDD 容量: $4.7\,\mu\mathrm{F} \times 2 + 0.1\,\mu\mathrm{F} \times 2 = 9.6\,\mu\mathrm{F}$
  - 突入電流:
    $$I_{inrush} = 9.6\,\mu\mathrm{F} \times \frac{5.0\,\mathrm{V}}{10\,\mathrm{ms}} \approx 4.8\,\mathrm{mA} \ll 3000\,\mathrm{mA}$$
    +5V 電源バスに電圧降下は発生せず、BMC や RS-485 の誤動作リスクは完全に排除されています。

### 3.4 BMC (ATtiny412) & 制御ロジック (Block 5)
- **`BOOT_REQ` 信号レベル整合**:
  - `5-R3` (10kΩ to GND) により、BMC リセット解除前（Pin 4 が Hi-Z）は確実に 0V（Normal Boot）に固定。
  - BMC が 5V を出力した際、MCU の Pin 9 (`PB5`) は入力高インピーダンスのため、直列抵抗 `5-R2` (10kΩ) での電圧降下はなく、MCU 端子電圧は 5.0V（$V_{IH} \ge 3.5\mathrm{V}$ をクリア）に到達。
  - 誤設定による MCU ポート出力短絡時の過電流保護としても機能。
