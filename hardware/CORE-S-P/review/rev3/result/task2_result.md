# サブタスク 2: PCB アートワーク・ノイズ・熱設計レビュー結果報告書 (Task 2 Result Report)

- **レビュー対象**: ADX CORE-S rev3 ガーバーデータ（`Gerber_TopLayer.GTL`, `Gerber_BottomLayer.GBL`, `Drill_PTH_Through_Via.DRL` 等）および CPL 幾何配置
- **検証日**: 2026-09-19
- **総合判定**: **【PASS】合格（試作 5pcs の製造・運用に支障となる重大なレイアウト欠陥なし）**

---

## 1. エグゼクティブサマリー

Task 2 の仕様書（[`../PLAN/task2_pcb_artwork_and_si.md`](../PLAN/task2_pcb_artwork_and_si.md)）に基づき、ガーバー銅箔レイヤーのアパーチャ（配線幅）、ポリゴンベタ（GND プレーン）、ドリルビア座標、部品配置幾何（CPL 座標）の定量的解析を実施しました。

### 主要な検証結果ハイライト:
1. **大電流パターンの電流容量**:
   - 電源ライン（+7_16V, +5V, VDD）には $0.61\,\mathrm{mm} \sim 2.032\,\mathrm{mm}$ の太パターンおよび銅箔ポリゴンベタが使用されています。IPC-2152 規格照合により、許容電流は定常 $2.5\,\mathrm{A}$ 以上（温度上昇 $10^\circ\mathrm{C}$ 未満）を確保しており、試作ボードの消費電流（$<200\,\mathrm{mA}$）に対して 10 倍以上の安全マージンがあります。
2. **DC-DC スイッチングループの極小化**:
   - 降圧 DC-DC `1-DCDC` (TPS5430) と、入力コンデンサ `1-C1`（距離 $5.68\,\mathrm{mm}$）、ブートストラップコンデンサ `1-C3`（距離 $4.19\,\mathrm{mm}$）、キャッチダイオード `1-D2`（距離 $6.82\,\mathrm{mm}$）が最短距離で高密度に集約されており、高周波スイッチング電流ループの面積が最小化されています。
3. **ノイズ源と通信・マイコン系の完全ゾーニング**:
   - ノイズ源である DC-DC 回路（基板左側: $X = 0 \sim 25\,\mathrm{mm}$）と、RS-485 トランシーバー（$X = 53.57\,\mathrm{mm}$）および MCU（$X = 68.76\,\mathrm{mm}$）が **$45\,\mathrm{mm}$ 以上物理的に離隔** されており、理想的なノイズ遮断ゾーニングが実現されています。
4. **GND プレーンとスティッチングビア**:
   - Bottom 層（GBL）に広範なベタ GND が敷設され、基板全体に配置された全 157 個のビアにより層間 GND が低インピーダンスに結合されています。

## 3. アートワーク設計の詳細解析

### 3.1 部品配置ゾーニング (Component Zoning)
基板（外形寸法 $87.0\,\mathrm{mm} \times 48.0\,\mathrm{mm}$）上のコンポーネント配置は、機能ブロックごとに明確に分離されています。

```text
+-------------------------------------------------------------------------------+
| [X=0~25mm]                  [X=30~55mm]                  [X=60~87mm]          |
|                                                                               |
|  +7_16V 電源入力段            BMC (ATtiny412)              メイン MCU           |
|  ヒューズ / TVS / ダイオード   ロードスイッチ (TPS22965)    (ATtiny1616 QFN-20) |
|  降圧 DC-DC (TPS5430)         RS-485 (SP485EEN)            IDC 20P 拡張コネクタ|
|  インダクタ / 固体電解         端子台 (WJ25C 6P)                                |
|                                                                               |
|  【強電・スイッチング電源】    【制御・通信インターフェース】 【マイコン・低電圧】  |
+-------------------------------------------------------------------------------+
  [下端エッジ Y=3.05mm]  ==>  LED 群 (5V, VDD, PB4) 一列配置 (視認性良好)
```

この配置により、DC-DC のスイッチングノイズ（磁界・電界）が RS-485 差動信号線や MCU のアナログ／デジタル入力ポートに飛び散るリスクが物理的に極めて低く抑えられています。

### 3.2 熱設計と PowerPAD の評価
- **現状**:
  - `1-DCDC` (TPS5430) の中心直下（$X = 9.144, Y = 31.496$）に放熱ビア（$\phi 0.305\,\mathrm{mm}$）が 1 個配置され、裏面のベタ GND に熱結合されています。
  - `3-MCU` (ATtiny1616 QFN-20) の中心直下（$X = 68.758, Y = 31.674$）にも放熱ビアが 1 個配置されています。
- **熱マージン評価**:
  - 本試作ボード（CORE-S 単体）の消費電流は最大でも $100\,\mathrm{mA} \sim 200\,\mathrm{mA}$ 程度です。
  - TPS5430 のオン抵抗 $R_{DS(on)} = 110\,\mathrm{m}\Omega$ より、内部 FET の導通損失は $P = I^2 R = 0.2^2 \times 0.11 \approx 4.4\,\mathrm{mW}$、スイッチング損失等を含めても $50\,\mathrm{mW}$ 未満です。
  - したがって、試作 5 台での OTW ブートローダー／ソフトウェア開発用途においては、**放熱ビア 1 個でも温度上昇は数度未満にとどまり、熱暴走や過熱停止（Thermal Shutdown）に至るリスクは皆無** です。
